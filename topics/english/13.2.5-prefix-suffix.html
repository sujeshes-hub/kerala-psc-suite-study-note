ഉപസർഗ്ഗങ്ങളും പ്രത്യയങ്ങളും – Prefix & Suffix (Affixes)

Prefix • Suffix • Root • Derivational vs Inflectional • Spelling Rules | Chapter 13.2.5 | LDC, LGS, Fireman, LP/UP, University Assistant, Secretariat Assistant, KAS

🔍 ഒന്നും കണ്ടെത്തിയില്ല. മറ്റൊരു വാക്ക് ശ്രമിക്കുക.

⭐ Star Guide

⭐ പ്രാധാന്യ സൂചകങ്ങൾ (Kerala PSC അടിസ്ഥാനത്തിൽ)

  • ⭐⭐⭐ ശ്രദ്ധിക്കേണ്ടത് — Derivational vs Inflectional, -osis/-itis അർത്ഥം, Verb-forming en-/em- (rich → enrich)

➕ ചുരുക്കം
  • Prefix = മുമ്പ്; Suffix = ശേഷം; രണ്ടും = Affixes
  • Political → Apolitical (a-); Fortunate → Unfortunate (un-)
  • Freedom = free + -dom (Suffix); Sunstroke = Compound
  • Pan- = All | para- = beside/auxiliary | with- = against
  • im- P/M/B | il- L | ir- R (അപവാദം: unlucky, unreal)
  • changeable (e നിൽക്കും); believable (e പോകും)

1. അധ്യായ ആമുഖം

  • ⭐⭐⭐⭐⭐ ഒരു മൂലപദത്തിന്റെ (Root / Base Word) അർത്ഥം മാറ്റാനോ പുതിയ പദവിഭാഗം (Part of Speech) ഉണ്ടാക്കാനോ ആ പദത്തോട് ചേർക്കുന്ന അക്ഷരക്കൂട്ടങ്ങളാണ് Affixes (ചേർപ്പുകൾ).
  • ⭐⭐⭐⭐⭐ മൂലപദത്തിന് മുമ്പ് ചേർക്കുന്നത് → ഉപസർഗ്ഗം (Prefix)
  • ⭐⭐⭐⭐⭐ മൂലപദത്തിന് ശേഷം ചേർക്കുന്നത് → പ്രത്യയം (Suffix)
  • ⭐⭐⭐⭐ ചോദ്യ രീതികൾ:
    • ഒരു വാക്കിന്റെ വിപരീതം ഉണ്ടാക്കാനുള്ള Prefix (political → apolitical)
    • Prefix + Suffix ചേർക്കൽ (believe → unbelievable)
    • മൂന്ന് വാക്കുകൾക്ക് പൊതുവായ Prefix (take, chief, behave → mis-)
    • Prefix/Suffix-ന്റെ അർത്ഥം (pan- = all)
    • Compound word ആണോ Affix ആണോ എന്ന വേർതിരിവ്
➕ PSC ഉപദേശം

Affix-കളുടെ അർത്ഥം അറിയാമെങ്കിൽ പരിചയമില്ലാത്ത വാക്കുകളുടെ അർത്ഥം പോലും ഊഹിച്ചെടുക്കാം. ഇത് Synonyms/Antonyms ചോദ്യങ്ങൾക്കും സഹായിക്കും.

📌 പരിശോധനാ കുറിപ്പ്

PYQ ലേബലുകൾ (29/2025, 166/2025-A, 106/2025-A, 095/2016, 163/2014, LDC 003/2020) ഔദ്യോഗിക ചോദ്യപേപ്പറുമായി ഒത്തുനോക്കി ഉറപ്പിക്കണം. ചോദ്യങ്ങളുടെ ഉത്തരങ്ങൾ ഭാഷാപരമായി ശരിയാണ്.

2. പിന്നാമ്പുറ കഥ

ഒരു തീവണ്ടി സങ്കൽപ്പിക്കുക:

ഭാഗംവിവരണംഉദാഹരണം
മൂലപദംനടുവിലെ പ്രധാന ബോഗിbelieve (വിശ്വസിക്കുക)
Prefixമുന്നിൽ ഘടിപ്പിക്കുന്ന എൻജിൻun- (അല്ല)
Suffixപിന്നിൽ ഘടിപ്പിക്കുന്ന ഗാർഡ് ബോഗി-able (കഴിയുന്ന)
⭐ ഉദാഹരണം

un- + believe + -able = unbelievable (അവിശ്വസനീയമായ)

(ഇവിടെ believe-ലെ അവസാന 'e' ഒഴിവാക്കിയാണ് -able ചേരുന്നത്. ഇത് സ്പെല്ലിംഗ് നിയമം 1.)

  • രണ്ട് എൻജിനുകൾ (രണ്ട് Prefix) വരാം: un + pre + meditate + ed = unpremeditated (മുൻകൂട്ടി ആലോചിക്കാത്തത്)
  • രണ്ട് ഗാർഡ് ബോഗികളും (രണ്ട് Suffix) വരാം: care + less + ly = carelessly, care + ful + ness = carefulness
  • ഓരോ Affix-നും സ്വന്തം അർത്ഥമുണ്ട്: re- = വീണ്ടും, pre- = മുമ്പ്, pan- = എല്ലാം, -less = ഇല്ലാത്ത, -ful = നിറഞ്ഞ. ഇവ അറിഞ്ഞാൽ അപരിചിത വാക്കുകളുടെ അർത്ഥവും കണ്ടെത്താം. ഉദാ: un-pre-meditat-ed = "മുമ്പേ (pre) ആലോചിച്ചിട്ടില്ലാത്ത (un)".
ചിത്രം 2.1 – Prefix + Root + Suffix = പുതിയ വാക്ക്.

3. അടിസ്ഥാന സങ്കല്പങ്ങൾ

പദംഅർത്ഥംഉദാഹരണം
Root / Base wordഅർത്ഥമുള്ള അടിസ്ഥാന പദംbelieve, free, care
Prefixമൂലപദത്തിന് മുമ്പ് ചേർക്കുന്നത്unhappy, rewrite
Suffixമൂലപദത്തിന് ശേഷം ചേർക്കുന്നത്careless, freedom
AffixPrefix + Suffix ഇവ രണ്ടിന്റെയും പൊതുപേര്–

Free morpheme vs Bound morpheme (Compound ചോദ്യങ്ങളുടെ താക്കോൽ)

  • Free morpheme: ഒറ്റയ്ക്ക് നിൽക്കാൻ കഴിയുന്ന, അർത്ഥമുള്ള വാക്ക് (sun, stroke, free, care).
  • Bound morpheme: ഒറ്റയ്ക്ക് നിൽക്കാനാകാത്ത അക്ഷരക്കൂട്ടം (un-, dis-, -dom, -ness, -ful). ഇവയാണ് Affixes.
  • രണ്ട് ഭാഗവും free ആണെങ്കിൽ അത് Compound word (sun + stroke, black + board). Affix ഉണ്ടെങ്കിൽ Derived word.
⭐ പ്രധാന നിയമം

Prefix ചേർക്കുമ്പോൾ മൂലപദത്തിന്റെ സ്പെല്ലിംഗ് ഒരിക്കലും മാറില്ല, ഒരക്ഷരവും ഒഴിവാകില്ല. ഉദാ: un + necessary = unnecessary (n ഇരട്ടിക്കും, ഒന്ന് Prefix-ന്റേതും ഒന്ന് Root-ന്റേതും), dis + appear = disappear, mis + spell = misspell, il + legal = illegal, ir + regular = irregular. സ്പെല്ലിംഗ് മാറ്റങ്ങൾ വരുന്നത് Suffix ചേർക്കുമ്പോൾ മാത്രമാണ്.

➕ വാക്ക് മുറിക്കുന്ന നിയമം (Word Division)

Prefix-ന് ശേഷവും Suffix-ന് മുമ്പും മുറിക്കാം (un-believ-able). ഇത് Copy Holder Printing 163/2014 പരീക്ഷയിൽ ചോദിച്ചതായി നോട്ടിൽ രേഖപ്പെടുത്തിയിരുന്നു. ഔദ്യോഗിക പേപ്പറുമായി ഒത്തുനോക്കുക.

7. ക്രിയകൾ നിർമ്മിക്കുന്ന Affixes

ക്രിയാ പ്രിഫിക്സുകൾ (Noun/Adjective → Verb)

  • en- ("ആക്കുക / ഉള്ളിലാക്കുക"): rich → enrich, large → enlarge, able → enable, danger → endanger, courage → encourage, sure → ensure, joy → enjoy, slave → enslave, title → entitle, circle → encircle
  • em- (b, p, m ന് മുമ്പ് en- → em-): power → empower, body → embody, bitter → embitter, bold → embolden
  • be-: friend → befriend, little → belittle, calm → becalm, head → behead, fool → befool

ക്രിയാ സഫിക്സുകൾ

  • -en: strength → strengthen, length → lengthen, threat → threaten, fright → frighten, haste → hasten, bright → brighten, wide → widen, short → shorten, weak → weaken, sweet → sweeten
  • -ify: beauty → beautify, pure → purify, clear → clarify, class → classify, terror → terrify, glory → glorify, simple → simplify, just → justify, false → falsify
  • -ize / -ise: sympathy → sympathize, apology → apologize, memory → memorize, critic → criticize, real → realize, equal → equalize, hospital → hospitalize
    • -ize (American/Oxford), -ise (British) ഇവ രണ്ടും സ്വീകാര്യം.
    • -ise എന്ന് അവസാനിക്കുന്ന ചില വാക്കുകളിൽ അത് Suffix അല്ല: advertise, surprise, revise, exercise, supervise, improvise, compromise.
  • -ate: activate, motivate, hyphenate, captivate (ഇവിടെ -ate ക്രിയാ പ്രത്യയം). Fortunate, moderate എന്നിവയിൽ -ate വിശേഷണ ധർമ്മത്തിലാണ്.
🧠 ട്രിക്ക്

"ആക്കുക" (make/cause to be) എന്ന അർത്ഥമെങ്കിൽ → മുൻപിൽ en- അല്ലെങ്കിൽ പിന്നിൽ -en / -ify / -ize.

9. വിശേഷണ & അളവ് സഫിക്സുകൾ

  • ⭐⭐⭐⭐⭐ -ful (നിറഞ്ഞ / full of):
    • വിശേഷണം: beauty → beautiful, care → careful, harm → harmful, peace → peaceful, hope → hopeful, use → useful
    • അളവ് നാമം: spoonful, mouthful, handful, cupful, houseful (plural: spoonfuls, mouthfuls)
    • ⚠️ Suffix ആയ -ful-ൽ ഒരു 'l' മാത്രം (careful, useful, beautiful), full എന്ന വാക്കിൽ മാത്രം രണ്ട് l.
  • ⭐⭐⭐⭐ -less (ഇല്ലാത്ത): friend → friendless, tire → tireless, care → careless, speech → speechless, mercy → merciless, fear → fearless
  • ⭐⭐⭐⭐⭐ -able vs -ible (കഴിയുന്ന / യോഗ്യമായ):
    • -able: പൂർണ്ണമായ ഇംഗ്ലീഷ് വാക്കിനോട് ചേരുന്നത് സാധാരണ -able ആണ്: comfortable, portable, changeable, believable, readable, breakable
    • -ible: ലാറ്റിൻ വേരുള്ള വാക്കുകൾ: reversible, sensible, accessible, edible, visible, eligible, terrible, possible
    • -able ആണ് കൂടുതൽ സാധാരണം, -ible കുറച്ച് വാക്കുകളിൽ മാത്രം.
  • ⭐⭐⭐ -al: musical, national, comical, intellectual (വിശേഷണം) | arrival, refusal, denial (നാമം)
  • ⭐⭐⭐ -ous: famous, dangerous, courageous, poisonous
  • ⭐⭐⭐ -ive: active, creative, talkative, attractive
  • ⭐⭐⭐ -ic: poetic, historic, scientific, heroic
  • ⭐⭐ -y: messy, noisy, rainy, healthy, sunny
  • ⭐⭐ -ish: childish, foolish, reddish
  • ⭐⭐ -er / -est: bigger / biggest, stronger / strongest, tiny → tiniest, brave → bravest (ഇവ Inflectional). എന്നാൽ *-er* ചിലപ്പോൾ "ചെയ്യുന്ന ആൾ" (teacher, painter) എന്ന Derivational നാമവും ഉണ്ടാക്കും.

10. ക്രിയാവിശേഷണ സഫിക്സുകൾ

  • ⭐⭐⭐⭐⭐ -ly: clear → clearly, slow → slowly, quick → quickly
  • ⭐⭐⭐⭐ -ily (y→i): happy → happily, lazy → lazily, eerie → eerily
  • ⭐⭐⭐ Noun + -ly = Adjective (ചിലത് Adverb ആയും ഉപയോഗിക്കാം): friend → friendly, father → fatherly, man → manly, state → stately; hourly, weekly, monthly, daily (Adjective & Adverb)
  • ⭐⭐ -ward / -wards (ദിശ): backward, forward, upward, homeward

11. സഫിക്സ് ചേർക്കുമ്പോഴുള്ള 4 സ്പെല്ലിംഗ് നിയമങ്ങൾ

നിയമം 1: Silent 'e' ഒഴിവാക്കൽ

മൂലപദം silent -e-ൽ അവസാനിച്ചാൽ, -able, -ing, -al, -ous, -ive, -ible, -ation പോലുള്ള സ്വരാക്ഷര Suffix വരുമ്പോൾ 'e' ഒഴിവാക്കും.

  • believe + able → believable (believeable ✗)
  • reverse + ible → reversible
  • arrive + al → arrival
  • fame + ous → famous
  • create + ive → creative
  • make + ing → making

നിയമം 2: 'e' നിലനിർത്തൽ

  • (a) -ce / -ge ന് ശേഷം -able / -ous വന്നാൽ 'e' നിലനിർത്തും (ഉച്ചാരണം soft ആയി നിലനിർത്താൻ):
    • change → changeable, notice → noticeable, manage → manageable, service → serviceable
    • courage → courageous, outrage → outrageous, advantage → advantageous
    • Noticable എന്നെഴുതിയാൽ 'c' കഠിനമായി (k) ഉച്ചരിക്കേണ്ടിവരും. അതിനാണ് 'e' വേണ്ടത്.
  • (b) വ്യഞ്ജനാക്ഷര Suffix (-ful, -less, -ly, -ment, -ness) വരുമ്പോൾ സാധാരണ 'e' നിലനിർത്തും: care → careful/careless, state → stately, excite → excitement, achieve → achievement, complete → completely
  • (c) അപവാദങ്ങൾ (e ഒഴിവാകുന്നവ): argue → argument, true → truly, whole → wholly, nine → ninth, due → duly, awe → awful, wise → wisdom, judge → judgment (judgement എന്നും സ്വീകാര്യം)

നിയമം 3: വ്യഞ്ജനം + y → y മാറ്റി i

  • happy → happily, happiness | lazy → lazily | beauty → beautiful | tiny → tiniest | mercy → merciless | eerie → eerily
  • -ing ചേർക്കുമ്പോൾ y മാറില്ല: cry → crying, study → studying
  • സ്വരം + y ആണെങ്കിൽ y മാറില്ല: enjoy → enjoyable, play → played, buy → buyer
  • അപവാദം: pay → paid, say → said, lay → laid

നിയമം 4: അവസാന വ്യഞ്ജനം ഇരട്ടിക്കൽ

ഒറ്റ അക്ഷരമുള്ള വാക്ക് (CVC ഘടന: വ്യഞ്ജനം–സ്വരം–വ്യഞ്ജനം) അല്ലെങ്കിൽ ഊന്നൽ അവസാന അക്ഷരത്തിലുള്ള വാക്ക് → അവസാന വ്യഞ്ജനം ഇരട്ടിക്കും, സ്വരത്തിൽ തുടങ്ങുന്ന Suffix വരുമ്പോൾ.

  • big → bigger | run → running | commit → committed | occur → occurrence | begin → beginning
  • ഊന്നൽ ആദ്യ അക്ഷരത്തിൽ ആണെങ്കിൽ ഇരട്ടിക്കില്ല: visit → visited, open → opened
  • രണ്ട് വ്യഞ്ജനം/രണ്ട് സ്വരം ഉള്ളവയും ഇരട്ടിക്കില്ല: help → helped, need → needed
  • w, x, y ഒരിക്കലും ഇരട്ടിക്കില്ല: snow → snowing, box → boxing

19. മെമ്മറി ട്രിക്കുകൾ (Mnemonics)

🧠 മുഖ്യ ട്രിക്കുകൾ
  1. in- രൂപഭേദങ്ങൾ (L-R-M-P കോഡ് – ജാഗ്രതയോടെ ഉപയോഗിക്കുക):
    • in- എടുക്കുന്ന വാക്കാണെങ്കിൽ: L → il-, R → ir-, B/M/P → im-.
    • ⚠️ അതിനുമുമ്പ് വാക്ക് in- ആണോ un- ആണോ എടുക്കുന്നതെന്ന് ഓർമ്മയിൽ നോക്കുക (unlucky, unreal, unpopular, unlawful, unlikely, unreliable).
  2. പൊതു Prefix ചോദ്യം: ഓപ്ഷനുകൾ ഓരോന്നും മൂന്ന് വാക്കുകളോടും ചേർത്ത് വായിക്കുക. മൂന്നും യഥാർത്ഥ ഇംഗ്ലീഷ് വാക്കാകുന്ന ഒന്നേ കാണൂ (mis + take / chief / behave).
  3. 'C-G Rule': -able/-ous ചേരുമ്പോൾ വാക്ക് -ce/-ge ആണെങ്കിൽ 'e' വെട്ടരുത്. ബാക്കി വാക്കുകളിൽ 'e' വെട്ടും.
  4. Class Change Test: -s, -ed, -ing, -er, -est (പദവിഭാഗം മാറുന്നില്ല) → Inflectional. പുതിയ അർത്ഥം/പദവിഭാഗം ഉണ്ടാക്കുന്ന എല്ലാം → Derivational.
  5. Free-Word Test: രണ്ട് ഭാഗവും ഒറ്റയ്ക്ക് അർത്ഥമുള്ള വാക്കുകളാണെങ്കിൽ Compound; ഒരു ഭാഗം ഒറ്റയ്ക്ക് നിൽക്കാത്തതാണെങ്കിൽ Affix.
  6. PAN = "പാൻ" ഇട്ട് എല്ലാം: Pan-demic = എല്ലാവർക്കും; Pan-orama = എല്ലാ ഭാഗവും കാണുന്നത്.

20. Common PSC Traps

⚠️ 6 മുഖ്യ ട്രാപ്പുകൾ

ട്രിക്ക് 1: Option Elimination

Q. Choose the correct opposite of 'regular' using a prefix.
(A) unregular (B) inregular (C) irregular (D) disregular

  • unregular, inregular, disregular ഇവ സ്റ്റാൻഡേർഡ് ഇംഗ്ലീഷ് വാക്കുകളായി തോന്നുന്നില്ല → 3 ഓപ്ഷനുകൾ സംശയാസ്പദം.
  • 'r'-ൽ തുടങ്ങുന്ന വാക്കുകൾക്ക് in- → ir- ആകുന്നു (irrelevant, irresponsible പോലെ).
  • ഉത്തരം: (C) irregular

ട്രിക്ക് 2: Keyword Trick (NOT, EXCEPT, INCORRECT)

Q. Which of the following is NOT a negative prefix?
(A) un- (B) dis- (C) pan- (D) non-

  • "NOT" എന്ന വാക്ക് കണ്ടപ്പോൾ തന്നെ ചോദ്യം തിരിച്ചാണെന്ന് തിരിച്ചറിയുക.
  • un-, dis-, non- മൂന്നും നെഗറ്റീവ് ആണെന്ന് പരിചിതമാണ് → ബാക്കിയുള്ളത് pan-.
  • ഉത്തരം: (C) pan- (pan- = all)

ട്രിക്ക് 3: Extreme Statement Check

Q. Which statement is correct?
(A) All prefixes change the part of speech of a word. (B) A suffix is added at the end of a root word. (C) A prefix is added at the end of a word. (D) A word can never contain both a prefix and a suffix.

  • (A) "All" എന്ന വാക്ക് ശ്രദ്ധിക്കുക. un-happy, dis-agree എന്നിവ വിഭാഗം മാറ്റുന്നില്ല → തെറ്റ്.
  • (C) Prefix മുമ്പാണ് → തെറ്റ്.
  • (D) "never" എന്ന അതിവാദം. unbelievable ഇതിനൊരു ഉദാഹരണമാണ് (un- + believe + -able) → തെറ്റ്.
  • ഉത്തരം: (B)

ട്രിക്ക് 6: Assertion–Reason

  • പക്ഷേ അതേ കാരണം കൊണ്ടാണ് A തെറ്റാകുന്നത്. Sun ഒരു Prefix അല്ല, അതിനാൽ sunstroke Compound ആണ്.

ട്രിക്ക് 7: Counting / Number Logic

Q. How many affixes (prefixes + suffixes) are there in the word 'unpremeditated'?

  • ഉത്തരം: (B) 3
  • ⚠️ ചോദ്യം "എത്ര Prefixes?" ആണെങ്കിൽ ഉത്തരം 2 ആകും. സംഖ്യ ചോദ്യങ്ങളിൽ എന്താണ് എണ്ണാൻ പറയുന്നതെന്ന് ഉറപ്പിക്കുക.

Q. Choose the correct spelling.

unfortunate. (*Misfortune* ഒരു Noun ആണ്, Adjective അല്ല.) 🧠 un- = not.
10. Choose the correct prefix for 'continued':
ശരിയുത്തരം: (B) dis-
discontinued. മറ്റുള്ളവ (uncontinued, incontinued, miscontinued) സാധാരണ ഉപയോഗത്തിലില്ല.
11. The suffix '-ful' in 'houseful' suggests:
ശരിയുത്തരം: (C) full of people
-ful = full of. 🧠 house + ful = full of people (ആൾക്കാരെക്കൊണ്ട് നിറഞ്ഞ).
12. How can we break words including prefix and suffix?
ശരിയുത്തരം: (B) After prefix or before suffix
un-believ-able. 🧠 Prefix-ന് ശേഷവും Suffix-ന് മുമ്പും മുറിക്കാം.
13. Suffix common to 'spoon' and 'mouth' (quantity):
ശരിയുത്തരം: (C) -ful
spoonful, mouthful (അളവ് നാമങ്ങൾ). (spoonless/mouthless അസാധാരണം, spoonness/mouthness ഇല്ല.) 🧠 -ful = full of/quantity.
14. Prefix meaning "having no concern with right or wrong" for 'moral':
ശരിയുത്തരം: (A) a-
amoral = ധാർമ്മികതയുമായി ബന്ധമില്ലാത്ത. *Immoral* = ധാർമ്മികമായി തെറ്റ് (വ്യത്യാസം ഓർക്കുക).
15. The suffix '-itis' means:
ശരിയുത്തരം: (B) inflammation
arthritis, bronchitis. (fear = -phobia, study = -logy, killing = -cide) 🧠 -itis = വീക്കം.
16. Correct spelling:
ശരിയുത്തരം: (B) argument
argue + ment (e ഒഴിവാകുന്ന അപവാദം). 🧠 argument, truly, wholly, ninth — e ഒഴിവാകുന്നവ.
17. 'change' + '-able':
ശരിയുത്തരം: (B) changeable
-ge + -able 'e' നിലനിർത്തും. 🧠 -ce/-ge + -able/-ous → keep 'e'.
18. 'Weekly' functions as:
ശരിയുത്തരം: (B) adjective and adverb
"a weekly magazine" (Adj), "published weekly" (Adv). 🧠 hourly, daily, monthly, yearly — ഇവയും ഇരട്ട ധർമ്മം.
19. 'Prepone' means:
ശരിയുത്തരം: (B) to bring forward to an earlier time
pre- = മുമ്പ് (ഇന്ത്യൻ ഇംഗ്ലീഷ് പ്രയോഗം). 🧠 prepone ↔ postpone.
20. 'Unpremeditated' എന്ന വാക്കിൽ എത്ര Affixes (Prefixes + Suffixes) ഉണ്ട്?
ശരിയുത്തരം: (B) 3
un- | pre- | meditat(e) | -ed. Root = meditate. Affixes: un-, pre-, -ed = 3. (ചോദ്യം "Prefixes?" ആണെങ്കിൽ ഉത്തരം 2.)

  3. Political → a- (apolitical) / non-.
  4. Believe → unbelievable.

📝 Teacher's Note

Affixes ചോദ്യങ്ങളിൽ ഏറ്റവും പ്രധാനം: (1) Negative Prefixes കൃത്യമായി ഓർക്കുക (un-, dis-, in-, im-, il-, ir-, a-, non-, de-). (4) Spelling: changeable vs believable, argument, truly. (5) Derivational vs Inflectional (8 inflectional suffixes മാത്രം). (6) Pan- = all, mis- = wrong. ഈ ആറ് കാര്യങ്ങൾ PSC-യുടെ പ്രിയപ്പെട്ട കെണികളാണ്.
