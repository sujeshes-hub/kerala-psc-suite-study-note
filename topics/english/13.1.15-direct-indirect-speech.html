നിബന്ധനാ വാക്യങ്ങൾ (Conditional Sentences / If Clauses)

Type 0–3 · Mixed · Inverted · Unless · had vs had had · Passive | Kerala PSC Rank File – Complete Verified Notes

🔍 ഒന്നും കണ്ടെത്തിയില്ല. മറ്റൊരു വാക്ക് ശ്രമിക്കുക.

⭐ Star Guide

⭐ പ്രാധാന്യ സൂചകങ്ങൾ (Kerala PSC അടിസ്ഥാനത്തിൽ)
  • ⭐⭐⭐⭐⭐ അതിപ്രധാനം — Type 2 (`If + V2/were → would + V1`), Type 3 (`had + V3 → would have + V3`), `had` vs `had had` കെണി, `Unless` നിയമം
  • ⭐⭐⭐⭐ പ്രധാനം — Type 1 (`If + V1/V5 → will + V1`), Subjunctive `were`, Inverted Conditionals (Should/Were/Had), Type 2 Passive
  • ⭐⭐⭐ ശ്രദ്ധിക്കേണ്ടത് — Mixed Conditional, `provided / in case / otherwise / but for`, `wish / if only`, `If`-ൽ will/would ഇല്ല
  • ⭐⭐ അറിഞ്ഞാൽ മതി — Type 0 (ശാസ്ത്ര സത്യങ്ങൾ), English Terms Glossary, `If`-ൽ will അപവാദം
  • ⭐ ചരിത്ര വിവരം — Conditional Sentences സിലബസ് കോഡ് 13.1.12
➕ ചുരുക്കം
  • Type 0: V1/V5 → V1/V5 (സത്യങ്ങൾ)
  • Type 1: V1/V5 → will + V1 (സാധ്യത)
  • Type 2: V2/were → would + V1 (സാങ്കല്പികം)
  • Type 3: had + V3 → would have + V3 (നടക്കാത്ത ഭൂതം)
  • had + Noun: Type 2 | had + V3 (had had): Type 3
  • Unless = If ... not (Unless-ൽ not വരില്ല)
  • If-ൽ will/would ഇല്ല

1. അധ്യായ ആമുഖം + English Terms

  • ⭐⭐⭐⭐⭐ Conditional Sentence എന്നത്: ഒരു പ്രവൃത്തി നടക്കണമെങ്കിൽ മറ്റൊരു നിബന്ധന (Condition) പൂർത്തിയാകണം എന്ന് സൂചിപ്പിക്കുന്ന വാക്യങ്ങൾ. ഇതിൽ രണ്ട് ഭാഗങ്ങളുണ്ട്:
    • 'If' Clause (Subordinate Clause): നിബന്ധന പറയുന്ന ഭാഗം.
    • Main Clause (Result Clause): നിബന്ധന നടന്നാലുള്ള ഫലം പറയുന്ന ഭാഗം.
  • ⭐⭐⭐⭐⭐ PSC-യിലെ പ്രാധാന്യം: LDC, LGS, BFO, Fireman, ഡിഗ്രി ലെവൽ പ്രിലിംസ് & മെയിൻസ് തുടങ്ങിയവയിൽ ജനറൽ ഇംഗ്ലീഷിൽ ഏറ്റവും സ്ഥിരമായി വരുന്ന വ്യാകരണ ഭാഗങ്ങളിൽ ഒന്നാണിത്. സാധാരണ രീതി: വാക്യത്തിന്റെ ഒരു ഭാഗം തന്ന് മറുഭാഗത്തെ ക്രിയ പൂരിപ്പിക്കാൻ ആവശ്യപ്പെടുക.
  • ⭐⭐⭐⭐ എങ്ങനെ പഠിക്കണം: ഓരോ വർഷവും ഇതിൽ നിന്ന് ചോദ്യം ഉണ്ടാകുമെന്ന് ആർക്കും ഉറപ്പുപറയാൻ കഴിയില്ല. പക്ഷേ ചോദ്യം വന്നാൽ 4 ക്രിയാ ജോഡികൾ (Type 0, 1, 2, 3) അറിയാവുന്നവർക്ക് വളരെ വേഗം ഉത്തരം കണ്ടെത്താം.

2. പിന്നാമ്പുറ കഥ (Behind the Story)

ഒരു ക്രിക്കറ്റ് മത്സരത്തിന് മുമ്പും ശേഷവും ഒരു കുട്ടി പറയുന്ന വാചകങ്ങൾ ശ്രദ്ധിക്കൂ:

⭐ Type 0 – എല്ലായ്പ്പോഴും സത്യമായ കാര്യം

"പന്ത് മുകളിലേക്ക് എറിഞ്ഞാൽ അത് താഴെ വീഴും."

"If you throw a ball up, it comes down."

എല്ലായ്പ്പോഴും സത്യമായ കാര്യമായതിനാൽ രണ്ട് ഭാഗത്തും Simple Present.

➕ Type 1 – മത്സരം തുടങ്ങുന്നതിന് മുമ്പ് (നടക്കാൻ സാധ്യതയുള്ള കാര്യം)

"നമ്മൾ നന്നായി കളിച്ചാൽ കളി ജയിക്കും."

"If we play well, we will win the match."

മത്സരം ഇനി നടക്കാനിരിക്കുന്നതേയുള്ളൂ, അതിനാൽ ജയിക്കാൻ യഥാർത്ഥ സാധ്യതയുണ്ട്. ആദ്യ ഭാഗത്ത് Simple Present (play), മറുഭാഗത്ത് will + V1.

➕ Type 2 – ഗ്യാലറിയിൽ ഇരുന്ന് സ്വപ്നം കാണുന്ന കുട്ടി (സാങ്കല്പികം)

"ഞാൻ ടീമിൽ ഉണ്ടായിരുന്നെങ്കിൽ ഒരു സെഞ്ച്വറി അടിച്ചേനെ!"

"If I were in the team, I would score a century."

അവൻ ടീമിൽ ഇല്ല, ഇത് വെറും ഭാവനയാണ്. ആദ്യ ഭാഗത്ത് Simple Past (were / V2), മറുഭാഗത്ത് would + V1.

➕ Type 3 – മത്സരം തോറ്റ ശേഷം (ഭൂതകാലത്തിൽ നടക്കാതെ പോയത്)

"അവർ നന്നായി കളിച്ചിരുന്നെങ്കിൽ കളി ജയിച്ചേനെ!"

"If they had played well, they would have won the match."

കളി കഴിഞ്ഞു. അവർ നന്നായി കളിച്ചില്ല, ജയിച്ചുമില്ല; ഇനി ഒന്നും മാറ്റാനാവില്ല. ആദ്യ ഭാഗത്ത് Past Perfect (had played), മറുഭാഗത്ത് would have + V3.

🧠 ഓർമ്മിക്കാനുള്ള ആശയം

കാലത്തിൽ ഓരോ പടി പിന്നോട്ട് പോകുമ്പോഴും If ഭാഗവും Main ഭാഗവും ഒരുമിച്ച് ഒരു പടി പിന്നോട്ട് പോകുന്നു. ഇതാണ് ഇതിന്റെ അടിസ്ഥാന യുക്തി.

3. നിബന്ധനാ വാക്യങ്ങളുടെ അടിസ്ഥാന ഘടന (A)

3.1 രണ്ട് ഭാഗങ്ങൾ

  1. The 'If' Clause: നിബന്ധന പറയുന്ന ഉപവാക്യം (If / Unless കൊണ്ട് തുടങ്ങുന്നു).
  2. The Main Clause: നിബന്ധന നടന്നാലുള്ള ഫലം.

3.2 Clause Order (വാക്യക്രമം)

  • ⭐⭐⭐⭐ If Clause ആദ്യം: "If it rains tomorrow, we will stay home." (If ആദ്യം, കോമ വേണം)
  • ⭐⭐⭐⭐ If Clause പിന്നിൽ: "You will be fined if you park your car there." (If പിന്നിൽ, കോമ വേണ്ട)
  • ⭐⭐⭐⭐ നിയമം രണ്ടിനും ഒന്നുതന്നെ. ഏത് ഭാഗം ആദ്യം വന്നാലും ക്രിയാ ജോഡി മാറില്ല.
⭐ സുവർണ്ണ നിയമം (PSC നിയമം)

If Clause-ൽ will / would ഉപയോഗിക്കരുത്. ഭാവിയെക്കുറിച്ചാണെങ്കിലും If ഭാഗത്ത് Simple Present തന്നെ വേണം.

  • ✔ "If it rains tomorrow, we will stay home."
  • ✘ "If it will rain tomorrow, we will stay home."
⚠️ അപവാദം (അപൂർവം)

ദയവായി/സന്നദ്ധത എന്ന അർത്ഥത്തിൽ will/would If ഭാഗത്ത് വരാം:

  • "If you will help me, I shall be grateful." (= നിങ്ങൾ സഹായിക്കാൻ തയ്യാറാണെങ്കിൽ)

ഇത് പരീക്ഷയിൽ അപൂർവമാണ്. സാധാരണ ചോദ്യങ്ങളിൽ ഈ അപവാദം പരിഗണിക്കേണ്ടതില്ല. പക്ഷേ "ഒരിക്കലും വരില്ല" എന്ന് അന്ധമായി ഉറപ്പിക്കരുത്.

ചിത്രം 3.1 – Clause Order: If ആദ്യം കോമ വേണം; If പിന്നിൽ കോമ വേണ്ട.

4. Zero Conditional (Type 0)

⭐ ഉപയോഗം

ശാസ്ത്രീയ സത്യങ്ങൾ, പ്രകൃതി നിയമങ്ങൾ, എപ്പോഴും ഒരേപോലെ സംഭവിക്കുന്ന കാര്യങ്ങൾ.

🧠 ഫോർമുല

If + Simple Present (V1/V5) → Simple Present (V1/V5)

ഇവിടെ If-ന് പകരം when / whenever ഉപയോഗിച്ചാലും അർത്ഥം മാറില്ല.

4.1 ഉദാഹരണങ്ങൾ

  • "If it rains, the grass gets wet."
  • "If you heat ice, it melts."
  • "If water reaches 100°C (സാധാരണ മർദ്ദത്തിൽ), it boils."
  • "If you mix red and blue, you get purple."
ചിത്രം 4.1 – Type 0: എപ്പോഴും സത്യം → രണ്ട് ഭാഗത്തും Simple Present.

5. First Conditional (Type 1)

⭐ ഉപയോഗം

ഭാവിയിൽ നടക്കാൻ യഥാർത്ഥ സാധ്യതയുള്ള (Real / Probable) കാര്യങ്ങൾ.

🧠 ഫോർമുല

If + Simple Present (V1/V5) → will / shall / can / may + V1

കർത്താവ് He/She/It/ഏകവചനം ആണെങ്കിൽ V5 (rains, works, comes). I/You/ബഹുവചനം ആണെങ്കിൽ V1 (rain, work, come).

5.1 വകഭേദങ്ങൾ (Variations)

  • If + Present Continuous / Present Perfect → will + V1: "If you have finished, you can go."
  • If + Simple Present → Imperative: "If you see him, tell him."
  • Main clause-ൽ must / should വരാം: "If you want to pass, you must work hard."

6. Second Conditional (Type 2)

⭐ ഉപയോഗം

വർത്തമാനകാലത്ത് സത്യമല്ലാത്തതോ, നടക്കാൻ സാധ്യത കുറഞ്ഞതോ, തികച്ചും സാങ്കല്പികമോ ആയ കാര്യങ്ങൾ (Unreal Present / Hypothetical). ഉപദേശം നൽകാനും (If I were you...) ഇത് ഉപയോഗിക്കുന്നു.

🧠 ഫോർമുല

If + Simple Past (V2 / were) → would / could / might + V1

6.1 would / could / might വ്യത്യാസം

Modalഅർത്ഥം
wouldഫലം (സാങ്കല്പിക ലോകത്ത് സ്വാഭാവികമായ ഫലം)
couldകഴിവ്/സാധ്യത ("I could travel more")
mightദുർബല സാധ്യത
✏️ കൃത്യത

should ആധുനിക ഇംഗ്ലീഷിൽ ഇവിടെ വളരെ അപൂർവമാണ്. should have + V3 സാധാരണയായി "ചെയ്യേണ്ടിയിരുന്നു" എന്ന ഉപദേശ/ഖേദ അർത്ഥത്തിലാണ് വരുന്നത്.

7. Subjunctive Mood – If + Subject + were (PSC Favourite)

ഇല്ലാത്ത ഒരവസ്ഥ സങ്കല്പിക്കുമ്പോഴോ നടക്കാത്ത ആഗ്രഹം പറയുമ്പോഴോ, കർത്താവ് ഏകവചനമായാലും (I, he, she, it) ഔപചാരിക/പരീക്ഷാ ഇംഗ്ലീഷിൽ was-ന് പകരം were ഉപയോഗിക്കുന്നു.

⭐ ഉദാഹരണങ്ങൾ
  • "If she were a bird, she would fly." (KPSC Model Question 881 [Unverified])
  • "If my father were there, he would help you."
  • "If I were you, I would accept the offer." (ഉപദേശം)
  • "He talks as if he were the boss." (as if / as though + were)
⚠️ ശ്രദ്ധിക്കുക

അനൗപചാരിക സംസാരത്തിൽ If I was... കേൾക്കാറുണ്ട്. എന്നാൽ PSC ഓപ്ഷനിൽ was-ഉം were-ഉം ഒരുമിച്ച് വന്നാൽ were ആണ് സ്റ്റാൻഡേർഡ് ഉത്തരം.

➕ If I were to + V1 (Type 2 വകഭേദം)

"If I were to win the lottery, I would travel the world."

8. Third Conditional (Type 3)

⭐ ഉപയോഗം

If + Past Perfect (had + V3) → would / could / might + have + V3

9. had vs had had – PSC Mega Trap (F1)

9.1 If I had (Type 2) vs If I had had (Type 3)

⭐ സന്ദർഭം 1: If + Subject + had + Noun (Simple Past, Type 2)

had-ന് ശേഷം നേരിട്ട് ഒരു നാമം (a car, a camera, enough money) വന്നാൽ, had എന്നത് have-ന്റെ Simple Past (V2) ആണ്. അതിനാൽ Main clause: would + V1.

"If I had a car, I would drop you at the bus stop."

➕ സന്ദർഭം 2: If + Subject + had + V3 / had had + Noun (Past Perfect, Type 3)

had-ന് ശേഷം മറ്റൊരു V3 (had known, had played) അല്ലെങ്കിൽ have-ന്റെ V3 ആയ had (had had) വന്നാൽ Past Perfect. Main clause: would have + V3.

"Even if I had had the money, I wouldn't have given him any."

(ആദ്യ had = സഹായക ക്രിയ, രണ്ടാമത്തെ had = have-ന്റെ V3.)

ചിത്രം 9.1 – had ഒറ്റയ്ക്ക് = Type 2; had had / had + V3 = Type 3.

10. Conditional Passive Voice (F2)

Type 2 വാക്യം Passive-ലേക്ക് മാറ്റുമ്പോൾ If ഭാഗം അതേപടി നിൽക്കും, Main clause-ലെ would + V1 → would + be + V3.

⭐ Active → Passive

Active: "If I had a camera, I would capture the picturesque beauty of the hill-station."

Passive: "If I had a camera, the picturesque beauty of the hill-station would be captured by me."

11. Unless നിയമം (F3)

⭐ Unless = If ... not

Unless = If ... not ("...ചെയ്തില്ലെങ്കിൽ / അല്ലാത്തപക്ഷം").

⚠️ ഇരട്ട നിഷേധം (Double Negative) വരരുത്

Unless-ൽ തന്നെ നെഗറ്റീവ് അർത്ഥമുള്ളതിനാൽ Unless ഭാഗത്ത് not / don't / doesn't / didn't വരരുത്.

  • ✘ "Unless you do not play well, you will not win."
  • ✔ "Unless you play well, you will not win."
  • ✔ "Unless you practise regularly, you cannot become a good athlete." (KPSC PYQ [Unverified])
  • ✔ "A sincere student cannot expect to achieve meaningful success in life unless he dedicates himself fully to his studies."
✏️ പരിമിതികൾ

Unless സാധാരണയായി Type 0/1/2-ൽ ഉപയോഗിക്കുന്നു. ചോദ്യ രൂപത്തിലുള്ള Main clause-ൽ ("Unless you come, what will I do?"-പോലുള്ളവ) അത് അസ്വാഭാവികമാണ്. അതിനാൽ മിക്ക പരീക്ഷാ ചോദ്യങ്ങളിലും ഇത് If ... not എന്നതിന് തുല്യമായ ലളിത രൂപത്തിൽ മാത്രം കാണാം.

12. Mixed Conditional (G1)

ഭൂതകാലത്തിലെ ഒരു കാര്യം ഇപ്പോഴത്തെ ഫലം ഉണ്ടാക്കുന്നെങ്കിൽ: If + had + V3 → would + V1 (Now).

⭐ ഉദാഹരണങ്ങൾ
  • "If I had studied medicine, I would be a doctor now."
  • "If he had taken the medicine, he would be fine now."
🧠 എങ്ങനെ തിരിച്ചറിയാം?

now / today പോലുള്ള വർത്തമാന സൂചന + ഭൂതകാലത്തിലെ had + V3 കാരണം → Main-ൽ would + V1 (not would have + V3).

13. Inverted Conditionals (G2)

14.1 If അല്ലാതെ നിബന്ധന സൂചിപ്പിക്കുന്ന പദങ്ങൾ

15. പ്രധാന വസ്തുതകൾ (Important Facts)

  • Conditional Sentence-ൽ If Clause-ഉം Main Clause-ഉം ഉണ്ട്. If ആദ്യം വന്നാൽ കോമ ചേർക്കണം.
  • Type 0: രണ്ട് ഭാഗത്തും Simple Present (ശാസ്ത്ര സത്യങ്ങൾ).
  • Type 1: If + Simple Present → will/shall/can/may + V1.
  • Type 2: If + Simple Past / were → would/could/might + V1.
  • Type 3: If + had + V3 → would/could/might + have + V3.
  • സാങ്കല്പിക വാക്യങ്ങളിൽ എല്ലാ കർത്താക്കൾക്കും were (ഔപചാരിക രൂപം).
  • If I had + Noun = Type 2 (would + V1). If I had had / had + V3 = Type 3 (would have + V3).
  • Unless = If ... not; Unless ഭാഗത്ത് not വരില്ല.
  • If ഭാഗത്ത് സാധാരണയായി will/would വരില്ല.
  • Inverted: Should (T1), Were (T2), Had (T3).

    20. മെമ്മറി ട്രിക്കുകൾ (Mnemonics)

    🧠 5 മുഖ്യ ട്രിക്കുകൾ
    1. '1-2-3 ക്രിയാ ജോഡി':
      • 1: V1/V5 ↔ will + V1
      • 2: V2 / were ↔ would + V1
      • 3: had + V3 ↔ would have + V3
    2. 'ഒരു പടി പിന്നോട്ട്' (Step Back Trick): will → would (ഒരു പടി), would → would have (രണ്ടാം പടി). If ഭാഗത്ത് V1 → V2 → had V3.
    3. 'ഹെൽപ്പിംഗ് വെർബ് എണ്ണം' (Auxiliary Count Trick): If ഭാഗം ഒറ്റ ക്രിയ (play/played) ആണെങ്കിൽ Main-ൽ ഒറ്റ modal (will/would + V1). If ഭാഗം had + V3 (രണ്ട് വാക്ക്) ആണെങ്കിൽ Main-ൽ would have + V3. (പരിമിതി: Type 0-ൽ modal ഇല്ല. ഇത് Type 1–3-ന് മാത്രം ഉപയോഗപ്പെടുന്ന സൂചനയാണ്.)
    4. 'were സൂചന': If I were / If she were കണ്ടാൽ സാധാരണയായി Main clause would + V1 ആയിരിക്കും. (ഇത് പരീക്ഷാ സൂചന മാത്രം. If they were late... പോലുള്ള വാക്യങ്ങളിൽ അർത്ഥം കൂടി നോക്കുക.)
    5. 'No-Will, No-Would' (If ഭാഗത്ത്): ഡാഷ് If/Unless ഭാഗത്താണെങ്കിൽ ഓപ്ഷനിലെ will, would, would have ആദ്യം വെട്ടിക്കളയുക. (അപൂർവ അപവാദം: "If you will help me..." മര്യാദാ രൂപം. സാധാരണ ചോദ്യങ്ങളിൽ വരില്ല.)

    21. Common PSC Traps

    ⚠️ 7 പ്രധാന ചതിക്കുഴികൾ
    1. Trap 1: If I had a car... കണ്ട് would have dropped എന്ന് എഴുതരുത്. had-ന് ശേഷം V3 ഉണ്ടോ എന്ന് നോക്കുക. ഇല്ലെങ്കിൽ Type 2 → would drop.
    2. Trap 2: If ഭാഗത്ത് would have: "...if they would have got lost" ✗ → had got ✓.
    3. Trap 3: Unless you do not work hard... ✗ (ഇരട്ട നിഷേധം) → Unless you work hard... ✓.
    4. Trap 4: would ran / would went ✗. Modal-ന് ശേഷം V1 മാത്രം.
    5. Trap 5: If it will rain tomorrow ✗. ഭാവി കാര്യത്തിലും If ഭാഗത്ത് Simple Present.
    6. Trap 6: INCORRECT/NOT/EXCEPT ചോദ്യങ്ങളിൽ ശരിയായത് തിരഞ്ഞെടുത്ത് ചതിയിൽ പെടുക.
    7. Trap 7: had + Noun-നെ Past Perfect എന്ന് തെറ്റിദ്ധരിക്കുക.

    22. PSC Smart Tricks (12)

    ⭐ അടിസ്ഥാന തത്വം

    ഈ തന്ത്രങ്ങൾ ശരിയുത്തരത്തിലേക്കുള്ള സാധ്യത (probability) വർദ്ധിപ്പിക്കുന്നു; വിഷയജ്ഞാനത്തിന് പകരമാകില്ല. "ഏറ്റവും നീളമുള്ള ഓപ്ഷൻ ശരി", "C എന്ന ഓപ്ഷൻ ശരി", "മുൻ പരീക്ഷയിൽ ആവർത്തിച്ച ഉത്തരം ശരി" തുടങ്ങിയ ഉപായങ്ങൾ വെറും മിഥ്യകളാണ്.

    ട്രിക്ക് 1: Option Elimination

    If it ______ tomorrow, we will stay home.
    ശരിയുത്തരം: (D) rains
    Main clause-ൽ will stay → Type 1 ജോഡി (If + V1/V5). (C) would rain: If ഭാഗത്ത് would വരില്ല. (B) had rained: Past Perfect, Type 3 ജോഡിയാണ് (would have). (A) rained: Type 2 ജോഡിയാണ് (would). ⚠️ ഇത് പ്രവർത്തിക്കുന്നത് Main clause-ലെ ക്രിയ വ്യക്തമായി വായിച്ചാണ്. Main clause മറച്ച് ചോദിച്ചാൽ അർത്ഥത്തിൽ നിന്ന് കാലം കണ്ടെത്തണം.

    ട്രിക്ക് 2: Keyword Tricks (unless, not, only, incorrect)

    Choose the correct sentence.
    (A) Unless you do not hurry, you will miss the bus.
    (B) Unless you hurry, you will miss the bus.
    (C) Unless you will hurry, you will miss the bus.
    (D) Unless you hurried, you will miss the bus.
    ശരിയുത്തരം: (B) Unless you hurry, you will miss the bus.
    Unless കണ്ടാൽ ഉടൻ not ഉള്ള ഓപ്ഷൻ സംശയിക്കുക (A വെട്ടുക). Unless ഭാഗത്ത് will (C) വരില്ല. (D) hurried + will miss ജോഡി തെറ്റ്. ⚠️ only/always/never/not തുടങ്ങിയ വാക്കുകൾ പരിശോധിക്കാനുള്ള സൂചന മാത്രമാണ്.

    ട്രിക്ക് 3: Common-Sense Logic

    If I ______ a bird, I would fly to you.
    ശരിയുത്തരം: (B) were
    ഞാൻ പക്ഷിയല്ല എന്നത് വ്യക്തം → സാങ്കല്പികം (Unreal) → Type 2. Main-ൽ would + സാങ്കല്പികത → were. ⚠️ യുക്തി ഉപയോഗിക്കാൻ അർത്ഥം മനസ്സിലാകണം. വാക്യം യഥാർത്ഥത്തിൽ സാധ്യമാണെങ്കിൽ (If I am late, I will call) Type 1 ആണ്.

    ട്രിക്ക് 4: Extreme Statement Check

    Which statement about 'Unless' is correct?
    (A) Unless always takes a negative verb.
    (B) Unless means 'if not', so the verb after it is affirmative.
    (C) Unless is used only in the Third Conditional.
    (D) Unless can never be used in a sentence containing 'will'.
    ശരിയുത്തരം: (B)
    (A) "always negative" → തെറ്റ്. (C) "only Third Conditional" → തെറ്റ്. (D) "never will" → തെറ്റ് ("Unless you hurry, you will miss the bus."). (B) മിതമായ, ശരിയായ പ്രസ്താവന. ⚠️ അങ്ങേയറ്റ പദങ്ങളുള്ള പ്രസ്താവന ചിലപ്പോൾ ശരിയുമാകാം. ഓരോന്നും വിഷയ വസ്തുതയുമായി പരിശോധിക്കുക.

    ട്രിക്ക് 5: Match the Following

    a. If it rains | b. If I were rich | c. If I had known | d. Unless you work hard
    1. I would help you. | 2. I would have told you. | 3. you will fail. | 4. the ground gets wet.
    ശരിയുത്തരം: (A) a-4, b-1, c-2, d-3
    ഏറ്റവും ഉറപ്പുള്ള ജോഡി: had known → would have told ⇒ c-2. c-2 ഇല്ലാത്ത (B), (C), (D) വെട്ടുക. a-4 (Type 0), b-1 (Type 2), d-3 (Unless → will fail).

    ട്രിക്ക് 6: Statement-Based

    ശരിയായവ തിരഞ്ഞെടുക്കുക:
    1. If I were you, I would apply.
    2. If she will come, I will go.
    3. If he had worked, he would have passed.
    ശരിയുത്തരം: (B) 1, 3 only
    പ്രസ്താവന 2 തെറ്റ് (If ഭാഗത്ത് will) → 2 ഉള്ള (A), (C), (D) വെട്ടുക. (3 ഉറപ്പില്ലെങ്കിൽ പോലും 2 തെറ്റെന്നറിഞ്ഞാൽ B-യിൽ എത്താം.)

    ട്രിക്ക് 7: Assertion–Reason

    A: "If she were a bird, she would fly" എന്നതിൽ she-ന് was അല്ല were ഉപയോഗിച്ചു.
    R: സാങ്കല്പിക/അവാസ്തവ അവസ്ഥ പറയുമ്പോൾ ഏകവചന കർത്താവിനൊപ്പവും were ഉപയോഗിക്കുന്നു (Subjunctive).
    ശരിയുത്തരം: (A) A, R ശരി; R വിശദീകരണം
    A ശരി (വാക്യത്തിൽ were ഉണ്ട്). R ശരി (Subjunctive നിയമം). R തന്നെയാണ് കാരണം. ⚠️ A, R രണ്ടും ശരിയായാലും R കാരണം ആകണമെന്നില്ല.

    ട്രിക്ക് 8: Chronology ('ഒരു പടി പിന്നോട്ട്' യുക്തി)

    If I ______ the news earlier, I would have informed you.
    ശരിയുത്തരം: (C) had heard
    Main-ൽ would have informed = ഭൂതത്തിലെ ഭൂതം (Type 3). If ഭാഗവും Simple Past-ൽ നിന്ന് ഒരു പടി പിന്നോട്ട് → Past Perfect. (D) If-ൽ would have വരില്ല; (A), (B) പടി പോരാ.

    ട്രിക്ക് 9: Similar-Option Comparison

    If it hadn't rained, we ______ to the beach.
    ശരിയുത്തരം: (A) would have gone
    നാല് ഓപ്ഷനുകളും would + ക്രിയ. Modal-ന് ശേഷം have + V3 മാത്രം ശരി. (B), (C), (D) ഘടനാപരമായി തെറ്റ് (would had, would has, would gone).

    ട്രിക്ക് 10: Question Wording (Negative / INCORRECT)

    Choose the INCORRECT sentence.
    (A) If I were you, I would go.
    (B) If it rains, we will stay.
    (C) If I would know, I would tell you.
    (D) If she had come, we would have met.
    ശരിയുത്തരം: (C) If I would know, I would tell you.
    "INCORRECT" കണ്ടാൽ തെറ്റായ വാക്യം തേടുക. (A), (B), (D) ശരിയായ ജോഡികൾ. (C) If ഭാഗത്ത് would know ✗ (ശരി: If I knew, I would tell you). ⚠️ incorrect / not / except / false അടിവരയിട്ട് ഓർമ്മിക്കുക.

    ട്രിക്ക് 11: PSC Pattern Awareness

    Error spotting: "If I (A) would have (B) known the answer, I (C) would have (D) told you."
    ശരിയുത്തരം: (A) would have
    If ഭാഗത്തെ would have തെറ്റ് → ശരി: had known. സാധാരണ രൂപങ്ങൾ: (i) വാക്യത്തിന്റെ ഒരു ഭാഗം തന്ന് ബാക്കി പൂരിപ്പിക്കുക, (ii) ശരിയായ വാക്യം കണ്ടെത്തുക, (iii) Error spotting. എല്ലാറ്റിലും ആദ്യം If ഭാഗത്തെ ക്രിയാരൂപവും Main clause-ലെ modal-ഉം ജോഡി ചേരുന്നുണ്ടോ എന്ന് നോക്കുക.

    ട്രിക്ക് 12: Informed Guessing & Negative Marking

    hadn't rained = Past Perfect → Type 3 → would have + V3. (B), (C), (D) ഘടനാപരമായി തെറ്റ്.
    13. Choose the INCORRECT sentence.
    ശരിയുത്തരം: (C) If I would know, I would tell you.
    If ഭാഗത്ത് would know ✘. ശരി: If I knew, I would tell you. (A), (B), (D) ശരി.
    14. Choose the correct Passive form: "If I had a camera, I would capture the beauty."
    ശരിയുത്തരം: (B) If I had a camera, the beauty would be captured by me.
    Type 2 Passive: would + be + V3. (A) would capture active ✘. (C) was captured tense മാറി. (D) is captured tense മാറി.
    15. If he had taken the medicine, he ______ fine now.
    ശരിയുത്തരം: (B) would be
    Mixed Conditional: ഭൂതകാല കാരണം (had taken), വർത്തമാന ഫലം (now) → would + V1.
    16. ______ they played well, they would have won.
    ശരിയുത്തരം: (B) Had
    Inverted Type 3: Had they played well = If they had played well. (A), (C), (D) ഈ ഘടനയിൽ ശരിയല്ല.
    17. You can borrow my book ______ you return it tomorrow.
    ശരിയുത്തരം: (A) provided
    provided = ...ആണെങ്കിൽ മാത്രം. (B) unless അർത്ഥം വിപരീതം. (C) in case = മുൻകരുതൽ. (D) lest = ഇല്ലാതിരിക്കാൻ (അപൂർവം).
    18. If it ______ for his help, I would fail.
    ശരിയുത്തരം: (B) were not
    If it were not for (Type 2 രൂപം). Type 3 രൂപം: Had it not been for his help, I would have failed.
    19. If I ______ the news earlier, I would have informed you.
    ശരിയുത്തരം: (C) had heard
    Main-ൽ would have informed → Type 3 → If + had + V3. (D) If-ൽ would have ✘.
    20. Even if I had had the money, I ______ him any.
    ശരിയുത്തരം: (A) wouldn't have given
    had had = Past Perfect → Type 3 → would have + V3.
