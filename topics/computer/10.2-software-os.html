1. അധ്യായ ആമുഖം

  • ⭐⭐⭐⭐⭐ സോഫ്റ്റ്‌വെയർ: കമ്പ്യൂട്ടറിനെക്കൊണ്ട് ഒരു ജോലി ചെയ്യിക്കാൻ നൽകുന്ന നിർദ്ദേശങ്ങളുടെ / പ്രോഗ്രാമുകളുടെ കൂട്ടം.
  • ⭐⭐⭐⭐ ഹാർഡ്‌വെയർ = ശരീരം (തൊട്ടുനോക്കാം – Tangible). സോഫ്റ്റ്‌വെയർ = ആത്മാവ് (തൊടാൻ പറ്റില്ല, പ്രവർത്തിപ്പിക്കാനേ പറ്റൂ – Intangible).
  • ⭐⭐⭐⭐ PSC പ്രാധാന്യം: 10th (LDC 883), +2, ഡിഗ്രി (573) എല്ലാ തലത്തിലും വരുന്ന വലിയ അധ്യായം. പ്രധാന മേഖലകൾ: System vs Application, OS ധർമ്മങ്ങൾ/ഉദാഹരണങ്ങൾ, Compiler–Interpreter, ഷോർട്ട്കട്ട് കീകൾ, ഫയൽ എക്സ്റ്റൻഷനുകൾ.

🧠 ഉദാഹരണം: ടി.വി (ഹാർഡ്‌വെയർ) ഉണ്ട്, പക്ഷേ ചാനലുകൾ (സോഫ്റ്റ്‌വെയർ) ഇല്ലെങ്കിൽ അതൊരു വെറും പെട്ടി!

⚠️ ഈ എഡിഷനിലെ പ്രധാന തിരുത്തലുകൾ
  • Word 2003-ലെ ഡിഫോൾട്ട് ഫോണ്ട് Times New Roman, 10 pt (12 അല്ല). Word 2007 മുതൽ Calibri 11 pt.
  • ICFOSS സ്ഥാപിച്ചത് 2009-ൽ (തിരുവനന്തപുരം) – 2011 അല്ല.
  • Android പതിപ്പുകളിൽ Honeycomb, Ice Cream Sandwich, Jelly Bean ചേർത്തു.
  • SQL-ൽ DCL, TCL വിഭാഗങ്ങൾ ചേർത്തു.
  • Java = Compiler + Interpreter (JVM bytecode) — പൂർണ്ണമായും Compiler അല്ല.

2. പിന്നാമ്പുറ കഥ (Behind the Story)

  • ⭐⭐⭐⭐⭐ 1843: ചാൾസ് ബാബേജിന്റെ Analytical Engine-നു വേണ്ടി അഡാ ലവ്‌ലേസ് (ലോർഡ് ബൈറന്റെ മകൾ) ആദ്യ അൽഗോരിതം എഴുതി → ലോകത്തിലെ ആദ്യ കമ്പ്യൂട്ടർ പ്രോഗ്രാമർ (ഒരു വനിത!).
  • ⭐⭐⭐⭐⭐ 1958: ജോൺ ഡബ്ല്യു. ടൂക്കി "Software" എന്ന പദം ആദ്യമായി ഉപയോഗിച്ചു.
  • ⭐⭐⭐⭐ 1975: ബിൽ ഗേറ്റ്സും പോൾ അലനും Microsoft സ്ഥാപിച്ചു – Proprietary സോഫ്റ്റ്‌വെയർ.
  • ⭐⭐⭐⭐ 1983: റിച്ചാർഡ് സ്റ്റാൾമാൻ GNU പ്രോജക്റ്റ്; 1985: Free Software Foundation (FSF).
  • ⭐⭐⭐⭐⭐ 1991: ഫിൻലൻഡിലെ വിദ്യാർത്ഥി ലിനസ് ടോർവാൾഡ്സ് → Linux.
  • ⭐⭐⭐ 1998: Open Source എന്ന പദം (എറിക് റെയ്മണ്ട്, ബ്രൂസ് പെരൻസ് – Open Source Initiative).

🧠 Trick: "1843 അഡാ, 1958 ടൂക്കി, 1991 ലിനസ്" — കാലക്രമത്തിൽ 3 പ്രധാന നാഴികക്കല്ലുകൾ.

3. സോഫ്റ്റ്‌വെയർ വർഗ്ഗീകരണം (System vs Application)

സോഫ്റ്റ്‌വെയർ → 1) System Software, 2) Application Software (മൂന്നാമത്തേത് ചിലപ്പോൾ: Utility, Middleware – സിസ്റ്റം സോഫ്റ്റ്‌വെയറിന്റെ ഭാഗമായി കണക്കാക്കും.)

3.1 സിസ്റ്റം സോഫ്റ്റ്‌വെയർ (System Software)

ഹാർഡ്‌വെയറിനെ നിയന്ത്രിക്കാനും ആപ്ലിക്കേഷനുകൾക്ക് പ്രവർത്തിക്കാനുള്ള അടിത്തറ (Platform) ഒരുക്കാനുമുള്ളത്. ഇത് ഇല്ലാതെ കമ്പ്യൂട്ടർ പ്രവർത്തിക്കില്ല. 4 വിഭാഗം + ഫേംവെയർ:

(i) ഓപ്പറേറ്റിംഗ് സിസ്റ്റം (OS): Windows, Linux, macOS, Android, iOS.

(ii) ലാംഗ്വേജ് ട്രാൻസ്ലേറ്ററുകൾ: മനുഷ്യൻ എഴുതുന്ന ഭാഷയെ മെഷീൻ ഭാഷ (Binary 0,1 – Object Code) ആക്കുന്നു.

ട്രാൻസ്ലേറ്റർഎന്ത് മാറ്റുന്നുരീതി🧠 ട്രിക്ക്
AssemblerAssembly Language (ADD, SUB, MOV) → Machine–Assembler = Assembly
CompilerHigh-level (C, C++, Java) → Object Codeമുഴുവൻ ഒറ്റയടിക്ക്; എല്ലാ Syntax error-ഉം ഒരുമിച്ച്; വേഗത കൂടുതൽCompiler = Complete
InterpreterHigh-level (Python, BASIC, Ruby, JavaScript, PHP)ഓരോ വരിയായി; തെറ്റ് കണ്ടാൽ അവിടെ നിർത്തും; വേഗത കുറവ്Interpreter = Individual line
  • Java: ആദ്യം Compiler ഉപയോഗിച്ച് Bytecode ആക്കും, പിന്നെ JVM (Java Virtual Machine) ഇന്റർപ്രെറ്റ് ചെയ്യും.
  • Linker: പല Object file-കളെ ബന്ധിപ്പിച്ച് ഒറ്റ Executable file ആക്കുന്നു. Loader: പ്രോഗ്രാമിനെ ഹാർഡ് ഡിസ്കിൽ നിന്ന് RAM-ലേക്ക് കയറ്റുന്നു. Debugger: തെറ്റുകൾ കണ്ടുപിടിച്ച് തിരുത്താൻ സഹായിക്കുന്ന ടൂൾ.
  • പ്രോഗ്രാമിംഗ് ഭാഷാ തലമുറകൾ: 1GL = Machine language, 2GL = Assembly, 3GL = High-level (C, Java), 4GL = SQL, 5GL = AI ഭാഷകൾ (Prolog).
  • Source Code = പ്രോഗ്രാമർ എഴുതിയത്; Object Code = Compiler ഉണ്ടാക്കിയ മെഷീൻ കോഡ്.

(iii) ഡിവൈസ് ഡ്രൈവറുകൾ (Device Drivers): പ്രിന്റർ, സ്കാനർ, ഗ്രാഫിക്സ്/സൗണ്ട് കാർഡ്, വെബ്ക്യാം പോലുള്ളവയ്ക്ക് OS-മായി സംസാരിക്കാൻ സഹായിക്കുന്ന ചെറിയ പ്രോഗ്രാമുകൾ. 🧠 ഡ്രൈവർ = ഉപകരണത്തിന്റെ 'പരിഭാഷകൻ'.

(iv) യൂട്ടിലിറ്റി സോഫ്റ്റ്‌വെയർ (Utility): സുരക്ഷ, പരിപാലനം, വേഗത:

  • Antivirus: Kaspersky, Quick Heal, Avast, Norton, McAfee, Windows Defender
  • Disk Defragmenter: ചിതറിയ ഫയൽ ഭാഗങ്ങൾ ഒരുമിപ്പിച്ച് വേഗത കൂട്ടുന്നു
  • File Compression: WinZip, WinRAR, 7-Zip
  • Backup, Disk Cleanup, Task Manager, Scandisk/Check Disk, Disk Formatter

(v) ഫേംവെയർ (Firmware): ROM, EPROM, Flash chip-കളിൽ നിർമ്മാണ സമയത്തേ സ്ഥിരമായി ചേർത്ത സോഫ്റ്റ്‌വെയർ. ഉദാ: BIOS / UEFI, ടി.വി റിമോട്ട്, വാഷിംഗ് മെഷീൻ പ്രോഗ്രാം. 🧠 ഫേംവെയർ = ഹാർഡ്‌വെയറും സോഫ്റ്റ്‌വെയറും ചേർന്ന 'ഇടനില'.

3.2 ആപ്ലിക്കേഷൻ സോഫ്റ്റ്‌വെയർ

ഉപയോക്താവിന്റെ (End-user) ആവശ്യങ്ങൾക്കായി സിസ്റ്റം സോഫ്റ്റ്‌വെയറിന് മുകളിൽ ഇൻസ്റ്റാൾ ചെയ്യുന്ന 'ആപ്പുകൾ'.

  • General-Purpose (പൊതു): Word Processor (MS Word), Spreadsheet (Excel), Presentation (PowerPoint), DBMS (Access), Image Editors (Photoshop, GIMP), Browsers (Chrome, Firefox), Media Player (VLC).
  • Specific-Purpose / Tailored (പ്രത്യേക): റെയിൽവേ റിസർവേഷൻ, ബാങ്കിംഗ് (Finacle), അക്കൗണ്ടിംഗ് (Tally), സ്കൂൾ മാനേജ്‌മെന്റ്, ശമ്പള സോഫ്റ്റ്‌വെയർ SPARK.
  • Off-the-shelf (Packaged) = കടയിൽ വാങ്ങാവുന്ന റെഡിമെയ്ഡ്; Custom/Tailored = ഓർഡർ പ്രകാരം നിർമ്മിച്ചത്.

3.3 ലൈസൻസിംഗ് അടിസ്ഥാനമാക്കിയ വിഭാഗങ്ങൾ

വിഭാഗംസവിശേഷതഉദാഹരണം
FOSS (Free & Open Source)Source code കാണാം, ഉപയോഗിക്കാം, മാറ്റാം, വിതരണം ചെയ്യാം. Copyleft / GPL ലൈസൻസ്. ഉപജ്ഞാതാവ് റിച്ചാർഡ് സ്റ്റാൾമാൻ (FSF 1985, GNU)Linux (Ubuntu, Debian, BOSS), Android, LibreOffice, GIMP, Inkscape, Firefox, Python, MySQL, VLC
Proprietaryകമ്പനി ഉടമസ്ഥത, പണം നൽകി ലൈസൻസ്, source code രഹസ്യംWindows, macOS, iOS, MS Office, Photoshop, CorelDRAW, Oracle
Freewareസൗജന്യം, പക്ഷേ source code മാറ്റാൻ പറ്റില്ലGoogle Chrome, Skype, Adobe Acrobat Reader
Shareware / Trialwareനിശ്ചിത കാലം (ഉദാ: 30 ദിവസം) സൗജന്യം, പിന്നെ പണംWinZip, WinRAR
Public Domainപകർപ്പവകാശമില്ല, ആർക്കും എന്തും ചെയ്യാം–

🧠 Trick: Free = "സ്വാതന്ത്ര്യം" (Freedom), "വില ഇല്ല" എന്നല്ല (Free as in speech, not free beer). Freeware = കാണാം, തൊടാൻ പാടില്ല; FOSS = കാണാം, തൊടാം.

4. ഓപ്പറേറ്റിംഗ് സിസ്റ്റം (OS)

OS = ഉപയോക്താവിനും ഹാർഡ്‌വെയറിനും ഇടയിലെ മധ്യവർത്തി (Interface); എല്ലാ വിഭവങ്ങളെയും നിയന്ത്രിക്കുന്ന Resource Manager.

4.1 ഘടനയും ബൂട്ടിംഗും

  • Kernel: OS-ന്റെ ഹൃദയം/കാതൽ; ഹാർഡ്‌വെയറുമായി നേരിട്ട് സംവദിക്കുന്നു; ബൂട്ട് ചെയ്യുമ്പോൾ ആദ്യം RAM-ൽ കയറുന്നതും ഓഫ് ചെയ്യുംവരെ അവിടെ ഇരിക്കുന്നതും.
  • Shell: ഉപയോക്താവിന്റെ കമാൻഡ് കേർണലിന് മനസ്സിലാകുംവിധം മാറ്റുന്ന Command Interpreter. 🧠 Kernel = പരിപ്പ് (അകം), Shell = തോട് (പുറം).
  • Booting: കമ്പ്യൂട്ടർ ഓൺ ചെയ്യുമ്പോൾ ROM-ലെ BIOS ആദ്യം POST (Power-On Self-Test) നടത്തി ഹാർഡ്‌വെയർ പരിശോധിക്കും; പിന്നെ ഹാർഡ് ഡിസ്കിൽ നിന്ന് OS-നെ RAM-ലേക്ക് ലോഡ് ചെയ്യും.
  • BIOS = Basic Input Output System. ബൂട്ടിംഗ് തുടങ്ങിക്കൊടുക്കുന്ന ചെറിയ പ്രോഗ്രാം = Bootstrap Loader; ഹാർഡ് ഡിസ്കിലെ ബൂട്ട് വിവരം MBR (Master Boot Record) ൽ.
  • Cold / Hard Boot: പൂർണ്ണമായി ഓഫ് ആയതിനെ പവർ ബട്ടൺ അമർത്തി ഓൺ ചെയ്യുക. Warm / Soft Boot: ഓണായിരിക്കെ Restart (Ctrl+Alt+Del). 🧠 Cold = തണുത്തുറഞ്ഞ യന്ത്രം ഉണർത്തൽ; Warm = ഇപ്പോഴേ ചൂടുള്ളത്, വീണ്ടും തുടങ്ങൽ.

4.2 OS-ന്റെ 6 ധർമ്മങ്ങൾ

  1. Process Management (CPU): Process = പ്രവർത്തിക്കുന്ന പ്രോഗ്രാം. CPU സമയം വീതിക്കൽ (FCFS, Round Robin, Shortest Job Next); Multitasking. Deadlock = രണ്ടോ അതിലധികമോ process-കൾ പരസ്പരം വിഭവത്തിനായി കാത്ത് നിശ്ചലമാകൽ.
  2. Memory Management: RAM-ൽ സ്ഥലം അനുവദിക്കൽ/തിരിച്ചെടുക്കൽ; RAM തികയാതെ വരുമ്പോൾ ഹാർഡ് ഡിസ്ക് ഉപയോഗിക്കുന്ന Virtual Memory (Paging & Swapping).
  3. File Management: ഫയൽ/ഫോൾഡർ ക്രമീകരണം. File System: Windows – FAT32, NTFS; Linux – ext3, ext4.
  4. Device (I/O) Management: ഡ്രൈവറുകൾ വഴി ഉപകരണ നിയന്ത്രണം. Spooling = പ്രിന്റർ പോലുള്ള വേഗത കുറഞ്ഞവയ്ക്കുള്ള ഡാറ്റ ക്യൂ ആയി സൂക്ഷിക്കൽ.
  5. User Interface: CLI/CUI (MS-DOS, UNIX shell) vs GUI (WIMP = Windows, Icons, Menus, Pointer). GUI ആദ്യം വികസിപ്പിച്ചത് Xerox PARC-ൽ.
  6. Security & Access Control: പാസ്‌വേഡ്, ഫയർവാൾ, യൂസർ പെർമിഷൻ.

8. ഡാറ്റാബേസ് പാക്കേജുകൾ (DBMS)

DBMS = ബന്ധമുള്ള വലിയ ഡാറ്റ സൂക്ഷിക്കാനും തിരയാനും (Retrieve) മാറ്റാനും (Manipulate) നിയന്ത്രിക്കാനുമുള്ള സോഫ്റ്റ്‌വെയർ.

  • ഉദാഹരണങ്ങൾ: Oracle, MySQL, MS SQL Server, MS Access (.accdb / പഴയത് .mdb), LibreOffice Base (.odb), PostgreSQL, IBM DB2, FoxPro, dBASE, Sybase, Ingres; NoSQL: MongoDB.
  • ഡാറ്റാബേസ് മോഡലുകൾ (4): Relational, Hierarchical, Network, Object-Oriented. ഏറ്റവും പ്രചാരം: RDBMS – 1970, ഡോ. ഇ.എഫ്. കോഡ് (E.F. Codd); വിവരം പട്ടികകളായി (Tables/Relations).
  • ശ്രേണി (ചെറുത് → വലുത്): Bit → Byte (Character) → Field → Record → File (Table) → Database.

8.1 പദാവലി

  • Column = Field = Attribute; Row = Record = Tuple. 🧠 "T-R, A-C" (Tuple-Row, Attribute-Column).
  • Degree = കോളങ്ങളുടെ എണ്ണം; Cardinality = വരികളുടെ (Tuple) എണ്ണം.
  • DBA = Database Administrator; Schema = ഡാറ്റാബേസ് ഘടന; Data Redundancy = ഡാറ്റ അനാവശ്യമായി ആവർത്തിക്കൽ; Normalization = redundancy ഒഴിവാക്കാനുള്ള രീതി.

8.2 കീകൾ (Keys)

കീഅർത്ഥം
Primary Keyഓരോ റെക്കോർഡിനെയും തനതായി തിരിച്ചറിയും; ആവർത്തിക്കരുത് (Unique), NULL ആകരുത്. ഉദാ: ആധാർ, റോൾ നമ്പർ
Foreign Keyഒരു പട്ടികയുടെ Primary Key മറ്റൊന്നിൽ വരുമ്പോൾ; രണ്ട് പട്ടികകളെ ബന്ധിപ്പിക്കും (Referential Integrity); മൂല്യം ആവർത്തിക്കാം
Candidate KeyPrimary Key ആകാൻ യോഗ്യമായ എല്ലാ ഫീൽഡും
Alternate KeyCandidate-ൽ Primary ആക്കാത്തവ
Composite Keyഒന്നിലധികം ഫീൽഡ് ചേർന്ന കീ
Super Keyഒരു റെക്കോർഡിനെ തിരിച്ചറിയാൻ കഴിയുന്ന ഏതൊരു ഫീൽഡ് സെറ്റും

🧠 Trick: Primary = "പ്രധാന തിരിച്ചറിയൽ കാർഡ്"; Foreign = "വിദേശ (മറ്റൊരു പട്ടികയിലെ) ബന്ധം".

19. പ്രതീക്ഷിത ചോദ്യങ്ങൾ (Interactive MCQs)

1. ഏതാണ് Application Software?
ശരിയുത്തരം: (C) Word Processor
Windows, Linux = OS; Compiler = Translator (System Software). Word Processor മാത്രമാണ് Application Software.
2. ഹൈ-ലെവൽ പ്രോഗ്രാമിനെ ഒറ്റയടിക്ക് മെഷീൻ ഭാഷയാക്കുന്നത്?
ശരിയുത്തരം: (C) Compiler
Compiler = മുഴുവൻ ഒറ്റയടിക്ക്; Interpreter = വരി വരിയായി; Assembler = Assembly-ക്ക്; Loader = RAM-ലേക്ക് ലോഡ് ചെയ്യും.
3. OS-ന്റെ ഹൃദയം എന്ന് വിളിക്കുന്നത്?
ശരിയുത്തരം: (B) Kernel
Kernel = OS-ന്റെ ഹൃദയം/കാതൽ; Shell = Command Interpreter (തോട്); BIOS = Firmware.
4. Linux വികസിപ്പിച്ചത് ആര്?
ശരിയുത്തരം: (C) ലിനസ് ടോർവാൾഡ്സ്
Linux (1991) – ലിനസ് ടോർവാൾഡ്സ്; സ്റ്റാൾമാൻ = GNU/FSF; ബിൽ ഗേറ്റ്സ് = Microsoft; സ്റ്റീവ് ജോബ്സ് = Apple.
5. Word-ൽ Spell Check-നുള്ള ഷോർട്ട്കട്ട് കീ?
ശരിയുത്തരം: (B) F7
F7 = Spell Check; Shift+F7 = Thesaurus; F5 = (PPT-യിൽ) Slide Show; F12 = Save As.
6. Word-ൽ ഇരുവശവും ഒരുപോലെ അലൈൻ ചെയ്യാൻ (Justify) ഉപയോഗിക്കുന്ന കീ?
ശരിയുത്തരം: (D) Ctrl+J
Ctrl+L = Left; Ctrl+R = Right; Ctrl+E = Center; Ctrl+J = Justify.
7. Excel-ൽ ഏത് ചിഹ്നത്തോടെയാണ് ഫോർമുല തുടങ്ങേണ്ടത്?
ശരിയുത്തരം: (B) =
Excel-ൽ എല്ലാ ഫോർമുലയും '=' (സമം) ചിഹ്നത്തോടെ തുടങ്ങണം. (+ അല്ലെങ്കിൽ − ഉപയോഗിച്ചും തുടങ്ങാം, പക്ഷേ PSC-യുടെ ഉത്തരം '=').
8. Excel-ൽ പൂജ്യം കൊണ്ട് ഹരിച്ചാൽ വരുന്ന എറർ?
ശരിയുത്തരം: (C) #DIV/0!
#VALUE! = തെറ്റായ ഡാറ്റ തരം; #REF! = സെൽ ഡിലീറ്റ്; #NAME? = ഫംഗ്ഷൻ പേരിൽ തെറ്റ്.
9. സെൽ റഫറൻസ് $A$1 ഏത് തരം?
ശരിയുത്തരം: (B) Absolute
$A$1 = Absolute (കോപ്പി ചെയ്താലും മാറില്ല). A1 = Relative; $A1 അല്ലെങ്കിൽ A$1 = Mixed. F4 കീ മാറ്റി മാറ്റി തരും.
10. റെക്കോർഡിനെ തനതായി തിരിച്ചറിയുന്ന, NULL ആകാത്ത കീ?
ശരിയുത്തരം: (B) Primary Key
Primary Key = Unique + Not NULL. Foreign Key = മറ്റൊരു പട്ടികയുമായി ബന്ധിപ്പിക്കൽ (NULL ആകാം, ആവർത്തിക്കാം).
11. DBMS ശ്രേണിയിൽ ചെറുതിൽ നിന്ന് വലുതിലേക്ക് ക്രമം?
ശരിയുത്തരം: (B) Field → Record → File → Database
Bit → Byte → Field → Record → File (Table) → Database. 🧠 "ബിറ്റ് ബൈറ്റിന്റെ കൂടെ, ഫീൽഡ് റെക്കോർഡിന്റെ കൂടെ, ഫയൽ ഡാറ്റാബേസിന്റെ കൂടെ."

ശരിയുത്തരം: (B) Ctrl+M
Ctrl+M = പുതിയ സ്ലൈഡ് (More slide); Ctrl+N = പുതിയ ഫയൽ; Ctrl+S = Save; F5 = Slide Show.
13. Transparent background (സുതാര്യ പശ്ചാത്തലം) ഏത് ഇമേജ് ഫോർമാറ്റിൽ ലഭ്യമാണ്?

.psd = Photoshop Document; .xcf = GIMP; .cdr = CorelDRAW; .ai = Illustrator.
15. ഏതാണ് Open Source OS?
ശരിയുത്തരം: (C) Linux/Ubuntu
Linux/Ubuntu = Open Source (FOSS). Windows, iOS, MS-DOS = Proprietary.
16. Word-ൽ ബൈൻഡിംഗിനായി ഇടതുവശത്തോ മുകളിലോ അധികം വിടുന്ന മാർജിനിനെ എന്ത് വിളിക്കും?

Writer = .odt; Calc = .ods; Impress = .odp; Base = .odb.
18. SQL-ൽ പട്ടികയുടെ ഘടന നിർവ്വചിക്കുന്ന (CREATE, ALTER, DROP) കമാൻഡുകൾ ഏത് വിഭാഗത്തിൽ?

ശരിയുത്തരം: (B) Degree
Degree = കോളം എണ്ണം; Cardinality = വരി (Tuple) എണ്ണം. 🧠 Degree = Column (D-C), Cardinality = Count of rows.
20. RGB കളർ മോഡൽ എന്തിനാണ് ഉപയോഗിക്കുന്നത്?

RGB (Red, Green, Blue) = സ്ക്രീൻ/മോണിറ്റർ; CMYK (Cyan, Magenta, Yellow, Key/Black) = പ്രിന്റിംഗ്. 🧠 RGB = Screen-ൽ വെളിച്ചം; CMYK = കടലാസിൽ മഷി.
21. Android-ന്റെ അടിസ്ഥാന കേർണൽ ഏതാണ്?
ശരിയുത്തരം: (C) Linux
Android = Linux കേർണൽ അടിസ്ഥാനം (Open Source). iOS/macOS = UNIX അടിസ്ഥാനം (Proprietary); Windows = NT കേർണൽ.
22. Excel-ൽ സംഖ്യകൾ ഡിഫോൾട്ടായി ഏത് വശത്തേക്ക് അലൈൻ ചെയ്യും?

23. MS Word 2007 മുതലുള്ള ഡിഫോൾട്ട് ഫോണ്ട് ഏതാണ്?

24. Mail Merge-ൽ ഉൾപ്പെടുന്ന ഘടകങ്ങൾ ഏവ?
ശരിയുത്തരം: (B) Main Document + Data Source
Mail Merge = ഒരേ കത്ത് പലരുടെ പേര്/വിലാസത്തിൽ. Main Document (കത്തിന്റെ ഫോർമാറ്റ്) + Data Source (പേരുകളുടെ പട്ടിക) ചേർത്ത് ഓരോ വ്യക്തിക്കും പ്രത്യേക കത്ത് ഉണ്ടാക്കുന്നു.
25. BOSS (Bharat Operating System Solutions) വികസിപ്പിച്ചത് ആര്?
