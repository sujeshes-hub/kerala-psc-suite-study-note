2. പിന്നാമ്പുറ കഥ (Behind the Story)

➕ വീടുപണി ഉദാഹരണം
വീട് പണിയിൽകമ്പ്യൂട്ടർ ലോകത്ത്
ഇഷ്ടിക, സിമന്റ്: ഭിത്തിയും മുറികളും വാതിലുംHTML: പേജിന്റെ ഘടന (Structure)
പെയിന്റും കർട്ടനും: ഭംഗിCSS: ഭംഗി, നിറം, ലേഔട്ട് (Style)
സ്വിച്ച് ഇട്ടാൽ ലൈറ്റ് കത്തുന്ന വയറിംഗ്JavaScript: പ്രവർത്തനം (Behaviour)
മുറിയിലെ സാധനങ്ങൾ രേഖപ്പെടുത്തിയ ലിസ്റ്റ്XML: വിവരം സൂക്ഷിക്കാനും കൈമാറാനും
ചുറ്റുമതിൽ + ഗേറ്റിലെ കാവൽക്കാരൻFirewall & സൈബർ സുരക്ഷ
കള്ളൻ കയറിയാൽ പോലീസും നിയമവുംഐ.ടി ആക്ട് 2000
ഒരൊറ്റ കൗണ്ടറിൽ എല്ലാ ബില്ലും അടയ്ക്കൽFRIENDS / അക്ഷയ / K-SMART (ഇ-ഗവേണൻസ്)
🧠 "ഘടന-ഭംഗി-ചലനം" = HTML – CSS – JavaScript (വീടിന്റെ ഭിത്തി – പെയിന്റ് – വയറിംഗ്)
➕ ഐ.ടി ആക്ടിന്റെ പിന്നിലെ കഥ

1990-കളിൽ ഇന്റർനെറ്റ് ഇന്ത്യയിൽ എത്തി (VSNL വഴി 1995 ഓഗസ്റ്റ് 15). അപ്പോൾ ഒരു പ്രശ്നം: കടലാസിലെ ഒപ്പിനും രേഖയ്ക്കും മാത്രമേ കോടതിയിൽ വിലയുണ്ടായിരുന്നുള്ളൂ. ഇ-മെയിലിനോ ഓൺലൈൻ കരാറിനോ നിയമസാധുത ഇല്ല. അങ്ങനെ ഐക്യരാഷ്ട്രസഭയുടെ UNCITRAL മാതൃകാ നിയമം (1996) അടിസ്ഥാനമാക്കി ഇന്ത്യ ഒരു നിയമം കൊണ്ടുവന്നു:

  • പാർലമെന്റ് പാസാക്കി: 2000 മെയ് (രാജ്യസഭ 17 മെയ്)
  • രാഷ്ട്രപതി കെ.ആർ. നാരായണൻ (മലയാളി) ഒപ്പുവെച്ചു: 2000 ജൂൺ 9
  • പ്രാബല്യത്തിൽ വന്നു: 2000 ഒക്ടോബർ 17
🧠 "ഒപ്പ് ജൂൺ (9), പ്രാബല്യം ഒക്ടോബർ (17)": ഒപ്പിട്ടത് നാരായണൻ, നടപ്പായത് ഒക്ടോബറിൽ.

WWW (World Wide Web)ഇന്റർനെറ്റിലെ പരസ്പരം ലിങ്ക് ചെയ്ത വെബ് പേജുകളുടെ ശേഖരം. ടിം ബർണേഴ്സ് ലീ (CERN) 1989-ൽ നിർദ്ദേശിച്ചു; ആദ്യ വെബ്സൈറ്റ് 1991
ഇന്റർനെറ്റ് ≠ വെബ്ഇന്റർനെറ്റ് = നെറ്റ്‌വർക്കുകളുടെ ശൃംഖല (റോഡ്). വെബ് = അതിലൂടെ ലഭിക്കുന്ന ഒരു സേവനം (വാഹനം)
വെബ് ബ്രൗസർവെബ് പേജ് കാണിക്കുന്ന സോഫ്റ്റ്‌വെയർ (Chrome, Firefox, Edge, Safari)
വെബ് സെർവർവെബ്സൈറ്റ് ഫയലുകൾ സൂക്ഷിച്ച് ബ്രൗസറിന് നൽകുന്ന കമ്പ്യൂട്ടർ
URLവെബ് പേജിന്റെ വിലാസം (Uniform Resource Locator)
HTTP / HTTPSവെബ് പേജ് കൈമാറുന്ന പ്രോട്ടോക്കോൾ. HTTPS = സുരക്ഷിതം (SSL/TLS എൻക്രിപ്ഷൻ)
ഡൊമെയ്ൻ നാമംexample.com പോലുള്ള പേര്. DNS ഇതിനെ IP വിലാസമാക്കി മാറ്റുന്നു
സ്റ്റാറ്റിക് പേജ്ഉള്ളടക്കം മാറാത്ത പേജ് (HTML/CSS മാത്രം)
ഡൈനാമിക് പേജ്ഉപയോക്താവിനും ഡാറ്റാബേസിനും അനുസരിച്ച് മാറുന്ന പേജ് (PHP, ASP, JSP)
ഹോം പേജ്വെബ്സൈറ്റിന്റെ ആദ്യ പേജ്
🧠 ഇന്റർനെറ്റ് = റോഡ്, വെബ് = അതിലെ വാഹനം. വെബ് പേജ് "നൽകുന്നത്" സെർവർ, "കാണിക്കുന്നത്" ബ്രൗസർ.

5.1 വെബ് ഡിസൈനിംഗിലെ അടിസ്ഥാന സാങ്കേതികവിദ്യകൾ

  • HTML (HyperText Markup Language): വെബ് പേജിന്റെ അടിസ്ഥാന ഘടന (Skeleton) നിർമ്മിക്കാൻ ടിം ബർണേഴ്സ് ലീ വികസിപ്പിച്ച മാർക്കപ്പ് ഭാഷ (ആദ്യ വിവരണം 1991). ഇത് പ്രോഗ്രാമിംഗ് ഭാഷയല്ല, മാർക്കപ്പ് ഭാഷയാണ്. ഏറ്റവും പുതിയ പതിപ്പ് HTML5. ഫയൽ എക്സ്റ്റൻഷൻ .html / .htm. HTML Case-insensitive ആണ്.
  • CSS (Cascading Style Sheets): നിറം, ഫോണ്ട്, ലേഔട്ട്, അനിമേഷൻ നൽകുന്ന സ്റ്റൈൽ ഷീറ്റ് ഭാഷ. ഹക്കോൺ വിയം ലീ (Håkon Wium Lie) 1994-ൽ നിർദ്ദേശിച്ചു; CSS1 ഔദ്യോഗികമായി 1996. ഫയൽ എക്സ്റ്റൻഷൻ .css.
  • XML (eXtensible Markup Language): വിവരം സൂക്ഷിക്കാനും കൈമാറാനും (Store & Transport) ഉപയോഗിക്കുന്നു, പ്രദർശിപ്പിക്കാനല്ല. സ്വന്തം ടാഗുകൾ ഉണ്ടാക്കാം (Extensible). XML Case-sensitive ആണ്, എല്ലാ ടാഗും അടയ്ക്കണം.
  • സ്ക്രിപ്റ്റിംഗ് ഭാഷകൾ:
    • ക്ലയന്റ്-സൈഡ് (ബ്രൗസറിൽ പ്രവർത്തിക്കുന്നു): JavaScript (1995, ബ്രെൻഡൻ ഐക്ക്, Netscape), VBScript.
    • സെർവർ-സൈഡ് (സെർവറിൽ പ്രവർത്തിക്കുന്നു): PHP, Python, ASP.NET, JSP, Ruby, Node.js.
🧠 "Client = Customer's browser, Server = Shop's computer." JavaScript ഉപഭോക്താവിന്റെ ബ്രൗസറിൽ, PHP കടയിലെ (സെർവറിലെ) കമ്പ്യൂട്ടറിൽ.

🧠 "I-I-E" = ഇൻലൈൻ (ഒന്നിന്), ഇന്റേണൽ (ഒരു പേജിന്), എക്സ്റ്റേണൽ (എല്ലാത്തിനും)

5.2 HTML പേജിന്റെ അടിസ്ഥാന ഘടന

<!DOCTYPE html>
<html>
  <head>
    <title>എന്റെ ആദ്യ പേജ്</title>
    <meta charset="UTF-8">
  </head>
  <body>
    <h1>ഹലോ</h1>
    <p>ഇതൊരു പാരഗ്രാഫ് ആണ്.</p>
  </body>
</html>
  • <title>: ബ്രൗസർ ടാബിൽ കാണുന്ന പേര് (<head>-ൽ മാത്രം).
  • <meta>: വെബ് പേജിനെക്കുറിച്ചുള്ള വിവരം (character set, keywords, description). Empty tag.
  • Comment: <!-- ഇതൊരു കമന്റ് --> (ബ്രൗസറിൽ കാണില്ല).
🧠 Head = തല (തലക്കെട്ട്/മെറ്റാ വിവരം, കാണില്ല), Body = ശരീരം (കാണുന്നത് എല്ലാം)

5.3 കണ്ടെയ്നർ ടാഗും എംപ്റ്റി ടാഗും

തരംഅർത്ഥംഉദാഹരണം
കണ്ടെയ്നർ ടാഗ് (Container / Paired tag)തുടക്ക ടാഗും ഒടുക്ക ടാഗും ഉണ്ട്. ഉള്ളടക്കം ഇടയിൽ<p>...</p>, <b>...</b>, <h1>...</h1>, <table>...</table>, <a>...</a>
എംപ്റ്റി ടാഗ് (Empty / Unpaired tag)ഒടുക്ക ടാഗ് ഇല്ല; ഉള്ളടക്കം ഇല്ല<br>, <hr>, <img>, <input>, <meta>, <link>
🧠 "BHI-IML" → ബ്ര (br), ഹ (hr), ഇ (img), ഇൻ (input), മെ (meta), ലി (link); അല്ലെങ്കിൽ "വര, വരി, ചിത്രം, ഇൻപുട്ട്" = ഒറ്റയ്ക്ക് നിൽക്കും.

5.4 പ്രധാന HTML ടാഗുകളും ആട്രിബ്യൂട്ടുകളും

⭐ ഡോക്യുമെന്റ് ഘടനാ ടാഗുകൾ
  • <!DOCTYPE html>: HTML5 ആണെന്ന് ബ്രൗസറിനെ അറിയിക്കുന്നു (ഇതൊരു ടാഗല്ല, declaration ആണ്).
  • <html>...</html>: റൂട്ട് എലമെന്റ്. <head>: തലക്കെട്ടും മെറ്റാ വിവരവും. <body>: കാണുന്ന ഉള്ളടക്കം.
  • <body> ആട്രിബ്യൂട്ടുകൾ: bgcolor (പശ്ചാത്തല നിറം), background (പശ്ചാത്തല ചിത്രം), text (അക്ഷര നിറം), link (സന്ദർശിക്കാത്ത ലിങ്ക് – നീല), vlink (സന്ദർശിച്ച ലിങ്ക് – വയലറ്റ്/പർപ്പിൾ), alink (ക്ലിക്ക് ചെയ്യുമ്പോൾ – ചുവപ്പ്).
🧠 "നീല → വയലറ്റ് → ചുവപ്പ്" = ലിങ്ക് കാണുമ്പോൾ നീല, പോയി വന്നാൽ വയലറ്റ്, ക്ലിക്കുമ്പോൾ ചുവപ്പ്. (L-V-A: link, vlink, alink)
➕ ടെക്സ്റ്റ് ഫോർമാറ്റിംഗ് ടാഗുകൾ
  • <h1>–<h6>: ഹെഡിംഗുകൾ. <h1> ഏറ്റവും വലുത്, <h6> ഏറ്റവും ചെറുത്.
  • <p>: പാരഗ്രാഫ് | <br>: പുതിയ വരി (Empty) | <hr>: വിലങ്ങനെ വര (Empty).
  • <b> / <strong>: Bold | <i> / <em>: Italic | <u>: Underline | <strike> / <del>: Strikethrough.
  • <sup>: ഉയർത്തി എഴുതൽ (a²) | <sub>: താഴ്ത്തി എഴുതൽ (H₂O).
  • <pre>: എഴുതിയ അതേ രൂപത്തിൽ കാണിക്കുന്നു | <center>: മധ്യത്തിൽ | <font>: ഫോണ്ട് (പഴയത്).
  • <marquee>: എഴുത്ത്/ചിത്രം തനിയെ നീങ്ങാൻ (Scrolling text).

⚠️ <marquee>, <strike>, <center>, <font> എന്നിവ HTML5-ൽ ഒഴിവാക്കിയ (Deprecated) ടാഗുകളാണ്. പക്ഷേ PSC ചോദ്യങ്ങളിൽ ഇപ്പോഴും വരാം.

➕ ലിങ്കുകളും ചിത്രങ്ങളും
  • <a> (Anchor): <a href="url">Text</a>. പുതിയ ടാബിൽ തുറക്കാൻ target="_blank". ഇ-മെയിൽ ലിങ്ക്: href="mailto:abc@xyz.com".
  • <img> (Empty): <img src="pic.jpg" alt="വിവരണം" width="100" height="100">. src = ചിത്രത്തിന്റെ സ്ഥാനം (Source), alt = ചിത്രം ലോഡ് ആയില്ലെങ്കിൽ കാണിക്കുന്ന ബദൽ ടെക്സ്റ്റ് (Alternate text).
🧠 a href = "ഹ്രസ്വമായി ഹൈപ്പർ റഫറൻസ്" (Hypertext REFerence); img src = "സോഴ്സ്".

3 തരം ലിസ്റ്റുകൾ

  1. <ol> (Ordered List): 1, 2, 3 / A, B, C / i, ii, iii. type ആട്രിബ്യൂട്ട്: 1, A, a, I, i.
  2. <ul> (Unordered List): ബുള്ളറ്റ് (Disc, Circle, Square).
  3. <dl> (Description List): <dt> (പദം), <dd> (വിവരണം).

രണ്ട് ലിസ്റ്റിലും ഇനങ്ങൾക്ക് <li> ഉപയോഗിക്കുന്നു.

🧠 OL = Ordered = അക്കം, UL = Unordered = ഉണ്ട (ബുള്ളറ്റ്)

ടേബിൾ ടാഗുകൾ

  • <table> (പട്ടിക), <caption> (തലക്കെട്ട്), <tr> (വരി), <th> (തലക്കെട്ട് കളം: Bold + Center), <td> (ഡാറ്റ കളം).
  • ആട്രിബ്യൂട്ടുകൾ: border (അതിര്), rowspan (വരികൾ ഒന്നിപ്പിക്കാൻ), colspan (കോളങ്ങൾ ഒന്നിപ്പിക്കാൻ), cellpadding (കളത്തിനുള്ളിലെ വിടവ്), cellspacing (കളങ്ങൾ തമ്മിലുള്ള വിടവ്).
🧠 TR = Row (വരി), TH = Header (തല), TD = Data (ഡാറ്റ); Row = വിലങ്ങനെ, Col = കുത്തനെ

ഫോം ടാഗുകൾ

  • <form>: വിവരം ശേഖരിക്കാനുള്ള ഫോം. ആട്രിബ്യൂട്ടുകൾ: action (വിവരം അയക്കേണ്ട സ്ഥലം), method (GET / POST).
  • <input> (Empty): type="text" (ടെക്സ്റ്റ് ബോക്സ്), "password", "radio" (ഒരെണ്ണം മാത്രം), "checkbox" (ഒന്നിലധികം), "submit", "reset", "button".
  • <select> + <option>: ഡ്രോപ്പ്-ഡൗൺ ലിസ്റ്റ് (HTML-ൽ <dropdown> എന്ന ടാഗ് ഇല്ല).
  • <textarea>: ഒന്നിലധികം വരിയുള്ള ടെക്സ്റ്റ് ബോക്സ് (rows, cols).
  • <label>: ഇൻപുട്ടിന്റെ ലേബൽ.
🧠 Radio = പഴയ റേഡിയോയിലെ ബട്ടൺ (ഒന്ന് അമർത്തിയാൽ മറ്റത് പൊങ്ങും → ഒരെണ്ണം മാത്രം); Checkbox = ഷോപ്പിംഗ് ലിസ്റ്റിൽ ടിക്ക് (പലതും ടിക്ക് ചെയ്യാം)
➕ മറ്റു ടാഗുകളും HTML5 പുതിയ സെമാന്റിക് ടാഗുകളും
  • <div> (ബ്ലോക്ക് വിഭാഗം), <span> (വരിക്കുള്ളിലെ ഭാഗം), <iframe> (പേജിനുള്ളിൽ മറ്റൊരു പേജ്), <audio>, <video>, <canvas> (HTML5), <link> (CSS ബന്ധിപ്പിക്കാൻ), <script> (JavaScript).
  • HTML5-ലെ പുതിയ സെമാന്റിക് ടാഗുകൾ: <header>, <footer>, <nav>, <section>, <article>, <aside>, <main>. HTML5 W3C ശുപാർശ: 2014 ഒക്ടോബർ. (HTML 4.01: 1999.)
  • ആട്രിബ്യൂട്ട് (Attribute): ടാഗിന് കൂടുതൽ വിവരം നൽകുന്ന ഭാഗം. name="value" രൂപത്തിൽ, തുടക്ക ടാഗിൽ മാത്രം. ഉദാ: href, src, alt, width, height, id, class, style, title.
➕ HTML നിറങ്ങളും എന്റിറ്റികളും
  • നിറങ്ങൾക്ക് #RRGGBB ഹെക്സാഡെസിമൽ കോഡ്: #000000 = കറുപ്പ്, #FFFFFF = വെള്ള, #FF0000 = ചുവപ്പ്, #00FF00 = പച്ച, #0000FF = നീല.
  • ക്യാരക്ടർ എന്റിറ്റികൾ: &nbsp; (ബ്രേക്ക് ആകാത്ത സ്പേസ്), &lt; (<), &gt; (>), &amp; (&), &copy; (©).
🧠 R-G-B = ചുവപ്പ്-പച്ച-നീല; എല്ലാം പൂജ്യം = ഇരുട്ട് (കറുപ്പ്), എല്ലാം F = വെളിച്ചം (വെള്ള).

6.1 അടിസ്ഥാന ആശയങ്ങൾ

  • പ്രോഗ്രാം: ഒരു ജോലി ചെയ്യാൻ കമ്പ്യൂട്ടറിന് നൽകുന്ന ക്രമീകൃത നിർദ്ദേശങ്ങളുടെ (Instructions) കൂട്ടം. എഴുതുന്ന പ്രക്രിയ = പ്രോഗ്രാമിംഗ്/കോഡിംഗ്; എഴുതുന്നയാൾ = പ്രോഗ്രാമർ.
  • അൽഗോരിതം (Algorithm): പ്രശ്നം പരിഹരിക്കാനുള്ള പടിപടിയായ (Step-by-step) യുക്തിപരമായ നിർദ്ദേശങ്ങൾ. പേര് അൽ-ഖ്വാരിസ്മി (പേർഷ്യൻ ഗണിതജ്ഞൻ) എന്ന പേരിൽ നിന്ന്. ഉദാ: ചായ ഉണ്ടാക്കാനുള്ള ഘട്ടങ്ങൾ.
    • നല്ല അൽഗോരിതത്തിന്റെ ഗുണങ്ങൾ: Finiteness (അവസാനിക്കണം), Definiteness (വ്യക്തത), Input (0 അല്ലെങ്കിൽ കൂടുതൽ), Output (കുറഞ്ഞത് 1), Effectiveness (പ്രായോഗികം).
  • ഫ്ലോചാർട്ട് (Flowchart): അൽഗോരിതത്തിന്റെ ചിത്രരൂപം, ചിഹ്നങ്ങളും അമ്പടയാളങ്ങളും ഉപയോഗിച്ച്.

  • ബഗ്ഗ് & ഡീബഗ്ഗിംഗ്: പ്രോഗ്രാമിലെ തെറ്റ് = Bug; തിരുത്തുന്ന പ്രക്രിയ = Debugging. 1947-ൽ ഹാർവാർഡ് Mark II കമ്പ്യൂട്ടറിൽ ഒരു നിശാശലഭം (Moth) കുടുങ്ങി; ഗ്രേസ് ഹോപ്പറുടെ ടീം ആ സംഭവം പ്രശസ്തമാക്കി.

എറർഎപ്പോൾ?ഉദാഹരണം
Syntax Errorഭാഷയുടെ വ്യാകരണം തെറ്റുമ്പോൾ. കംപൈലർ കണ്ടെത്തും, പ്രോഗ്രാം ഓടില്ലസെമികോളൻ വിട്ടുപോകൽ
Logical Errorപ്രോഗ്രാം ഓടും, പക്ഷേ ഉത്തരം തെറ്റ്. കണ്ടെത്താൻ ഏറ്റവും പ്രയാസംകൂട്ടേണ്ടിടത്ത് കുറയ്ക്കൽ
Runtime Errorഓടുന്നതിനിടെ പരാജയപ്പെടുംപൂജ്യം കൊണ്ട് ഹരിക്കൽ
  • പ്രോഗ്രാമിംഗിന്റെ 3 അടിസ്ഥാന നിർമ്മിതികൾ (Control structures): Sequence (ക്രമം), Selection (തിരഞ്ഞെടുക്കൽ: IF), Iteration (ആവർത്തനം: LOOP).

ഭാഷാ തലങ്ങൾ & ട്രാൻസ്ലേറ്ററുകൾ

തരംവിവരണം
മെഷീൻ ഭാഷ (Low-level)0, 1 മാത്രം. കമ്പ്യൂട്ടറിന് നേരിട്ട് മനസ്സിലാകും
അസംബ്ലി ഭാഷചുരുക്കെഴുത്തുകൾ (ADD, MOV). Assembler മെഷീൻ ഭാഷയാക്കും
ഹൈ-ലെവൽ ഭാഷമനുഷ്യർക്ക് വായിക്കാവുന്നത് (C, Java, Python). Compiler / Interpreter വേണം
Compilerമുഴുവൻ പ്രോഗ്രാമും ഒരുമിച്ച് മെഷീൻ കോഡാക്കും; എററുകൾ ലിസ്റ്റായി കാണിക്കും
Interpreterവരി വരിയായി വിവർത്തനം ചെയ്ത് ഓടിക്കും; എറർ കണ്ടാൽ അവിടെ നിൽക്കും
🧠 Compiler = Translator-ന്റെ "പുസ്തകം മുഴുവൻ ഒറ്റയടിക്ക്", Interpreter = "ഒരു വരി, ഒരു വിവർത്തനം (ലൈവ് പരിഭാഷ)"

6.2 പ്രോഗ്രാമിംഗ് നിർദ്ദേശങ്ങൾ (10.3.2–10.3.6)

സിലബസ് കോഡ്നിർദ്ദേശ വിഭാഗംധർമ്മവും ഉദാഹരണവും🧠 ഓർമ്മ
10.3.2Input (ഇൻപുട്ട്)കീബോർഡ്, മൗസ് തുടങ്ങിയവയിൽ നിന്ന് ഡാറ്റ അകത്തേക്ക് വാങ്ങുന്നു. INPUT, READ, ACCEPT, SCANഇൻ = അകത്ത്: READ
10.3.3Output (ഔട്ട്പുട്ട്)ഫലം മോണിറ്റർ/പ്രിന്ററിൽ പുറത്തേക്ക് കാണിക്കുന്നു. PRINT, WRITE, DISPLAY, SHOWഔട്ട് = പുറത്ത്: PRINT
10.3.4Store (സ്റ്റോർ/അസൈൻമെന്റ്)മൂല്യമോ കണക്കുകൂട്ടൽ ഫലമോ മെമ്മറിയിലെ വേരിയബിളിൽ സൂക്ഷിക്കുന്നു. LET A = 10, SUM = A + B, MOVസ്റ്റോർ = അലമാരയിൽ വെക്കൽ: =
10.3.5Control (നിയന്ത്രണം)തീരുമാനമെടുക്കൽ (IF…THEN…ELSE) + ആവർത്തനം (FOR, WHILE, REPEAT)കൺട്രോൾ = ട്രാഫിക് പോലീസ്: IF / LOOP
10.3.6Transfer (ട്രാൻസ്ഫർ/ജമ്പ്)ക്രമത്തിൽ ഓടുന്നതിന് പകരം മറ്റൊരു വരിയിലേക്കോ ഉപപ്രോഗ്രാമിലേക്കോ ചാടുന്നു. GOTO, JUMP, CALL, RETURN, BREAKട്രാൻസ്ഫർ = ചാട്ടം: GOTO
⭐ പ്രധാന കുറിപ്പ്

സിലബസ് വാചകത്തിൽ "Control transfer" ഒറ്റ പദമാണ്. അതുകൊണ്ട് ചില ചോദ്യ ഉറവിടങ്ങളിൽ 4 തരം: Input, Output, Store, Control Transfer എന്നും വരാം. നിങ്ങൾ 5 ആയി പഠിച്ചാൽ രണ്ട് രീതിയും ഉത്തരം കിട്ടും. ഓപ്ഷനിൽ "Control Transfer" കണ്ടാൽ അത് Control + Transfer രണ്ടും ഉൾക്കൊള്ളുന്നതായി കരുതുക.

🧠 "IOS-CT" → ഇൻപുട്ട്, ഔട്ട്പുട്ട്, സ്റ്റോർ, കൺട്രോൾ, ട്രാൻസ്ഫർ. കഥ: "വാങ്ങി (Input) → വെച്ചു (Store) → തീരുമാനിച്ചു (Control) → ചാടി (Transfer) → കാണിച്ചു (Output)".

7. ഇ-ഗവേണൻസ്: ദേശീയ-കേരള പദ്ധതികൾ (10.6.1, 10.6.2 & 5.19)

ഇ-ഗവേണൻസ് (Electronic Governance): സർക്കാർ സേവനങ്ങളും വിവരങ്ങളും ICT (Information & Communication Technology) ഉപയോഗിച്ച് പൗരന്മാരിലേക്കും സ്ഥാപനങ്ങളിലേക്കും വേഗത്തിലും സുതാര്യമായും എത്തിക്കുന്ന ഭരണം. ലക്ഷ്യങ്ങൾ: അഴിമതി കുറയ്ക്കുക, കാലതാമസം ഒഴിവാക്കുക, ഇടനിലക്കാരെ ഒഴിവാക്കുക, 24x7 സേവനം.

⭐ SMART Governance

Simple, Moral, Accountable, Responsive, Transparent.

7.1 നേട്ടങ്ങളും വെല്ലുവിളികളും

നേട്ടങ്ങൾവെല്ലുവിളികൾ
സുതാര്യത, അഴിമതി കുറവ്, സമയലാഭം, ചെലവ് കുറവ്, 24x7 ലഭ്യതഡിജിറ്റൽ വിഭജനം (Digital Divide), ഡിജിറ്റൽ നിരക്ഷരത, ഇന്റർനെറ്റ് ലഭ്യതക്കുറവ്, സൈബർ സുരക്ഷ, സ്വകാര്യത, ഭാഷാ തടസ്സം

7.2 ഇ-ഗവേണൻസിന്റെ 4 ഘട്ടങ്ങൾ

Information (വിവരം നൽകൽ) → Interaction (ഇടപെടൽ) → Transaction (ഇടപാട്/പണമടയ്ക്കൽ) → Transformation (പൂർണ്ണ മാറ്റം).

🧠 "I-I-T-T": വിവരം, ഇടപെടൽ, ഇടപാട്, രൂപാന്തരം.

7.3 ഇ-ഗവേണൻസിലെ 4 മാതൃകകൾ

  1. G2C (Government to Citizen): പൗരന് സേവനം (സർട്ടിഫിക്കറ്റ്, നികുതി, ബിൽ, പെൻഷൻ). ഉദാ: അക്ഷയ, ഫ്രണ്ട്സ്, ഇ-ഡിസ്ട്രിക്റ്റ്, K-SMART, DigiLocker, UMANG.
  2. G2B (Government to Business): വ്യവസായ ലൈസൻസ്, ഇ-ടെൻഡർ, GST പോർട്ടൽ, MCA21, GeM.
  3. G2G (Government to Government): വകുപ്പുകൾ തമ്മിൽ. ഉദാ: ഇ-ഓഫീസ്, K-SWAN, CCTNS.
  4. G2E (Government to Employee): ജീവനക്കാർക്ക്. ഉദാ: SPARK (കേരളം), ജീവൻ പ്രമാൺ, ഐ-ഗോട്ട് കർമ്മയോഗി.
🧠 "C-B-G-E" = പൗരൻ, ബിസിനസ്, ഗവൺമെന്റ്, ജീവനക്കാരൻ; SPARK = "ശമ്പളത്തിന്റെ തീപ്പൊരി" → ജീവനക്കാർക്ക് (G2E).

7.4 ഇന്ത്യയിലെ പ്രധാന പദ്ധതികൾ

  • NeGP (National e-Governance Plan): 2006 മെയ് 18. മുദ്രാവാക്യം: "Public Services Closer Home". e-Kranti = NeGP 2.0.
  • ഡിജിറ്റൽ ഇന്ത്യ (Digital India): 2015 ജൂലൈ 1-ന് പ്രധാനമന്ത്രി നരേന്ദ്ര മോദി ഉദ്ഘാടനം ചെയ്തു. മുദ്രാവാക്യം: "Power to Empower". 3 ദർശന മേഖലകൾ: ഡിജിറ്റൽ അടിസ്ഥാന സൗകര്യം, ഭരണവും സേവനങ്ങളും ആവശ്യാനുസരണം, പൗരന്മാരുടെ ഡിജിറ്റൽ ശാക്തീകരണം.
    • 9 തൂണുകൾ: Broadband Highways, Universal Access to Mobile Connectivity, Public Internet Access Programme, e-Governance, e-Kranti, Information for All, Electronics Manufacturing, IT for Jobs, Early Harvest Programmes.
  • UMANG: കേന്ദ്ര-സംസ്ഥാന സേവനങ്ങൾ ഒരു മൊബൈൽ ആപ്പിൽ (2017).
  • DigiLocker: ആധാർ, ലൈസൻസ്, RC, സർട്ടിഫിക്കറ്റ് തുടങ്ങിയവ ഡിജിറ്റലായി ക്ലൗഡിൽ (2015).
  • മറ്റുള്ളവ: PRAGATI (Pro-Active Governance And Timely Implementation), ജീവൻ പ്രമാൺ (പെൻഷൻകാർക്ക് ബയോമെട്രിക് ഡിജിറ്റൽ ലൈഫ് സർട്ടിഫിക്കറ്റ്, 2014), MyGov, GeM (Government e-Marketplace, 2016), e-NAM, BHIM-UPI, ആധാർ (UIDAI), e-Courts.

7.5 കേരളത്തിലെ ഇ-ഗവേണൻസ്

  • CIA Triad: Confidentiality (രഹസ്യസ്വഭാവം: അധികാരമുള്ളവർക്ക് മാത്രം), Integrity (സമഗ്രത: അനധികൃത മാറ്റം പാടില്ല), Availability (ലഭ്യത: വേണ്ടപ്പോൾ കിട്ടണം). Robustness ഇതിൽ പെടില്ല.
    • അധികം: Authentication (ആരാണെന്ന് ഉറപ്പിക്കൽ), Authorization (എന്ത് ചെയ്യാൻ അനുമതി), Non-repudiation (നിഷേധിക്കാൻ പറ്റാത്ത തെളിവ്; ഡിജിറ്റൽ ഒപ്പ് ഇതിനാണ്).
  • പ്രധാന ദിനങ്ങൾ: ലോക കമ്പ്യൂട്ടർ സുരക്ഷാ ദിനം നവംബർ 30 (1988-ലെ Morris Worm-ന് ശേഷം ACM ആരംഭിച്ചു). ഡിസംബർ 2 = കമ്പ്യൂട്ടർ സാക്ഷരതാ ദിനം. ദേശീയ സൈബർ സുരക്ഷാ ബോധവത്കരണ മാസം: ഒക്ടോബർ. Safer Internet Day: ഫെബ്രുവരിയിലെ രണ്ടാം ചൊവ്വ.
  • ഫയർവാൾ (Firewall): സ്വകാര്യ കമ്പ്യൂട്ടറിനും/നെറ്റ്‌വർക്കിനും ഇന്റർനെറ്റിനും ഇടയിലെ സുരക്ഷാ മതിൽ; ഇൻകമിംഗ്/ഔട്ട്ഗോയിംഗ് ട്രാഫിക് പരിശോധിച്ച് അപകടകരമായത് തടയുന്നു. ഹാർഡ്‌വെയർ, സോഫ്റ്റ്‌വെയർ അല്ലെങ്കിൽ രണ്ടും. (ഫയർവാൾ വൈറസ് നീക്കം ചെയ്യില്ല; അത് ആന്റിവൈറസിന്റെ ജോലി.)
  • സുരക്ഷാ മാർഗ്ഗങ്ങൾ: ആന്റിവൈറസ് + അപ്‌ഡേറ്റ്, ശക്തമായ പാസ്‌വേഡ്, 2FA / MFA, എൻക്രിപ്ഷൻ, VPN, ബാക്കപ്പ്, HTTPS ഉള്ള സൈറ്റുകൾ മാത്രം, അജ്ഞാത ലിങ്ക് ക്ലിക്ക് ചെയ്യാതിരിക്കൽ, OTP ആരുമായും പങ്കിടാതിരിക്കൽ.
  • ക്രിപ്റ്റോഗ്രഫി: വിവരം രഹസ്യ കോഡാക്കുന്നത് = Encryption (Plaintext → Ciphertext); തിരിച്ചാക്കുന്നത് = Decryption. Symmetric (ഒരേ കീ), Asymmetric (Public + Private key ജോടി).
  • ഡിജിറ്റൽ സിഗ്നേച്ചർ: Asymmetric ക്രിപ്റ്റോഗ്രഫിയും ഹാഷും ഉപയോഗിച്ച്; അയക്കുന്നയാൾ Private key കൊണ്ട് ഒപ്പിടും, സ്വീകരിക്കുന്നയാൾ Public key കൊണ്ട് പരിശോധിക്കും. സർട്ടിഫിക്കറ്റ് നൽകുന്നത് Certifying Authority (CA); അവരെ നിയന്ത്രിക്കുന്നത് CCA. ക്ലാസുകൾ: Class 1, 2, 3.

  • Trap 8: ഡിസംബർ 2 = കമ്പ്യൂട്ടർ സാക്ഷരതാ ദിനം, നവംബർ 30 = കമ്പ്യൂട്ടർ സുരക്ഷാ ദിനം.

  • Trap 12: <br>, <hr>, <img>, <input> എംപ്റ്റി ടാഗുകൾ: അവയ്ക്ക് </br> പോലുള്ള ഒടുക്ക ടാഗ് ഇല്ല.
