1. അധ്യായ ആമുഖം

  • ⭐⭐⭐⭐⭐ വിഷയം: കമ്പ്യൂട്ടറിലെ കണ്ണുകൊണ്ട് കാണാനും കൈകൊണ്ട് തൊടാനും കഴിയുന്ന (Tangible) എല്ലാ ഭൗതിക ഭാഗങ്ങളും ചേർന്നതാണ് ഹാർഡ്‌വെയർ (Hardware).
  • ⭐⭐⭐⭐⭐ PSC പ്രാധാന്യം: കമ്പ്യൂട്ടർ സയൻസ് (4 മാർക്ക്) ഭാഗത്തെ ഏറ്റവും കൂടുതൽ ചോദ്യങ്ങൾ വരുന്ന അടിസ്ഥാന അധ്യായം. LDC (883), പ്ലസ് ടു, ഡിഗ്രി (573) എന്നിവയ്ക്കെല്ലാം (B) ബാധകം.
  • ⭐⭐⭐⭐ ഏഴ് ഉപവിഷയങ്ങൾ (10.1.1–10.1.7): ഹാർഡ്‌വെയർ അടിസ്ഥാനം, ഇൻപുട്ട്, ഔട്ട്പുട്ട്, പ്രൈമറി മെമ്മറി, സെക്കൻഡറി മെമ്മറി, മെമ്മറി യൂണിറ്റുകൾ.
➕ തുടക്കക്കാർക്കുള്ള ഒറ്റവരി നിർവ്വചനങ്ങൾ
  • ഹാർഡ്‌വെയർ = തൊടാൻ പറ്റുന്നത് (കീബോർഡ്, മോണിറ്റർ)
  • സോഫ്റ്റ്‌വെയർ = തൊടാൻ പറ്റാത്ത പ്രോഗ്രാം (Windows, MS Word)
  • ഫേംവെയർ = ഹാർഡ്‌വെയർ ചിപ്പിനുള്ളിൽ സ്ഥിരമായി എഴുതിവെച്ച പ്രോഗ്രാം (BIOS)
  • 🧠 "ഹാർഡ് = തൊടാം, സോഫ്റ്റ് = തൊടാൻ പറ്റില്ല"
⭐ KPSC പ്രധാന ചോദ്യമേഖലകൾ
  • ഇൻപുട്ട്-ഔട്ട്പുട്ട് ഉപകരണങ്ങളെ വേർതിരിക്കൽ
  • പ്രിന്ററുകളുടെ തരങ്ങളും വേഗത യൂണിറ്റുകളും (DPI, PPM, CPS)
  • റാം vs റോം വ്യത്യാസം
  • ഏറ്റവും വേഗതയേറിയ മെമ്മറികൾ (Registers, Cache)
  • ഫ്ലോപ്പി, സി.ഡി, ഡി.വി.ഡി എന്നിവയുടെ ശേഷി
  • ബിറ്റ്-നിബിൾ-ബൈറ്റ് യൂണിറ്റുകൾ

2. പിന്നാമ്പുറ കഥ (Behind the Story)

  • ⭐⭐⭐⭐ കഥ 1 – മാംഗോ ഷേക്ക്: അമ്മ അടുക്കളയിൽ മാംഗോ ഷേക്ക് ഉണ്ടാക്കുന്നത് ഓർക്കുക:
    • മാങ്ങയും പാലും പഞ്ചസാരയും മിക്സി ജാറിലിടുന്നു → ഇൻപുട്ട് (Input)
    • മിക്സി കറങ്ങി അരയ്ക്കുന്നു → പ്രോസസ്സിംഗ് (CPU)
    • ഗ്ലാസ്സിൽ ഒഴിച്ച് കുടിക്കാൻ തരുന്നു → ഔട്ട്പുട്ട് (Output)
    • അപ്പോൾത്തന്നെ കുടിക്കുന്നെങ്കിൽ കിച്ചൻ കൗണ്ടറിൽ വെക്കുന്നു → പ്രൈമറി മെമ്മറി (RAM)
    • നാളത്തേക്ക് വെക്കാൻ ഫ്രിഡ്ജിൽ → സെക്കൻഡറി മെമ്മറി (Hard Disk)
    🧠 "ഈ കഥ ഓർത്താൽ IPO + Storage എന്ന ചക്രം മറക്കില്ല"
  • ⭐⭐⭐⭐⭐ കഥ 2 – മൗസിന്റെ ഉത്ഭവം: 1960-കളുടെ തുടക്കത്തിൽ കമ്പ്യൂട്ടർ പ്രവർത്തിപ്പിക്കാൻ കീബോർഡിൽ വലിയ കോഡുകൾ ടൈപ്പ് ചെയ്യണമായിരുന്നു. സ്ക്രീനിലെ പോയിന്റിലേക്ക് വേഗത്തിൽ എത്താൻ അമേരിക്കൻ എഞ്ചിനീയർ ഡഗ്ലസ് എംഗൽബാർട്ട് (Douglas Engelbart) 1963–64-ൽ ഒരു ചെറിയ മരപ്പെട്ടിക്കുള്ളിൽ (Wooden shell) രണ്ട് ലോഹ ചക്രങ്ങൾ ഘടിപ്പിച്ച് ഉപകരണം നിർമ്മിച്ചു. പിന്നിൽനിന്ന് കമ്പ്യൂട്ടറിലേക്ക് നീണ്ട വയർ ചുണ്ടെലിയുടെ വാൽ പോലെ തോന്നിയതിനാൽ 'മൗസ്' എന്ന പേര് വീണു.
➕ PSC വസ്തുത (മൗസ്)

മൗസിന് പേറ്റന്റ് ലഭിച്ചത് 1970-ൽ ആണ്. ഇത് ആദ്യമായി പരസ്യമായി കാണിച്ചത് 1968-ലെ "Mother of All Demos"-ൽ ആയിരുന്നു.

3. തിരുത്തലുകളുടെ പട്ടിക ✏️

✏️ നോട്ടിലെ 6 തിരുത്തലുകൾ
#നോട്ടിൽ ഉണ്ടായിരുന്നത്ശരിയായ വിവരം
1ലൈറ്റ് പെൻ ക്രിക്കറ്റ് ടി.വി വിശകലനത്തിന് ഉപയോഗിക്കുന്നുടി.വിയിൽ സ്ക്രീനിൽ വരയ്ക്കുന്ന ഉപകരണം ടെലസ്ട്രേറ്റർ (Telestrator) ആണ്. ലൈറ്റ് പെൻ CAD / സ്ക്രീനിൽ വരയ്ക്കാൻ.
2ലോകത്തിലെ ആദ്യ സൂപ്പർ കമ്പ്യൂട്ടർ CRAY-1 (1976)ആദ്യ സൂപ്പർ കമ്പ്യൂട്ടർ CDC 6600 (1964, സെയ്മൂർ ക്രേ). CRAY-1 (1976) ആദ്യത്തെ വിജയകരമായ വാണിജ്യ സൂപ്പർ കമ്പ്യൂട്ടർ.
3ഐ.സി: ജാക്ക് കിൽബിയും റോബർട്ട് നോയ്സും ചേർന്ന് 1958കിൽബി 1958 (ടെക്സസ് ഇൻസ്ട്രുമെന്റ്സ്) ആദ്യ IC. നോയ്സ് 1959-ൽ സിലിക്കൺ IC സ്വതന്ത്രമായി വികസിപ്പിച്ചു.
4ഇന്റൽ 4004 – ടെഡ് ഹോഫ്, ഫെഡറിക്കോ ഫാഗിൻഡിസൈൻ ടീം: ടെഡ് ഹോഫ്, ഫെഡറിക്കോ ഫാഗിൻ, സ്റ്റാൻലി മസോർ, മസതോഷി ഷിമ.
5യോട്ടാബൈറ്റ് ഏറ്റവും വലിയ ഔദ്യോഗിക യൂണിറ്റ്2022-ൽ SI പുതിയ പ്രിഫിക്സുകൾ ചേർത്തു: Ronna (R), Quetta (Q). ഇപ്പോൾ Ronnabyte, Quettabyte ഉണ്ട്.
6HDD "റെയ്നോൾഡ് ജോൺസൺ"ശരി. കൂടെ ➕ RAMAC 305-ന്റെ ശേഷി ഏകദേശം 5 MB.
⚠️ PSC Trap Box (ആദ്യ സൂപ്പർ കമ്പ്യൂട്ടർ)

ആദ്യ സൂപ്പർ കമ്പ്യൂട്ടർ CDC 6600 (1964) ആണ്; CRAY-1 (1976) അല്ല! CRAY-1 ആദ്യത്തെ വിജയകരമായ വാണിജ്യ സൂപ്പർ കമ്പ്യൂട്ടർ മാത്രമാണ്.

⚠️ PSC Trap Box (IC ചരിത്രം)

ആദ്യ IC = ജാക്ക് കിൽബി (1958); റോബർട്ട് നോയ്സ് = 1959-ൽ സിലിക്കൺ IC (സ്വതന്ത്രമായി). രണ്ടുപേരും ചേർന്നല്ല!

4. ഹാർഡ്‌വെയർ അടിസ്ഥാനം (10.1.1)

  • ⭐⭐⭐⭐⭐ ഹാർഡ്‌വെയർ: കമ്പ്യൂട്ടറിന്റെ ഭൗതിക ഭാഗങ്ങൾ (Physical components). അതിന് പ്രവർത്തിക്കാൻ നിർദ്ദേശം നൽകുന്ന പ്രോഗ്രാമുകളാണ് സോഫ്റ്റ്‌വെയർ. (ഉപമ: ശരീരം = ഹാർഡ്‌വെയർ, ജീവൻ/മനസ്സ് = സോഫ്റ്റ്‌വെയർ)
  • ⭐⭐⭐⭐⭐ ഹാർഡ്‌വെയർ നാല് വിഭാഗം: ഇൻപുട്ട് യൂണിറ്റ്, CPU, മെമ്മറി യൂണിറ്റ്, ഔട്ട്പുട്ട് യൂണിറ്റ്. 🧠 I-C-M-O ("ഐ സി മോ")
➕ I-C-M-O വിശദീകരണം
  • I = Input Unit: കീബോർഡ്, മൗസ്, സ്കാനർ (ഡാറ്റ അകത്തേക്ക്)
  • C = CPU: പ്രോസസ്സിംഗ് (തലച്ചോറ്)
  • M = Memory Unit: RAM, ROM, ഹാർഡ് ഡിസ്ക് (സൂക്ഷിക്കൽ)
  • O = Output Unit: മോണിറ്റർ, പ്രിന്റർ (ഫലം പുറത്തേക്ക്)

5. വോൺ ന്യൂമാൻ ആർക്കിടെക്ചർ

  • ⭐⭐⭐⭐ 1945-ൽ ജോൺ വോൺ ന്യൂമാൻ മുന്നോട്ടുവെച്ച 'സ്റ്റോർഡ് പ്രോഗ്രാം കൺസെപ്റ്റ്' (ഡാറ്റയും നിർദ്ദേശങ്ങളും ഒരേ മെമ്മറിയിൽ സൂക്ഷിക്കുന്ന രീതി) അനുസരിച്ചാണ് ഇന്നത്തെ കമ്പ്യൂട്ടറുകൾ നിർമ്മിച്ചിരിക്കുന്നത്.
  • ഉൾപ്പെടുന്നവ: ഇൻപുട്ട് യൂണിറ്റ്, CPU, മെമ്മറി യൂണിറ്റ്, ഔട്ട്പുട്ട് യൂണിറ്റ്.
⭐ ഇൻസ്ട്രക്ഷൻ സൈക്കിൾ (CPU ഒരു നിർദ്ദേശം ചെയ്യുന്ന വിധം)

Fetch (എടുക്കൽ) → Decode (മനസ്സിലാക്കൽ) → Execute (നടപ്പാക്കൽ)

🧠 "F-D-E: ഫെച്ച് ചെയ്യൂ, ഡീകോഡ് ചെയ്യൂ, എക്സിക്യൂട്ട് ചെയ്യൂ"

6. CPU – സി.പി.യു (Central Processing Unit)

  • ⭐⭐⭐⭐⭐ CPU = "കമ്പ്യൂട്ടറിന്റെ തലച്ചോറ്" (Brain of the Computer). ഒറ്റ സിലിക്കൺ ചിപ്പിൽ (IC) നിർമ്മിച്ച CPU-വിനെ മൈക്രോപ്രൊസസ്സർ (Microprocessor) എന്ന് വിളിക്കുന്നു.
  • ⭐⭐⭐⭐⭐ ലോകത്തിലെ ആദ്യ മൈക്രോപ്രൊസസ്സർ: ഇന്റൽ 4004 (1971). ഡിസൈൻ ടീം: ടെഡ് ഹോഫ്, ഫെഡറിക്കോ ഫാഗിൻ, സ്റ്റാൻലി മസോർ, മസതോഷി ഷിമ.
  • ⭐⭐⭐⭐ ഇന്ത്യ: തദ്ദേശീയമായി വികസിപ്പിച്ച ആദ്യ മൈക്രോപ്രൊസസ്സർ 'ശക്തി' (Shakti – IIT മദ്രാസ്). സി-ഡാക് (C-DAC) വികസിപ്പിച്ച പ്രൊസസ്സർ 'വേഗ' (Vega).
  • ⭐⭐⭐ IIT മദ്രാസ് ഉള്ളത് ചെന്നൈയിൽ; C-DAC ആസ്ഥാനം പൂനെ. ഇന്ത്യയുടെ DHRUV64 (C-DAC) എന്ന 64-ബിറ്റ് ഡ്യുവൽ കോർ പ്രൊസസ്സറും ഈ ശ്രേണിയിൽ വരുന്നു.
  • ⭐⭐⭐⭐ CPU വേഗത (Clock Speed): ഹെർട്സ് (Hz) → ആധുനികം ജിഗാഹെർട്സ് (GHz); മറ്റൊരു അളവ് MIPS (Million Instructions Per Second).
  • ⭐⭐⭐ ക്ലോക്ക് സ്പീഡ് = CPU ഒരു സെക്കൻഡിൽ എത്ര "ടിക്" (പൾസ്) ഉണ്ടാക്കുന്നു എന്നത്. 3 GHz = സെക്കൻഡിൽ 300 കോടി ടിക്.
  • ⭐⭐⭐ കോറുകൾ (Dual core, Quad core): ഒരു ചിപ്പിനുള്ളിലെ പ്രോസസ്സിംഗ് യൂണിറ്റുകൾ. കോറുകൾ കൂടുന്തോറും ഒരേസമയം കൂടുതൽ ജോലി ചെയ്യാം.

6.1 CPU-വിന്റെ 3 പ്രധാന ഭാഗങ്ങൾ

ഭാഗംധർമ്മംഓർമ്മ
ALU (Arithmetic Logic Unit)ഗണിത ക്രിയകളും (+ − × ÷) യുക്തിപരമായ താരതമ്യങ്ങളും (AND, OR, NOT, <, >, =) ചെയ്യുന്നു🧠 കണക്ക്
CU (Control Unit)"കമ്പ്യൂട്ടറിന്റെ നാഡീവ്യൂഹം". സ്വയം ഡാറ്റ പ്രോസസ്സ് ചെയ്യില്ല; എല്ലാ ഭാഗങ്ങളെയും ഏകോപിപ്പിക്കുകയും നിയന്ത്രിക്കുകയും ചെയ്യുന്നു🧠 ഭരണം
രജിസ്റ്ററുകൾ (Registers)CPU-വിനുള്ളിലെ ഏറ്റവും വേഗതയേറിയ ചെറു താത്കാലിക മെമ്മറി യൂണിറ്റുകൾ🧠 കയ്യിലെ കുറിപ്പ്

6.2 രജിസ്റ്ററുകളുടെ തരങ്ങൾ

  • PC (Program Counter): അടുത്ത നിർദ്ദേശത്തിന്റെ അഡ്രസ്സ് സൂക്ഷിക്കുന്നു
  • Accumulator: ALU ഫലങ്ങൾ സൂക്ഷിക്കുന്നു
  • IR (Instruction Register): ഇപ്പോൾ നടപ്പാക്കുന്ന നിർദ്ദേശം
  • MAR (Memory Address Register): മെമ്മറി അഡ്രസ്സ്
  • MDR (Memory Data Register): മെമ്മറിയിൽനിന്ന് വരുന്ന/പോകുന്ന ഡാറ്റ
🧠 ട്രിക്ക് – CPU-യുടെ 3 ഭാഗങ്ങൾ

"അച്ഛൻ (ALU) കണക്കെഴുതും, കൺട്രോൾ (CU) നടത്തിപ്പുകാരൻ, രജിസ്റ്റർ രഹസ്യ പെട്ടി"

ലളിതമായി: ALU = കണക്ക്, CU = ഭരണം, Register = കയ്യിലെ കുറിപ്പ്.

➕ CPU-വും മെമ്മറിയും തമ്മിലുള്ള ബന്ധം

CPU-വിന് നേരിട്ട് സംസാരിക്കാവുന്നത് പ്രൈമറി മെമ്മറിയോട് മാത്രം. ഹാർഡ് ഡിസ്കിലെ ഡാറ്റ ആദ്യം റാമിൽ എത്തണം.

➕ GPU (Graphics Processing Unit)

ചിത്രങ്ങളും വീഡിയോയും ഗെയിമും പ്രോസസ്സ് ചെയ്യുന്ന പ്രത്യേക പ്രൊസസ്സർ (ഗ്രാഫിക്സ് കാർഡ്).

7. മദർബോർഡും അനുബന്ധ ഘടകങ്ങളും

  • ⭐⭐⭐⭐⭐ മദർബോർഡ് (Motherboard / Mainboard / System Board / PCB): CPU, RAM, ഹാർഡ് ഡിസ്ക്, പോർട്ടുകൾ തുടങ്ങിയ എല്ലാ പ്രധാന ഘടകങ്ങളെയും പരസ്പരം ബന്ധിപ്പിക്കുന്ന പ്രധാന സർക്യൂട്ട് ബോർഡ് (PCB – Printed Circuit Board).
🧠 "മദർ = അമ്മ; വീട്ടിലെ എല്ലാവരെയും ഒരുമിപ്പിക്കുന്നു"

7.1 മദർബോർഡിലെ ഭാഗങ്ങൾ

ഭാഗംധർമ്മം
CPU സോക്കറ്റ്പ്രോസസ്സർ ഘടിപ്പിക്കുന്ന സ്ഥലം
RAM സ്ലോട്ട് (DIMM)റാം ഘടിപ്പിക്കാൻ
ചിപ്സെറ്റ് (Chipset)മദർബോർഡിലെ ഘടകങ്ങൾക്കിടയിൽ ഡാറ്റാ ഗതാഗതം നിയന്ത്രിക്കുന്നു
എക്സ്പാൻഷൻ സ്ലോട്ടുകൾ (PCI / PCIe)ഗ്രാഫിക്സ്, സൗണ്ട് കാർഡ് തുടങ്ങിയവ ഘടിപ്പിക്കാൻ
BIOS ചിപ്പ്കമ്പ്യൂട്ടർ ഓൺ ചെയ്യുമ്പോൾ ആദ്യം പ്രവർത്തിക്കുന്ന പ്രോഗ്രാം
CMOS ബാറ്ററിസമയം/തീയതി സൂക്ഷിക്കാൻ
SATA കണക്ടറുകൾഹാർഡ് ഡിസ്ക്/SSD ബന്ധിപ്പിക്കാൻ

8. ബസ്സുകൾ (Buses)

  • ⭐⭐⭐⭐⭐ ബസ്സുകൾ: മദർബോർഡിൽ ഘടകങ്ങൾക്കിടയിൽ ഡാറ്റയും സിഗ്നലുകളും കൈമാറുന്ന ചെറു വൈദ്യുത പാതകൾ. മൂന്ന് തരം: Data Bus, Address Bus, Control Bus.
  • ⭐⭐⭐⭐ ബസ് വിഡ്ത്ത് (Bus Width): ഒരേസമയം ബസ്സിലൂടെ പോകുന്ന ബിറ്റുകളുടെ എണ്ണം.
ബസ് തരംധർമ്മംദിശ
Data Busഡാറ്റ കൊണ്ടുപോകുന്നുഇരുവശത്തേക്കും (Bidirectional)
Address Busഡാറ്റ എവിടെ എന്ന വിലാസംഒരു ദിശയിൽ (CPU → മെമ്മറി)
Control Busനിയന്ത്രണ സിഗ്നലുകൾഇരുവശത്തേക്കും
🧠 "ഡാറ്റ = ലോറി, അഡ്രസ്സ് = വിലാസം, കൺട്രോൾ = ട്രാഫിക് പോലീസ്"

9. SMPS, UPS, CMOS ബാറ്ററി

  • ⭐⭐⭐⭐ SMPS (Switched-Mode Power Supply): വിവിധ ഭാഗങ്ങൾക്ക് വേണ്ട വൈദ്യുതി നൽകുന്നു; AC-യെ DC ആക്കി മാറ്റുന്നു.
  • ⭐⭐⭐⭐ UPS (Uninterruptible Power Supply): വൈദ്യുതി പോയാലും കമ്പ്യൂട്ടർ ഓഫാകാതെ ബാറ്ററി ബാക്കപ്പ് നൽകുന്നു.
  • ⭐⭐⭐⭐ CMOS ബാറ്ററി (Complementary Metal-Oxide Semiconductor): കമ്പ്യൂട്ടർ ഓഫാക്കിയാലും തീയതിയും സമയവും BIOS സെറ്റിംഗ്സും നഷ്ടപ്പെടാതെ സൂക്ഷിക്കാൻ മദർബോർഡിലുള്ള ചെറിയ വട്ടത്തിലുള്ള ലിഥിയം ബാറ്ററി. (സാധാരണ CR2032)
🧠 ട്രിക്ക്

SMPS = "മാറ്റി തരും" (AC→DC); UPS = "ഉടൻ പവർ സപ്പോർട്ട്" (ബാറ്ററി); CMOS = "ക്ലോക്ക് മെമ്മറി ഓൺ സ്റ്റാൻഡ്ബൈ", ഘടികാരത്തിന്റെ ബാറ്ററി.

10. പ്രധാന പോർട്ടുകൾ (Ports)

ബാഹ്യ ഉപകരണങ്ങളെ കമ്പ്യൂട്ടറുമായി ബന്ധിപ്പിക്കുന്ന കണക്ഷൻ സ്ഥാനങ്ങൾ:

പോർട്ട്ഉപയോഗം / സവിശേഷതഓർമ്മ സൂചന
USB (Universal Serial Bus)മൗസ്, കീബോർഡ്, പെൻഡ്രൈവ്, പ്രിന്റർ തുടങ്ങി മിക്ക ഉപകരണങ്ങളും. സഹ-ഉപജ്ഞാതാവ്: ഇന്ത്യൻ വംശജൻ അജയ് ഭട്ട് (Ajay Bhatt). ആദ്യ സ്പെസിഫിക്കേഷൻ 1996.🧠 "യൂ-എസ്-ബി = എല്ലാം ബന്ധിപ്പിക്കും"
HDMI (High-Definition Multimedia Interface)HD വീഡിയോയും ഓഡിയോയും ഒരേ കേബിളിൽ (മോണിറ്റർ, ടി.വി, പ്രൊജക്ടർ)🧠 HDMI = Hear + Display, ശബ്ദവും ദൃശ്യവും
VGA (Video Graphics Array)മോണിറ്ററിനെ CPU-വുമായി ബന്ധിപ്പിക്കുന്ന നീല നിറത്തിലെ 15-പിൻ കണക്ടർ; വീഡിയോ മാത്രം🧠 VGA = Video Gave Alone (ഓഡിയോ ഇല്ല)
PS/2പഴയ കമ്പ്യൂട്ടറിൽ മൗസ് (പച്ച), കീബോർഡ് (വയലറ്റ്/പർപ്പിൾ); 6-പിൻ വട്ട പോർട്ട്🧠 "പച്ച മൗസ്, വയലറ്റ് കീബോർഡ്" ("പച്ച = പുല്ല് തിന്നുന്ന മൗസ്")
പാരലൽ പോർട്ട് (LPT)പഴയ പ്രിന്ററുകൾ; 25-പിൻ🧠 പാരലൽ = പ്രിന്റർ
ഇതർനെറ്റ് / LAN (RJ-45)നെറ്റ്‌വർക്ക് / ഇന്റർനെറ്റ് കേബിൾRJ-45 = നെറ്റ്‌വർക്ക്
RJ-11പഴയ ടെലിഫോൺ / മോഡംRJ-11 = ഫോൺ
➕ സീരിയൽ പോർട്ട് (COM)പഴയ മോഡം, മൗസ്; 9-പിൻ—
➕ DVIഡിജിറ്റൽ വീഡിയോ (VGA-യുടെ പിൻഗാമി)—
➕ USB Type-Cചെറിയ, ഇരുവശവും കുത്താവുന്ന പുതിയ കണക്ടർ—
➕ ഓഡിയോ ജാക്കുകൾപച്ച = സ്പീക്കർ/ഹെഡ്ഫോൺ (Output), പിങ്ക് = മൈക്രോഫോൺ (Input), നീല = Line-in🧠 "പച്ച കേൾക്കാൻ, പിങ്ക് പറയാൻ"
🧠 പോർട്ടുകളുടെ ഓർമ്മ – ഒറ്റവരി

"USB എല്ലാം, HDMI ശബ്ദവും ദൃശ്യവും, VGA ദൃശ്യം മാത്രം, PS/2 പച്ച-വയലറ്റ്, പാരലൽ പ്രിന്റർ, RJ-45 നെറ്റ്, RJ-11 ഫോൺ"

11. അധിക വസ്തുതകൾ (Additional PSC Facts)

➕ ഹാർഡ്‌വെയർ അടിസ്ഥാനം – അധിക വസ്തുതകൾ
  • കമ്പ്യൂട്ടറിന്റെ പിതാവ്: ചാൾസ് ബാബേജ് (ഡിഫറൻസ് എഞ്ചിൻ, അനലിറ്റിക്കൽ എഞ്ചിൻ). ആധുനിക കമ്പ്യൂട്ടർ ശാസ്ത്രത്തിന്റെ പിതാവ്: അലൻ ട്യൂറിംഗ്.
  • ലോക കമ്പ്യൂട്ടർ സാക്ഷരതാ ദിനം: ഡിസംബർ 2.
  • ആദ്യത്തെ ജനറൽ-പർപ്പസ് ഇലക്ട്രോണിക് കമ്പ്യൂട്ടർ: ENIAC (1946); ജോൺ എക്കർട്ട്, ജോൺ മോക്ലി എന്നിവർ.
  • ലോകത്തിലെ ആദ്യ പ്രോഗ്രാമർ: അഡ ലവ്‌ലേസ് (Ada Lovelace), ബാബേജിന്റെ അനലിറ്റിക്കൽ എഞ്ചിനു വേണ്ടി.
  • വലിപ്പമനുസരിച്ച് കമ്പ്യൂട്ടറുകൾ: സൂപ്പർ കമ്പ്യൂട്ടർ > മെയിൻഫ്രെയിം > മിനി > മൈക്രോ (PC, ലാപ്‌ടോപ്പ്).
  • പ്രവർത്തന തത്വമനുസരിച്ച്: അനലോഗ് (തുടർച്ചയായ അളവുകൾ, ഉദാ: സ്പീഡോമീറ്റർ), ഡിജിറ്റൽ (0, 1), ഹൈബ്രിഡ് (രണ്ടും, ഉദാ: ആശുപത്രിയിലെ ECG/ICU മോണിറ്റർ).

16. മെമ്മറി ട്രിക്കുകൾ (Mnemonics)

🧠 Trick 1 – ഹാർഡ്‌വെയർ 4 വിഭാഗം

I-C-M-O ("ഐ സി മോ") → Input, CPU, Memory, Output.

🧠 Trick 2 – CPU 3 ഭാഗങ്ങൾ

"അച്ഛൻ (ALU) കണക്കെഴുതും, കൺട്രോൾ (CU) നടത്തിപ്പുകാരൻ, രജിസ്റ്റർ രഹസ്യ പെട്ടി"

ലളിതം: ALU = കണക്ക്, CU = ഭരണം, Register = കയ്യിലെ കുറിപ്പ്.

🧠 Trick 3 – ഇൻസ്ട്രക്ഷൻ സൈക്കിൾ

"F-D-E: ഫെച്ച് ചെയ്യൂ, ഡീകോഡ് ചെയ്യൂ, എക്സിക്യൂട്ട് ചെയ്യൂ"

🧠 Trick 4 – ബസ്സുകൾ

"ഡാറ്റ = ലോറി, അഡ്രസ്സ് = വിലാസം, കൺട്രോൾ = ട്രാഫിക് പോലീസ്"

🧠 Trick 5 – SMPS, UPS, CMOS

SMPS = "മാറ്റി തരും" (AC→DC); UPS = "ഉടൻ പവർ സപ്പോർട്ട്" (ബാറ്ററി); CMOS = "ക്ലോക്ക് മെമ്മറി ഓൺ സ്റ്റാൻഡ്ബൈ" (ഘടികാരത്തിന്റെ ബാറ്ററി)

🧠 Trick 6 – PS/2 നിറങ്ങൾ

"പച്ച മൗസ്, വയലറ്റ് കീബോർഡ്" ("പച്ച = പുല്ല് തിന്നുന്ന മൗസ്")

🧠 Trick 7 – HDMI vs VGA

HDMI = "Hear + Display" (ശബ്ദവും ദൃശ്യവും); VGA = "Video Gave Alone" (ഓഡിയോ ഇല്ല)

🧠 Trick 8 – RJ-45 vs RJ-11

RJ-45 = നെറ്റ്‌വർക്ക്; RJ-11 = ഫോൺ ("45 = 4G/5G വേഗം; 11 = പഴയ ഫോൺ")

🧠 Trick 9 – ഓഡിയോ ജാക്ക്

"പച്ച കേൾക്കാൻ, പിങ്ക് പറയാൻ" → പച്ച = സ്പീക്കർ (Output); പിങ്ക് = മൈക്രോഫോൺ (Input).

🧠 Trick 10 – മദർബോർഡ്

"മദർ = അമ്മ; വീട്ടിലെ എല്ലാവരെയും ഒരുമിപ്പിക്കുന്നു" → എല്ലാ ഘടകങ്ങളെയും ബന്ധിപ്പിക്കുന്നു.

3. ഗണിത ക്രിയകളും യുക്തിപരമായ താരതമ്യങ്ങളും ചെയ്യുന്ന CPU-യുടെ ഭാഗം?
ശരിയുത്തരം: (B) ALU
Arithmetic Logic Unit – ഗണിതവും യുക്തിയും; CU = നിയന്ത്രണം; Registers = താത്കാലിക മെമ്മറി.
4. "കമ്പ്യൂട്ടറിന്റെ നാഡീവ്യൂഹം" എന്നറിയപ്പെടുന്നത്?
ശരിയുത്തരം: (B) CU
Control Unit – സ്വയം ഡാറ്റ പ്രോസസ്സ് ചെയ്യില്ല; എല്ലാ ഭാഗങ്ങളെയും ഏകോപിപ്പിക്കുന്നു.
5. ആദ്യ സൂപ്പർ കമ്പ്യൂട്ടർ ഏത്?
ശരിയുത്തരം: (B) CDC 6600 (1964)
സെയ്മൂർ ക്രേ രൂപകല്പന ചെയ്തത്. CRAY-1 (1976) = ആദ്യ വിജയകരമായ വാണിജ്യ സൂപ്പർ കമ്പ്യൂട്ടർ.
6. ആദ്യ IC നിർമ്മിച്ചത് ആര്?
ശരിയുത്തരം: (B) ജാക്ക് കിൽബി (1958)
ടെക്സസ് ഇൻസ്ട്രുമെന്റ്സിൽ; റോബർട്ട് നോയ്സ് 1959-ൽ സിലിക്കൺ IC സ്വതന്ത്രമായി വികസിപ്പിച്ചു.
7. AC-യെ DC ആക്കി മാറ്റുന്ന ഉപകരണം?
ശരിയുത്തരം: (B) SMPS
Switched-Mode Power Supply – AC→DC; UPS = ബാറ്ററി ബാക്കപ്പ്; CMOS = ക്ലോക്ക് ബാറ്ററി.
8. പച്ച നിറത്തിലുള്ള PS/2 പോർട്ട് എന്തിനാണ്?
ശരിയുത്തരം: (B) മൗസ്
പച്ച = മൗസ്; വയലറ്റ് = കീബോർഡ്. 6-പിൻ വട്ട പോർട്ട്.
9. വീഡിയോയും ഓഡിയോയും ഒരേ കേബിളിൽ കൈമാറുന്ന പോർട്ട്?
ശരിയുത്തരം: (B) HDMI
High-Definition Multimedia Interface – ശബ്ദവും ദൃശ്യവും; VGA/DVI വീഡിയോ മാത്രം.
10. USB-യുടെ സഹ-ഉപജ്ഞാതാവ് ആര്?
ശരിയുത്തരം: (B) അജയ് ഭട്ട്
ഇന്ത്യൻ വംശജൻ; USB ആദ്യ സ്പെസിഫിക്കേഷൻ 1996.
11. മദർബോർഡിൽ ഡാറ്റയും സിഗ്നലുകളും കൈമാറുന്ന പാത?
ശരിയുത്തരം: (A) Bus
മൂന്ന് തരം: Data Bus, Address Bus, Control Bus.
12. CPU-യിലെ ഏറ്റവും വേഗതയേറിയ മെമ്മറി യൂണിറ്റ്?
ശരിയുത്തരം: (B) Registers
CPU-വിനുള്ളിലെ താത്കാലിക മെമ്മറി; Cache രണ്ടാം സ്ഥാനം.
13. RJ-45 പോർട്ട് എന്തിനാണ്?
ശരിയുത്തരം: (B) നെറ്റ്‌വർക്ക്
RJ-45 = LAN/ഇതർനെറ്റ്; RJ-11 = ഫോൺ.
14. ഇന്ത്യ തദ്ദേശീയമായി വികസിപ്പിച്ച ആദ്യ മൈക്രോപ്രൊസസ്സർ?
ശരിയുത്തരം: (B) ശക്തി
IIT മദ്രാസ് (ചെന്നൈ); വേഗ = C-DAC; DHRUV64 = C-DAC 64-ബിറ്റ്.
15. CMOS ബാറ്ററിയുടെ ധർമ്മം?
ശരിയുത്തരം: (B) തീയതിയും സമയവും സൂക്ഷിക്കുക
കമ്പ്യൂട്ടർ ഓഫാക്കിയാലും സമയം/BIOS സെറ്റിംഗ്സ് സൂക്ഷിക്കുന്നു (CR2032).
16. VGA പോർട്ടിന്റെ പിൻ എണ്ണം?
ശരിയുത്തരം: (B) 15
നീല നിറം; വീഡിയോ മാത്രം; സീരിയൽ = 9, പാരലൽ = 25, PS/2 = 6.
17. "ഡാറ്റ = ലോറി" എന്ന ഉപമ ഏത് ബസ്സിനെ സൂചിപ്പിക്കുന്നു?
ശരിയുത്തരം: (B) Data Bus
ഡാറ്റ കൊണ്ടുപോകുന്നു; Address = വിലാസം; Control = ട്രാഫിക് പോലീസ്.
18. ENIAC കമ്പ്യൂട്ടർ വർഷം?
ശരിയുത്തരം: (B) 1946
ആദ്യ ജനറൽ-പർപ്പസ് ഇലക്ട്രോണിക് കമ്പ്യൂട്ടർ; ജോൺ എക്കർട്ട്, ജോൺ മോക്ലി.
19. 2022-ൽ SI ചേർത്ത പുതിയ പ്രിഫിക്സുകൾ ഏവ?
ശരിയുത്തരം: (A) Ronna, Quetta
Ronna (R), Quetta (Q) – 2022-ൽ ചേർത്തു; ഇപ്പോൾ Ronnabyte, Quettabyte ഉണ്ട്.
20. മൗസ് കണ്ടുപിടിച്ചത് ആര്?
ശരിയുത്തരം: (B) ഡഗ്ലസ് എംഗൽബാർട്ട്
1963–64-ൽ; പേറ്റന്റ് 1970-ൽ; ആദ്യ പരസ്യ പ്രദർശനം 1968 "Mother of All Demos".

21. Quick Revision

⏱️ 5-Minute / Last-Minute Revision
  • ഹാർഡ്‌വെയർ = തൊടാം; സോഫ്റ്റ്‌വെയർ = തൊടാൻ പറ്റില്ല; ഫേംവെയർ = ചിപ്പിൽ (BIOS).
  • I-C-M-O: Input, CPU, Memory, Output.
  • CPU = തലച്ചോറ്; 3 ഭാഗങ്ങൾ: ALU (കണക്ക്), CU (നിയന്ത്രണം), Registers (താത്കാലികം).
  • ഇന്റൽ 4004 (1971) = ആദ്യ മൈക്രോപ്രൊസസ്സർ; ടെഡ് ഹോഫ്, ഫെഡറിക്കോ ഫാഗിൻ, സ്റ്റാൻലി മസോർ, മസതോഷി ഷിമ.
  • ശക്തി (IIT മദ്രാസ്), വേഗ (C-DAC) = ഇന്ത്യൻ പ്രൊസസ്സറുകൾ.
  • മദർബോർഡ് = അമ്മ; CPU socket, RAM slot, Chipset, PCIe, BIOS, SATA.
  • ബസ്സുകൾ: Data, Address, Control.
  • SMPS = AC→DC; UPS = ബാറ്ററി; CMOS = ക്ലോക്ക് ബാറ്ററി (CR2032).
  • പോർട്ടുകൾ: USB (അജയ് ഭട്ട്), HDMI (ശബ്ദം+ദൃശ്യം), VGA (ദൃശ്യം മാത്രം, നീല, 15-പിൻ), PS/2 (പച്ച മൗസ്, വയലറ്റ് കീബോർഡ്), പാരലൽ (25-പിൻ), RJ-45 (നെറ്റ്), RJ-11 (ഫോൺ).
  • ആദ്യ സൂപ്പർ കമ്പ്യൂട്ടർ: CDC 6600 (1964); CRAY-1 (1976) = വാണിജ്യം.
  • ചരിത്രം: ചാൾസ് ബാബേജ് (പിതാവ്), അഡ ലവ്‌ലേസ് (ആദ്യ പ്രോഗ്രാമർ), ENIAC (1946), മൗസ് (1963–64).

23. ഉപസംഹാരം

പ്രധാന Takeaways

  • കമ്പ്യൂട്ടർ ഹാർഡ്‌വെയറിൽ I-C-M-O (Input, CPU, Memory, Output) എന്നീ നാല് വിഭാഗങ്ങൾ ഉൾപ്പെടുന്നു.
  • CPU യഥാർത്ഥത്തിൽ "കമ്പ്യൂട്ടറിന്റെ തലച്ചോറ്"; ALU, CU, Registers എന്നിവയാണ് പ്രധാന ഭാഗങ്ങൾ.
  • മദർബോർഡ് എല്ലാ ഘടകങ്ങളെയും ബന്ധിപ്പിക്കുന്നു; ബസ്സുകൾ വഴിയാണ് ഡാറ്റ കൈമാറ്റം.
  • SMPS, UPS, CMOS എന്നിവ വൈദ്യുതിയും സമയവും സംരക്ഷിക്കുന്നു.
  • USB, HDMI, VGA, PS/2, RJ-45 തുടങ്ങിയ പോർട്ടുകളുടെ ഉപയോഗവും നിറവും പ്രധാനം.
  • ചാൾസ് ബാബേജ് മുതൽ ഇന്റൽ 4004 വരെയും ശക്തി വരെയുള്ള ചരിത്രം ഓർക്കുക.
📝 Teacher's Note

"CPU-യുടെ ഏത് ഭാഗം?", "ഏത് പോർട്ട്?", "ആദ്യ മൈക്രോപ്രൊസസ്സർ ഏത്?" – ഇവയാണ് PSC-യുടെ പ്രിയപ്പെട്ട ചോദ്യങ്ങൾ. ALU/CU/Registers തമ്മിൽ മാറിപ്പോകരുത്. ഭാഗം 2 (ഇൻപുട്ട്-ഔട്ട്പുട്ട് ഉപകരണങ്ങൾ) വേണമെങ്കിൽ പറയുക.
