⭐ Star Guide

⭐ പ്രാധാന്യ സൂചകങ്ങൾ (Kerala PSC അടിസ്ഥാനത്തിൽ)
  • ⭐⭐⭐⭐⭐ അതിപ്രധാനം — CPU ഭാഗങ്ങൾ (ALU, CU, Registers); RAM vs ROM (Volatile); Cache (SRAM); BIOS (ROM-ൽ); പ്രിന്റർ തരങ്ങൾ (Impact/Non-impact); ഫ്ലോപ്പി 1.44 MB, CD 700 MB, DVD 4.7 GB, Blu-ray 25 GB.
  • ⭐⭐⭐⭐ പ്രധാനം — MICR (ബാങ്ക് ചെക്ക്), OMR (പരീക്ഷ), OCR (ടെക്സ്റ്റ്), BCR (ബാർകോഡ്), QR; DPI/PPM/CPS/LPM; Bit-Nibble-Byte-യൂണിറ്റുകൾ; BIOS, POST, ഫേംവേയർ.
  • ⭐⭐⭐ ശ്രദ്ധിക്കേണ്ടത് — മോണിറ്റർ തരങ്ങൾ (CRT, LCD, LED, OLED); SRAM vs DRAM; EPROM (UV) vs EEPROM (വൈദ്യുതി); HDD vs SSD; മൗസ്/കീബോർഡ് ഉപജ്ഞാതാക്കൾ.
  • ⭐⭐ അറിഞ്ഞാൽ മതി — CPU കോറുകൾ; GPU; വോൺ ന്യൂമാൻ; MIPS; ഹിസ്റ്ററി (CDC 6600, PARAM 8000); CMOS ബാറ്ററി.
  • ⭐ ചരിത്രം — ENIAC (1946); ചാൾസ് ബാബേജ്; അഡ ലവ്‌ലേസ്; കമ്പ്യൂട്ടർ തലമുറകൾ.
➕ ചുരുക്കം
  • CPU = ALU + CU + Registers (കമ്പ്യൂട്ടറിന്റെ തലച്ചോറ്); CU = നാഡീവ്യൂഹം.
  • RAM = Volatile (വൈദ്യുതി പോയാൽ മായും); ROM = Non-volatile (BIOS ഇതിൽ).
  • ഏറ്റവും വേഗത: Registers > Cache (SRAM) > RAM (DRAM) > SSD > HDD > Optical > Tape.
  • പ്രിന്റർ: DMP-CPS, Line-LPM, Laser/Inkjet-PPM; വ്യക്തത = DPI.
  • യൂണിറ്റ്: Bit (0/1) → Nibble (4 bits) → Byte (8 bits) → KB (1024 B) → MB → GB → TB → PB → EB → ZB → YB.
✏️ പ്രധാന തിരുത്തലുകൾ (Source-ൽ നിന്ന്)
  1. ലൈറ്റ് പെൻ ക്രിക്കറ്റ് ടി.വി വിശകലനത്തിനല്ല; അത് ടെലസ്ട്രേറ്റർ (Telestrator) ആണ്.
  2. ആദ്യ സൂപ്പർ കമ്പ്യൂട്ടർ CDC 6600 (1964, സെയ്മൂർ ക്രേ); CRAY-1 (1976) വിജയകരമായ വാണിജ്യ സൂപ്പർ കമ്പ്യൂട്ടർ.
  3. IC: കിൽബി 1958 (ടെക്സസ് ഇൻസ്ട്രുമെന്റ്സ്); നോയ്സ് 1959 (സിലിക്കൺ IC).
  4. 2022-ൽ SI പുതിയ പ്രിഫിക്സ്: Ronna (R), Quetta (Q) — Ronnabyte, Quettabyte.
  5. ഇന്റൽ 4004 ഡിസൈൻ ടീം: ടെഡ് ഹോഫ്, ഫെഡറിക്കോ ഫാഗിൻ, സ്റ്റാൻലി മസോർ, മസതോഷി ഷിമ.
  6. HDD RAMAC 305 ശേഷി ഏകദേശം 5 MB.

1. അധ്യായ ആമുഖം

  • ⭐⭐⭐⭐⭐ വിഷയം: കമ്പ്യൂട്ടറിലെ കണ്ണുകൊണ്ട് കാണാനും കൈകൊണ്ട് തൊടാനും കഴിയുന്ന (Tangible) എല്ലാ ഭൗതിക ഭാഗങ്ങളും ചേർന്നതാണ് ഹാർഡ്‌വെയർ. മനുഷ്യശരീരത്തിൽ കൈകാലുകൾ, കണ്ണ്, ചെവി, തലച്ചോറ് എന്നിവ പ്രവർത്തിക്കുന്നതുപോലെ കമ്പ്യൂട്ടറിൽ കീബോർഡ്, മൗസ്, മോണിറ്റർ, CPU, ഹാർഡ് ഡിസ്ക് എന്നിവ പ്രവർത്തിക്കുന്നു.
  • ⭐⭐⭐⭐⭐ Kerala PSC പ്രാധാന്യം: കമ്പ്യൂട്ടർ സയൻസ് (4 മാർക്ക്) ഭാഗത്തെ ഏറ്റവും കൂടുതൽ ചോദ്യങ്ങൾ വരുന്ന അടിസ്ഥാന അധ്യായമാണിത്. എൽ.ഡി.സി (883), ഡിഗ്രി ലെവൽ (573) എന്നിവയ്ക്കെല്ലാം (B) ഈ 6 ഉപവിഷയങ്ങളും ബാധകം.
  • ⭐⭐⭐⭐ സ്ഥിരം ചോദ്യ മേഖലകൾ: ഇൻപുട്ട്-ഔട്ട്പുട്ട് ഉപകരണങ്ങളെ വേർതിരിക്കൽ; പ്രിന്റർ തരങ്ങളും വേഗത യൂണിറ്റുകളും (DPI, PPM, CPS); RAM vs ROM; ഏറ്റവും വേഗതയേറിയ മെമ്മറികൾ (Registers, Cache); ഫ്ലോപ്പി, CD, DVD ശേഷി; Bit-Nibble-Byte.
  • ⭐⭐⭐ ഒറ്റവരി നിർവ്വചനങ്ങൾ:
    • ഹാർഡ്‌വെയർ = തൊടാൻ പറ്റുന്നത് (കീബോർഡ്, മോണിറ്റർ)
    • സോഫ്റ്റ്‌വെയർ = തൊടാൻ പറ്റാത്ത പ്രോഗ്രാം (Windows, MS Word)
    • ഫേംവെയർ = ഹാർഡ്‌വെയർ ചിപ്പിനുള്ളിൽ സ്ഥിരമായി എഴുതിവെച്ച പ്രോഗ്രാം (BIOS)

2. പിന്നാമ്പുറ കഥ (Behind the Story)

മാംഗോ ഷേക്ക് കഥ (IPO + Storage ചക്രം)

അമ്മ അടുക്കളയിൽ മാംഗോ ഷേക്ക് ഉണ്ടാക്കുന്നു എന്ന് കരുതുക:

  1. മാങ്ങയും പാലും പഞ്ചസാരയും മിക്സി ജാറിലിടുന്നു → ഇൻപുട്ട് (Input)
  2. മിക്സി കറങ്ങി അരയ്ക്കുന്നു → പ്രോസസ്സിംഗ് (CPU)
  3. ഗ്ലാസ്സിൽ ഒഴിച്ച് കുടിക്കാൻ തരുന്നു → ഔട്ട്പുട്ട് (Output)
  4. അപ്പോൾത്തന്നെ കുടിക്കുന്നെങ്കിൽ കിച്ചൻ കൗണ്ടറിൽ വെക്കുന്നു → പ്രൈമറി മെമ്മറി (RAM)
  5. നാളത്തേക്ക് വെക്കാൻ ഫ്രിഡ്ജിൽ → സെക്കൻഡറി മെമ്മറി (Hard Disk)
🧠 ഓർമ്മ സൂചന

ഈ കഥ ഓർത്താൽ IPO + Storage (Input → Process → Output + Storage) എന്ന കമ്പ്യൂട്ടറിന്റെ അടിസ്ഥാന ചക്രം ഒരിക്കലും മറക്കില്ല.

മൗസിന്റെ കഥ

1960-കളുടെ തുടക്കത്തിൽ കമ്പ്യൂട്ടർ പ്രവർത്തിപ്പിക്കാൻ കീബോർഡിൽ വലിയ കോഡുകൾ ടൈപ്പ് ചെയ്യണമായിരുന്നു. സ്ക്രീനിലെ പോയിന്റിലേക്ക് വേഗത്തിൽ എത്താൻ അമേരിക്കൻ എഞ്ചിനീയർ ഡഗ്ലസ് എംഗൽബാർട്ട് (Douglas Engelbart) 1963–64-ൽ ഒരു ചെറിയ മരപ്പെട്ടിക്കുള്ളിൽ (Wooden shell) രണ്ട് ലോഹ ചക്രങ്ങൾ ഘടിപ്പിച്ച് ഉപകരണം നിർമ്മിച്ചു. പിന്നിൽനിന്ന് കമ്പ്യൂട്ടറിലേക്ക് നീണ്ട വയർ ചുണ്ടെലിയുടെ വാൽ പോലെ തോന്നിയതിനാൽ 'മൗസ്' എന്ന പേര് വീണു.

➕ PSC വസ്തുത

മൗസിന് പേറ്റന്റ് ലഭിച്ചത് 1970-ൽ ആണ്. ഇത് ആദ്യമായി പരസ്യമായി കാണിച്ചത് 1968-ലെ "Mother of All Demos"-ൽ ആയിരുന്നു.

3A. ഹാർഡ്‌വെയർ അടിസ്ഥാനവും CPU-ഉം മദർബോർഡും (10.1.1)

1) ഹാർഡ്‌വെയർ & സോഫ്റ്റ്‌വെയർ

  • ഹാർഡ്‌വെയർ: കമ്പ്യൂട്ടറിന്റെ ഭൗതിക ഭാഗങ്ങൾ (Physical components). അതിന് പ്രവർത്തിക്കാൻ നിർദ്ദേശം നൽകുന്ന പ്രോഗ്രാമുകളാണ് സോഫ്റ്റ്‌വെയർ. (ഉപമ: ശരീരം = ഹാർഡ്‌വെയർ, ജീവൻ/മനസ്സ് = സോഫ്റ്റ്‌വെയർ)
  • ഹാർഡ്‌വെയർ നാല് വിഭാഗം: ഇൻപുട്ട് യൂണിറ്റ്, CPU, മെമ്മറി യൂണിറ്റ്, ഔട്ട്പുട്ട് യൂണിറ്റ്.
🧠 ഓർമ്മ സൂചന

I-C-M-O ("ഐ സി മോ") — Input, CPU, Memory, Output

2) വോൺ ന്യൂമാൻ ആർക്കിടെക്ചർ (Von Neumann Architecture)

  • 1945-ൽ ജോൺ വോൺ ന്യൂമാൻ മുന്നോട്ടുവെച്ച 'സ്റ്റോർഡ് പ്രോഗ്രാം കൺസെപ്റ്റ്' (ഡാറ്റയും നിർദ്ദേശങ്ങളും ഒരേ മെമ്മറിയിൽ സൂക്ഷിക്കുന്ന രീതി) അനുസരിച്ചാണ് ഇന്നത്തെ കമ്പ്യൂട്ടറുകൾ നിർമ്മിച്ചിരിക്കുന്നത്.
  • ഇൻപുട്ട് യൂണിറ്റ്, CPU, മെമ്മറി യൂണിറ്റ്, ഔട്ട്പുട്ട് യൂണിറ്റ് എന്നിവ ഉൾപ്പെടുന്നു.
  • ഇൻസ്ട്രക്ഷൻ സൈക്കിൾ (CPU ഒരു നിർദ്ദേശം ചെയ്യുന്ന വിധം): Fetch (എടുക്കൽ) → Decode (മനസ്സിലാക്കൽ) → Execute (നടപ്പാക്കൽ).
🧠 ഓർമ്മ സൂചന

"F-D-E: ഫെച്ച് ചെയ്യൂ, ഡീകോഡ് ചെയ്യൂ, എക്സിക്യൂട്ട് ചെയ്യൂ"

3) സി.പി.യു (CPU – Central Processing Unit)

  • ⭐⭐⭐⭐⭐ "കമ്പ്യൂട്ടറിന്റെ തലച്ചോറ്" (Brain of the Computer). ഒറ്റ സിലിക്കൺ ചിപ്പിൽ (IC) നിർമ്മിച്ച CPU-വിനെ മൈക്രോപ്രൊസസ്സർ (Microprocessor) എന്ന് വിളിക്കുന്നു.
  • ലോകത്തിലെ ആദ്യ മൈക്രോപ്രൊസസ്സർ: ഇന്റൽ 4004 (1971). ഡിസൈൻ ടീം: ടെഡ് ഹോഫ്, ഫെഡറിക്കോ ഫാഗിൻ, സ്റ്റാൻലി മസോർ, മസതോഷി ഷിമ.
  • ഇന്ത്യ തദ്ദേശീയമായി വികസിപ്പിച്ച ആദ്യ മൈക്രോപ്രൊസസ്സർ: 'ശക്തി' (Shakti – ഐ.ഐ.ടി മദ്രാസ്). സി-ഡാക് (C-DAC) വികസിപ്പിച്ച പ്രൊസസ്സർ: 'വേഗ' (Vega).
  • ഐ.ഐ.ടി മദ്രാസ് ഉള്ളത് ചെന്നൈയിൽ; സി-ഡാക് ആസ്ഥാനം പൂനെ. ഇന്ത്യയുടെ DHRUV64 (C-DAC) എന്ന 64-ബിറ്റ് ഡ്യുവൽ കോർ പ്രൊസസ്സറും ഈ ശ്രേണിയിൽ വരുന്നു.
  • CPU വേഗത (Clock Speed): ഹെർട്സ് (Hz) → ആധുനികം ജിഗാഹെർട്സ് (GHz); മറ്റൊരു അളവ് MIPS (Million Instructions Per Second).
  • ക്ലോക്ക് സ്പീഡ് = CPU ഒരു സെക്കൻഡിൽ എത്ര "ടിക്" (പൾസ്) ഉണ്ടാക്കുന്നു എന്നത്. 3 GHz = സെക്കൻഡിൽ 300 കോടി ടിക്.
  • കോറുകൾ (Cores): Dual core, Quad core — ഒരു ചിപ്പിനുള്ളിലെ പ്രോസസ്സിംഗ് യൂണിറ്റുകൾ. കോറുകൾ കൂടുന്തോറും ഒരേസമയം കൂടുതൽ ജോലി ചെയ്യാം.

CPU-വിന്റെ 3 പ്രധാന ഭാഗങ്ങൾ:

ഭാഗംപൂർണ്ണരൂപംധർമ്മം
ALU Arithmetic Logic Unit ഗണിത ക്രിയകളും (+ − × ÷) യുക്തിപരമായ താരതമ്യങ്ങളും (AND, OR, NOT, <, >, =) ചെയ്യുന്നു.
CU Control Unit "കമ്പ്യൂട്ടറിന്റെ നാഡീവ്യൂഹം". സ്വയം ഡാറ്റ പ്രോസസ്സ് ചെയ്യില്ല; എല്ലാ ഭാഗങ്ങളെയും ഏകോപിപ്പിക്കുകയും നിയന്ത്രിക്കുകയും ചെയ്യുന്നു.
Registers Registers CPU-വിനുള്ളിലെ ഏറ്റവും വേഗതയേറിയ ചെറു താത്കാലിക മെമ്മറി യൂണിറ്റുകൾ.

പ്രധാന രജിസ്റ്ററുകൾ:

  • PC (Program Counter): അടുത്ത നിർദ്ദേശത്തിന്റെ അഡ്രസ്സ് സൂക്ഷിക്കുന്നു
  • Accumulator: ALU ഫലങ്ങൾ സൂക്ഷിക്കുന്നു
  • IR (Instruction Register): ഇപ്പോൾ നടപ്പാക്കുന്ന നിർദ്ദേശം
  • MAR (Memory Address Register): മെമ്മറി അഡ്രസ്സ്
  • MDR (Memory Data Register): മെമ്മറിയിൽനിന്ന് വരുന്ന/പോകുന്ന ഡാറ്റ
🧠 ഓർമ്മ സൂചന

"അച്ഛൻ (ALU) കണക്കെഴുതും, കൺട്രോൾ (CU) നടത്തിപ്പുകാരൻ, രജിസ്റ്റർ രഹസ്യ പെട്ടി"
ലളിതമായി: ALU = കണക്ക്, CU = ഭരണം, Register = കയ്യിലെ കുറിപ്പ്

  • CPU-വും മെമ്മറിയും തമ്മിലുള്ള ബന്ധം: CPU-വിന് നേരിട്ട് സംസാരിക്കാവുന്നത് പ്രൈമറി മെമ്മറിയോട് മാത്രം. ഹാർഡ് ഡിസ്കിലെ ഡാറ്റ ആദ്യം റാമിൽ എത്തണം.
  • GPU (Graphics Processing Unit): ചിത്രങ്ങളും വീഡിയോയും ഗെയിമും പ്രോസസ്സ് ചെയ്യുന്ന പ്രത്യേക പ്രൊസസ്സർ (ഗ്രാഫിക്സ് കാർഡ്).

4) മദർബോർഡും അനുബന്ധ ഘടകങ്ങളും

  • ⭐⭐⭐⭐ മദർബോർഡ് (Motherboard / Mainboard / System Board / PCB): CPU, RAM, ഹാർഡ് ഡിസ്ക്, പോർട്ടുകൾ തുടങ്ങിയ എല്ലാ പ്രധാന ഘടകങ്ങളെയും പരസ്പരം ബന്ധിപ്പിക്കുന്ന പ്രധാന സർക്യൂട്ട് ബോർഡ് (PCB – Printed Circuit Board).
🧠 ഓർമ്മ സൂചന

"മദർ = അമ്മ; വീട്ടിലെ എല്ലാവരെയും ഒരുമിപ്പിക്കുന്നു"

മദർബോർഡിലെ ഭാഗങ്ങൾ:

  • CPU സോക്കറ്റ്: പ്രോസസ്സർ ഘടിപ്പിക്കുന്ന സ്ഥലം
  • RAM സ്ലോട്ട് (DIMM): റാം ഘടിപ്പിക്കാൻ
  • ചിപ്സെറ്റ് (Chipset): മദർബോർഡിലെ ഘടകങ്ങൾക്കിടയിൽ ഡാറ്റാ ഗതാഗതം നിയന്ത്രിക്കുന്നു
  • എക്സ്പാൻഷൻ സ്ലോട്ടുകൾ (PCI / PCIe): ഗ്രാഫിക്സ്, സൗണ്ട് കാർഡ് തുടങ്ങിയവ ഘടിപ്പിക്കാൻ
  • BIOS ചിപ്പ്, CMOS ബാറ്ററി, SATA കണക്ടറുകൾ

ബസ്സുകൾ (Buses):

മദർബോർഡിൽ ഘടകങ്ങൾക്കിടയിൽ ഡാറ്റയും സിഗ്നലുകളും കൈമാറുന്ന ചെറു വൈദ്യുത പാതകൾ. ഒരേസമയം ബസ്സിലൂടെ പോകുന്ന ബിറ്റുകളുടെ എണ്ണം = ബസ് വിഡ്ത്ത് (Bus Width).

ബസ്ധർമ്മം
Data Busഡാറ്റ കൊണ്ടുപോകുന്നു (ഇരുവശത്തേക്കും)
Address Busഡാറ്റ എവിടെ എന്ന വിലാസം (ഒരു ദിശയിൽ, CPU → മെമ്മറി)
Control Busനിയന്ത്രണ സിഗ്നലുകൾ
🧠 ഓർമ്മ സൂചന

"ഡാറ്റ = ലോറി, അഡ്രസ്സ് = വിലാസം, കൺട്രോൾ = ട്രാഫിക് പോലീസ്"

വൈദ്യുതി ഘടകങ്ങൾ:

  • SMPS (Switched-Mode Power Supply): വിവിധ ഭാഗങ്ങൾക്ക് വേണ്ട വൈദ്യുതി നൽകുന്നു; AC-യെ DC ആക്കി മാറ്റുന്നു.
  • UPS (Uninterruptible Power Supply): വൈദ്യുതി പോയാലും കമ്പ്യൂട്ടർ ഓഫാകാതെ ബാറ്ററി ബാക്കപ്പ് നൽകുന്നു.
🧠 ഓർമ്മ സൂചന

SMPS = "മാറ്റി തരും" (AC→DC); UPS = "ഉടൻ പവർ സപ്പോർട്ട്" (ബാറ്ററി)

  • CMOS ബാറ്ററി (Complementary Metal-Oxide Semiconductor): കമ്പ്യൂട്ടർ ഓഫാക്കിയാലും തീയതിയും സമയവും BIOS സെറ്റിംഗ്സും നഷ്ടപ്പെടാതെ സൂക്ഷിക്കാൻ മദർബോർഡിലുള്ള ചെറിയ വട്ടത്തിലുള്ള ലിഥിയം ബാറ്ററി. സാധാരണ CR2032.
🧠 ഓർമ്മ സൂചന

CMOS = "ക്ലോക്ക് മെമ്മറി ഓൺ സ്റ്റാൻഡ്ബൈ", ഘടികാരത്തിന്റെ ബാറ്ററി.

3B. ഇൻപുട്ട് ഉപകരണങ്ങൾ (10.1.2)

ഉപയോക്താവ് നൽകുന്ന വിവരങ്ങളെയും (Data) നിർദ്ദേശങ്ങളെയും (Instructions) കമ്പ്യൂട്ടറിന് മനസ്സിലാകുന്ന ബൈനറി രൂപത്തിലേക്ക് (0, 1) മാറ്റി CPU-വിലേക്ക് അയക്കുന്ന ഉപകരണങ്ങളാണ് ഇൻപുട്ട് ഉപകരണങ്ങൾ.

2. പോയിന്റിംഗ് ഉപകരണങ്ങൾ (Pointing Devices)

സ്ക്രീനിലെ കഴ്സറിന്റെ (പോയിന്റർ) ചലനം നിയന്ത്രിക്കാൻ ഉപയോഗിക്കുന്നു (GUI – Graphical User Interface-ൽ അനിവാര്യം).

  • മൗസ് (Mouse): ഉപജ്ഞാതാവ് ഡഗ്ലസ് എംഗൽബാർട്ട് (1963/64).
    • Left click = തിരഞ്ഞെടുക്കാൻ (Select) · Right click = മെനു/പ്രോപ്പർട്ടീസ് · Double click = ഫയൽ/പ്രോഗ്രാം തുറക്കാൻ · Drag = വലിച്ചിടാൻ · Scroll = മുകളിലേക്ക്/താഴേക്ക് നീങ്ങാൻ
    • പഴയ മെക്കാനിക്കൽ മൗസിൽ റബ്ബർ പന്ത്; ഇന്നത്തെ ഒപ്റ്റിക്കൽ മൗസിൽ LED ലൈറ്റും ഫോട്ടോഡയോഡും (ഒപ്റ്റിക്കൽ സെൻസർ).
    • ഉപരിതലം നോക്കാതെ വയർലെസ് ആയി പ്രവർത്തിക്കുന്ന മൗസ് ബ്ലൂടൂത്ത്/RF ഉപയോഗിക്കുന്നു.
  • ട്രാക്ക്ബോൾ (Trackball): മൗസ് കമഴ്ത്തിവെച്ചതുപോലെ. ഉപകരണം നീക്കാതെ മുകളിലെ പന്ത് വിരൽകൊണ്ട് കറക്കി പോയിന്റർ നീക്കുന്നു (ലാപ്‌ടോപ്പ്, മെഡിക്കൽ/റഡാർ സിസ്റ്റങ്ങൾ).
  • ജോയ്സ്റ്റിക് (Joystick): വീഡിയോ ഗെയിമുകൾ, ഫ്ലൈറ്റ് സിമുലേറ്റർ, ക്രെയിൻ നിയന്ത്രണം. ഗിയർ ലിവർ പോലെ; 360° കറങ്ങും.
  • ലൈറ്റ് പെൻ (Light Pen): ഫോട്ടോസെൽ ഘടിപ്പിച്ച പേന പോലുള്ള ഉപകരണം; സ്ക്രീനിൽ നേരിട്ട് വരയ്ക്കാനും ഡിസൈൻ (CAD) ചെയ്യാനും ഉപയോഗിക്കുന്നു.
  • ടച്ച്പാഡ് / ട്രാക്ക്പാഡ് (Touchpad): ലാപ്‌ടോപ്പിൽ മൗസിനു പകരം വിരൽസ്പർശം കൊണ്ട് പോയിന്റർ നീക്കുന്ന പ്രതലം.
  • സ്റ്റൈലസ് (Stylus) & ഗ്രാഫിക്സ് ടാബ്‌ലെറ്റ് (Digitizer): ടച്ച് സ്ക്രീനിലും ഡ്രോയിംഗ് പാഡിലും എഴുതാനും വരയ്ക്കാനും ഉപയോഗിക്കുന്ന പേന.
  • ടച്ച് സ്ക്രീൻ: ഇൻപുട്ടും ഔട്ട്പുട്ടും ചെയ്യുന്നു.
🧠 ട്രിക്കുകൾ
  • "ഒപ്റ്റിക്കൽ = ഒളി (ലൈറ്റ്)"; ഒപ്റ്റിക്കൽ മൗസിൽ പന്തില്ല, വെളിച്ചമേയുള്ളൂ.
  • ജോയ് (സന്തോഷം) = ഗെയിം
✏️ തിരുത്തൽ

ക്രിക്കറ്റ് ടി.വി വിശകലനത്തിൽ കാണുന്ന സ്ക്രീനിൽ വരയ്ക്കുന്ന ഉപകരണം ടെലസ്ട്രേറ്റർ (Telestrator) ആണ്. ലൈറ്റ് പെൻ അല്ല.

3. സ്കാനറുകളും ഡയറക്ട് ഡാറ്റാ എൻട്രി ഉപകരണങ്ങളും

കടലാസിലെ വിവരങ്ങളോ ചിത്രങ്ങളോ നേരിട്ട് കമ്പ്യൂട്ടറിലേക്ക് ഡിജിറ്റൽ രൂപത്തിൽ മാറ്റുന്ന ഉപകരണങ്ങൾ. പൂർണ്ണരൂപവും ഉപയോഗവും PSC സ്ഥിരമായി ചോദിക്കുന്നു.

MICR Magnetic Ink Character Recognition ബാങ്ക് ചെക്കുകൾ പരിശോധിക്കാനും പ്രോസസ്സ് ചെയ്യാനും. ചെക്കിനടിയിലെ അക്കങ്ങൾ അയൺ ഓക്സൈഡ് കലർന്ന കാന്തിക മഷിയിൽ. 9 അക്ക കോഡ്: ആദ്യ 3 = നഗരം, അടുത്ത 3 = ബാങ്ക്, അവസാന 3 = ബ്രാഞ്ച്. M = Magnetic / Money; "മണി" (പണം, ചെക്ക്)
OMR Optical Mark Recognition PSC ഉൾപ്പെടെയുള്ള മത്സരപ്പരീക്ഷകളുടെ ഉത്തരക്കടലാസിലെ കറുപ്പിച്ച കുമിളകൾ, സർവ്വേ ഫോമുകൾ പ്രകാശരശ്മി ഉപയോഗിച്ച് വായിക്കുന്നു. M = Mark; ഉത്തരം മാർക്ക് ചെയ്യുന്നത്
OCR Optical Character Recognition അച്ചടിച്ച/എഴുതിയ അക്ഷരങ്ങളുള്ള പേജ് സ്കാൻ ചെയ്ത് എഡിറ്റ് ചെയ്യാവുന്ന ടെക്സ്റ്റ് ആക്കുന്നു. C = Character; അക്ഷരം → ടെക്സ്റ്റ്
ICR Intelligent Character Recognition കൈയെഴുത്ത് അക്ഷരങ്ങൾ വായിക്കുന്ന OCR-ന്റെ പുതിയ രൂപം. I = ഇന്റലിജന്റ്, കൈയെഴുത്ത് തിരിച്ചറിയും
BCR Barcode Reader / Scanner സൂപ്പർമാർക്കറ്റ് / POS (Point of Sale)-ൽ ബാർകോഡുകൾ (UPC – Universal Product Code) ലേസർ ഉപയോഗിച്ച് വായിക്കുന്നു. ഉപജ്ഞാതാവ്: നോർമൻ ജോസഫ് വുഡ്‌ലാൻഡ് (ബെർണാഡ് സിൽവറിനൊപ്പം, 1952-ൽ പേറ്റന്റ്). B = Barcode; ബാർ = വര

1. മോണിറ്റർ (Monitor / VDU – Visual Display Unit)

പ്രധാന സോഫ്റ്റ് കോപ്പി ഔട്ട്പുട്ട് ഉപകരണം.

തരംവിശദീകരണം
CRT (Cathode Ray Tube) പഴയ ടി.വി പോലെ വലുതും ഭാരമുള്ളതും. വാക്വം ട്യൂബ്, ഫോസ്ഫറസ് പുരട്ടിയ സ്ക്രീൻ, ഇലക്ട്രോൺ ഗൺ. വൈദ്യുതി ഉപഭോഗം വളരെ കൂടുതൽ.
LCD (Liquid Crystal Display) രണ്ട് പോളറൈസ്ഡ് ഗ്ലാസ് പാളികൾക്കിടയിൽ ദ്രാവക ക്രിസ്റ്റൽ; കനം കുറഞ്ഞ ഫ്ലാറ്റ് പാനൽ (ലാപ്‌ടോപ്പ്, കാൽക്കുലേറ്റർ). വകഭേദം: TFT (Thin Film Transistor).
LED (Light Emitting Diode) ബാക്ക്‌ലൈറ്റായി LED; കുറഞ്ഞ വൈദ്യുതി, മികച്ച വ്യക്തത. കൂടുതൽ മികച്ചത്: OLED (Organic LED), AMOLED.

മോണിറ്റർ സംബന്ധമായ പ്രധാന പദങ്ങൾ:

  • വലിപ്പം: ഒരു മൂലയിൽനിന്ന് എതിർമൂലയിലേക്ക് കോണോടുകോൺ (Diagonally) ഇഞ്ചിൽ.
  • പിക്സൽ (Pixel – Picture Element): ചിത്രത്തിന്റെ ഏറ്റവും ചെറിയ ഘടകം.
  • റെസല്യൂഷൻ (Resolution): തിരശ്ചീന × ലംബ പിക്സലുകളുടെ എണ്ണം (ഉദാ: 1920 × 1080 = Full HD). പിക്സൽ കൂടുന്തോറും വ്യക്തത കൂടും.
    • HD = 1280×720, Full HD = 1920×1080, 4K (UHD) = 3840×2160, 8K = 7680×4320
  • ആസ്പെക്ട് റേഷ്യോ (Aspect Ratio): വീതി:ഉയരം, ഇന്നത്തെ സാധാരണം 16:9; പഴയത് 4:3.
  • ഡോട്ട് പിച്ച് (Dot Pitch): ഒരേ നിറത്തിലെ അടുത്തടുത്ത രണ്ട് പിക്സലുകൾ തമ്മിലുള്ള കോണോടുകോൺ അകലം (മില്ലിമീറ്റർ). കുറയുന്തോറും വ്യക്തത കൂടും.
  • റിഫ്രഷ് റേറ്റ് (Refresh Rate): ഒരു സെക്കൻഡിൽ സ്ക്രീൻ എത്ര തവണ പുതുക്കുന്നു; യൂണിറ്റ് ഹെർട്സ് (Hz) (60 Hz, 120 Hz).
  • RGB: മോണിറ്ററിലെ അടിസ്ഥാന നിറങ്ങൾ Red, Green, Blue; CMYK പ്രിന്റിംഗിലേത്.
🧠 ട്രിക്കുകൾ
  • "ഡോട്ട് പിച്ച് കുറവ് = വ്യക്തത കൂടുതൽ" (വിപരീതം); റെസല്യൂഷൻ കൂടിയാൽ വ്യക്തത കൂടും.
  • "സ്ക്രീനിൽ RGB, പേപ്പറിൽ CMYK"

2. പ്രിന്ററുകൾ (Printers – Hard Copy)

പ്രിന്ററിന്റെ വ്യക്തത (Resolution) അളക്കുന്ന യൂണിറ്റ്: DPI (Dots Per Inch). പ്രവർത്തനം അനുസരിച്ച് രണ്ട് വിഭാഗം:

(1) ഇംപാക്ട് പ്രിന്ററുകൾ (Impact Printers)

  • ടൈപ്പ്റൈറ്റർ പോലെ പ്രിന്റ് ഹെഡോ പിന്നുകളോ മഷി റിബണിൽ നേരിട്ട് ഇടിച്ച് അക്ഷരം പതിപ്പിക്കുന്നു.
  • സവിശേഷതകൾ: ശബ്ദം കൂടുതൽ, വേഗത കുറവ്, ചെലവ് കുറവ്, കാർബൺ പേപ്പർ വെച്ച് ഒന്നിലധികം കോപ്പി എടുക്കാം.
  • ഉദാഹരണങ്ങൾ:
    • ഡോട്ട് മാട്രിക്സ് പ്രിന്റർ (DMP): 9 അല്ലെങ്കിൽ 24 പിന്നുകൾ റിബണിൽ ഇടിച്ച് കുത്തുകളായി അക്ഷരം. (റെയിൽവേ റിസർവേഷൻ, പോസ്റ്റ് ഓഫീസ്, ബിൽ). വേഗത: CPS (Characters Per Second).
    • ഡെയ്സി വീൽ പ്രിന്റർ: പൂവിതൾ ചക്രത്തിൽ അക്ഷരങ്ങൾ; ഗ്രാഫിക്സ് അച്ചടിക്കാൻ കഴിയില്ല. വേഗത: CPS.
    • ലൈൻ പ്രിന്ററുകൾ (Drum, Chain, Band): ഒരു സമയം ഒരു വരി; വേഗത LPM (Lines Per Minute).

(2) നോൺ-ഇംപാക്ട് പ്രിന്ററുകൾ (Non-Impact Printers)

  • കടലാസിലോ റിബണിലോ ഇടിക്കാതെ ലേസർ, മഷി സ്പ്രേ, താപം എന്നിവ ഉപയോഗിക്കുന്നു.
  • സവിശേഷതകൾ: ശബ്ദമില്ല, വേഗതയും ക്വാളിറ്റിയും കൂടുതൽ, കാർബൺ കോപ്പി പറ്റില്ല. വേഗത: PPM (Pages Per Minute).
  • ഉദാഹരണങ്ങൾ:
    • ലേസർ പ്രിന്റർ: ഏറ്റവും വേഗതയേറിയതും ഉന്നത നിലവാരമുള്ളതും. ഫോട്ടോകോപ്പിയർ തത്വം; ലേസർ ബീമും ഫോട്ടോസെൻസിറ്റീവ് ഡ്രമ്മും. ഉണങ്ങിയ മഷിപ്പൊടി "ടോണർ (Toner)".
      • ലേസർ പ്രിന്റർ പ്രവർത്തനക്രമം: ഡ്രമ്മിൽ ചാർജ് → ലേസർ ചിത്രമെഴുതും → ടോണർ പറ്റും → കടലാസിലേക്ക് മാറ്റി ചൂടാക്കി (Fuser) ഉറപ്പിക്കും.
    • ഇങ്ക്ജെറ്റ് പ്രിന്റർ: സൂക്ഷ്മ നോസിലുകളിലൂടെ ദ്രാവക മഷി സ്പ്രേ ചെയ്യുന്നു; കളർ ഫോട്ടോ പ്രിന്റിംഗ്. CMYK = Cyan, Magenta, Yellow, Black (Key).
    • തെർമ്മൽ പ്രിന്റർ: മഷിയില്ല, താപം ഉപയോഗിച്ച് തെർമ്മോകോമിക് പേപ്പറിൽ അച്ചടിക്കുന്നു. ATM രസീത്, KSRTC ടിക്കറ്റ് മെഷീൻ, സൂപ്പർമാർക്കറ്റ് ബിൽ.
  • 3D പ്രിന്റർ: പ്ലാസ്റ്റിക് പോലുള്ള വസ്തു പാളിയായി അടുക്കി ത്രിമാന വസ്തുക്കൾ നിർമ്മിക്കുന്നു.
  • ബ്രെയിൽ എംബോസർ: അന്ധർക്കുള്ള ബ്രെയിൽ ലിപി ഉയർത്തി അച്ചടിക്കുന്നു.

പ്ലോട്ടർ = "പ്ലാൻ-ടർ" (പ്ലാൻ വരയ്ക്കുന്നത്). ഔട്ട്പുട്ട് ആണ്!

➕ അധിക PSC വസ്തുത: ഇൻപുട്ടും ഔട്ട്പുട്ടും ആയി ഒരേസമയം പ്രവർത്തിക്കുന്ന ഉപകരണങ്ങൾ (Both I/O)

"ഇൻപുട്ട്, ഔട്ട്പുട്ട് ഉപകരണമായി പ്രവർത്തിക്കുന്നത് ഏത്?" എന്ന ചോദ്യത്തിന്റെ ഉത്തരം ഇവയിൽ ഒന്ന്:

  1. ടച്ച് സ്ക്രീൻ: ദൃശ്യം കാണിക്കുന്നു + സ്പർശം സ്വീകരിക്കുന്നു
  2. മോഡം (Modulator-Demodulator): ഡാറ്റ അയക്കുകയും സ്വീകരിക്കുകയും ചെയ്യുന്നു
  3. ഹെഡ്സെറ്റ്: ഇയർഫോൺ + മൈക്രോഫോൺ
  4. ഫാക്സ് മെഷീൻ, മൾട്ടി-ഫംഗ്ഷൻ പ്രിന്റർ (സ്കാനർ + പ്രിന്റർ)
  5. നെറ്റ്‌വർക്ക് ഇന്റർഫേസ് കാർഡ് (NIC), ഓഡിയോ/സൗണ്ട് കാർഡ്

🧠 ട്രിക്ക്: "ടച്ച് മോ ഹെ ഫാ" = ടച്ച് സ്ക്രീൻ, മോഡം, ഹെഡ്സെറ്റ്, ഫാക്സ്

മോണിറ്റർ മാത്രം = ഔട്ട്പുട്ട്; ടച്ച് സ്ക്രീൻ = രണ്ടും. മൈക്ക്, സ്കാനർ = ഇൻപുട്ട് മാത്രം.

3D. പ്രൈമറി മെമ്മറി (Primary / Main Memory) (10.1.4)

CPU-വിന് നേരിട്ട് ബന്ധപ്പെടാൻ (Directly accessible) കഴിയുന്ന ആന്തരിക മെമ്മറി. ഇതിനെ Primary / Main / Internal / Semiconductor Memory എന്നും വിളിക്കുന്നു. RAM, ROM, Cache എന്നിവ ഉൾപ്പെടുന്നു.

🧠 ഓർമ്മ സൂചന

"പ്രൈമറി = പ്രൈം (മുഖ്യം): CPU-വിന്റെ അടുത്ത കൂട്ടുകാരൻ". രജിസ്റ്ററുകളും CPU-വിനുള്ളിലെ മെമ്മറിയായി പ്രൈമറി ഗണത്തിൽ കണക്കാക്കാറുണ്ട്.

1. റാം (RAM – Random Access Memory)

  • പ്രവർത്തിക്കുന്ന പ്രോഗ്രാമുകളും ഡാറ്റയും താത്കാലികമായി സൂക്ഷിക്കുന്ന മെമ്മറി (കമ്പ്യൂട്ടറിന്റെ 'വർക്കിംഗ് ടേബിൾ').
  • വായിക്കാനും (Read) എഴുതാനും (Write) കഴിയുന്നതിനാൽ Read/Write Memory എന്നും അറിയപ്പെടുന്നു.
  • "Random Access" എന്നാൽ ഏത് സ്ഥലത്തെ ഡാറ്റയും ഒരേ സമയം കൊണ്ട് നേരിട്ട് എടുക്കാം (ക്രമത്തിൽ പോകേണ്ട).
  • വൊളറ്റൈൽ മെമ്മറി (Volatile): വൈദ്യുതി നിലച്ചാൽ / കമ്പ്യൂട്ടർ ഓഫാക്കിയാൽ വിവരങ്ങൾ ഉടൻ മാഞ്ഞുപോകും (അസ്ഥിര / താത്കാലിക മെമ്മറി).
🧠 ഓർമ്മ സൂചന

"റാം = റബ്ബർ ബോർഡ്: ഓഫാക്കിയാൽ മായും". Volatile = ആവിയാകുന്നത് (ഇല്ലാതാകുന്നത്).

റാമിന്റെ രണ്ട് പ്രധാന വിഭാഗങ്ങൾ:

റിഫ്രഷ്വേണ്ടവേണം (കപ്പാസിറ്ററിലെ ചാർജ് ചോരുന്നതിനാൽ, മില്ലിസെക്കൻഡ് ഇടവേളകളിൽ)

"S = Speed (Static = വേഗത, സ്ഥിരം, വില കൂടുതൽ); D = Dynamic = ഡിമാൻഡ്: റിഫ്രഷ് വേണം, വില കുറവ്". ലളിതമായി: Static = Stable, Fast, Costly, Cache.

  • DDR = Double Data Rate (ക്ലോക്കിന്റെ ഒരു ചക്രത്തിൽ രണ്ടുതവണ ഡാറ്റ കൈമാറുന്നു). DDR4, DDR5 എന്നിങ്ങനെ പുതിയ പതിപ്പുകൾ.
  • ലാപ്‌ടോപ്പ് റാം: SO-DIMM; ഡെസ്ക്ടോപ്പ്: DIMM.

2. റോം (ROM – Read Only Memory)

  • നിർമ്മാണ സമയത്ത് സ്ഥിരമായി നിർദ്ദേശങ്ങൾ രേഖപ്പെടുത്തിയ മെമ്മറി. സാധാരണ വായിക്കാൻ മാത്രം കഴിയും; മാറ്റം വരുത്താൻ കഴിയില്ല.
  • നോൺ-വൊളറ്റൈൽ (Non-volatile): വൈദ്യുതി നിലച്ചാലും വിവരങ്ങൾ നഷ്ടപ്പെടില്ല.
  • ബയോസ് (BIOS – Basic Input Output System): കമ്പ്യൂട്ടർ ഓൺ ചെയ്യുമ്പോൾ OS-നെ ഹാർഡ് ഡിസ്കിൽനിന്ന് റാമിലേക്ക് ലോഡ് ചെയ്യുന്ന ബൂട്ടിംഗ് (Booting) പ്രക്രിയയ്ക്ക് വേണ്ട പ്രോഗ്രാം. റോമിൽ സൂക്ഷിക്കുന്നു.
  • POST (Power-On Self-Test): ഓൺ ചെയ്യുമ്പോൾ ഹാർഡ്‌വെയർ ശരിയാണോ എന്ന് BIOS നടത്തുന്ന പരിശോധന.
  • ഫേംവെയർ (Firmware): റോം പോലുള്ള ചിപ്പുകളിൽ സ്ഥിരമായി ഉൾക്കൊള്ളിച്ച സോഫ്റ്റ്‌വെയർ.

ബൂട്ടിംഗ് രണ്ട് തരം:

  • കോൾഡ് ബൂട്ട് (Cold Boot): പവർ ഓഫ് ആയതിൽ നിന്ന് ഓൺ ചെയ്യുന്നത്
  • വാം ബൂട്ട് (Warm Boot): ഓടിക്കൊണ്ടിരിക്കുമ്പോൾ Restart (Ctrl+Alt+Del)
🧠 ഓർമ്മ സൂചന

"കോൾഡ് = തണുത്തത് (ഓഫ് ആയത്); വാം = ചൂടുള്ളത് (ഓൺ ആയിരിക്കെ)"

  • ആധുനിക കമ്പ്യൂട്ടറുകളിൽ BIOS-നു പകരം UEFI (Unified Extensible Firmware Interface) ഉപയോഗിക്കുന്നു.
  • ബൂട്ട്സ്ട്രാപ്പ് ലോഡർ: ബൂട്ടിംഗ് തുടങ്ങിവെക്കുന്ന ചെറിയ പ്രോഗ്രാം (റോമിൽ).

റോമിന്റെ തരങ്ങൾ (PSC സ്ഥിരം ചോദ്യം):

തരംവിശദീകരണം🧠 ട്രിക്ക്
MROM (Masked ROM) നിർമ്മാണ സമയത്തുതന്നെ ഡാറ്റ രേഖപ്പെടുത്തുന്ന ആദ്യകാല റോം M = Manufacturer (നിർമ്മാതാവ് എഴുതുന്നു)
PROM (Programmable ROM) ഉപയോക്താവിന് ഒരിക്കൽ മാത്രം എഴുതാം (OTP); മായ്ക്കാൻ പറ്റില്ല P = Once
EPROM (Erasable PROM) അൾട്രാവയലറ്റ് (UV) രശ്മി കൊണ്ട് മായ്ച്ച് വീണ്ടും പ്രോഗ്രാം ചെയ്യാം E = Eliminate with UV ("ഇല്ലാതാക്കാൻ യു.വി.")
EEPROM (Electrically Erasable PROM) ചിപ്പ് പുറത്തെടുക്കാതെ വൈദ്യുതി ഉപയോഗിച്ച് മായ്ക്കാനും എഴുതാനും കഴിയും EE = Electrically Erasable
  • ഫ്ലാഷ് മെമ്മറി: EEPROM-ന്റെ വകഭേദം. പെൻഡ്രൈവ്, മെമ്മറി കാർഡ്, SSD എന്നിവയിൽ. കണ്ടുപിടിച്ചത് ഫുജിയോ മസൂക്ക (Fujio Masuoka, തോഷിബ). ഫ്ലാഷിൽ ഡാറ്റ ബ്ലോക്കുകളായി മായ്ക്കുന്നു.
🧠 ഓർമ്മ സൂചന

ഓർഡർ: MROM → PROM → EPROM → EEPROM (ചെയ്ത് മാറ്റാനുള്ള സ്വാതന്ത്ര്യം കൂടിക്കൂടി വരുന്നു)

3. കാഷെ മെമ്മറി (Cache Memory) & വെർച്വൽ മെമ്മറി

  • കാഷെ മെമ്മറി: CPU-വിനും റാമിനും ഇടയിലുള്ള അതിവേഗ മെമ്മറി (SRAM). CPU-വിന്റെയും റാമിന്റെയും വേഗത്തിലുള്ള വ്യത്യാസം കുറച്ച് പ്രോസസ്സിംഗ് വേഗത കൂട്ടാൻ, CPU കൂടെക്കൂടെ ആവശ്യപ്പെടുന്ന ഡാറ്റ ഇതിൽ സൂക്ഷിക്കുന്നു. തലങ്ങൾ: L1, L2, L3.
    • L1 = CPU-വിനുള്ളിൽ, ഏറ്റവും വേഗം, ശേഷി ഏറ്റവും കുറവ്; L2, L3 അതിനുശേഷം (വേഗത കുറഞ്ഞ് ശേഷി കൂടിവരുന്നു).
🧠 ഓർമ്മ സൂചന

"L1 = ലാസ്റ്റ് സ്റ്റെപ്പ് CPU-വിന് മുമ്പ്" (ഏറ്റവും അടുത്തത്). കാഷെ = "കാഷ്" (പണം) പോലെ കൈയിലുള്ള ചെറിയ അളവ്, ഏറ്റവും വേഗത്തിൽ എടുക്കാവുന്നത്.

⚠️ PSC ശ്രദ്ധ

ഓപ്ഷനിൽ രജിസ്റ്റർ ഉണ്ടെങ്കിൽ ഏറ്റവും വേഗതയേറിയത് രജിസ്റ്റർ; ഇല്ലെങ്കിൽ കാഷെ.

  • വെർച്വൽ മെമ്മറി (Virtual Memory): റാം തികയാതെ വരുമ്പോൾ OS ഹാർഡ് ഡിസ്കിന്റെ ഒരു ഭാഗം താത്കാലികമായി റാം ആയി ഉപയോഗിക്കുന്ന സാങ്കേതികവിദ്യ. (വിൻഡോസിൽ Page file, ലിനക്സിൽ Swap space).
🧠 ഓർമ്മ സൂചന

"വെർച്വൽ = ഭാവനാ (യഥാർത്ഥമല്ലാത്ത) റാം": ഡിസ്കിനെ റാമായി നടിക്കുന്നു, പക്ഷേ വേഗത കുറവ്.

➕ ആകെ വൊളറ്റൈൽ vs നോൺ-വൊളറ്റൈൽ

വൊളറ്റൈൽ: RAM, Cache, Registers.
നോൺ-വൊളറ്റൈൽ: ROM, എല്ലാ സെക്കൻഡറി മെമ്മറികളും.

3E. സെക്കൻഡറി മെമ്മറി (Secondary / Auxiliary / Backing Storage) (10.1.5)

റാമിന് ശേഷി കുറവും വില കൂടുതലും ആയതിനാൽ, വലിയ അളവിലുള്ള ഫയലുകളും പ്രോഗ്രാമുകളും സ്ഥിരമായി (Non-volatile) സൂക്ഷിക്കാനുള്ള ബാഹ്യ മെമ്മറി. CPU-വിന് നേരിട്ട് ആക്സസ് ഇല്ല; ഡാറ്റ ആദ്യം റാമിൽ എത്തണം.

സാങ്കേതികവിദ്യ അനുസരിച്ച് മൂന്ന് വിഭാഗം: കാന്തിക (Magnetic), പ്രകാശിക (Optical), ഫ്ലാഷ് (Flash / Solid State).

🧠 ഓർമ്മ സൂചന

"മാ-ഒ-ഫ്ലാ" = മാഗ്നറ്റിക്, ഒപ്റ്റിക്കൽ, ഫ്ലാഷ്

1. കാന്തിക സംഭരണ ഉപകരണങ്ങൾ (Magnetic)

  • മാഗ്നറ്റിക് ടേപ്പ് (Magnetic Tape): പ്ലാസ്റ്റിക് റിബണിൽ കാന്തിക പദാർത്ഥം (ഓഡിയോ കാസറ്റ് പോലെ). ക്രമത്തിൽ മാത്രം വായിക്കാം, അതിനാൽ സീക്വൻഷ്യൽ ആക്സസ്; മറ്റ് ഡിസ്കുകൾ ഡയറക്ട്/റാൻഡം ആക്സസ്. വില കുറവ്; ബാക്കപ്പ്, ആർക്കൈവിംഗ് എന്നിവയ്ക്ക് ഉപയോഗം.
🧠 ഓർമ്മ സൂചന

ടേപ്പ് = "ടേപ്പ് റെക്കോർഡർ": പാട്ടിന്റെ അവസാനത്തേക്ക് പോകാൻ എല്ലാം കടന്നുപോകണം

  • ഫ്ലോപ്പി ഡിസ്ക് (Floppy Disk / Diskette): ചതുരാകൃതിയിലുള്ള പ്ലാസ്റ്റിക് കവറിനുള്ളിലെ വഴക്കമുള്ള (Flexible) കാന്തിക ഡിസ്ക് (മൈലാർ പ്ലാസ്റ്റിക്). വലിപ്പങ്ങൾ: 8 ഇഞ്ച്, 5.25 ഇഞ്ച് (1.2 MB), 3.5 ഇഞ്ച്. ഏറ്റവും വ്യാപകം: 3.5 ഇഞ്ച് = 1.44 MB.
    • IBM 1971-ൽ ആദ്യ (8 ഇഞ്ച്) ഫ്ലോപ്പി പുറത്തിറക്കി. 3.5 ഇഞ്ച് ഫ്ലോപ്പി വികസിപ്പിച്ചത് സോണി (1981).
🧠 ഓർമ്മ സൂചന

"ഫ്ലോപ്പി ഫോർട്ടി-ഫോർ: 1.44" (1 · 44)

  • ഹാർഡ് ഡിസ്ക് ഡ്രൈവ് (HDD): അലുമിനിയം/ഗ്ലാസ് തട്ടുകൾ (Platters) കാന്തിക പദാർത്ഥം (അയൺ ഓക്സൈഡ്) പുരട്ടി ഒന്നിനുമീതെ ഒന്നായി അടുക്കി അതിവേഗം (5400 അല്ലെങ്കിൽ 7200 RPM) കറങ്ങുന്നു. ഡാറ്റ വായിക്കാനും എഴുതാനും റീഡ്/റൈറ്റ് ഹെഡുകൾ.
    • ഡിസ്കിലെ വൃത്താകൃതിയിലുള്ള പാതകൾ = ട്രാക്കുകൾ (Tracks); ട്രാക്കിലെ ചെറു വിഭാഗങ്ങൾ = സെക്ടറുകൾ (Sectors). ട്രാക്കും സെക്ടറും നിർമ്മിക്കുന്ന പ്രക്രിയ = ഫോർമാറ്റിംഗ് (Formatting).
    • സ്പിൻഡിൽ (തട്ടുകൾ കറക്കുന്ന അച്ചുതണ്ട്), ആക്ച്വേറ്റർ ആം (ഹെഡ് നീക്കുന്ന കൈ).
    • 1956-ൽ IBM (റെയ്നോൾഡ് ജോൺസൺ) ആദ്യ ഹാർഡ് ഡിസ്ക് (RAMAC 305) നിർമ്മിച്ചു. ഇതിന്റെ ശേഷി ഏകദേശം 5 MB ആയിരുന്നു.
🧠 ഓർമ്മ സൂചന

"ട്രാക്ക് = റോഡ്, സെക്ടർ = റോഡിലെ കഷണം"

2. പ്രകാശിക സംഭരണ ഉപകരണങ്ങൾ (Optical)

ഡിസ്ക് പ്രതലത്തിലെ സൂക്ഷ്മ കുഴികളും (Pits) നിരപ്പായ ഭാഗങ്ങളും (Lands) ഉപയോഗിച്ച് ലേസർ രശ്മി കൊണ്ട് എഴുതുകയും വായിക്കുകയും ചെയ്യുന്നു. ഡിസ്കിന്റെ ഒരു സ്പൈറൽ (ചുരുളൻ) ട്രാക്കിലാണ് ഡാറ്റ.

ഡിസ്ക്ലേസർശേഷി🧠
CD (Compact Disc) ഇൻഫ്രാറെഡ് (780 nm) 700 MB (അല്ലെങ്കിൽ 650 MB). വ്യാസം 12 സെ.മീ "സി.ഡി ഏഴുനൂറ്"
DVD (Digital Versatile Disc / Digital Video Disc) ചുവപ്പ് (650 nm) Single layer 4.7 GB, Dual layer 8.5 GB, Double-sided single 9.4 GB, Double-sided dual 17 GB "ഡി.വി.ഡി ഫോർ-സെവൻ"
Blu-ray Disc (BD) നീല-വയലറ്റ് (405 nm), ഹൈ-ഡെഫനിഷൻ / 4K Single layer 25 GB, Dual layer 50 GB, Multi layer 100–128 GB "ബ്ലൂ-റേ ട്വന്റിഫൈവ്"
  • പേര് "Blu-ray" (Blue-ray അല്ല) എന്ന് 'e' ഇല്ലാതെ.
  • തരംഗദൈർഘ്യം കുറഞ്ഞ ലേസർ = കൂടുതൽ ചെറിയ കുഴികൾ = കൂടുതൽ ശേഷി.
🧠 ഓർമ്മ സൂചന

"ലേസർ നിറം: CD-ഇൻഫ്രാറെഡ്, DVD-ചുവപ്പ്, Blu-ray-നീല"; തരംഗദൈർഘ്യം കുറയുന്ന ക്രമത്തിൽ ശേഷി കൂടുന്നു

CD തരങ്ങൾ:

  • CD-ROM: നിർമ്മാണ സമയത്ത് രേഖപ്പെടുത്തിയത്; വായിക്കാൻ മാത്രം
  • CD-R (Recordable): ഒരിക്കൽ മാത്രം എഴുതാം (Burn), പലതവണ വായിക്കാം = WORM (Write Once, Read Many)
  • CD-RW (ReWritable): മായ്ച്ച് പലതവണ എഴുതാം
🧠 ഓർമ്മ സൂചന

R = Record (ഒരു തവണ), RW = ReWrite (പല തവണ), ROM = Read മാത്രം

DVD-യിലും DVD-ROM, DVD-R, DVD-RW, DVD-RAM തരങ്ങൾ ഉണ്ട്.

3. ഫ്ലാഷ് / സോളിഡ് സ്റ്റേറ്റ് മെമ്മറി (Flash / Solid State)

ചലിക്കുന്ന ഭാഗങ്ങളില്ലാത്ത (No moving parts), EEPROM/ഫ്ലാഷ് സാങ്കേതികവിദ്യ ഉപയോഗിക്കുന്ന സെമികണ്ടക്ടർ മെമ്മറി.

  • SSD (Solid State Drive): ആധുനിക ലാപ്‌ടോപ്പ്/കമ്പ്യൂട്ടറിൽ HDD-ക്ക് പകരം. ശബ്ദമില്ല, ചൂട് കുറവ്, വീണാലും കേടുപാട് സാധ്യത കുറവ്, ബൂട്ടിംഗ് വളരെ വേഗം. എന്നാൽ ഒരു GB-ക്കുള്ള വില HDD-യേക്കാൾ കൂടുതൽ.
  • പെൻഡ്രൈവ് (Pen Drive / USB Flash Drive / Thumb Drive) & മെമ്മറി കാർഡ് (SD Card – Secure Digital): USB പോർട്ട് / കാർഡ് സ്ലോട്ട് വഴി എളുപ്പത്തിൽ കൊണ്ടുനടക്കാം. microSD മൊബൈലുകളിൽ.

➕ HDD vs SSD
  • HDD = കറങ്ങുന്ന കാന്തിക തട്ടുകൾ, ശബ്ദം, വേഗത കുറവ്, വില കുറവ്, ശേഷി കൂടുതൽ.
  • SSD = ഫ്ലാഷ് ചിപ്പ്, നിശ്ശബ്ദം, വേഗത കൂടുതൽ, വില കൂടുതൽ.

5. പ്രധാന വസ്തുതകൾ (Important Facts)

  • കമ്പ്യൂട്ടറിന്റെ തലച്ചോറ്: CPU; നാഡീവ്യൂഹം: Control Unit (CU); ഗണിത-യുക്‌തി ക്രിയകൾ: ALU.

  • ലേസർ പ്രിന്ററിലെ ഉണങ്ങിയ മഷിപ്പൊടി: ടോണർ; ATM / ബസ് ടിക്കറ്റ് മെഷീൻ: തെർമ്മൽ പ്രിന്റർ.
  • പ്രിന്റർ വ്യക്തത: DPI; ലേസർ/ഇങ്ക്ജെറ്റ് വേഗത: PPM; ഡോട്ട് മാട്രിക്സ്: CPS; ലൈൻ പ്രിന്റർ: LPM.
  • വൈദ്യുതി പോയാൽ ഡാറ്റ നഷ്ടപ്പെടുന്നത് (Volatile): RAM. നഷ്ടപ്പെടാത്തത് (Non-volatile): ROM & എല്ലാ സെക്കൻഡറി മെമ്മറികളും.
  • BIOS സൂക്ഷിക്കുന്നത്: ROM-ൽ.
  • UV രശ്മി കൊണ്ട് മായ്ക്കാവുന്ന റോം: EPROM; വൈദ്യുതി കൊണ്ട്: EEPROM.
  • മെമ്മറിയുടെ ഏറ്റവും ചെറിയ യൂണിറ്റ്: ബിറ്റ് (0/1); 4 ബിറ്റ് = 1 നിബിൾ; 8 ബിറ്റ് = 1 ബൈറ്റ്.

12. Common PSC Traps (പരീക്ഷയിലെ ചതിക്കുഴികൾ)

⚠️ Trap 1 — 1 KB = 1000 ബൈറ്റോ 1024 ബൈറ്റോ?

ബൈനറിയിൽ 1 KB = 1024 Bytes (210). ഓപ്ഷനിൽ 1000 കണ്ടാൽ എടുക്കരുത്.

⚠️ Trap 2 — പ്ലോട്ടർ ഇൻപുട്ടോ ഔട്ട്പുട്ടോ?

ഔട്ട്പുട്ട്.

⚠️ Trap 3 — ഒപ്റ്റിക്കൽ മെമ്മറി ഏത്?

ഫ്ലോപ്പി, ഹാർഡ് ഡിസ്ക് = കാന്തിക; പെൻഡ്രൈവ്, SSD = ഫ്ലാഷ്; CD, DVD, Blu-ray = ഒപ്റ്റിക്കൽ.

⚠️ Trap 4 — മോണിറ്റർ വലിപ്പം

കോണോടുകോൺ (Diagonal), നീളം/വീതി അല്ല.

⚠️ Trap 5 — BIOS vs CMOS

BIOS = ROM-ലെ പ്രോഗ്രാം; CMOS = തീയതി/സമയം/ക്രമീകരണം നിലനിർത്തുന്ന ബാറ്ററി.

⚠️ Trap 6 — ഏറ്റവും വേഗതയേറിയത്

ഓപ്ഷനിൽ രജിസ്റ്റർ ഉണ്ടോ എന്ന് നോക്കുക.

⚠️ Trap 7 — ടച്ച് സ്ക്രീൻ

ഇൻപുട്ട് മാത്രമല്ല; ഇൻപുട്ട് + ഔട്ട്പുട്ട്.

⚠️ Trap 8 — ലൈറ്റ് പെൻ vs ടെലസ്ട്രേറ്റർ

ടി.വിയിൽ വരയ്ക്കുന്നത് ടെലസ്ട്രേറ്റർ.

⚠️ Trap 9 — ഫ്ലാഷ് മെമ്മറി

ഇത് EEPROM-ന്റെ വകഭേദം; EPROM (UV) അല്ല.

ശരിയുത്തരം: (B) 1.44 MB
5.25 ഇഞ്ച് = 1.2 MB; 3.5 ഇഞ്ച് = 1.44 MB. 🧠 "ഫ്ലോപ്പി ഫോർട്ടി-ഫോർ".
14. ഒരു ബൈറ്റിൽ എത്ര ബിറ്റുകൾ ഉണ്ട്?
ശരിയുത്തരം: (C) 8
1 ബൈറ്റ് = 8 ബിറ്റുകൾ = 2 നിബിളുകൾ. 4 ബിറ്റ് = 1 നിബിൾ.
15. ബ്ലൂ-റേ ഡിസ്കിൽ ഉപയോഗിക്കുന്ന ലേസർ?
ശരിയുത്തരം: (C) നീല-വയലറ്റ് (405 nm)

18. Exam Tips / ഒഴിവാക്കേണ്ട അബദ്ധങ്ങൾ

  1. Volatile ആണോ അല്ലയോ? RAM, Cache, Registers മാത്രം വൊളറ്റൈൽ. ROM + എല്ലാ സെക്കൻഡറി മെമ്മറികളും (HDD, SSD, CD, DVD, Pen drive, Floppy) നോൺ-വൊളറ്റൈൽ.
  2. കീ പേരുകൾ: Caps Lock, Num Lock, Scroll Lock = ടോഗിൾ; Shift, Ctrl, Alt = മോഡിഫയർ. 🧠 "Lock" ഉള്ളത് ടോഗിൾ.
  3. പൂർണ്ണരൂപത്തിലെ അവസാന വാക്ക്: MICR, OMR, OCR എന്നിവയിൽ R = Recognition (അല്ലെങ്കിൽ Reader), Record/Register/Response അല്ല.
  4. യൂണിറ്റ് ചോദ്യങ്ങളിൽ b/B ശ്രദ്ധിക്കുക.
  5. "ഒഴിവാക്കൽ രീതി" (Elimination): Odd-one-out ചോദ്യത്തിൽ ആദ്യം ഇൻപുട്ട്/ഔട്ട്പുട്ട്/സ്റ്റോറേജ് എന്ന് ഓരോ ഓപ്ഷനും വർഗ്ഗീകരിക്കുക.

19. Top Maximum Facts (ഏറ്റവും പ്രധാന 15)

🏆 പരീക്ഷയ്ക്ക് തൊട്ടുമുമ്പ് നിർബന്ധമായും അറിഞ്ഞിരിക്കേണ്ടവ
  1. തലച്ചോറ്: CPU; നാഡീവ്യൂഹം: CU; ഗണിതം: ALU.
  2. ഏറ്റവും വേഗതയേറിയ മെമ്മറി: രജിസ്റ്റർ; CPU-RAM ഇടയിൽ: കാഷെ (SRAM).
  3. മൗസ്: ഡഗ്ലസ് എംഗൽബാർട്ട്; കീബോർഡ്/QWERTY: ക്രിസ്റ്റഫർ ലാഥം ഷോൾസ്.
  4. ബാങ്ക് ചെക്ക്: MICR; പരീക്ഷാ ഷീറ്റ്: OMR.
  5. വലിയ ഡ്രോയിംഗുകൾ / ഭൂപടങ്ങൾ അച്ചടിക്കുന്ന ഔട്ട്പുട്ട്: പ്ലോട്ടർ.
  6. ടോണർ: ലേസർ; ATM / ബസ് ടിക്കറ്റ്: തെർമ്മൽ.
  7. വ്യക്തത: DPI; ലേസർ വേഗത: PPM.
  8. ചിത്രത്തിന്റെ ഏറ്റവും ചെറിയ ഘടകം: പിക്സൽ; മോണിറ്റർ വലിപ്പം: കോണോടുകോൺ.
  9. താത്കാലിക മെമ്മറി: RAM (Volatile).
  10. സ്ഥിര പ്രൈമറി മെമ്മറി: ROM; BIOS ഇതിൽ.
  11. UV മായ്ക്കൽ: EPROM; വൈദ്യുതി: EEPROM.
  12. ശേഷി: ഫ്ലോപ്പി 1.44 MB · CD 700 MB · DVD 4.7 GB · Blu-ray 25/50 GB.
  13. CD-R = WORM (Write Once, Read Many).
  14. Bit ഏറ്റവും ചെറിയ യൂണിറ്റ്; 4 bits = Nibble; 8 bits = Byte.
  15. 1024 B = 1 KB → 1024 KB = 1 MB → 1024 MB = 1 GB → 1024 GB = 1 TB → 1024 TB = 1 PB (തുടർന്ന് EB, ZB, YB).

20. 5-Minute / Last-Minute Revision

⏱️ 5 മിനിറ്റിൽ മുഴുവൻ റിവിഷൻ
  • CPU = ALU + CU + Registers · ആദ്യ മൈക്രോപ്രൊസസ്സർ: Intel 4004 (1971) · ഇന്ത്യൻ: Shakti, Vega.
  • കീകൾ: Function (F1–F12) · Toggle (Caps, Num, Scroll Lock) · Modifier (Shift, Ctrl, Alt).
  • പോയിന്റിംഗ് (Input): Mouse, Trackball, Joystick, Light Pen, Touchpad, Stylus.
  • സ്കാനറുകൾ: MICR (ചെക്ക്) · OMR (പരീക്ഷ) · OCR (ടെക്സ്റ്റ്) · BCR (ബാർകോഡ്) · QR (2D).
  • പ്രിന്റർ: Impact (DMP [CPS], Daisy wheel, Line [LPM]) · Non-Impact (Laser [Toner, PPM], Inkjet, Thermal [ATM/KSRTC]).
  • I/O: Touch screen, Modem, Headset, Fax.
  • പ്രൈമറി: RAM (Volatile: SRAM [Cache], DRAM [Main]) · ROM (Non-volatile: BIOS; PROM, EPROM [UV], EEPROM [വൈദ്യുതി]).
  • സെക്കൻഡറി: Magnetic (Tape [Sequential], Floppy 1.44 MB, HDD [Track, Sector]) · Optical (CD 700 MB, DVD 4.7 GB, Blu-ray 25/50 GB) · Flash (SSD, Pen drive, SD).
  • വേഗത ക്രമം: Registers → Cache → RAM → SSD → HDD → Optical → Tape.
  • യൂണിറ്റ്: Bit → Nibble (4) → Byte (8) → KB → MB → GB → TB → PB → EB → ZB → YB (×1024).
