⭐ Star Guide

⭐ പ്രാധാന്യ സൂചകങ്ങൾ (Kerala PSC അടിസ്ഥാനത്തിൽ)
  • ⭐⭐⭐⭐⭐ അതിപ്രധാനം — തുക വിഭജനം (a:b:cൽ), വ്യത്യാസത്തിൽ നിന്ന് സംഖ്യ കാണൽ, A:B:C സംയോജനം, മധ്യാനുപാതം (√ab), മൂന്നാം അനുപാതം (b²/a), നാലാം അനുപാതം (bc/a), ല.സ.ഗു-അംശബന്ധ കണക്ക്, വയസ്സ് ചോദ്യങ്ങൾ
  • ⭐⭐⭐⭐ പ്രധാനം — ഡ്യൂപ്ലിക്കേറ്റ് (a²:b²), സബ്-ഡ്യൂപ്ലിക്കേറ്റ് (√a:√b), ട്രിപ്ലിക്കേറ്റ് (a³:b³), സബ്-ട്രിപ്ലിക്കേറ്റ് (∛a:∛b), ശതമാനം ↔ അംശബന്ധം, നാണയ കണക്കുകൾ
  • ⭐⭐⭐ ശ്രദ്ധിക്കേണ്ടത് — പങ്കാളിത്തം (C×T), മിശ്രിതം/അലിഗേഷൻ, സംഖ്യകളോട് സംഖ്യ കൂട്ടൽ, ഭിന്നസംഖ്യാ അംശബന്ധം (1/2:1/3 → 3:2)
  • ⭐⭐ അറിഞ്ഞാൽ മതി — തുടർ അനുപാതം, അനുപാത ഗുണധർമ്മങ്ങൾ (Componendo–Dividendo), നേർ–വിപരീത അനുപാതം
  • ⭐ അടിസ്ഥാന റിമൈൻഡർ — അംശബന്ധത്തിന് യൂണിറ്റ് ഇല്ല; രണ്ട് അളവുകളും ഒരേ യൂണിറ്റിൽ ആയിരിക്കണം
➕ ചുരുക്കം
  • a : b :: c : d ⇒ ad = bc
  • മധ്യാനുപാതം = √ab (സംഖ്യകൾക്കിടയിൽ)
  • മൂന്നാം അനുപാതം = b²/a
  • നാലാം അനുപാതം = bc/a
  • A:B = a:b, B:C = c:d ⇒ A:B:C = ac:bc:bd
  • Sub = മൂലം; Sub ഇല്ലെങ്കിൽ കൃതി

1. അധ്യായ ആമുഖം

  • ⭐⭐⭐⭐⭐ വിഷയം: ഒരേ ഇനത്തിൽപ്പെട്ട (ഒരേ യൂണിറ്റിലുള്ള) രണ്ടോ അതിലധികമോ അളവുകളെ പരസ്പരം താരതമ്യം ചെയ്യുന്ന ഗണിതരീതിയാണ് അംശബന്ധം (Ratio). രണ്ട് അംശബന്ധങ്ങൾ തുല്യമാകുമ്പോൾ അതിനെ അനുപാതം (Proportion) എന്ന് വിളിക്കുന്നു.
  • ⭐⭐⭐⭐ PSC പ്രാധാന്യം: കേരള പി.എസ്.സി പരീക്ഷകളിൽ (പത്താം ക്ലാസ് തലം, പ്ലസ് ടു തലം, ഡിഗ്രി തലം) ഈ അധ്യായത്തിൽ നിന്ന് സാധാരണയായി ഒന്നോ അതിലധികമോ ചോദ്യങ്ങൾ കാണാറുണ്ട്. ചോദ്യങ്ങളുടെ കൃത്യമായ എണ്ണം ഓരോ പരീക്ഷയിലും വ്യത്യാസപ്പെടും.
  • ⭐⭐⭐⭐ മറ്റ് അധ്യായങ്ങളുമായുള്ള ബന്ധം: വയസ്സ്, പങ്കാളിത്തം (Partnership), മിശ്രിതങ്ങൾ, സമയവും ദൂരവും, ശതമാനം തുടങ്ങിയ അധ്യായങ്ങളിലെ കണക്കുകൾ അംശബന്ധം ഉപയോഗിച്ച് സമവാക്യമില്ലാതെ വേഗത്തിൽ ചെയ്യാം. അതിനാൽ ഇത് ലഘുഗണിതത്തിന്റെ അടിസ്ഥാന അധ്യായമാണ്.
  • ⭐⭐⭐⭐ സ്ഥിരമായി കാണുന്ന ചോദ്യ മാതൃകകൾ: A:B:C കാണൽ, തുക വീതിക്കൽ, മൂന്നാം അനുപാതം, മധ്യാനുപാതം, നാണയ കണക്കുകൾ, വയസ്സുകളുടെ അംശബന്ധം, ല.സ.ഗു-അംശബന്ധ കണക്കുകൾ.

2. പിന്നാമ്പുറ കഥ

അമ്മ ദോശമാവ് ഉണ്ടാക്കുമ്പോൾ 2 ഗ്ലാസ് അരിക്ക് 1 ഗ്ലാസ് ഉഴുന്ന് എടുക്കുന്നു. അരിയും ഉഴുന്നും തമ്മിലുള്ള ബന്ധം 2 : 1 ആണ്.

കല്യാണ സദ്യയ്ക്ക് പാചകക്കാരൻ 100 കിലോ അരിയും 50 കിലോ ഉഴുന്നും എടുക്കുന്നു. 100 : 50 നെ 50 കൊണ്ട് ഹരിച്ചാലും 2 : 1 തന്നെ കിട്ടും.

അളവ് 2 ഗ്ലാസായാലും 100 കിലോയായാലും അവ തമ്മിലുള്ള ബന്ധം മാറിയില്ല. ഈ ബന്ധമാണ് അംശബന്ധം (Ratio). രണ്ട് കൂട്ടുകളും ഒരേ രുചി തരുന്നതിനാൽ 2 : 1 = 100 : 50 ആണ്. ഇങ്ങനെ രണ്ട് അംശബന്ധങ്ങൾ തുല്യമാകുന്നതിനെ അനുപാതം (Proportion) എന്ന് പറയുന്നു.

🧠 ഓർമ്മ

അംശബന്ധം = ഒരു താരതമ്യം (2:1 — "ഇത് അതിന്റെ ഇരട്ടി"). അനുപാതം = രണ്ട് താരതമ്യങ്ങൾ തുല്യം (2:1 = 100:50).

3. A. അംശബന്ധത്തിന്റെ അടിസ്ഥാന നിയമങ്ങളും തരങ്ങളും

a, b എന്നീ രണ്ട് അളവുകളുടെ അംശബന്ധം a : b എന്ന് എഴുതുന്നു ("a ടു b" എന്ന് വായിക്കും). ഭിന്നസംഖ്യാ രൂപത്തിൽ a/b എന്നും എഴുതാം.

  • a-യെ പൂർവ്വപദം (Antecedent) എന്നും b-യെ ഉത്തരപദം (Consequent) എന്നും വിളിക്കുന്നു.

3.1 അടിസ്ഥാന നിയമങ്ങൾ

⭐ 4 പ്രധാന നിയമങ്ങൾ
  1. നിയമം 1 – യൂണിറ്റ് തുല്യമായിരിക്കണം: രണ്ട് അളവുകളും ഒരേ യൂണിറ്റിൽ ആയിരിക്കണം. അംശബന്ധത്തിന് സ്വന്തമായി യൂണിറ്റ് ഇല്ല.
    ഉദാ: 2 മീറ്ററും 50 സെ.മീ-ഉം തമ്മിലുള്ള അംശബന്ധം: 2 m = 200 cm, അതിനാൽ 200 : 50 = 4 : 1. (2 : 50 എന്ന് നേരിട്ട് എഴുതരുത്.)
  2. നിയമം 2 – ലഘുരൂപം: പൊതുഘടകം (ഉ.സ.ഘ) കൊണ്ട് ഹരിച്ച് ലഘുരൂപത്തിൽ എഴുതുക. ഉദാ: 6 : 8 = 3 : 4; 12 : 18 = 2 : 3.
  3. നിയമം 3 – മൂല്യം മാറാത്ത പ്രവൃത്തികൾ: രണ്ട് പദങ്ങളെയും ഒരേ പൂജ്യമല്ലാത്ത സംഖ്യ കൊണ്ട് ഗുണിച്ചാലോ ഹരിച്ചാലോ അംശബന്ധം മാറില്ല. എന്നാൽ രണ്ട് പദങ്ങളോടും ഒരേ സംഖ്യ കൂട്ടിയാലോ കുറച്ചാലോ അംശബന്ധം മാറും.
  4. നിയമം 4 – ക്രമം പ്രധാനം: a : b യും b : a യും വ്യത്യസ്തമാണ്. ചോദ്യത്തിൽ "ആരുടെ : ആരുടെ" എന്ന ക്രമം നോക്കുക.

3.2 അംശബന്ധങ്ങൾ താരതമ്യം ചെയ്യൽ

a : b യും c : d യും താരതമ്യം ചെയ്യാൻ കോണോടുകോൺ ഗുണിക്കുക (a/b vs c/d):

  • ad > bc ആയാൽ a : b വലുത്; ad < bc ആയാൽ c : d വലുത്.
  • ഉദാ: 3 : 4 ഉം 5 : 7 ഉം. 3 × 7 = 21, 4 × 5 = 20. 21 > 20 ആയതിനാൽ 3 : 4 വലുത്.

🧠 Trick (വേഗവഴി): a/b ന് 1-ൽ നിന്നുള്ള വിടവ് (b−a)/b കുറയുന്തോറും അംശബന്ധം വലുതാണ്. (a < b ആകുമ്പോൾ മാത്രം.)

3.3 വിവിധ തരം അംശബന്ധങ്ങൾ

🧠 6 പ്രധാന തരങ്ങൾ
  1. വിപരീത അംശബന്ധം (Inverse / Reciprocal):
    • a : b യുടെ വിപരീതം b : a (4 : 5 → 5 : 4).
    • a : b : c യുടെ വിപരീതം 1/a : 1/b : 1/c = bc : ac : ab.
    • ഉദാ: 2 : 3 : 4 ന്റെ വിപരീതം = (3×4) : (2×4) : (2×3) = 12 : 8 : 6 = 6 : 4 : 3.
  2. ഡ്യൂപ്ലിക്കേറ്റ് റേഷ്യോ (Duplicate): വർഗ്ഗങ്ങളുടെ അംശബന്ധം a² : b². (3 : 4 → 9 : 16)
  3. സബ്-ഡ്യൂപ്ലിക്കേറ്റ് റേഷ്യോ (Sub-duplicate): വർഗ്ഗമൂലങ്ങളുടെ അംശബന്ധം √a : √b.
    PSC ശൈലി: 81 : 49 → √81 : √49 = 9 : 7.
  4. ട്രിപ്ലിക്കേറ്റ് റേഷ്യോ (Triplicate): ഘനങ്ങളുടെ അംശബന്ധം a³ : b³.
    PSC ശൈലി: 2 : 5 → 8 : 125.
  5. സബ്-ട്രിപ്ലിക്കേറ്റ് റേഷ്യോ (Sub-triplicate): ഘനമൂലങ്ങളുടെ അംശബന്ധം ∛a : ∛b.
    PSC ശൈലി: 64 : 27 → 4 : 3.
  6. സംയുക്ത അംശബന്ധം (Compound): a : b, c : d എന്നിവയുടെ സംയുക്തം = ac : bd. ഉദാ: 2 : 3, 4 : 5 → 8 : 15.
⭐ ഓർമ്മിക്കുക

"Sub" എന്ന് വന്നാൽ മൂലം (root) കാണുക. "Sub" ഇല്ലെങ്കിൽ കൃതി (വർഗ്ഗം/ഘനം) കാണുക.

4. B. അംശബന്ധങ്ങൾ സംയോജിപ്പിക്കലും രൂപമാറ്റങ്ങളും

4.1 A : B ഉം B : C ഉം തന്നാൽ A : B : C

⭐ അടിസ്ഥാന തത്വം

രണ്ട് അംശബന്ധങ്ങളിലും പൊതുവായുള്ള പദം (B) തുല്യമാക്കുക. ഇതിന് B-യുടെ രണ്ട് വിലകളുടെ ല.സ.ഗു ഉപയോഗിക്കാം (ഏറ്റവും സുരക്ഷിതം), അല്ലെങ്കിൽ ക്രോസ് ഗുണനം.

സൂത്രവാക്യം:
A : B = a : b, B : C = c : d ആയാൽ
A : B : C = ac : bc : bd

A : C മാത്രം വേണമെങ്കിൽ: A/C = (A/B) × (B/C)
🧠 ഉദാഹരണം 1 – PSC ശൈലി

u : v = 4 : 7, v : w = 9 : 7. അപ്പോൾ u : v : w = (4×9) : (7×9) : (7×7) = 36 : 63 : 49 ആണ്. അതിനാൽ u : w = 36 : 49.

🧠 ഉദാഹരണം 2 – PSC ശൈലി

A : B = 7 : 8, B : C = 7 : 9. അപ്പോൾ A/C = (7/8) × (7/9) = 49/72, അതായത് A : C = 49 : 72.

🧠 ഉദാഹരണം 3 – ല.സ.ഗു രീതി

A : B = 3 : 4, B : C = 6 : 7. B-യുടെ വിലകൾ 4, 6; ല.സ.ഗു 12.

A : B = 9 : 12 (×3), B : C = 12 : 14 (×2).

അതിനാൽ A : B : C = 9 : 12 : 14.

4.2 A : B ഉം A : C ഉം തന്നാൽ

ഇവിടെ പൊതുവായ പദം A ആണ്. A തുല്യമാക്കുക.

ഉദാ.: A : B = 2 : 3, A : C = 4 : 5 ആയാൽ
A : B = 4 : 6 (A-യെ 4 ആക്കുക)
അതിനാൽ A : B : C = 4 : 6 : 5

4.3 നാല് അംശബന്ധങ്ങൾ (A:B, B:C, C:D)

ഓരോ ഘട്ടത്തിലും പൊതുപദം തുല്യമാക്കി ഒരുമിപ്പിക്കുക.

ഉദാ.: A : B = 1 : 2, B : C = 3 : 4, C : D = 5 : 6
ഘട്ടംABCD
ഘട്ടം 1 (A : B : C)1×3 = 32×3 = 62×4 = 8—

അതിനാൽ A : B : C : D = 15 : 30 : 40 : 48.

4.4 ഭിന്നസംഖ്യാ രൂപത്തിലും ഗുണിത രൂപത്തിലുമുള്ള അംശബന്ധങ്ങൾ

🧠 കേസ് 1 – ഭിന്നസംഖ്യാ രൂപം

A/3 = B/4 = C/5 ആയാൽ A : B : C = 3 : 4 : 5.

🧠 കേസ് 2 – ഗുണിത രൂപം

2A = 3B = 4C ആയാൽ ല.സ.ഗു (12) കൊണ്ട് ഹരിക്കുക:

A = 6k, B = 4k, C = 3k
അതായത് A : B : C = 6 : 4 : 3

(മറച്ചുപിടിച്ച് ഗുണിക്കുന്ന രീതിയിലും 12 : 8 : 6 = 6 : 4 : 3.)

🧠 കേസ് 3 – ശതമാനവും അംശബന്ധവും

x-ന്റെ 15% = y-യുടെ 20% ആയാൽ x : y = 20 : 15 = 4 : 3.

കാരണം: 0.15x = 0.20y ⇒ x/y = 0.20/0.15 = 4/3.

🧠 കേസ് 4 – ബീജഗണിത മൂല്യം

A = 3B/4 ആയാൽ (2B − A)/A എത്ര?

A = 3, B = 4 എടുത്താൽ (8 − 3)/3 = 5/3.

4.5 ശതമാനവും അംശബന്ധവും

  • a : b ആയാൽ ആദ്യത്തെ അളവ് ആകെയുടെ a/(a+b) × 100% ആണ്. ഉദാ: 3 : 2 → 60% : 40%.
  • x, y-യേക്കാൾ 25% കൂടുതലാണെങ്കിൽ x : y = 125 : 100 = 5 : 4.
  • x, y-യേക്കാൾ 20% കുറവാണെങ്കിൽ x : y = 80 : 100 = 4 : 5.
⚠️ ശ്രദ്ധിക്കുക

x : y = 5 : 4 ആയാൽ x, y-യേക്കാൾ 25% കൂടുതൽ ആണ്. എന്നാൽ y, x-നേക്കാൾ 20% മാത്രമേ കുറവുള്ളൂ (25% അല്ല).

5. C. അനുപാതം (Proportion)

a : b = c : d ആയാൽ ഇതിനെ a : b :: c : d എന്നും എഴുതാം.

  • അറ്റത്തെ പദങ്ങളായ a, d അന്ത്യപദങ്ങൾ (Extremes); നടുവിലെ b, c മധ്യപദങ്ങൾ (Means).
⭐ അടിസ്ഥാന നിയമം

അന്ത്യപദങ്ങളുടെ ഗുണനഫലം = മധ്യപദങ്ങളുടെ ഗുണനഫലം:

ad = bc

5.1 നാലാം അനുപാതം (Fourth Proportional)

a : b = c : x ആയാൽ x = bc/a
🧠 PSC ശൈലി ഉദാഹരണങ്ങൾ
  • 5 : 9 = x : 45 ആയാൽ x = (5 × 45)/9 = 25.
  • 3 : 8 = x : 24 ആയാൽ x = (3 × 24)/8 = 9.

5.2 മധ്യാനുപാതം (Mean Proportional)

a : x :: x : b ആയാൽ x² = ab, അതായത് x = √ab
  • ഉദാ: 4, 9 ന്റെ മധ്യാനുപാതം = √(4×9) = √36 = 6.
  • പ്രധാന സൂചന: മധ്യാനുപാതം എപ്പോഴും തന്നിരിക്കുന്ന രണ്ട് സംഖ്യകൾക്ക് ഇടയിൽ ആയിരിക്കും (4 < 6 < 9).

5.3 മൂന്നാം അനുപാതം (Third Proportional)

a : b :: b : x ആയാൽ x = b²/a
🧠 PSC ശൈലി ഉദാഹരണങ്ങൾ
  • 4, 12 ന്റെ മൂന്നാം അനുപാതം = 12²/4 = 144/4 = 36.
  • (x² − y²), (x − y) ന്റെ മൂന്നാം അനുപാതം = (x − y)² / (x² − y²) = (x − y)² / ((x − y)(x + y)) = (x − y)/(x + y).

5.4 തുടർ അനുപാതം (Continued Proportion)

a : b = b : c ആയാൽ a, b, c തുടർ അനുപാതത്തിലാണ്. ഇവിടെ b² = ac, b മധ്യാനുപാതവും c മൂന്നാം അനുപാതവുമാണ്.

  • ഉദാ: 4, 6, 9 തുടർ അനുപാതത്തിലാണ് (6² = 36 = 4 × 9).

5.5 അനുപാത ഗുണധർമ്മങ്ങൾ

a/b = c/d ആയാൽ താഴെപ്പറയുന്ന ഗുണധർമ്മങ്ങൾ ബാധകം:

ഗുണധർമ്മംഫലം
Invertendo (വിപരീതം)b/a = d/c
Alternendo (ഏകാന്തരം)a/c = b/d
Componendo (കൂട്ടൽ)(a + b)/b = (c + d)/d
Dividendo (കുറയ്ക്കൽ)(a − b)/b = (c − d)/d
Componendo–Dividendo(a + b)/(a − b) = (c + d)/(c − d)
ഉദാ.: a/b = 3/2 ആയാൽ (a + b)/(a − b) = (3 + 2)/(3 − 2) = 5/1 = 5.

5.6 നേർ അനുപാതവും വിപരീത അനുപാതവും

നേർ അനുപാതം (Direct)വിപരീത അനുപാതം (Inverse)
സ്ഥിരം ആയത്x/yx × y
ഒന്ന് കൂടിയാൽമറ്റേത് കൂടുംമറ്റേത് കുറയും
ഉദാഹരണംപേനയുടെ എണ്ണം – വിലആളുകളുടെ എണ്ണം – ജോലിക്ക് വേണ്ട ദിവസം
ഉദാ. (നേർ): 5 പേനയ്ക്ക് ₹60 ആയാൽ 8 പേനയ്ക്ക്?
(60/5) × 8 = ₹96
ഉദാ. (വിപരീത): 8 പേർ 12 ദിവസം കൊണ്ട് ചെയ്യുന്ന ജോലി 6 പേർ ചെയ്താൽ?
(8 × 12)/6 = 16 ദിവസം

6. D. തുക വിഭജിക്കലും വ്യത്യാസത്തിൽ നിന്ന് സംഖ്യ കാണലും

6.1 ഒരു തുകയെ അംശബന്ധത്തിൽ വിഭജിക്കൽ

⭐ സൂത്രവാക്യം

S എന്ന തുകയെ a : b : c അനുപാതത്തിൽ വിഭജിക്കുമ്പോൾ:

ആദ്യത്തെ വിഹിതം = a/(a + b + c) × S
രണ്ടാമത്തെ വിഹിതം = b/(a + b + c) × S
മൂന്നാമത്തെ വിഹിതം = c/(a + b + c) × S
🧠 PSC ശൈലി ഉദാഹരണങ്ങൾ
  • ഉദാ. 1: ₹1800 നെ 4 : 3 : 2 ൽ വീതിച്ചാൽ രണ്ടാമന്: ആകെ ഭാഗം 9, (3/9) × 1800 = ₹600.
  • ഉദാ. 2: ₹2400 നെ 5 : 4 : 3 ൽ വീതിച്ചാൽ ഒന്നാമന്: (5/12) × 2400 = ₹1000.
  • ഉദാ. 3: നീലയും വെള്ളയും ചായം 5 : 3 ൽ കലർത്തി 40 ലിറ്റർ ഉണ്ടാക്കുമ്പോൾ വെള്ള: (3/8) × 40 = 15 ലിറ്റർ.
  • ഉദാ. 4: സ്വർണ്ണവും ചെമ്പും 9 : 2; 66 ഗ്രാം ആഭരണത്തിന് സ്വർണ്ണം: (9/11) × 66 = 54 ഗ്രാം.

6.2 വ്യത്യാസത്തിൽ നിന്ന് സംഖ്യകൾ കണ്ടെത്തൽ

⭐ രീതി

ഭാഗങ്ങളുടെ വ്യത്യാസം = തന്നിരിക്കുന്ന വ്യത്യാസം. അതിൽ നിന്ന് 1 ഭാഗം കണ്ടെത്തുക.

🧠 PSC ശൈലി ഉദാഹരണങ്ങൾ
  • ഉദാ. 1: രവി : രാജു = 2 : 5, രാജുവിന് ₹3000 കൂടുതൽ. വ്യത്യാസം 3 ഭാഗം = 3000, 1 ഭാഗം = 1000. രാജുവിന്റെ തുക = 5 × 1000 = ₹5000.
  • ഉദാ. 2: തുക 2 : 5 ൽ വീതിച്ചപ്പോൾ ബാബുവിന് ₹1500 കൂടുതൽ. 3 ഭാഗം = 1500, 1 ഭാഗം = 500. ആകെ = 7 × 500 = ₹3500.
  • ഉദാ. 3: ആൺകുട്ടി : പെൺകുട്ടി = 12 : 13, പെൺകുട്ടികൾ 24 കൂടുതൽ. 1 ഭാഗം = 24. ആൺകുട്ടികൾ = 12 × 24 = 288 (പെൺകുട്ടികൾ 312, ആകെ 600).

6.3 തുകയും അംശബന്ധവും തന്നാൽ

ഉദാ.: തുക 54, അംശബന്ധം 7 : 2 ആയാൽ
ആകെ ഭാഗം 9, 1 ഭാഗം = 54/9 = 6
സംഖ്യകൾ 42, 12
⚠️ Trap

₹1300 നെ 1/2 : 1/3 : 1/4 ൽ വീതിക്കുമ്പോൾ 2 + 3 + 4 = 9 എന്ന് കൂട്ടരുത്. 12 കൊണ്ട് ഗുണിച്ച് 6 : 4 : 3 ആക്കുക; 6 + 4 + 3 = 13 ഭാഗം = 1300; ഒന്നാമന് 6 × 100 = ₹600.

7. E. ല.സ.ഗു, വയസ്സ്, വരുമാനം–ചെലവ്, പങ്കാളിത്തം

7.1 അംശബന്ധവും ല.സ.ഗു (LCM) – ഉ.സ.ഘ (HCF) യും

സംഖ്യകളുടെ അംശബന്ധം ലഘുരൂപത്തിൽ a : b ഉം ഉ.സ.ഘ = x ഉം ആയാൽ:

സംഖ്യകൾ = ax, bx
ല.സ.ഗു = abx
വലിയ സംഖ്യ = LCM / ചെറിയ റേഷ്യോ
ചെറിയ സംഖ്യ = LCM / വലിയ റേഷ്യോ
🧠 PSC ശൈലി ഉദാഹരണം

അംശബന്ധം 4 : 5, ല.സ.ഗു 140.

20x = 140 ⇒ x = 7
സംഖ്യകൾ 28, 35
വലിയ സംഖ്യ = 140/4 = 35
⭐ നിബന്ധന

ഈ സൂത്രവാക്യം a, b പരസ്പര അഭാജ്യം (co-prime) ആയിരിക്കുമ്പോൾ മാത്രമേ ശരിയാകൂ. അംശബന്ധം എപ്പോഴും ആദ്യം ലഘുരൂപത്തിലാക്കുക.

ഉ.സ.ഘ തന്നാൽ: സംഖ്യകളുടെ ഗുണനഫലം = LCM × HCF (ax · bx = abx · x ✔).

⚠️ Trap

രണ്ട് സംഖ്യകളുടെ അംശബന്ധം 3 : 4, ല.സ.ഗു 60 ആയാൽ സംഖ്യകളുടെ തുക?

  • സംഖ്യകൾ 3x, 4x ആയാൽ ല.സ.ഗു = 12x. 12x = 60 ⇒ x = 5 (ഇതാണ് ഉ.സ.ഘ).
  • സംഖ്യകൾ 15, 20; തുക = 35. (60/7 എന്ന് ചെയ്യരുത്.)

7.2 വയസ്സ് കണക്കുകൾ (Problems on Ages)

🧠 PSC ശൈലി ഉദാഹരണം 1

റീന : സീമ = 3 : 4. 6 വർഷം കഴിഞ്ഞാൽ റീനയ്ക്ക് 21.

റീനയുടെ ഇപ്പോഴത്തെ വയസ്സ് = 21 − 6 = 15 = 3 ഭാഗം
1 ഭാഗം = 5
സീമ = 4 × 5 = 20 വയസ്സ്
🧠 PSC ശൈലി ഉദാഹരണം 2 (വ്യത്യാസം സ്ഥിരം)

അപ്പു : അമ്മു = 1 : 2; 15 വർഷം കഴിഞ്ഞാൽ 2 : 3. അമ്മുവിന്റെ ഇപ്പോഴത്തെ വയസ്സ്?

ഇപ്പോൾ വ്യത്യാസം 2 − 1 = 1 ഭാഗം
15 വർഷം കഴിഞ്ഞും വ്യത്യാസം 3 − 2 = 1 ഭാഗം
"1 ഭാഗം" ഒരേ വലുപ്പമാണ്, അതിനാൽ 15 വർഷം കൊണ്ട് അപ്പുവിന്റെ "1 ഭാഗം" "2 ഭാഗം" ആയി.
അതായത് 1 ഭാഗം = 15 വർഷം
അമ്മു = 2 × 15 = 30
⚠️ ജാഗ്രത

വ്യത്യാസത്തിന്റെ ഭാഗങ്ങൾ രണ്ട് സന്ദർഭത്തിലും തുല്യമല്ലെങ്കിൽ ഈ ഷോർട്ട്കട്ട് ശരിയാകില്ല. അപ്പോൾ ക്രോസ്-ഗുണന സമവാക്യം ഉപയോഗിക്കുക.

🧠 ഉദാ (സമവാക്യ രീതി)

അച്ഛൻ : മകൻ = 7 : 2. 12 വർഷം കഴിഞ്ഞാൽ അച്ഛൻ മകന്റെ ഇരട്ടി.

7x + 12 = 2(2x + 12)
7x + 12 = 4x + 24
3x = 12 ⇒ x = 4
ഇപ്പോൾ അച്ഛൻ 28, മകൻ 8

7.3 വരുമാനം – ചെലവ് – നീക്കിയിരുപ്പ്

വരുമാനം = ചെലവ് + നീക്കിയിരുപ്പ്
🧠 PSC ശൈലി ഉദാഹരണം

ചെലവ് : നീക്കിയിരുപ്പ് = 5 : 1. വരുമാനം 10%, ചെലവ് 20% കൂടിയാൽ നീക്കിയിരുപ്പിലെ മാറ്റം?

ചെലവ് 500, നീക്കിയിരുപ്പ് 100, വരുമാനം 600 എടുക്കുക.
പുതിയ വരുമാനം = 660, പുതിയ ചെലവ് = 600
പുതിയ നീക്കിയിരുപ്പ് = 60
കുറവ് = (100 − 60)/100 × 100 = 40% കുറവ്

7.4 രണ്ട് സംഖ്യകളോടും ഒരേ സംഖ്യ കൂട്ടുമ്പോൾ

ഉദാ.: രണ്ട് സംഖ്യകളുടെ അംശബന്ധം 3 : 5. ഓരോന്നിനോടും 10 കൂട്ടിയാൽ 5 : 7.

7(3x + 10) = 5(5x + 10)
21x + 70 = 25x + 50
4x = 20 ⇒ x = 5
സംഖ്യകൾ 15, 25
പരിശോധന: 25 : 35 = 5 : 7 ✔

7.5 പങ്കാളിത്ത കച്ചവടം (Partnership)

⭐ സൂത്രവാക്യം

ലാഭവിഹിതങ്ങളുടെ അംശബന്ധം = (മുതൽ × കാലം) ന്റെ അംശബന്ധം.

ഉദാ.: A: ₹5000, 12 മാസം; B: ₹6000, 8 മാസം.
5000 × 12 : 6000 × 8 = 60000 : 48000 = 5 : 4

8. F. നാണയ കണക്കുകളും മിശ്രിത കണക്കുകളും

8.1 നാണയ കണക്കുകൾ (Coin Problems)

⭐ പ്രധാന തത്വം

രണ്ട് തരം ചോദ്യങ്ങൾ ഉണ്ട്. ഏതാണെന്ന് ആദ്യം തിരിച്ചറിയുക:

  • തരം 1 – എണ്ണത്തിന്റെ അംശബന്ധം: എണ്ണത്തെ നാണയമൂല്യം കൊണ്ട് ഗുണിച്ച് തുകയാക്കുക.
  • തരം 2 – തുകയുടെ അംശബന്ധം: തുകയെ നാണയമൂല്യം കൊണ്ട് ഹരിച്ച് എണ്ണം കാണുക.
🧠 ഉദാ. – തരം 1 (എണ്ണം)

₹1, 50 പൈസ, 25 പൈസ നാണയങ്ങൾ 5 : 8 : 4 എന്ന എണ്ണ അംശബന്ധത്തിൽ; ആകെ ₹300. 50 പൈസ നാണയങ്ങൾ എത്ര?

മൂല്യങ്ങൾ: 5 × 1 = 5; 8 × 0.50 = 4; 4 × 0.25 = 1
ആകെ = ₹10 (ഒരു യൂണിറ്റിന്)
1 യൂണിറ്റ് = 300/10 = 30
50 പൈസ നാണയങ്ങൾ = 8 × 30 = 240

പരിശോധന: ₹1 നാണയം 150 = ₹150; 50 പൈസ 240 = ₹120; 25 പൈസ 120 = ₹30. ആകെ ₹300 ✔

🧠 ഉദാ. – തരം 2 (തുക)

₹1, 50 പൈസ, 25 പൈസ നാണയങ്ങളിലെ തുകകൾ 5 : 8 : 4 ആയാൽ എണ്ണങ്ങളുടെ അംശബന്ധം?

എണ്ണം = തുക/മൂല്യം
= 5/1 : 8/0.5 : 4/0.25
= 5 : 16 : 16

8.2 മിശ്രിത കണക്കുകൾ (Mixture & Alligation)

⭐ അലിഗേഷൻ സൂത്രവാക്യം

വില C (കുറഞ്ഞത്), D (കൂടിയത്) എന്നിവ കലർത്തി ശരാശരി വില M കിട്ടാൻ:

കുറഞ്ഞ വില : കൂടിയ വില = (D − M) : (M − C)
🧠 PSC ശൈലി ഉദാഹരണം

₹50/കി.ഗ്രാം, ₹70/കി.ഗ്രാം വെളിച്ചെണ്ണ കലർത്തി ₹55 കിട്ടാൻ:

(70 − 55) : (55 − 50) = 15 : 5 = 3 : 1
ഇവിടെ ₹50 രൂപയുള്ളത് 3 ഭാഗം, ₹70 രൂപയുള്ളത് 1 ഭാഗം

പരിശോധന: (3 × 50 + 1 × 70)/4 = 220/4 = 55 ✔

⚠️ ശ്രദ്ധ

ഉത്തരം ശരാശരി വിലയോട് അടുത്ത വിലയുള്ള വസ്തു കൂടുതൽ ഉണ്ടായിരിക്കും (55, 50-നോട് അടുത്താണ്, അതിനാൽ 50 രൂപയുള്ളത് കൂടുതൽ).

8.3 പാൽ–വെള്ളം ഉദാഹരണം

ഉദാ.: 35 ലിറ്റർ മിശ്രിതത്തിൽ പാൽ : വെള്ളം = 4 : 3. പാൽ : വെള്ളം = 4 : 5 ആക്കാൻ എത്ര വെള്ളം ചേർക്കണം?
ഇപ്പോൾ: പാൽ = 4/(4+3) × 35 = 20 L; വെള്ളം = 15 L
പാൽ മാറില്ല. പുതിയ വെള്ളം = 25 L (കാരണം 20/25 = 4/5)
ചേർക്കേണ്ടത് = 25 − 15 = 10 L

15. മെമ്മറി ട്രിക്കുകൾ & Common PSC Traps

15.1 മെമ്മറി ട്രിക്കുകൾ

🧠 Trick 1 – മറച്ചുപിടിക്കൽ ട്രിക്ക് (pA = qB = rC)

2A = 3B = 5C ആയാൽ:

  • A-ക്ക് 3 × 5 = 15
  • B-ക്ക് 2 × 5 = 10
  • C-ക്ക് 2 × 3 = 6

A : B : C = 15 : 10 : 6

രീതി: ഓരോ അക്ഷരത്തിന്റെയും ഗുണകത്തെ മറച്ച് ബാക്കിയുള്ള രണ്ട് ഗുണകങ്ങൾ ഗുണിക്കുക.

🧠 Trick 2 – ഗുണിതം നോക്കൽ ട്രിക്ക്

അംശബന്ധം ലഘുരൂപത്തിൽ 2 : 5 ഉം തുകകൾ പൂർണ്ണസംഖ്യകളും ആയാൽ, 5 ഭാഗം ലഭിക്കുന്നയാളുടെ തുക 5-ന്റെ ഗുണിതമായിരിക്കും. ആകെ തുക 7-ന്റെ ഗുണിതവും ആയിരിക്കും.

ഉദാ: 9 : 2 ൽ സ്വർണ്ണം 9-ന്റെ ഗുണിതം; ഓപ്ഷനുകളായ 12, 55, 54, 58 ൽ 54 മാത്രം.

ജാഗ്രത: അംശബന്ധം ലഘുരൂപത്തിലല്ലെങ്കിൽ ഈ ട്രിക്ക് പ്രവർത്തിക്കില്ല.

🧠 Trick 3 – രണ്ടിനോടും ഒരേ സംഖ്യ കൂട്ടുമ്പോൾ

R : S = 3 : 5. രണ്ടുപേർക്കും ₹5000 കൂട്ടിയപ്പോൾ 29 : 45.

45(3x + 5000) = 29(5x + 5000)
135x + 225000 = 145x + 145000
10x = 80000 ⇒ x = 8000
R = 3 × 8000 = ₹24,000
പരിശോധന: S = 40000; 29000 : 45000 = 29 : 45 ✔
🧠 Trick 4 – തുകയും വ്യത്യാസവും

രണ്ട് സംഖ്യകളുടെ തുക : വ്യത്യാസം = a : b ആയാൽ സംഖ്യകൾ (a + b) : (a − b).

ഉദാ: തുക : വ്യത്യാസം = 5 : 1 ⇒ സംഖ്യകൾ 6 : 4 = 3 : 2.

🧠 Trick 5 – "Sub = മൂലം" മന്ത്രം

"Sub" കണ്ടാൽ root, "Sub" ഇല്ലെങ്കിൽ power.

  • Duplicate (no sub) → a² : b² (square)
  • Sub-duplicate (sub) → √a : √b (square root)
  • Triplicate (no sub) → a³ : b³ (cube)
  • Sub-triplicate (sub) → ∛a : ∛b (cube root)
🧠 Trick 6 – അംശബന്ധത്തിന്റെ ക്രമം

ചോദ്യത്തിൽ "A : B" എന്ന ക്രമത്തിൽ തന്നാൽ ഉത്തരവും അതേ ക്രമത്തിൽ എഴുതുക. തിരിച്ച് ചോദിച്ചാൽ ഒഴിവാക്കൽ സാധ്യമാകും.

ഉദാ: "ആൺകുട്ടികളുടെ എണ്ണം" ചോദിച്ചാൽ 12 ഭാഗം, "പെൺകുട്ടികളുടെ എണ്ണം" ചോദിച്ചാൽ 13 ഭാഗം.

  1. Trap 1 (ഭിന്നസംഖ്യാ അംശബന്ധത്തിൽ വീതിക്കൽ): ₹1300 നെ 1/2 : 1/3 : 1/4 ൽ വീതിക്കുമ്പോൾ 2 + 3 + 4 = 9 എന്ന് കൂട്ടരുത്. 12 കൊണ്ട് ഗുണിച്ച് 6 : 4 : 3 ആക്കുക; 6 + 4 + 3 = 13 ഭാഗം = 1300; ഒന്നാമന് 6 × 100 = ₹600.

16.1 പങ്കാളിത്ത ലാഭം

16.2 ജ്യാമിതി അംശബന്ധങ്ങൾ

  • ത്രികോണത്തിന്റെ കോണുകൾ 1 : 2 : 3 ആയാൽ 30°, 60°, 90° (6x = 180°).

  • സമചതുരങ്ങളുടെ വശങ്ങൾ a : b ആയാൽ ചുറ്റളവുകൾ a : b; പരപ്പളവുകൾ a² : b².
  • ഘനങ്ങളുടെ വശങ്ങൾ a : b ആയാൽ വ്യാപ്തങ്ങൾ a³ : b³ (ട്രിപ്ലിക്കേറ്റ് റേഷ്യോ).

16.3 സുവർണ്ണ അംശബന്ധം (Golden Ratio)

സുവർണ്ണ അംശബന്ധം ഏകദേശം 1.618 : 1 ആണ്. ഇത് സാധാരണ PSC ലഘുഗണിതത്തിൽ വരാറില്ല, പൊതുവിജ്ഞാനമായി അറിയാം.

ചോദ്യം: ₹3600 നെ 7 : 5 അനുപാതത്തിൽ വീതിച്ചാൽ വലിയ വിഹിതം?

(A) ₹1500 (B) ₹2000 (C) ₹2100 (D) ₹2400

  • ഘട്ടം 1 (വലുപ്പം): 7 ഭാഗം, 5 ഭാഗത്തേക്കാൾ വലുത്, അതിനാൽ വലിയ വിഹിതം ആകെയുടെ പകുതിയായ ₹1800-ൽ കൂടുതലായിരിക്കണം. (A) ₹1500 ഒഴിവാക്കാം.
  • ഘട്ടം 2 (ഗുണിതം): അംശബന്ധം ലഘുരൂപത്തിലാണ്, തുക പൂർണ്ണസംഖ്യയാണ്. അതിനാൽ 7 ഭാഗത്തിന്റെ തുക 7-ന്റെ ഗുണിതം ആയിരിക്കും. 2000 ÷ 7 ശേഷിക്കും, 2400 ÷ 7 ശേഷിക്കും. (B), (D) ഒഴിവാക്കാം.

ഉത്തരം: (C) ₹2100. (7/12 × 3600 = 2100.)

ട്രിക്ക് 2: Common-Sense Logic – "1-ൽ നിന്നുള്ള വിടവ്" (അംശബന്ധ താരതമ്യം)

ചോദ്യം: ഇവയിൽ ഏറ്റവും വലിയ അംശബന്ധം?

(A) 2 : 3 (B) 5 : 8 (C) 7 : 10 (D) 3 : 5

  • a/b ന് 1-ൽ നിന്നുള്ള വിടവ് (b − a)/b: (A) 1/3 ≈ 0.33; (B) 3/8 = 0.375; (C) 3/10 = 0.30; (D) 2/5 = 0.40.
  • വിടവ് ഏറ്റവും കുറഞ്ഞത് (C) ആണ്, അതിനാൽ ഏറ്റവും വലുത് 7 : 10.

ഉത്തരം: (C). പരിശോധന: 0.70 > 0.667 > 0.625 > 0.60.

⚠️ അംശം ഛേദത്തേക്കാൾ വലിയ (1-ൽ കൂടുതൽ) അംശബന്ധങ്ങൾക്ക് ഇത് നേരിട്ട് പ്രയോഗിക്കരുത്.

ചോദ്യം: താഴെയുള്ളവയിൽ തെറ്റായ പ്രസ്താവന ഏത്?

(A) 81 : 49 ന്റെ സബ്-ഡ്യൂപ്ലിക്കേറ്റ് റേഷ്യോ 9 : 7

(B) 2 : 5 ന്റെ ട്രിപ്ലിക്കേറ്റ് റേഷ്യോ 8 : 125

(C) 4, 12 ന്റെ മൂന്നാം അനുപാതം 36

(D) 4, 9 ന്റെ മധ്യാനുപാതം 36

  • ആദ്യം ചോദ്യം വായിക്കുക: "തെറ്റായത്" ആണ് വേണ്ടത്; ശരിയായത് തിരഞ്ഞെടുക്കരുത്.
  • ഘട്ടം 1: മധ്യാനുപാതം തന്ന രണ്ട് സംഖ്യകൾക്ക് ഇടയിൽ ആയിരിക്കണം. 4-നും 9-നും ഇടയിൽ 36 വരില്ല. (D) തെറ്റ്.
  • ഘട്ടം 2 (പരിശോധന): (A), (B), (C) ശരിയാണ് (9 : 7; 8 : 125; 144/4 = 36). 4, 9 ന്റെ യഥാർത്ഥ മധ്യാനുപാതം √36 = 6.

ഉത്തരം: (D).

ട്രിക്ക് 4: Extreme Statement Check – പ്രസ്താവനകൾ

ചോദ്യം: ശരിയായ പ്രസ്താവന/പ്രസ്താവനകൾ?

  1. ഏതു രണ്ട് പൂർണ്ണസംഖ്യകളുടെയും മധ്യാനുപാതം ഒരു പൂർണ്ണസംഖ്യയാണ്.
  2. a : b യുടെ ഡ്യൂപ്ലിക്കേറ്റ് റേഷ്യോ a² : b² ആണ്.
  3. അംശബന്ധത്തിന് സ്വന്തമായി യൂണിറ്റ് ഉണ്ട്.

(A) 1 മാത്രം (B) 2 മാത്രം (C) 1, 2 (D) 2, 3

  • "ഏതു … ഉം" എന്ന വ്യാപക പ്രസ്താവന ഒരു ഉദാഹരണം കൊണ്ട് പരിശോധിക്കുക: 2, 3 ന്റെ മധ്യാനുപാതം √6, പൂർണ്ണസംഖ്യയല്ല. പ്രസ്താവന 1 തെറ്റ്.
  • പ്രസ്താവന 2 ശരി. പ്രസ്താവന 3 തെറ്റ് (അംശബന്ധത്തിന് യൂണിറ്റ് ഇല്ല).

ഉത്തരം: (B).

⚠️ "എപ്പോഴും, ഒരിക്കലും, ഏതും" എന്നിവ സ്വയം തെറ്റല്ല. "ഒരേ യൂണിറ്റിൽ അല്ലാത്ത അളവുകളുടെ അംശബന്ധം കാണാൻ കഴിയില്ല" എന്നത് ശരിയാണ്. ഓരോ പ്രസ്താവനയും ഒരു ഉദാഹരണം കൊണ്ട് പരിശോധിക്കുക.

ട്രിക്ക് 5: Match the Following – അറിയാവുന്നത് ആദ്യം

ചോദ്യം: പട്ടിക I: a. 2 : 3 ന്റെ ട്രിപ്ലിക്കേറ്റ്; b. 2 : 3 ന്റെ ഡ്യൂപ്ലിക്കേറ്റ്; c. 4 : 9 ന്റെ സബ്-ഡ്യൂപ്ലിക്കേറ്റ്; d. 2 : 3 ന്റെ വിപരീതം. പട്ടിക II: 1. 3 : 2 2. 8 : 27 3. 2 : 3 4. 4 : 9.

(A) a-2, b-4, c-3, d-1 (B) a-4, b-2, c-3, d-1 (C) a-2, b-4, c-1, d-3 (D) a-1, b-4, c-3, d-2

  • ഏറ്റവും എളുപ്പമുള്ളത് ആദ്യം: d (വിപരീതം) = 3 : 2 ⇒ d-1. d-ക്ക് 1 അല്ലാത്ത (C), (D) ഒഴിവാക്കാം.
  • അടുത്തത്: a (ട്രിപ്ലിക്കേറ്റ്) = 8 : 27 ⇒ a-2. a-4 ഉള്ള (B) ഒഴിവാക്കാം.

ഉത്തരം: (A). (b: 4 : 9 ✔, c: √4 : √9 = 2 : 3 ✔.)

ട്രിക്ക് 6: Assertion–Reason – ആദ്യം A, പിന്നെ R

ചോദ്യം: A: x-ന്റെ 15% = y-യുടെ 20% ആയാൽ x : y = 3 : 4. R: 15x = 20y ആയതിനാൽ x/y = 20/15 = 4/3.

(A) A, R ശരി; R വിശദീകരിക്കുന്നു (B) A, R ശരി; R വിശദീകരിക്കുന്നില്ല (C) A ശരി, R തെറ്റ് (D) A തെറ്റ്, R ശരി

  • സാമാന്യ യുക്തി: x-ന്റെ ചെറിയ ശതമാനം (15%) y-യുടെ വലിയ ശതമാനത്തിന് (20%) തുല്യമാകണമെങ്കിൽ x ആണ് വലുത്. അതിനാൽ x : y > 1. 3 : 4 < 1 ആയതിനാൽ A തെറ്റ്.
  • R പരിശോധിക്കുക: 0.15x = 0.20y ⇒ x/y = 4/3. R ശരി.

ഉത്തരം: (D).

ട്രിക്ക് 7: Number Logic – ഭാഗങ്ങളും ആകെയും

ചോദ്യം: അച്ഛന്റെയും മകന്റെയും വയസ്സുകളുടെ അംശബന്ധം 7 : 2, തുക 54. മകന്റെ വയസ്സ്?

(A) 10 (B) 12 (C) 14 (D) 16

  • ആകെ ഭാഗം 7 + 2 = 9; ആകെ 54 ആയതിനാൽ 1 ഭാഗം = 6. അതിനാൽ മകന്റെ വയസ്സ് 6-ന്റെ ഗുണിതം (2 × 6).
  • ഓപ്ഷനുകളിൽ 6-ന്റെ ഗുണിതം 12 മാത്രം.

ഉത്തരം: (B) 12. (അച്ഛൻ 42 ✔; 42 : 12 = 7 : 2.)

ട്രിക്ക് 8: Similar-Option Comparison – ഏതാണ് ചോദിച്ചത്?

ചോദ്യം: A : B = 2 : 3, B : C = 4 : 5 ആയാൽ A : C?

(A) 8 : 12 : 15 (B) 8 : 15 (C) 12 : 15 (D) 2 : 5

  • B തുല്യമാക്കുക (3, 4 ന്റെ ല.സ.ഗു 12): A : B = 8 : 12, B : C = 12 : 15. അപ്പോൾ A : B : C = 8 : 12 : 15.
  • ചോദിച്ചത് A : C ആണ്. (A) മൂന്ന് പദങ്ങളുണ്ട്, അത് A : B : C ആണ്. (C) B : C ആണ്. (D) ക്രോസ് ഗുണനത്തിലെ പിഴവിൽ നിന്ന് വരുന്ന ഉത്തരമാണ് (രണ്ട് ഭാഗങ്ങളും തുല്യമായി കൂട്ടിയത്).

ഉത്തരം: (B) 8 : 15.

ട്രിക്ക് 9: Question Wording – യൂണിറ്റും ക്രമവും

ചോദ്യം: 2 മീറ്ററും 50 സെ.മീ-ഉം തമ്മിലുള്ള അംശബന്ധം?

(A) 2 : 50 (B) 1 : 25 (C) 4 : 1 (D) 1 : 4

  • 2 m = 200 cm; 200 : 50 = 4 : 1. (A), (B) യൂണിറ്റ് മാറ്റാത്ത ചതിക്കുഴികളാണ് (2 : 50 = 1 : 25). (D) ക്രമം തിരിഞ്ഞത്.

ഉത്തരം: (C). ("50 സെ.മീ-ഉം 2 മീറ്ററും തമ്മിൽ" എന്ന് ചോദിച്ചിരുന്നെങ്കിൽ (D) ശരി.)

  4. ഉത്തരം ഒന്ന് ഉറപ്പാക്കുക: കിട്ടിയ ഉത്തരം ചോദ്യത്തിൽ തിരികെ വെച്ച് നോക്കുക (back-substitution).
  5. ഭിന്നസംഖ്യാ അംശബന്ധം: ഛേദങ്ങളുടെ ല.സ.ഗു കൊണ്ട് ഗുണിച്ച് പൂർണ്ണസംഖ്യയാക്കുക.
