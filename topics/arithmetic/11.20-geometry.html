⭐ Star Guide

⭐ പ്രാധാന്യ സൂചകങ്ങൾ (Kerala PSC അടിസ്ഥാനത്തിൽ)
  • ⭐⭐⭐⭐⭐ അതിപ്രധാനം — പൂരകം (90°), അനുപൂരകം (180°), ബഹുഭുജങ്ങളുടെ ആന്തര തുക (n−2)×180°, ബാഹ്യകോൺ തുക 360°, സമബഹുഭുജ ബാഹ്യകോൺ 360°/n, വികർണ്ണങ്ങൾ n(n−3)/2, ചക്രീയ ചതുർഭുജ എതിർകോൺ 180°, അർദ്ധവൃത്ത കോൺ 90°, കേന്ദ്രകോൺ = 2 × പരിധികോൺ, ത്രികോണ അസമത്വം
  • ⭐⭐⭐⭐ പ്രധാനം — ത്രികോണ കേന്ദ്രങ്ങൾ (Centroid, Incenter, Circumcenter, Orthocenter), പൈതഗോറസ് ത്രയങ്ങൾ, സർവ്വസമത (SSS/SAS/ASA/RHS), സദൃശ ത്രികോണ പരപ്പളവ് അംശബന്ധം, ചതുർഭുജ വികർണ്ണ ഗുണങ്ങൾ, ഞാണ്-കേന്ദ്ര ലംബം, തൊടുവര ⊥ ആരം, ദൂരം & മധ്യബിന്ദു സൂത്രവാക്യം
  • ⭐⭐⭐ ശ്രദ്ധിക്കേണ്ടത് — സമാന്തര വരകളും ഛേദകവും (F/Z/C), ബാഹ്യകോൺ സിദ്ധാന്തം, ചരിവ് (slope), ഞാണ് സംഗമ നിയമം, തൊടുവര നീളം √(d²−r²)
  • ⭐⭐ അറിഞ്ഞാൽ മതി — പൊതു തൊടുവരകളുടെ എണ്ണം, വിഭജന സൂത്രവാക്യം, ത്രികോണ കേന്ദ്രം (centroid of coordinates)
  • ⭐ ചരിത്ര വിവരം — യൂക്ലിഡ് (ജ്യാമിതിയുടെ പിതാവ്), ബൗധായനൻ, ആര്യഭടൻ, പൈതഗോറസ്
➕ ചുരുക്കം (2–3 മാർക്കിന്)
  • പൂരകം = 90° · അനുപൂരകം = 180°
  • ബഹുഭുജ ആന്തര തുക = (n−2)×180°
  • ബാഹ്യകോൺ തുക = 360° (ഏത് n-നും)
  • വികർണ്ണം = n(n−3)/2
  • ചക്രീയ ചതുർഭുജം എതിർകോൺ = 180°
  • അർദ്ധവൃത്ത കോൺ = 90°

1. അധ്യായ ആമുഖം

  • ⭐⭐⭐⭐⭐ ബിന്ദുക്കൾ, വരകൾ, കോണുകൾ, രൂപങ്ങൾ എന്നിവയുടെ സ്വഭാവവും അവ തമ്മിലുള്ള ബന്ധവും പഠിക്കുന്ന ഗണിതശാഖയാണ് ജ്യാമിതി (Geometry). തേനീച്ചക്കൂടിന്റെ ഷഡ്ഭുജ ആകൃതി മുതൽ പാലങ്ങളുടെ ഉറപ്പ് വരെ ഇതിന്റെ ഉദാഹരണങ്ങളാണ്.
  • ⭐⭐⭐⭐ PSC ബന്ധം: LDC 883, Secretariat Assistant 573 തുടങ്ങിയ പരീക്ഷകളിൽ ഈ ഭാഗത്തുനിന്ന് സാധാരണ 1–3 ചോദ്യങ്ങൾ വരാറുണ്ട് (ഇത് ഏകദേശ ട്രെൻഡ് മാത്രം; ഓരോ പരീക്ഷയിലും വ്യത്യാസപ്പെടാം).
  • ⭐⭐⭐⭐⭐ പ്രധാന ചോദ്യ മേഖലകൾ: പൂരക-അനുപൂരക കോണുകൾ · ബഹുഭുജത്തിന്റെ ആന്തര/ബാഹ്യകോണുകൾ, വികർണ്ണങ്ങളുടെ എണ്ണം · ചക്രീയ ചതുർഭുജം · കേന്ദ്രകോൺ സിദ്ധാന്തം, അർദ്ധവൃത്തത്തിലെ കോൺ · ത്രികോണ അസമത്വം, ത്രികോണ കേന്ദ്രങ്ങൾ.

1.1 Syllabus Checklist

  • A: ബിന്ദു, രേഖ, രശ്മി, കോണുകളുടെ വർഗ്ഗീകരണം, പൂരക/അനുപൂരക കോണുകൾ, രേഖീയ ജോഡി, എതിർകോണുകൾ, സമാന്തര വരകളും ഛേദകവും
  • B: ത്രികോണങ്ങൾ – തരങ്ങൾ, ബാഹ്യകോൺ സിദ്ധാന്തം, സർവ്വസമത, സദൃശത, പൈതഗോറസ്, 4 കേന്ദ്രങ്ങൾ
  • C: ബഹുഭുജങ്ങളും വികർണ്ണങ്ങളും
  • D: ചതുർഭുജങ്ങൾ, ചക്രീയ ചതുർഭുജം
  • E: വൃത്തങ്ങൾ, ഞാണുകൾ, തൊടുവരകൾ
  • F: നിർദ്ദേശാങ്ക ജ്യാമിതി അടിസ്ഥാനം – അകലം, മധ്യബിന്ദു, ചരിവ്, വിഭജന സൂത്രവാക്യം
➕ ഈ അധ്യായത്തിന്റെ സ്ഥാനം

ചുറ്റളവ്, പരപ്പളവ്, വ്യാപ്തം എന്നിവ 11.13–11.16 അധ്യായങ്ങളിൽ പൂർത്തിയായി. ഇവിടെ SCERT 8, 9, 10 ക്ലാസ് പാഠപുസ്തകങ്ങളിലെ ശുദ്ധ ജ്യാമിതി (Pure Geometry) ആണ് — അളവുകളല്ല, സ്വഭാവങ്ങളും ബന്ധങ്ങളുമാണ്.

2. പിന്നാമ്പുറ കഥ (Behind the Story)

2.1 ത്രികോണ കോണുകളുടെ തുക = 180° എന്നതിന്റെ രഹസ്യം

ഒരു കടലാസിൽ ഇഷ്ടമുള്ള ത്രികോണം വരച്ച് മൂന്ന് മൂലകളും കീറിയെടുക്കുക. അവ ഒരു നേർവരയോട് ചേർത്ത് വച്ചാൽ കൃത്യം ഒരു നേർവര (180°) ആകും. ത്രികോണം ഏതായാലും ഇത് സത്യമാണ്.

2.2 ബഹുഭുജങ്ങളിലേക്കുള്ള വഴി

  • ചതുർഭുജത്തിൽ ഒരു വികർണ്ണം വരച്ചാൽ 2 ത്രികോണം → 2 × 180° = 360°
  • പഞ്ചഭുജത്തിൽ 3 ത്രികോണം → 3 × 180° = 540°
  • n വശമുള്ള ബഹുഭുജത്തിൽ (n − 2) ത്രികോണം → (n − 2) × 180°

🧠 Trick: ഇതാണ് ഫോർമുല മനഃപാഠമാക്കേണ്ടതില്ല എന്നതിന്റെ രഹസ്യം — ഒരു മൂലയിൽ നിന്ന് വികർണ്ണങ്ങൾ വരച്ച് ത്രികോണങ്ങൾ എണ്ണിയാൽ മതി.

2.3 യൂക്ലിഡ് – ജ്യാമിതിയുടെ പിതാവ്

  • ⭐⭐⭐⭐ യൂക്ലിഡ് (Euclid): ബി.സി. മൂന്നാം നൂറ്റാണ്ടിലെ (ഏകദേശം ബി.സി. 300) ഗ്രീക്ക് ഗണിതശാസ്ത്രജ്ഞൻ. 13 വാല്യങ്ങളുള്ള 'എലമെന്റ്സ്' (Elements) രചിച്ചു. ജ്യാമിതിയുടെ പിതാവ് എന്നറിയപ്പെടുന്നു.
  • ⭐⭐⭐ ഇന്ത്യയിൽ: ബൗധായനൻ (ശുൽബസൂത്രങ്ങൾ), ആര്യഭടൻ എന്നിവർ ജ്യാമിതിക്ക് സംഭാവന നൽകി. (പൈതഗോറസ് സിദ്ധാന്തത്തിന്റെ ആദ്യകാല രൂപം ബൗധായന ശുൽബസൂത്രത്തിൽ കാണാം.)
  • ⭐⭐⭐ പൈതഗോറസ് (ഗ്രീക്ക്, ബി.സി. 6-ാം നൂറ്റാണ്ട്) – അദ്ദേഹത്തിന്റെ പേരിലുള്ള സിദ്ധാന്തം.

3. A. അടിസ്ഥാന ആശയങ്ങൾ, രേഖകൾ, കോണുകൾ

3.1 ബിന്ദുവും വരകളും

പദംഅർത്ഥംഓർമ്മിക്കാൻ
ബിന്ദു (Point)നീളം, വീതി, കനം ഇല്ല; സ്ഥാനം മാത്രംപെൻസിൽ കുത്ത്
രേഖാഖണ്ഡം (Line Segment)രണ്ട് അന്ത്യബിന്ദു, നിശ്ചിത നീളംസ്കെയിലിലെ ഭാഗം
രശ്മി (Ray)ഒരറ്റം മാത്രം; ഒരു ദിശയിൽ അനന്തംടോർച്ച് പ്രകാശം
രേഖ (Line)രണ്ട് ദിശയിലും അനന്തംഅറ്റമില്ലാത്ത വര
ഏകരേഖീയ ബിന്ദുക്കൾ (Collinear)ഒരേ നേർവരയിലെ ബിന്ദുക്കൾ—
സംഗമ രേഖകൾ (Concurrent)3+ വരകൾ ഒരേ ബിന്ദുവിൽ കൂടുന്നുആ ബിന്ദു = സംഗമബിന്ദു
സമാന്തര രേഖകൾ (Parallel)ഒരിക്കലും കൂടിമുട്ടില്ല; ലംബ അകലം തുല്യംറെയിൽപ്പാളം
📌 ബിന്ദു-രേഖ ബന്ധം
  • ഒരു ബിന്ദുവിലൂടെ അനന്തം നേർവരകൾ വരയ്ക്കാം
  • രണ്ട് ബിന്ദുക്കളിലൂടെ ഒരേയൊരു നേർവര മാത്രം
  • 3 ഏകരേഖീയമല്ലാത്ത ബിന്ദുക്കളിലൂടെ ഒരു വൃത്തം വരയ്ക്കാം
⚠️ ട്രാപ്പ്

രണ്ട് വ്യത്യസ്ത നേർവരകൾ പരമാവധി ഒരു ബിന്ദുവിൽ മാത്രമേ കൂടിമുട്ടൂ. രണ്ട് ബിന്ദുക്കളിൽ കൂടിമുട്ടുന്ന രണ്ട് "നേർവരകൾ" യഥാർത്ഥത്തിൽ ഒരേ വരയാണ്.

3.2 കോണുകളുടെ തരങ്ങൾ

ഒരേ ബിന്ദുവിൽ (മൂല / Vertex) നിന്ന് പുറപ്പെടുന്ന രണ്ട് രശ്മികൾ ചേർന്നാണ് കോൺ (Angle) ഉണ്ടാകുന്നത്.

കോൺപരിധി
ന്യൂനകോൺ (Acute)0° < θ < 90°
മട്ടകോൺ (Right)= 90°
ബൃഹത്കോൺ (Obtuse)90° < θ < 180°
നേർകോൺ (Straight)= 180°
പ്രതിവർത്തന കോൺ (Reflex)180° < θ < 360°
പൂർണ്ണകോൺ (Complete)= 360°

🧠 Trick: "ന്യൂനം = ചെറുത്, ബൃഹത് = വലുത്". ന്യൂനകോൺ ചെറുത് (90°-ൽ താഴെ); ബൃഹത്കോൺ വലുത് (90°–180°).

📌 ലംബരേഖകൾ (Perpendicular): 90°-ൽ കൂടിമുട്ടുന്ന വരകൾ.

3.3 പൂരകം, അനുപൂരകം (⭐ സ്ഥിരം ചോദ്യം)

തരംതുകകോൺ θ ആയാൽസ്വന്തം കോണിന് തുല്യം
പൂരക (Complementary)90°90° − θ45°
അനുപൂരക (Supplementary)180°180° − θ90°
➕ ഉദാഹരണങ്ങൾ
  • 35°-ന്റെ പൂരകം = 90 − 35 = 55°
  • 105°-ന്റെ അനുപൂരകം = 180 − 105 = 75°
  • 62°-ന്റെ പൂരകം = 28°; അനുപൂരകം = 118°
📌 രേഖീയ ജോഡി (Linear Pair)

ഒരു നേർവരയിൽ അടുത്തടുത്ത് വരുന്ന രണ്ട് കോണുകൾ; തുക 180°. (എല്ലാ രേഖീയ ജോഡിയും അനുപൂരകമാണ്; എല്ലാ അനുപൂരകവും രേഖീയ ജോഡിയാകണമെന്നില്ല.)

🧠 Memory Trick: C (Complementary) S-ന് മുമ്പ് വരുന്നു; C = 90, S = 180 (Corner = 90°, Straight = 180°).

3.4 എതിർകോണുകൾ (Vertically Opposite Angles)

രണ്ട് നേർവരകൾ പരസ്പരം മുറിക്കുമ്പോൾ അഭിമുഖമായ കോണുകൾ എപ്പോഴും തുല്യം. അടുത്തടുത്ത കോണുകൾ രേഖീയ ജോഡിയാണ് (തുക 180°).

3.5 സമാന്തര വരകളും ഛേദകവും (Transversal)

കോൺ ജോഡിആകൃതിബന്ധം
സമാന കോണുകൾ (Corresponding)Fതുല്യം
മറുകോണുകൾ (Alternate Interior)Zതുല്യം
സഹ-ആന്തര കോണുകൾ (Co-interior / Consecutive Interior)C / Uതുക 180°
⚠️ ട്രാപ്പ്

ഈ ബന്ധങ്ങൾ വരകൾ സമാന്തരമാണെങ്കിൽ മാത്രം. വരകൾ സമാന്തരമല്ലെങ്കിൽ ഉപയോഗിക്കരുത്. നേരെമറിച്ച്, സമാന കോണുകളോ മറുകോണുകളോ തുല്യമാണെങ്കിൽ വരകൾ സമാന്തരമാണെന്ന് തെളിയിക്കാം.

ചിത്രം 3.1 – സമാന്തര വരകളെ ഛേദകം മുറിക്കുമ്പോൾ ഉണ്ടാകുന്ന കോൺ ബന്ധങ്ങൾ.

4. B. ത്രികോണങ്ങളുടെ ജ്യാമിതി

മൂന്ന് വരകൾ ചേർന്ന അടഞ്ഞ രൂപം. ആന്തരകോണുകളുടെ തുക എപ്പോഴും 180°.

4.1 വർഗ്ഗീകരണം – വശങ്ങൾ അടിസ്ഥാനമാക്കി

തരംസവിശേഷത
സമഭുജ (Equilateral)3 വശവും തുല്യം; ഓരോ കോണും 60°
സമപാർശ്വ (Isosceles)2 വശം തുല്യം; അവയ്ക്ക് എതിർകോണുകളും തുല്യം
വിഷമഭുജ (Scalene)3 വശവും 3 കോണും വ്യത്യസ്തം

4.2 വർഗ്ഗീകരണം – കോണുകൾ അടിസ്ഥാനമാക്കി

തരംസവിശേഷത
ന്യൂനകോണ ത്രികോണം (Acute)3 കോണും 90°-ൽ താഴെ
മട്ടത്രികോണം (Right)ഒരു കോൺ 90°; മറ്റ് രണ്ടും പൂരകം; ഏറ്റവും വലിയ വശം കർണ്ണം (Hypotenuse)
ബൃഹത്കോണ ത്രികോണം (Obtuse)ഒരു കോൺ 90°-ൽ കൂടുതൽ
📌 ക്രമ നിയമം

ഒരു ത്രികോണത്തിൽ ഏറ്റവും വലിയ കോണിന് എതിർവശമാണ് ഏറ്റവും വലിയ വശം; ഏറ്റവും ചെറിയ കോണിന് എതിർവശം ഏറ്റവും ചെറിയ വശം.

4.3 ത്രികോണ അസമത്വ നിയമം (Triangle Inequality ⭐)

📌 സുവർണ്ണ നിയമം

ഒരു ത്രികോണം സാധ്യമാകാൻ, ഏത് രണ്ട് വശങ്ങളുടെ തുകയും മൂന്നാം വശത്തേക്കാൾ വലുതായിരിക്കണം: a + b > c

അതിനാൽ രണ്ട് വശങ്ങളുടെ വ്യത്യാസം < മൂന്നാം വശം < തുക (|a − b| < c < a + b).

🧠 Quick Check: രണ്ട് ചെറിയ വശങ്ങൾ കൂട്ടി വലിയ വശവുമായി താരതമ്യം ചെയ്താൽ മതി.

➕ ഉദാഹരണം

(A) 3, 4, 5    (B) 5, 6, 10    (C) 4, 5, 10    (D) 6, 6, 6 – ഏത് കൊണ്ട് ത്രികോണം സാധ്യമല്ല?

  • (A) 3 + 4 = 7 > 5 ✔
  • (B) 5 + 6 = 11 > 10 ✔
  • (D) 6 + 6 = 12 > 6 ✔
  • (C) 4 + 5 = 9 < 10 ✘ → ഉത്തരം (C)
⚠️ ട്രാപ്പ്

a + b = c ആയാൽ (ഉദാ: 3, 4, 7) ത്രികോണം സാധ്യമല്ല — വരകൾ ഒരേ നേർരേഖയിൽ വീഴും. ">" കർശനമായിരിക്കണം (≥ അല്ല).

4.4 ബാഹ്യകോൺ സിദ്ധാന്തം (SCERT ക്ലാസ് 8)

ബാഹ്യകോൺ = എതിർവശത്തെ രണ്ട് ആന്തരകോണുകളുടെ തുക
➕ ഉദാഹരണം

രണ്ട് കോണുകൾ 40°, 60° ആയാൽ മൂന്നാമത്തെ കോൺ = 180 − 40 − 60 = 80°.

  • ബാഹ്യകോണുകൾ: 180 − 40 = 140°, 180 − 60 = 120°, 180 − 80 = 100°
  • പരിശോധന: 100° = 40° + 60° ✔
  • ⭐ മൂന്ന് ബാഹ്യകോണുകളുടെ തുക = 140 + 120 + 100 = 360°

4.5 പൈതഗോറസ് സിദ്ധാന്തം

മട്ടത്രികോണത്തിൽ: കർണ്ണം² = ലംബം² + പാദം² (c² = a² + b²)

4.6 സർവ്വസമത്വം (Congruence)

ആകൃതിയും വലിപ്പവും ഒരുപോലെ ഉള്ള ത്രികോണങ്ങൾ. സർവ്വസമത നിബന്ധനകൾ:

ASA2 കോണുകളും അവയ്ക്കിടയിലെ വശവും തുല്യം

4.7 സദൃശ ത്രികോണങ്ങൾ (Similar Triangles)

ആകൃതി ഒന്ന്, വലിപ്പം വ്യത്യസ്തം. കോണുകൾ തുല്യവും, തത്തുല്യ വശങ്ങൾ ഒരേ അംശബന്ധത്തിലും ആയിരിക്കും.

📌 വശാംശബന്ധം a : b ആയാൽ
  • ചുറ്റളവുകളുടെ അംശബന്ധം = a : b
  • പരപ്പളവുകളുടെ അംശബന്ധം = a² : b²
  • ഉന്നതികളുടെ (Altitudes) അംശബന്ധം = a : b
  • മധ്യമങ്ങളുടെ (Medians) അംശബന്ധം = a : b
➕ ഉദാഹരണം

വശങ്ങളുടെ അംശബന്ധം 2 : 3 ആയാൽ പരപ്പളവ് അംശബന്ധം 4 : 9; വശാംശബന്ധം 3 : 5 ആയാൽ പരപ്പളവ് 9 : 25.

🧠 Trick: "നീളം ഒരു തവണ, വിസ്തീർണ്ണം രണ്ട് തവണ (വർഗ്ഗം)".

4.8 ത്രികോണത്തിന്റെ 4 കേന്ദ്രങ്ങൾ (⭐)

കേന്ദ്രംഏത് വരകളുടെ സംഗമംപ്രത്യേകത
മധ്യമകേന്ദ്രം / ഭാരകേന്ദ്രം (Centroid) മധ്യമങ്ങൾ (Medians: മൂലയിൽ നിന്ന് എതിർവശത്തിന്റെ മധ്യബിന്ദുവിലേക്ക്) ഓരോ മധ്യമത്തെയും മൂലയിൽ നിന്ന് 2 : 1 അംശബന്ധത്തിൽ ഭാഗിക്കുന്നു. എപ്പോഴും ത്രികോണത്തിനുള്ളിൽ
അന്തർവൃത്ത കേന്ദ്രം (Incenter) കോൺ സമഭാജികൾ (Angle Bisectors) 3 വശങ്ങളിൽ നിന്നും തുല്യ അകലം; അന്തർവൃത്തത്തിന്റെ (Incircle) കേന്ദ്രം. എപ്പോഴും ഉള്ളിൽ
പരിവൃത്ത കേന്ദ്രം (Circumcenter) വശങ്ങളുടെ ലംബസമഭാജികൾ (Perpendicular Bisectors) 3 മൂലകളിൽ നിന്നും തുല്യ അകലം; പരിവൃത്തത്തിന്റെ (Circumcircle) കേന്ദ്രം. മട്ടത്രികോണത്തിൽ കർണ്ണത്തിന്റെ മധ്യബിന്ദു
ലംബകേന്ദ്രം (Orthocenter) ഉന്നതികൾ (Altitudes: മൂലയിൽ നിന്ന് എതിർവശത്തേക്കുള്ള ലംബം) മട്ടത്രികോണത്തിൽ മട്ടകോണുള്ള മൂല
📌 സുപ്രധാന വസ്തുതകൾ
  • ⭐ സമഭുജ ത്രികോണത്തിൽ 4 കേന്ദ്രങ്ങളും ഒരേ ബിന്ദുവാണ്.
  • ⭐ കേന്ദ്രങ്ങൾ ത്രികോണത്തിന് പുറത്ത് വരുന്ന സാഹചര്യം: ബൃഹത്കോണ ത്രികോണത്തിൽ ലംബകേന്ദ്രവും പരിവൃത്ത കേന്ദ്രവും പുറത്താണ്. (മധ്യമകേന്ദ്രവും അന്തർവൃത്ത കേന്ദ്രവും എപ്പോഴും ഉള്ളിൽ.)
  • ⭐ മട്ടത്രികോണത്തിൽ: പരിവൃത്ത കേന്ദ്രം = കർണ്ണത്തിന്റെ മധ്യബിന്ദു; ലംബകേന്ദ്രം = മട്ടമൂല.
ചിത്രം 4.1 – ത്രികോണത്തിന്റെ 4 കേന്ദ്രങ്ങൾ ഒറ്റനോട്ടത്തിൽ.
🧠 Memory Trick – 4 കേന്ദ്രങ്ങൾ
  • Centroid = Medians (C-M: "സി.എം." — മുഖ്യമന്ത്രി)
  • Incenter = Interior bisectors (I = Inside, Incircle)
  • Circumcenter = Circle through vertices (Perpendicular bisector)
  • Orthocenter = Ortho (ലംബം) = Altitudes

📌 നിയമം 3 – ഒരു മൂലയിൽ
ആന്തരകോൺ + ബാഹ്യകോൺ = 180°
📌 നിയമം 4 – സമബഹുഭുജം (Regular Polygon – എല്ലാ വശവും കോണും തുല്യം)
ഒരു ബാഹ്യകോൺ = 360° / n
n = 360° / (ഒരു ബാഹ്യകോൺ)
ഒരു ആന്തരകോൺ = 180° − 360°/n = [(n−2) × 180°] / n
📌 നിയമം 5 – വികർണ്ണങ്ങൾ (Diagonals)

അടുത്തടുത്തല്ലാത്ത രണ്ട് മൂലകളെ യോജിപ്പിക്കുന്ന വര. ഒരു മൂലയിൽ നിന്ന് (n − 3) വികർണ്ണങ്ങൾ; അവ ബഹുഭുജത്തെ (n − 2) ത്രികോണങ്ങളാക്കുന്നു.

ആകെ വികർണ്ണങ്ങൾ = n(n − 3) / 2

5.4 SCERT-ശൈലി ഉദാഹരണങ്ങൾ

➕ Q1. 27 വശങ്ങളുള്ള ബഹുഭുജത്തിന്റെ കോണുകളുടെ തുക?

പരിഹാരം: (27 − 2) × 180° = 25 × 180° = 4500°

മറ്റ് ഉദാഹരണങ്ങൾ: 52 വശം: 50 × 180 = 9000°; 20 വശം: 18 × 180 = 3240°

➕ Q2. ആന്തരകോണുകളുടെ തുക 8100° ആയാൽ വശങ്ങൾ?

പരിഹാരം: (n − 2) = 8100 ÷ 180 = 45 → n = 47

മറ്റൊന്ന്: തുക 2160° ആയാൽ (n − 2) = 12 → n = 14

➕ Q3. 15 വശമുള്ള സമബഹുഭുജത്തിന്റെ ഒരു ബാഹ്യ, ആന്തരകോൺ?

പരിഹാരം: ബാഹ്യകോൺ = 360 ÷ 15 = 24° → ആന്തരകോൺ = 180 − 24 = 156°

മറ്റൊന്ന്: 18 വശം: ബാഹ്യ 20°, ആന്തര 160°

➕ Q4. ഒരു ആന്തരകോൺ 168° ആയാൽ വശങ്ങൾ?

പരിഹാരം: ബാഹ്യകോൺ = 180 − 168 = 12° → n = 360 ÷ 12 = 30

മറ്റൊന്ന്: ആന്തരകോൺ 144° ആയാൽ ബാഹ്യ 36° → n = 10

➕ Q5. ആന്തര, ബാഹ്യ തുകകൾ തുല്യമാകുന്നത് ഏത് ബഹുഭുജത്തിൽ?

പരിഹാരം: (n − 2) × 180 = 360 → n − 2 = 2 → n = 4, ചതുർഭുജം

ബന്ധം: ബാഹ്യ തുക ആന്തരത്തിന്റെ ഇരട്ടി: ത്രികോണം (360 = 2 × 180); പകുതി: ഷഡ്ഭുജം (360 = ½ × 720)

➕ Q6. 20 വികർണ്ണങ്ങളുള്ള ബഹുഭുജത്തിന് എത്ര വശം?

പരിഹാരം: n(n − 3) = 40 → വ്യത്യാസം 3 വരുന്ന രണ്ട് സംഖ്യകളുടെ ഗുണനഫലം 40 → 8 × 5 → n = 8 (അഷ്ടഭുജം)

🧠 Shortcut

ആന്തരകോൺ 150° ആയാൽ ബാഹ്യ 30° → n = 12. ബാഹ്യകോൺ എപ്പോഴും ആദ്യം കാണുക; അത് 360-ന്റെ ഹരണം (factor) ആയിരിക്കണം.

ചിത്രം 5.1 – ഒരു മൂലയിൽ നിന്ന് വികർണ്ണങ്ങൾ വരച്ചാൽ (n − 2) ത്രികോണങ്ങൾ കിട്ടും; തുക = (n − 2) × 180°.

6.1 ചതുർഭുജങ്ങളുടെ തരങ്ങൾ

ചതുർഭുജംപ്രധാന സവിശേഷതകൾ
സാമാന്തരികം (Parallelogram) എതിർവശങ്ങൾ തുല്യവും സമാന്തരവും; എതിർകോണുകൾ തുല്യം; അടുത്തടുത്ത കോണുകളുടെ തുക 180°; വികർണ്ണങ്ങൾ പരസ്പരം സമഭാഗിക്കുന്നു
സമഭുജ സാമാന്തരികം (Rhombus) 4 വശവും തുല്യം; വികർണ്ണങ്ങൾ പരസ്പരം ലംബമായി (90°) സമഭാഗിക്കുന്നു; വികർണ്ണങ്ങൾ കോണുകളെ സമഭാഗിക്കുന്നു; വികർണ്ണങ്ങൾ തുല്യമല്ല
ചതുരം (Rectangle) 4 കോണും 90°; വികർണ്ണങ്ങൾ തുല്യം (പരസ്പരം സമഭാഗിക്കും, ലംബമല്ല)
സമചതുരം (Square) 4 വശവും 4 കോണും തുല്യം; വികർണ്ണങ്ങൾ തുല്യവും പരസ്പരം ലംബസമഭാഗിയും
ലംബകം (Trapezium) ഒരു ജോഡി എതിർവശങ്ങൾ മാത്രം സമാന്തരം. സമാന്തരവശങ്ങൾക്കിടയിലെ ഒരേ വശത്തെ കോണുകളുടെ തുക 180°. സമാന്തരമല്ലാത്ത വശങ്ങൾ തുല്യമായാൽ സമപാർശ്വ ലംബകം
പട്ടം (Kite) അടുത്തടുത്ത 2 ജോഡി വശങ്ങൾ തുല്യം; വികർണ്ണങ്ങൾ ലംബം
📌 പ്രധാന ബന്ധങ്ങൾ
  • ⭐ സമചതുരം = ചതുരവും സമഭുജ സാമാന്തരികവും ഒരുമിച്ചാണ്.

7. E. വൃത്തങ്ങൾ, ഞാണുകൾ, തൊടുവരകൾ

7.1 അടിസ്ഥാന പദങ്ങൾ

പദംഅർത്ഥം
ആരം (Radius)കേന്ദ്രത്തിൽ നിന്ന് പരിധിയിലേക്കുള്ള ദൂരം (r)
വ്യാസം (Diameter)2r; കേന്ദ്രത്തിലൂടെ കടന്നുപോകുന്ന ഏറ്റവും നീളമുള്ള ഞാൺ
ഞാൺ (Chord)വൃത്തത്തിലെ രണ്ട് ബിന്ദുക്കളെ യോജിപ്പിക്കുന്ന രേഖാഖണ്ഡം
ചാപം (Arc)വൃത്തത്തിന്റെ ഒരു ഭാഗം (Minor / Major)
ഖണ്ഡം (Segment)ഞാണിനാൽ വേർതിരിക്കപ്പെടുന്ന വൃത്തത്തിന്റെ ഭാഗം
സെക്ടർ (Sector)രണ്ട് ആരങ്ങളും ഒരു ചാപവും ചേർന്ന ഭാഗം
ഛേദകം (Secant)വൃത്തത്തെ രണ്ട് ബിന്ദുക്കളിൽ ഛേദിക്കുന്ന നേർവര
തൊടുവര (Tangent)വൃത്തത്തെ ഒരേയൊരു ബിന്ദുവിൽ തൊടുന്ന നേർവര

7.2 കേന്ദ്രകോൺ സിദ്ധാന്തം ⭐

📌 സുപ്രധാന സിദ്ധാന്തം
കേന്ദ്രകോൺ = 2 × (അതേ ചാപത്തിലെ പരിധികോൺ)

ഒരു ചാപം കേന്ദ്രത്തിൽ ഉണ്ടാക്കുന്ന കോൺ = മറുചാപത്തിലെ (പരിധിയിലെ) കോണിന്റെ ഇരട്ടി.

➕ ഉദാഹരണം

കേന്ദ്രകോൺ 110° ആയാൽ പരിധിയിലെ കോൺ = 110 ÷ 2 = 55°.

പരിധിയിലെ കോൺ 65° ആയാൽ കേന്ദ്രകോൺ = 2 × 65 = 130°.

7.3 അർദ്ധവൃത്തത്തിലെ കോൺ = 90° ⭐

📌 പ്രത്യേക കേസ്

വ്യാസത്തിന്റെ രണ്ടറ്റവും പരിധിയിലെ ഏതൊരു ബിന്ദുവുമായി യോജിപ്പിച്ചാൽ ഉണ്ടാകുന്ന കോൺ മട്ടകോൺ (90°).

കാരണം: കേന്ദ്രകോൺ 180° ആണ് (വ്യാസം ഒരു നേർവര) → പരിധിയിൽ 180 ÷ 2 = 90°.

7.4 ഒരേ ഖണ്ഡത്തിലെ കോണുകൾ തുല്യം

ഒരു ഞാണിന്റെ ഒരേ വശത്തെ പരിധിയിലെ കോണുകൾ തുല്യം.

7.5 ഞാൺ - കേന്ദ്ര ലംബം

r² = d² + (L/2)²

r = ആരം, d = കേന്ദ്രത്തിൽ നിന്നുള്ള ലംബ അകലം, L = ഞാണിന്റെ നീളം.

കേന്ദ്രത്തിൽ നിന്ന് ഞാണിലേക്കുള്ള ലംബം ഞാണിനെ സമഭാഗിക്കുന്നു.

➕ ഉദാഹരണം

r = 5, d = 3 → L/2 = √(25 − 9) = 4 → ഞാൺ = 8 (3-4-5 ത്രയം!)

r = 13, d = 5 → L/2 = √(169 − 25) = 12 → ഞാൺ = 24 (5-12-13 ത്രയം)

7.6 ഞാണുകളുടെ സംഗമ നിയമം

AB, CD ഞാണുകൾ വൃത്തത്തിനുള്ളിൽ P-യിൽ കൂടിമുട്ടിയാൽ: PA × PB = PC × PD

7.7 തൊടുവരകൾ (Tangents)

സവിശേഷതവിവരം

ആരവുമായുള്ള ബന്ധംതൊടുബിന്ദുവിലെ ആരം തൊടുവരയ്ക്ക് ലംബം (90°)
രണ്ട് തൊടുവരകൾപുറത്തെ ബിന്ദുവിൽ നിന്നുള്ള രണ്ട് തൊടുവരകളുടെ നീളം തുല്യം
തൊടുവര-ഛേദക ബന്ധംPT² = PA × PB

8.3 പ്രധാന സൂത്രവാക്യങ്ങൾ

മൂലബിന്ദുവിൽ നിന്ന് (x, y) ലേക്കുള്ള അകലം = √(x² + y²)
രണ്ട് ബിന്ദുക്കൾ തമ്മിലുള്ള അകലം d = √[(x₂ − x₁)² + (y₂ − y₁)²]
മധ്യബിന്ദു M = [(x₁ + x₂)/2, (y₁ + y₂)/2]
ചരിവ് (Slope) m = (y₂ − y₁) / (x₂ − x₁)
നേർവരയുടെ സമവാക്യം: y = mx + c
ത്രികോണ കേന്ദ്രം (Centroid) = [(x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3]
വിഭജന സൂത്രവാക്യം (m : n ആന്തരമായി) = [(mx₂ + nx₁)/(m+n), (my₂ + ny₁)/(m+n)]

8.4 ചരിവ് ബന്ധങ്ങൾ

📌 4 പ്രധാന നിയമങ്ങൾ
  • സമാന്തര വരകൾ: ചരിവ് തുല്യം (m₁ = m₂)
  • ലംബ വരകൾ: ചരിവുകളുടെ ഗുണനഫലം −1 (m₁ × m₂ = −1)
  • X-അക്ഷത്തിന് സമാന്തര വര: ചരിവ് = 0
  • Y-അക്ഷത്തിന് സമാന്തര വര: ചരിവ് നിർവ്വചിതമല്ല (undefined)

8.5 ഉദാഹരണങ്ങൾ

➕ ഉദാ 1 – അകലം

(1, 2), (4, 6) തമ്മിലുള്ള അകലം = √[(4−1)² + (6−2)²] = √(9 + 16) = √25 = 5

➕ ഉദാ 2 – മധ്യബിന്ദു

(2, 4), (6, 10)-ന്റെ മധ്യബിന്ദു = [(2+6)/2, (4+10)/2] = (4, 7) → (4, 7)

➕ ഉദാ 3 – ചരിവ്

(1, 2), (3, 6)-ന്റെ ചരിവ് = (6−2)/(3−1) = 4/2 = 2

➕ ഉദാ 4 – മൂലബിന്ദുവിൽ നിന്നുള്ള അകലം

(3, 4)-ൽ നിന്ന് മൂലബിന്ദുവിലേക്കുള്ള അകലം = √(9 + 16) = √25 = 5

➕ ഉദാ 5 – ത്രികോണ കേന്ദ്രം

(1, 2), (4, 5), (7, 3) എന്നീ മൂലകളുള്ള ത്രികോണത്തിന്റെ കേന്ദ്രം?

Centroid = [(1+4+7)/3, (2+5+3)/3] = [12/3, 10/3] = (4, 10/3)

ചോദ്യം: 20 വശമുള്ള ബഹുഭുജത്തിന്റെ ആന്തരകോണുകളുടെ തുക?

പരിഹാരം: (20−2) × 180 = 18 × 180 = 3240°

📌 മാതൃക 2 – ബാഹ്യകോൺ → n

ചോദ്യം: ഒരു സമബഹുഭുജത്തിന്റെ ഒരു ബാഹ്യകോൺ 24° ആയാൽ വശങ്ങൾ?

പരിഹാരം: n = 360/24 = 15

📌 മാതൃക 3 – പൂരകം

ചോദ്യം: 48°-ന്റെ പൂരക കോൺ?

പരിഹാരം: 90 − 48 = 42°

📌 മാതൃക 4 – വികർണ്ണം

ചോദ്യം: ദശഭുജത്തിന്റെ വികർണ്ണങ്ങളുടെ എണ്ണം?

പരിഹാരം: 10 × 7 / 2 = 35

📌 മാതൃക 5 – കേന്ദ്രകോൺ

ചോദ്യം: കേന്ദ്രകോൺ 130° ആയാൽ പരിധിയിലെ കോൺ?

പരിഹാരം: 130 ÷ 2 = 65°

13. ആശയക്കുഴപ്പമുണ്ടാക്കുന്ന വസ്തുതകൾ

ആശയക്കുഴപ്പംവ്യക്തത
പൂരകം vs അനുപൂരകം പൂരകം 90°, അനുപൂരകം 180°
ബാഹ്യകോൺ തുക എപ്പോഴും 360° (n-നെ ആശ്രയിക്കില്ല)
ആന്തരകോൺ തുക (n − 2) × 180° (n-നെ ആശ്രയിക്കും)
ചതുരം vs സമഭുജ സാമാന്തരികം ചതുരം: വികർണ്ണം തുല്യം; സമഭുജം: വികർണ്ണം ലംബം
Centroid vs Orthocenter Centroid = മധ്യമം; Orthocenter = ഉന്നതി
Incenter vs Circumcenter Incenter = കോൺ സമഭാജി (അകത്തെ വൃത്തം); Circumcenter = ലംബസമഭാജി (പുറത്തെ വൃത്തം)
സർവ്വസമം vs സദൃശം സർവ്വസമം: വലിപ്പവും ആകൃതിയും; സദൃശം: ആകൃതി മാത്രം
ഞാൺ vs വ്യാസം വ്യാസം = കേന്ദ്രത്തിലൂടെയുള്ള ഏറ്റവും നീളമുള്ള ഞാൺ
തൊടുവര vs ഛേദകം തൊടുവര 1 ബിന്ദു; ഛേദകം 2 ബിന്ദു
വികർണ്ണം vs വശം വികർണ്ണം അടുത്തടുത്തല്ലാത്ത മൂലകളെ യോജിപ്പിക്കുന്നു
ആന്തരകോൺ vs ബാഹ്യകോൺ ഒരു മൂലയിൽ: ആന്തര + ബാഹ്യ = 180°
ഒരേ ചുറ്റളവിൽ വൃത്തം vs സമചതുരം വൃത്തത്തിനാണ് കൂടുതൽ പരപ്പളവ്
⚠️ PSC Trap Box

"ഒരു ബഹുഭുജത്തിന്റെ ഒരു ബാഹ്യകോൺ 40° (സമബഹുഭുജം). ഒരു ആന്തരകോൺ എത്ര?"

തെറ്റ്: n = 360/40 = 9 എന്ന് മാത്രം എഴുതുക (ചോദിച്ചത് കോൺ ആണ്, n അല്ല!)

ശരി: ആന്തരകോൺ = 180 − 40 = 140°

ചോദ്യം ഡിഗ്രിയാണോ വശങ്ങളുടെ എണ്ണമാണോ എന്ന് നോക്കുക.

📌 ചെറിയ പരിശോധന

"ഒരു ത്രികോണത്തിന്റെ രണ്ട് വശങ്ങൾ 5, 9. മൂന്നാം വശം എത്ര പരിധിയിൽ?"

|9−5| < x < 9+5 → 4 < x < 14 (4-ഉം 14-ഉം ഉൾപ്പെടില്ല!)

📌 രണ്ടാം പരിശോധന

"സമചതുരത്തിന്റെ ഒരു വികർണ്ണം 10 സെ.മീ. വശം?"

d = a√2 → 10 = a√2 → a = 10/√2 = 5√2 = 5√2 സെ.മീ ≈ 7.07

കെണി: d = a എന്നോ d = 2a എന്നോ തെറ്റായി കരുതൽ.

"n മൈനസ് 2, ഗുണം 180"

"360 ഹരിക്കൂ n കൊണ്ട്"

🧠 Trick 5 – വികർണ്ണം

"n ഗുണം (n − 3), പകുതി"

"F – തുല്യം; Z – തുല്യം; C – 180"

🧠 Trick 9 – ചരിവ്

"ഉയർച്ച / ദൂരം" (Rise over Run) = (y₂ − y₁)/(x₂ − x₁).

16. Common PSC Traps (പരീക്ഷയിലെ ചതിക്കുഴികൾ)

⚠️ Trap 1 – ബാഹ്യകോൺ / ആന്തരകോൺ മാറിപ്പോകൽ

ചോദ്യം: ഒരു സമബഹുഭുജത്തിന്റെ ഒരു ബാഹ്യകോൺ 30° ആയാൽ n?

ശരി: n = 360/30 = 12

ചോദ്യം: ഒരു സമബഹുഭുജത്തിന്റെ ഒരു ആന്തരകോൺ 30° ആകുമോ?

അസാധ്യം! സമബഹുഭുജത്തിലെ ആന്തരകോൺ എപ്പോഴും n കൂടുമ്പോൾ 180°-നോട് അടുക്കും, എന്നാൽ 30° എന്ന് വരില്ല (n=3-ൽ പോലും 60°).

⚠️ Trap 2 – +1 vs +2 കുഴയ്ക്കൽ

ചോദ്യം: ബഹുഭുജത്തിന്റെ ആന്തര തുക 1260° ആയാൽ n?

തെറ്റ്: 1260/180 = 7 → n = 7 (ഇത് തെറ്റാണ്! n − 2 = 7, അല്ല!)

ശരി: (n − 2) = 1260/180 = 7 → n = 7 + 2 = 9 (നവഭുജം)

⚠️ Trap 3 – a + b = c vs a + b > c

ചോദ്യം: 3, 4, 7 കൊണ്ട് ത്രികോണം സാധ്യമോ?

തെറ്റ്: "3 + 4 = 7 ആണെങ്കിലും സാധ്യമാകും" എന്ന് കരുതൽ.

ശരി: 3 + 4 = 7 (തുല്യം) → ത്രികോണം സാധ്യമല്ല. കർശനമായും ">" ആയിരിക്കണം.

⚠️ Trap 4 – AAA സർവ്വസമത

ചോദ്യം: AAA സർവ്വസമത നിബന്ധനയാണോ?

തെറ്റ്: "അതെ" എന്ന് കരുതൽ.

ശരി: AAA സർവ്വസമതയല്ല — അത് സാദൃശ്യത്തിന് മാത്രം മതി.

⚠️ Trap 5 – കേന്ദ്രകോൺ = പരിധികോൺ

ചോദ്യം: കേന്ദ്രകോൺ 80° ആയാൽ പരിധിയിലെ കോൺ?

തെറ്റ്: 80° (ഇരട്ടി മറന്നു!)

ശരി: 80/2 = 40°

⚠️ Trap 6 – പൂരകം / അനുപൂരകം കുഴയ്ക്കൽ

ചോദ്യം: 55°-ന്റെ പൂരകം?

തെറ്റ്: 180 − 55 = 125° (ഇത് അനുപൂരകം!)

ശരി: 90 − 55 = 35°

⚠️ Trap 7 – ചതുര വികർണ്ണം "ലംബം"

ചോദ്യം: ചതുരത്തിന്റെ വികർണ്ണങ്ങൾ ലംബമാണോ?

തെറ്റ്: "അതെ" എന്ന് കരുതൽ.

ശരി: ചതുരത്തിന്റെ വികർണ്ണങ്ങൾ തുല്യം, പക്ഷേ ലംബമല്ല (ലംബമാകുന്നത് സമചതുരത്തിനും സമഭുജ സാമാന്തരികത്തിനും മാത്രം).

⚠️ Trap 8 – സമാന്തരമല്ലാത്ത വരകളിൽ F, Z, C

സമാന കോണുകൾ, മറുകോണുകൾ, സഹ-ആന്തര കോണുകൾ — ഈ ബന്ധങ്ങൾ വരകൾ സമാന്തരമാണെങ്കിൽ മാത്രം. സമാന്തരമല്ലെങ്കിൽ ഉപയോഗിക്കരുത്.

⚠️ Trap 9 – ത്രികോണ കേന്ദ്രങ്ങളുടെ പേരുകൾ

Circumcenter ↔ Incenter കുഴയ്ക്കൽ — Circumcenter = പുറത്തെ വൃത്തം (ലംബസമഭാജി), Incenter = അകത്തെ വൃത്തം (കോൺ സമഭാജി).

⚠️ Trap 10 – സദൃശ പരപ്പളവ് അംശബന്ധം

ചോദ്യം: രണ്ട് സദൃശ ത്രികോണങ്ങളുടെ വശാംശബന്ധം 3 : 5 ആയാൽ പരപ്പളവ് അംശബന്ധം?

തെറ്റ്: 3 : 5 (വശാംശബന്ധം തന്നെ പരപ്പളവിന് എന്ന് കരുതൽ)

ശരി: 9 : 25 (വർഗ്ഗം!)

⚠️ Trap 11 – ഞാൺ നീളം / അകലം കുഴയ്ക്കൽ

ചോദ്യം: r = 10, d = 6 → ഞാണിന്റെ നീളം?

തെറ്റ്: 8 (√(100 − 36) — ഇത് പകുതി ഞാൺ!)

ശരി: 2 × 8 = 16

⚠️ Trap 12 – തൊടുവര ⊥ ആരം

തൊടുബിന്ദുവിൽ തൊടുവര ആരത്തിന് എപ്പോഴും ലംബം (90°). ഇത് മറന്നാൽ തൊടുവര നീളം കണക്കാക്കാൻ പറ്റില്ല.

⚠️ Trap 13 – വ്യാസം vs ആരം

ചോദ്യത്തിൽ വ്യാസം (diameter) തന്നാൽ ആരം = d/2 ആക്കണം. ഉദാ: വ്യാസം 14 → r = 7 (14 അല്ല!).

⚠️ Trap 14 – ന്യൂനകോൺ vs ബൃഹത്കോൺ

ന്യൂനകോൺ: 0° < θ < 90°; ബൃഹത്കോൺ: 90° < θ < 180°. 90° = മട്ടം (ഇവയിൽ ഉൾപ്പെടില്ല!).

⚠️ Trap 15 – സമചതുര വികർണ്ണം d²/2 vs a²

സമചതുരത്തിന്റെ വികർണ്ണം d തന്നാൽ പരപ്പളവ് = d²/2; വശം a തന്നാൽ = a². രണ്ടും കുഴയ്ക്കരുത്.

⚠️ Trap 16 – Circumcenter of Right Triangle

മട്ടത്രികോണത്തിൽ Circumcenter = കർണ്ണത്തിന്റെ മധ്യബിന്ദു; Orthocenter = മട്ടമൂല. ഇവ രണ്ടും ഒരുമിച്ച് കുഴയ്ക്കരുത്.

17. Additional Kerala PSC Facts (അധിക വസ്തുതകൾ)

  • ⭐⭐⭐ മധ്യരേഖാ സിദ്ധാന്തം (Midpoint Theorem): ഒരു ത്രികോണത്തിന്റെ രണ്ട് വശങ്ങളുടെ മധ്യബിന്ദുക്കളെ യോജിപ്പിക്കുന്ന വര മൂന്നാം വശത്തിന് സമാന്തരവും അതിന്റെ പകുതി നീളവും ആയിരിക്കും.
  • ⭐⭐⭐ സമഭുജ ത്രികോണത്തിന്റെ പരപ്പളവ് = (√3 / 4) × a²
  • ⭐⭐⭐⭐ മട്ടത്രികോണ പരപ്പളവ് = ½ × പാദം × ഉന്നതി
  • ⭐⭐⭐ ത്രികോണത്തിന്റെ 3 ഉന്നതികളും, 3 മധ്യമങ്ങളും എപ്പോഴും ഒരു ബിന്ദുവിൽ കൂടും (concurrent).
  • ⭐⭐⭐ ഷഡ്ഭുജത്തിൽ ഒരു ആന്തരകോൺ 120° (സമബഹുഭുജം); തേനീച്ചക്കൂട് ഷഡ്ഭുജാകൃതിയിൽ.
  • ⭐⭐⭐ ബൗധായനൻ / ആര്യഭടൻ ഭാരതീയ ഗണിതശാസ്ത്രജ്ഞർ; യൂക്ലിഡ് ജ്യാമിതിയുടെ പിതാവ്.
  • ⭐⭐⭐ പൈതഗോറസ് (ഗ്രീക്ക്, ബി.സി. 6-ാം നൂറ്റാണ്ട്) പേരിലുള്ള സിദ്ധാന്തം.
  • ⭐⭐ ഒരു വൃത്തത്തിനുള്ളിൽ ഒരേ ഞാണിനോട് ചേർന്ന വിപരീത ഖണ്ഡങ്ങളിലെ കോണുകളുടെ തുക 180° (ചക്രീയ ചതുർഭുജ നിയമത്തിന് തുല്യം).
  • ⭐⭐ ഒരു ബിന്ദുവിന് ചുറ്റും തുല്യ വൃത്തങ്ങൾ വരയ്ക്കുമ്പോൾ ആകെ കോൺ 360°.
  • ⭐⭐ ത്രികോണത്തിന്റെ 3 ബാഹ്യകോണുകളുടെ തുക = 360° (ഏത് ബഹുഭുജത്തിലെയും പോലെ).
  • ⭐⭐ ഏത് ത്രികോണത്തിന്റെയും 3 വശങ്ങളുടെ ലംബസമഭാജികൾ ഒരു ബിന്ദുവിൽ കൂടും — ആ ബിന്ദു = Circumcenter.
  • ⭐⭐ ഏത് ത്രികോണത്തിന്റെയും 3 കോൺ സമഭാജികൾ ഒരു ബിന്ദുവിൽ കൂടും — ആ ബിന്ദു = Incenter.
  • ⭐ ത്രികോണ അസമത്വ നിയമത്തിന് തുല്യമായ രൂപം: |a − b| < c < a + b.
  • ⭐ സമബഹുഭുജത്തിൽ 4 കേന്ദ്രങ്ങൾ ഒരേ ബിന്ദുവാണ് (Centroid = Incenter = Circumcenter = Orthocenter).
  • ⭐ വൃത്തത്തിന് അകത്ത് ഒരു ബിന്ദുവിൽ നിന്ന് തൊടുവര വരയ്ക്കാൻ കഴിയില്ല (0 തൊടുവരകൾ).

18. Theory അറിയില്ലെങ്കിലും ഉത്തരം കണ്ടെത്താനുള്ള PSC Smart Tricks

⚠️ പ്രധാന മുന്നറിയിപ്പ്

ഈ ട്രിക്കുകൾ ശരിയായ ഉത്തരത്തിന്റെ സാധ്യത കൂട്ടുന്നു; അറിവിന് പകരമല്ല. "നീളമുള്ള ഓപ്ഷൻ ശരി", "എപ്പോഴും C" തുടങ്ങിയ മിഥ്യാധാരണകൾ വിശ്വസിക്കരുത്. നെഗറ്റീവ് മാർക്ക് ഉണ്ടെങ്കിൽ (PSC-യിൽ സാധാരണ 1/3 കുറയ്ക്കൽ, നോട്ടിഫിക്കേഷൻ പരിശോധിക്കുക): 4 ഓപ്ഷനുകളിൽ 2 എണ്ണം സുരക്ഷിതമായി ഒഴിവാക്കാൻ കഴിഞ്ഞാൽ ഊഹം ലാഭകരം; ഒന്നും ഒഴിവാക്കാൻ പറ്റുന്നില്ലെങ്കിൽ ഒഴിവാക്കുന്നത് സുരക്ഷിതം.

Trick 1: Option Elimination (ഒഴിവാക്കൽ വിദ്യ)

📌 ഉദാഹരണം

Q. 40° കോണിന്റെ പൂരക കോൺ?

(A) 140°   (B) 50°   (C) 320°   (D) 90°

  • പൂരകം = 90°-ൽ താഴെ ആയിരിക്കും (കോൺ പോസിറ്റീവ് ആകുമ്പോൾ) → (A) 140°, (C) 320° ഒഴിവാക്കാം.
  • (D) 90° = മട്ടകോൺ; 40° + 90° = 130° ≠ 90° → ഒഴിവാക്കാം.
  • ബാക്കി (B) 50°: 40 + 50 = 90 ✔ → ഉത്തരം (B).

🔑 സിദ്ധാന്തം മറന്നാലും "90-ൽ താഴെ" എന്ന അറിവ് മതി 3 ഓപ്ഷൻ ഒഴിവാക്കാൻ.

Trick 2: Keyword Check (കീവേഡ് പരിശോധന)

only, always, never, all, none, first, largest, NOT, EXCEPT, incorrect എന്നിവ സൂചനകളാണ്, ശരി/തെറ്റ് തീരുമാനിക്കുന്ന നിയമങ്ങളല്ല.

📌 ഉദാഹരണം

Q. ചതുർഭുജങ്ങളെക്കുറിച്ചുള്ള തെറ്റായ പ്രസ്താവന ഏത്?

(A) ചതുരത്തിന്റെ വികർണ്ണങ്ങൾ തുല്യം
(B) സമഭുജ സാമാന്തരികത്തിന്റെ വികർണ്ണങ്ങൾ ലംബം
(C) ചതുരത്തിന്റെ വികർണ്ണങ്ങൾ എപ്പോഴും ലംബമാണ്
(D) സാമാന്തരികത്തിന്റെ വികർണ്ണങ്ങൾ പരസ്പരം സമഭാഗിക്കും

  • "തെറ്റായത്" എന്ന വാക്ക് ശ്രദ്ധിക്കുക → ഓരോന്നും പരിശോധിക്കുക.
  • (A) ശരി, (B) ശരി, (D) ശരി.
  • (C): "എപ്പോഴും ലംബം" – ചതുരത്തിൽ വികർണ്ണം ലംബമാകുന്നത് സമചതുരമാകുമ്പോൾ മാത്രം → തെറ്റ് → ഉത്തരം (C).
  • ഇവിടെ "എപ്പോഴും" എന്ന വാക്ക് തെറ്റാണെന്ന് പരിശോധിച്ച ശേഷമാണ് നമ്മൾ തീരുമാനിച്ചത്; വാക്ക് കണ്ടത് കൊണ്ട് മാത്രമല്ല.
  • ⚠️ "എപ്പോഴും" ഉള്ള പ്രസ്താവനയും ശരിയാകാം: "ഏത് ബഹുഭുജത്തിന്റെയും ബാഹ്യകോണുകളുടെ തുക എപ്പോഴും 360°" – ഇത് ശരിയാണ്.

Trick 3: Common-Sense Logic (യുക്തി)

📌 ഉദാഹരണം

Q. ഒരു ത്രികോണത്തിന്റെ രണ്ട് കോണുകൾ 70°, 80° ആയാൽ മൂന്നാമത്തേത്?

(A) 150°   (B) 30°   (C) 170°   (D) 10°

  • മൂന്ന് കോണിന്റെ തുക 180°; 70 + 80 = 150 ഇതിനകം → മൂന്നാമത്തേത് 30°.
  • (A) 150, (C) 170 ഒഴിവാക്കാം (തുക 180 കവിയും). (D) 10 → 70 + 80 + 10 = 160 ≠ 180 ✘. ഉത്തരം (B) 30°.

Trick 4: Extreme Statement Check

📌 ഉദാഹരണം

Q. "ത്രികോണത്തിന്റെ ഏത് രണ്ട് വശങ്ങളുടെ തുകയും മൂന്നാമത്തെ വശത്തേക്കാൾ വലുതായിരിക്കും." ഇത് ശരിയാണോ?

  • "ഏത് രണ്ട്" എന്നത് എല്ലാ കോമ്പിനേഷനും എന്നർത്ഥം. സ്കെച്ച് വരച്ച് ചിന്തിക്കുക: രണ്ട് വശങ്ങൾ ചേർന്ന് "ചുറ്റിവളഞ്ഞ് വഴിയായി" പോയാലും നേരിട്ടുള്ള വഴിയേക്കാൾ (മൂന്നാം വശം) കുറഞ്ഞ ദൂരമാവില്ല → ശരി.
  • ✔ പരിശോധനയാണ് പ്രധാനം; "എപ്പോഴും/ഏത്" ഉള്ളത് കൊണ്ട് തള്ളിക്കളയരുത്.

Trick 5: Match-the-Following

📌 ഉദാഹരണം
1. Centroida. ലംബസമഭാജികൾ
2. Circumcenterb. മധ്യമങ്ങൾ
3. Orthocenterc. ഉന്നതികൾ
4. Incenterd. കോൺ സമഭാജികൾ

Options: (A) 1-b, 2-a, 3-c, 4-d (B) 1-a, 2-b, 3-c, 4-d (C) 1-c, 2-a, 3-b, 4-d (D) 1-b, 2-d, 3-c, 4-a

  • ഉറപ്പുള്ള ജോഡി ആദ്യം: Centroid = മധ്യമങ്ങൾ (1-b) → (B), (C) ഒഴിവാക്കാം.
  • ബാക്കി (A), (D): Incenter = കോൺ സമഭാജി (4-d) → (D)-ൽ 4-a → ഒഴിവാക്കാം.
  • ഉത്തരം (A). (2 ജോഡി അറിഞ്ഞാൽ തന്നെ ഉത്തരം ഉറപ്പിക്കാം.)

Trick 6: Statement-Based Questions

📌 ഉദാഹരണം

Q. പ്രസ്താവനകൾ പരിഗണിക്കുക:

  • (i) ബഹുഭുജത്തിന്റെ ബാഹ്യകോൺ തുക 360° ആണ്.
  • (ii) ത്രികോണത്തിന്റെ ആന്തരകോൺ തുക 360° ആണ്.
  • (iii) ചക്രീയ ചതുർഭുജത്തിൽ എതിർകോണുകൾ അനുപൂരകമാണ്.

Options: (A) (i) മാത്രം (B) (i), (iii) (C) (ii), (iii) (D) മൂന്നും

  • (i) ശരി; (ii) തെറ്റ് (180°); (iii) ശരി.
  • (ii) തെറ്റായതിനാൽ (C), (D) ഒഴിവാക്കാം. (i), (iii) രണ്ടും ശരി → (B).
  • ഓരോ പ്രസ്താവനയും വെവ്വേറെ പരിശോധിക്കുക.

(A) (n−2)180/n   (B) (n−2)180/2   (C) 360/n   (D) (n−2)180

ശരിയുത്തരം: (A) 30°
ചെറിയ വശത്തിന് എതിർവശത്തെ കോൺ ചെറുതാണ് → 30°. (B) 60° വലിയ ലംബവശത്തിന് എതിർ; (C) 90° കർണ്ണത്തിന് എതിർ (ഏറ്റവും വലിയ കോൺ).
19. വൃത്തത്തിന്റെ ആരം 13 സെ.മീ., കേന്ദ്രത്തിൽ നിന്ന് 12 സെ.മീ. അകലെയുള്ള ഞാണിന്റെ നീളം?

20. ഒരു സമചതുരത്തിന്റെ വികർണ്ണം 10 സെ.മീ. ആയാൽ പരപ്പളവ്?

21.2 സോൾവ്ഡ് ഉദാഹരണങ്ങൾ

➕ ഉദാഹരണം 1 – പൂരക അംശബന്ധം

ചോദ്യം: ഒരു കോണും അതിന്റെ പൂരകവും 2 : 1 അംശബന്ധത്തിലാണ്. കോൺ ഏത്?

പരിഹാരം: തുക = 90° → 3 ഭാഗം = 90 → 1 ഭാഗം = 30° → കോൺ = 60°.

➕ ഉദാഹരണം 2 – അനുപൂരക ബന്ധം

ചോദ്യം: ഒരു കോണിന്റെ അനുപൂരകം, അതിന്റെ പൂരകത്തിന്റെ 3 മടങ്ങാണ്. കോൺ ഏത്?

പരിഹാരം: θ എന്ന് എടുക്കുക: 180 − θ = 3(90 − θ) → 180 − θ = 270 − 3θ → 2θ = 90 → θ = 45°.

➕ ഉദാഹരണം 3 – സമഭുജ ത്രികോണ ഉന്നതി

ചോദ്യം: ഒരു സമഭുജ ത്രികോണത്തിൽ (വശം 6 സെ.മീ.) ഉന്നതി?

പരിഹാരം: ഉന്നതി = (√3 / 2) × 6 = 3√3 സെ.മീ.

➕ ഉദാഹരണം 4 – സമബഹുഭുജ വികർണ്ണം

ചോദ്യം: ഒരു സമബഹുഭുജത്തിന്റെ ഒരു ബാഹ്യകോൺ 40° ആയാൽ വികർണ്ണങ്ങളുടെ എണ്ണം?

പരിഹാരം: n = 360/40 = 9 → വികർണ്ണം = 9(9−3)/2 = 9×6/2 = 27.

➕ ഉദാഹരണം 5 – ചക്രീയ ചതുർഭുജം

ചോദ്യം: ഒരു ചക്രീയ ചതുർഭുജത്തിന്റെ കോണുകൾ x, x+20°, 2x, 2x+10° ആയാൽ x?

പരിഹാരം: ചക്രീയ ചതുർഭുജത്തിൽ എതിർ കോണുകൾ അനുപൂരകം. രണ്ട് ജോഡികൾ: (x, 2x) ഉം (x+20°, 2x+10°) ഉം:

  • x + 2x = 180 → 3x = 180 → x = 60°
  • പരിശോധന: (x+20°) + (2x+10°) = 80 + 130 = 210 ≠ 180 ✘
  • ശരിയായ ജോഡി: (x, 2x+10°) ഉം (x+20°, 2x) ഉം:
  • x + 2x+10 = 180 → 3x = 170 → x = 170/3 (പൂർണ്ണസംഖ്യ അല്ല — ചോദ്യത്തിൽ തെറ്റ്)
  • ചോദ്യത്തിൽ കോണുകൾ: x, x+20°, 2x, 2x+10°. തുക = 360°:
  • x + (x+20) + 2x + (2x+10) = 360 → 6x + 30 = 360 → 6x = 330 → x = 55°
➕ ഉദാഹരണം 6 – ത്രികോണ അസമത്വം

ചോദ്യം: 5, 8, x എന്നീ വശങ്ങളുള്ള ത്രികോണത്തിന് x-ന്റെ പരിധി?

പരിഹാരം: |8−5| < x < 8+5 → 3 < x < 13 (3-ഉം 13-ഉം ഉൾപ്പെടില്ല!)

22. Exam Tips & Top Maximum Facts

22.1 Exam Tips (പരീക്ഷയിൽ ഓർക്കേണ്ടത്)

  1. ഫോർമുല ഓർമ്മയില്ലെങ്കിൽ n = 3, 4 വച്ച് പരിശോധിക്കുക (ത്രികോണം 180°, ചതുർഭുജം 360°).
  2. വേഗത: ഒരു ബഹുഭുജ ചോദ്യത്തിന് 30–45 സെക്കൻഡ് മതി; ബാഹ്യകോൺ ആദ്യം കാണുക.
  3. ഡിഗ്രി ചിഹ്നം: ഓപ്ഷനുകളിൽ ഡിഗ്രി/വശങ്ങൾ/സെ.മീ. എന്ന യൂണിറ്റ് ശ്രദ്ധിക്കുക.
  4. ഒഴിവാക്കേണ്ടത്: പകുതി ഞാൺ നീളം ഉത്തരമായി എഴുതൽ; ആന്തര/ബാഹ്യകോൺ മാറിപ്പോകൽ; കേന്ദ്രകോണിനെ പകുതിയാക്കാൻ മറക്കൽ.

23.3 Teacher's Note
