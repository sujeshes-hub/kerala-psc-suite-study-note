  • ഗൃഹിണി, യക്ഷിണി = ണത്വ നിയമം (ഋ/ര/ഷ-യ്ക്ക് ശേഷം ന→ണ)

1. വസ്തുതാ പരിശോധനാ നില

  • ഈ അധ്യായത്തിലെ പ്രത്യയ നിയമങ്ങൾ കേരള പാണിനീയത്തിലെ ലിംഗവിഭാഗം, സംസ്കൃത വ്യാകരണ പാരമ്പര്യം എന്നിവയുമായി ഒത്തുപോകുന്നവയാണ്.
  • മുൻ പതിപ്പിൽ "KPSC ഔദ്യോഗിക ഉത്തരസൂചിക പ്രകാരം [Confirmed]" എന്ന് പല സ്ഥലത്തും എഴുതിയിരുന്നു. ആ ഉത്തരസൂചികകൾ ഈ പതിപ്പിൽ നേരിട്ട് പരിശോധിച്ചിട്ടില്ല. അതിനാൽ അത്തരം "Confirmed" ടാഗുകൾ ഒഴിവാക്കി. ഉറപ്പില്ലാത്തവ ⚠️ Verify ആയി അടയാളപ്പെടുത്തിയിട്ടുണ്ട്.
  • PYQ: സ്ഥിരീകരിച്ച ഒരു യഥാർത്ഥ PYQ പോലും ഈ പതിപ്പിൽ ചേർത്തിട്ടില്ല. താഴെയുള്ള എല്ലാ ചോദ്യങ്ങളും PSC-style practice question ആണ്.

മാർക്കർ നിർദ്ദേശിക

  • 🔧 Fix = മുൻ പതിപ്പിലെ തെറ്റ് തിരുത്തി
  • ➕ Added = ഈ പതിപ്പിൽ പുതുതായി ചേർത്തത്
  • ⚠️ Verify = ഉറപ്പിക്കാത്തത്; പരീക്ഷയ്ക്ക് മുമ്പ് PSC ഉത്തരസൂചികയുമായി ഒത്തുനോക്കുക
  • ✅ = വ്യാകരണ നിയമത്തിൽ നിന്ന് തന്നെ ഉറപ്പിക്കാവുന്നത്

2. ഒറ്റനോട്ടത്തിൽ

2.1 തുടക്കക്കാർക്കുള്ള പാഠം ➕ Added

ലിംഗം (Gender) എന്നാൽ ഒരു നാമപദം ആണിനെയാണോ പെണ്ണിനെയാണോ ഇവ രണ്ടുമല്ലാത്തതിനെയാണോ കുറിക്കുന്നത് എന്നതാണ്. മലയാളത്തിൽ മൂന്ന് ലിംഗങ്ങളുണ്ട്:

ലിംഗംഅർത്ഥംഉദാഹരണം
പുല്ലിംഗംപുരുഷൻഅവൻ, രാജാവ്, ഗായകൻ
സ്ത്രീലിംഗംസ്ത്രീഅവൾ, രാജ്ഞി, ഗായിക
നപുംസകലിംഗംആണും പെണ്ണുമല്ലാത്തത്അത്, മരം, പുസ്തകം
  • മലയാളത്തിൽ ലിംഗം അർത്ഥത്തെ ആശ്രയിച്ചാണ്: പെണ്ണിനെ കുറിക്കുന്നത് സ്ത്രീലിംഗം.
  • സംസ്കൃതത്തിൽ ലിംഗം വ്യാകരണപരമാണ്. അർത്ഥം "ഭാര്യ" എന്നാണെങ്കിലും ദാരങ്ങൾ പുല്ലിംഗ ബഹുവചന ശബ്ദമാണ്, കളത്രം നപുംസകലിംഗമാണ്. അതുകൊണ്ടാണ് ഇവയെ "സ്ത്രീലിംഗ പ്രത്യയം ചേർത്ത പദം" എന്ന് കണക്കാക്കാത്തത് (ചതിക്കുഴി 6 കാണുക).

2.2 സ്ത്രീലിംഗ പദം തിരിച്ചറിയാനുള്ള 3 ചോദ്യങ്ങൾ

  1. പദത്തിന്റെ അവസാനം എന്ത്? (ഇ, അൾ, ത്തി, ച്ചി, ട്ടി, ഇക, ഇനി, ത്രി, വതി, മതി, ആനി…)
  2. അത് തനി മലയാളമോ സംസ്കൃതമോ? (ത്തി/ച്ചി/ട്ടി/അൾ = തനി മലയാളം; ഇക/ഇനി/ത്രി/വതി/മതി/ആനി = സംസ്കൃതം)
  3. ഇത് സ്വതന്ത്ര സ്ത്രീപദമാണോ (അമ്മ, പെണ്ണ്, സ്ത്രീ), അതോ പുല്ലിംഗത്തിൽ നിന്ന് ഉണ്ടാക്കിയതാണോ?

2.3 രൂപീകരണ വഴികൾ 🔧 Fix

ചിത്രം 2.1 – സ്ത്രീലിംഗ നിർമ്മാണത്തിന്റെ 4 വഴികൾ (മുൻ ചിത്രത്തിലെ ഉറപ്പില്ലാത്ത പദങ്ങൾ ഒഴിവാക്കി).

3A. തനി മലയാള പ്രത്യയങ്ങൾ (ഇ, അൾ, വൾ, ത്തി, ച്ചി, ട്ടി)

പ്രത്യയംഎവിടെ ചേരുന്നുഉദാഹരണങ്ങൾ
അൾ / വൾ (അൻ → അൾ)ചുട്ടെഴുത്ത്, സർവ്വനാമം, വിശേഷണംഅവൾ (അ+അൾ), ഇവൾ (ഇ+അൾ), ഏവൾ, നല്ലവൾ (നല്ല+അൾ), വലിയവൾ, ചെറിയവൾ, മകൾ
ഇ (അൻ ലോപിച്ച് ഇ)ഗുണനാമം, സാമാന്യനാമംകള്ളൻ→കള്ളി, മിടുക്കൻ→മിടുക്കി, മുടന്തി, കുരുടി, കിഴവി, കൂനി, തോഴി
ത്തികുലനാമം, തൊഴിൽനാമംതട്ടാൻ→തട്ടാത്തി, വണ്ണാൻ→വണ്ണാത്തി, വേലൻ→വേലത്തി, മലയൻ→മലയത്തി, തീയൻ→തീയത്തി, പാണൻ→പാണത്തി
ച്ചിഇ/യ-യ്ക്ക് ശേഷം ത്തി → ച്ചി (താലവ്യാദേശം)മടിച്ചി, പുലച്ചി (പുലയത്തി എന്നും), ഇടച്ചി (ഇടയത്തി എന്നും), ചെട്ടിച്ചി
ട്ടിചില പദങ്ങളിൽ ത്തി → ട്ടി (മൂർദ്ധന്യാദേശം)തമ്പുരാൻ→തമ്പുരാട്ടി, മണവാളൻ→മണവാട്ടി
🔧 Fixes
  • "ചെട്ടിശ്ശി/ചെട്ടിത്തി" എന്നത് ചെട്ടിച്ചി എന്നാക്കി (ഇകാരത്തിന് ശേഷം ച്ചി എന്ന നിയമമനുസരിച്ച്).
  • "കറുവച്ചി", "ചാണാച്ചി" എന്നിവ ഉറപ്പില്ലാത്തതിനാൽ ഒഴിവാക്കി.
  • "അമ്മായിയമ്മ / അമ്മാവി" ട്ടി-പ്രത്യയ ഉദാഹരണമല്ല (ട്ടി ചേർന്ന പദമല്ല), അതിനാൽ ആ നിരയിൽ നിന്ന് മാറ്റി.
  • ⚠️ Verify "കണിയാൻ → കണിയാട്ടി" സ്ഥിരീകരിച്ചിട്ടില്ല. "കണിയാത്തി" എന്ന രൂപം കൂടുതൽ പരിചിതമാണ്. ഉത്തരമായി ഇതിനെ ആശ്രയിക്കരുത്.
⭐ പ്രധാന നിയമം

ത്തി, ച്ചി, ട്ടി മൂന്നും ഒരേ പ്രത്യയത്തിന്റെ (ത്തി) രൂപഭേദങ്ങളാണ്. അതായത് ഒരു പ്രത്യയം, മൂന്ന് രൂപം. പദത്തിന്റെ അവസാനത്തിലെ ശബ്ദമനുസരിച്ച് ഇത് മാറുന്നു.

➕ Added (ഇതേ ഗണത്തിൽ വരുന്ന കൂടുതൽ പദങ്ങൾ)
  • അനുജൻ→അനുജത്തി, ജ്യേഷ്ഠൻ→ജ്യേഷ്ഠത്തി
  • ചേട്ടൻ→ചേച്ചി (വ്യവഹാര രൂപം)
  • -ക്കാരൻ → -ക്കാരി: വേലക്കാരൻ→വേലക്കാരി, വീട്ടുകാരൻ→വീട്ടുകാരി
  • അവൻ→അവൾ, മകൻ→മകൾ

3B. സംസ്കൃത സ്ത്രീലിംഗ പ്രത്യയങ്ങൾ

സംസ്കൃതത്തിൽ സ്ത്രീലിംഗം ഉണ്ടാക്കാൻ പ്രധാനമായും ആ (ടാപ്), ഈ (ങീപ്) എന്നിവ ചേർക്കുന്നു. മലയാളത്തിൽ പദാന്ത്യത്തിലെ ദീർഘം ഹ്രസ്വമായി എഴുതുന്നു (ആ→അ, ഈ→ഇ).

പ്രത്യയംഉദാഹരണങ്ങൾ
അ (സംസ്കൃതം "ആ")സുത, തനയ, ആത്മജ (മകൾ); ശിഷ്യ, പ്രിയ, ബാല, വൃദ്ധ, അനുജ
ഇ (സംസ്കൃതം "ഈ")ദേവി, നദി, കുമാരി, സുന്ദരി, നടി, സഖി, ദാസി, ഗോപി, ബ്രാഹ്മണി
ഇക (-അകൻ → -ഇക)ഗായിക, നായിക, അധ്യാപിക, ബാലിക, സേവിക, ലേഖിക

🔧 Fixes
  • "ഇക" വരിയിലെ "പാചിക", "പ്രേക്ഷിക" എന്നിവ ഒഴിവാക്കി (ഉറപ്പില്ല). "അപവാദം: രജകൻ→രജകി" എന്ന ഭാഗത്ത് ⚠️ Verify ചേർത്തു; യാചകി മാത്രം ഈ അധ്യായത്തിന്റെ ഉത്തരമായി നിലനിർത്തുന്നു (D3 കാണുക).
  • "പത്നി (പതി)" ഇനി/നി ഗണത്തിൽ ചേരില്ല. ഇത് ക്രമമില്ലാത്ത രൂപമാണ് (പതി→പത്നി), അതിനാൽ ഒറ്റയ്ക്ക് പഠിക്കുക.
  • "രോഹിണി" ഒഴിവാക്കി. ഇത് പുല്ലിംഗത്തിൽ നിന്ന് ഉണ്ടാക്കിയ സ്ത്രീലിംഗ ഉദാഹരണമല്ല.
  • "ശ്രോത്രി", "വക്ത്രി" ഒഴിവാക്കി (ഉപയോഗം ഉറപ്പില്ല).
  • ➕ ണത്വ നിയമം: ഗൃഹിണി, യക്ഷിണി എന്നിവയിൽ ഋ / ര / ഷ എന്നിവയ്ക്ക് ശേഷം 'ന' → 'ണ' ആകുന്നു ✅.
  • ➕ ഇന്ദ്രാണി = ഇന്ദ്രന്റെ ഭാര്യ (ശചീദേവി); ഭവാനി = ഭവന്റെ (ശിവന്റെ) ഭാര്യ.

3C. സ്വയം യോഗ്യതയുള്ള സ്ത്രീ × ഭാര്യ (പുംയോഗാഖ്യ)

ഒരു സ്ത്രീക്ക് രണ്ട് വിധത്തിൽ ഒരു പേര് കിട്ടാം:

  1. സ്വന്തം കഴിവും യോഗ്യതയും കൊണ്ട് (ആചാര്യ = സ്വയം പഠിപ്പിക്കുന്നവൾ)
  2. ഭർത്താവിന്റെ പദവി കൊണ്ട് (ആചാര്യാനി = ആചാര്യന്റെ ഭാര്യ)
പുല്ലിംഗംസ്വയം ആ യോഗ്യതയുള്ളവൾആ പുരുഷന്റെ ഭാര്യ
ആചാര്യൻആചാര്യആചാര്യാനി
ഇന്ദ്രൻ—ഇന്ദ്രാണി
മാതുലൻ (അമ്മാവൻ)—മാതുലാനി (അമ്മായി)
ക്ഷത്രിയൻക്ഷത്രിയ (ക്ഷത്രിയകുലത്തിൽ ജനിച്ചവൾ)ക്ഷത്രിയാണി
ശൂദ്രൻശൂദ്ര (ശൂദ്രകുലത്തിൽ ജനിച്ചവൾ)ശൂദ്രീ
ആര്യൻആര്യആര്യാണി
ഉപാധ്യായൻഉപാധ്യായ (സ്വയം പഠിപ്പിക്കുന്നവൾ)ഉപാധ്യായി (ചിലർ ഉപാധ്യായാനി എന്നും)
🔧 Fix (ഉപാധ്യായൻ)

മുൻ പതിപ്പിൽ "ഉപാധ്യായി = സ്വയം പഠിപ്പിക്കുന്നവൾ, ഉപാധ്യായാനി = ഭാര്യ" എന്നായിരുന്നു. സംസ്കൃത വ്യാകരണ പാരമ്പര്യത്തിൽ ഉപാധ്യായ = സ്വയം അധ്യാപിക, ഉപാധ്യായി = ഭാര്യ എന്നാണ് പൊതുവെ പറയുന്നത്. ⚠️ Verify ഇത് PSC ഉറവിടത്തിൽ പരിശോധിച്ചിട്ടില്ല. ചോദ്യത്തിൽ ഉപാധ്യായി/ഉപാധ്യായ വന്നാൽ ഉത്തരസൂചിക നോക്കുക.

🧠 ഓർക്കുക

ആചാര്യ × ആചാര്യാനി സ്ഥിരമായി കാണുന്ന ജോഡിയാണ്. ഇന്ദ്രാണി, മാതുലാനി എന്നിവയും ഓർത്തുവെക്കുക. ബാക്കി വരികൾ ഉയർന്ന നിലവാരമുള്ള (Degree) ചോദ്യങ്ങൾക്ക് മാത്രം.

  • സിംഹം → സിംഹി
  • കാള → പശു
  • പോത്ത് → എരുമ

F3. ഉപപദം ചേർത്തത്

പെൺ- / തള്ള- → പെൺകുട്ടി, പെൺസിംഹം, തള്ളക്കോഴി, തള്ളയാട്

4. താരതമ്യ പട്ടികകൾ

പട്ടിക 1: ഒരേപോലെ തോന്നുന്ന ജോഡികൾ

ജോഡി 1ജോഡി 2ശ്രദ്ധിക്കേണ്ടത്
സധവ = ഭർത്താവുള്ളവൾവിധവ = ഭർത്താവ് മരിച്ചവൾവിധവയുടെ വിപരീതപദം = സധവ; പുല്ലിംഗം = വിധുരൻ
നവോഢ = പുതുതായി വിവാഹിതയായവൾകന്യക = വിവാഹിതയാകാത്തവൾനവ + ഊഢ
ആചാര്യ = സ്വയം ആചാര്യആചാര്യാനി = ആചാര്യന്റെ ഭാര്യആനി = ഭാര്യ
ഗായകൻ → ഗായികയാചകൻ → യാചകിഇക മാതൃക എല്ലായിടത്തും ബാധകമല്ല
തനയ, സുത, ആത്മജ = മകൾകളത്രം, ജായ, പത്നി = ഭാര്യമകൾ ≠ ഭാര്യ
പിടി = പെണ്ണാനപിട = പെൺകോഴിആനയ്ക്ക് പിടി, കോഴിക്ക് പിട
തരുണി = യുവതിതരണി = സൂര്യൻ / വഞ്ചിധരണി = ഭൂമി (14.6 കാണുക)

പട്ടിക 2: പ്രത്യയം തിരിച്ചറിയാൻ

പദത്തിന്റെ അവസാനംഏത് ഗണംഉദാഹരണം
-അൾ / -വൾതനി മലയാളംഅവൾ, നല്ലവൾ
-ത്തി / -ച്ചി / -ട്ടിതനി മലയാളം (ഒരേ പ്രത്യയം)വേലത്തി, മടിച്ചി, തമ്പുരാട്ടി
-ഇകസംസ്കൃതംഗായിക
-ഇനി / -ണിസംസ്കൃതം (-ഇൻ)യോഗിനി, ഗൃഹിണി
-ത്രിസംസ്കൃതം (-താവ്)നേത്രി, കവയിത്രി
-വതി / -മതിസംസ്കൃതം (-വാൻ / -മാൻ)ഭഗവതി, ശ്രീമതി
-ആനി / -ആണിസംസ്കൃതം (ഭാര്യ)ഇന്ദ്രാണി

പട്ടിക 3: സംസ്കൃത പ്രത്യയ ചാർട്ട്

ചിത്രം 4.1 – സംസ്കൃത സ്ത്രീലിംഗ പ്രത്യയങ്ങളുടെ വിഷ്വൽ ചാർട്ട്.

5. പരീക്ഷയിലെ ചതിക്കുഴികൾ (8)

⚠️ Trap 1 – വിധവ

"പുല്ലിംഗം" ചോദിച്ചാൽ വിധുരൻ. "വിപരീതപദം" ചോദിച്ചാൽ സധവ / സുമംഗലി. ചോദ്യം രണ്ടുതവണ വായിക്കുക.

⚠️ Trap 2 – രാജ്ഞി, സാമ്രാജ്ഞി

സംസാരത്തിൽ "രാഞ്ജി" എന്ന് ഉച്ചരിക്കും. എഴുത്തിൽ ജ്ഞി ആണ് ശരി.

⚠️ Trap 3 – യാചകൻ → യാചകി

ഗായിക മാതൃക കണ്ട് 'യാചിക' എടുക്കരുത് (⚠️ D3).

⚠️ Trap 4 – ആചാര്യ × ആചാര്യാനി

"സ്വയം പഠിപ്പിക്കുന്നവൾ" = ആചാര്യ. "ആചാര്യന്റെ ഭാര്യ" = ആചാര്യാനി.

⚠️ Trap 5 – ദുഹിതാവ്, നന്ദിനി = മകൾ

ഇവ ഭാര്യയല്ല. നന്ദനൻ = മകൻ, നന്ദിനി = മകൾ.

⚠️ Trap 6 – ദാരങ്ങൾ, കളത്രം, ജായ = ഭാര്യ (അർത്ഥം)

ദാരങ്ങൾ വ്യാകരണപരമായി പുല്ലിംഗ ബഹുവചനമാണ്, കളത്രം നപുംസകമാണ്. "സ്ത്രീലിംഗ പ്രത്യയം ചേർന്ന പദം" എന്ന് ചോദിച്ചാൽ ഇവയെ എടുക്കരുത്.

⚠️ Trap 7 – സന്ന്യാസിനി, ഗൃഹിണി

ഇരട്ടിപ്പും ണ/ന മാറ്റവും ശ്രദ്ധിക്കുക.

⚠️ Trap 8 – പ്രത്യയം ചോദിച്ചാൽ

തമ്പുരാട്ടി → തമ്പുരാൻ + ത്തി (ട്ടി രൂപം). "ട്ടി" സ്വതന്ത്ര പ്രത്യയമായി തെറ്റിദ്ധരിക്കരുത്.

6. മെമ്മറി ട്രിക്കുകൾ

🧠 ത്തി–ച്ചി–ട്ടി

മൂന്ന് പ്രത്യയമല്ല, ഒരു പ്രത്യയം (ത്തി) മൂന്ന് വേഷത്തിൽ. പദാന്ത്യം നോക്കി മാറുന്നു.

🧠 യാചകി

"യാചിക = ഹർജി; ഭിക്ഷ തേടുന്ന സ്ത്രീ = യാചകി".

🧠 ആനി/ആണി = ഭാര്യ

ഇന്ദ്രാണി, മാതുലാനി, ആചാര്യാനി.

🧠 മകൾ (ത – സു – ആ – ന – ദു)

തനയ, സുത, ആത്മജ, നന്ദിനി, ദുഹിതാവ്.

🧠 ത്രി = താവ്

നേതാവ്→നേത്രി, ദാതാവ്→ദാത്രി, രചയിതാവ്→രചയിത്രി.

🧠 വതി / മതി

വാൻ→വതി, മാൻ→മതി (ഗുണവാൻ→ഗുണവതി, ശ്രീമാൻ→ശ്രീമതി).

🧠 ഗൃഹിണി

ഗൃ (ഋ) വന്നാൽ ന → ണ.

🧠 രാജ്ഞി

"രാജാവ്" പോലെ ആദ്യം ജ; പിന്നെ ഞ.

🧠 തരുണി / തരണി / ധരണി

യുവതി / സൂര്യൻ (വഞ്ചി) / ഭൂമി.

7. അതിവേഗ റിവിഷൻ (MUST REMEMBER)

⚡ അവസാന നിമിഷ റിവിഷൻ
  1. തനി മലയാളം: ഇ, അൾ, വൾ, ത്തി (ച്ചി, ട്ടി).
  2. സംസ്കൃതം: അ, ഇ, ഇക, ഇനി/ണി, ത്രി, വതി/മതി, ആനി/ആണി.
  3. ആചാര്യ = സ്വയം പഠിപ്പിക്കുന്നവൾ; ആചാര്യാനി = ആചാര്യന്റെ ഭാര്യ.
  4. സ്പെല്ലിംഗ്: കവയിത്രി, രചയിത്രി, യാചകി, വിദുഷി, ഗൃഹിണി, സന്ന്യാസിനി, രാജ്ഞി, സാമ്രാജ്ഞി, വാരസ്യാർ (അന്തർജനം ⚠️).
  5. വിധവ: പുല്ലിംഗം വിധുരൻ; വിപരീതം സധവ.
  6. മകൾ: തനയ, സുത, ആത്മജ, നന്ദിനി, ദുഹിതാവ്.
  7. ഭാര്യ: പത്നി, കളത്രം, ജായ, ദാരങ്ങൾ, സഹധർമ്മിണി.
  8. പിടി (ആന), പിട (കോഴി), പേട (മാൻ).

8. Theory അറിയില്ലെങ്കിലും ഉത്തരം കണ്ടെത്താനുള്ള PSC Smart Tricks

⚠️ ആദ്യം ഓർക്കുക

ഈ വിദ്യകൾ ശരിയാകാനുള്ള സാധ്യത കൂട്ടുന്നതേയുള്ളൂ. അറിവിന് പകരമാകില്ല. "ഏറ്റവും നീളമുള്ള ഓപ്ഷൻ ശരി", "എപ്പോഴും C", "മുൻ വർഷത്തെ ഉത്തരം ആവർത്തിക്കും" എന്നിവ വെറും മിഥ്യയാണ്. താഴെ ഒരു ഓപ്ഷൻ ഒഴിവാക്കുന്നത് അതിന്റെ ഉള്ളടക്കം കൊണ്ടാണ്, ആകൃതി കൊണ്ടല്ല.

Trick 1: Option Elimination (പ്രത്യയ ഘടന നോക്കി)

ചോദ്യം: 'ഗുണവാൻ' എന്ന പദത്തിന്റെ സ്ത്രീലിംഗ രൂപം?
(A) ഗുണവാനി   (B) ഗുണവതി   (C) ഗുണവൾ   (D) ഗുണിക

  1. 'വാൻ' അവസാനിക്കുന്ന സംസ്കൃത പദം → സ്ത്രീലിംഗ നിയമം -വതി.
  2. (A) 'ആനി' ഭാര്യാനാമ പ്രത്യയമാണ്; ഇവിടെ ഭാര്യ എന്ന അർത്ഥം ചോദ്യത്തിൽ ഇല്ല → ഒഴിവാക്കാം.
  3. (D) 'ഇക' അകൻ-അവസാന പദങ്ങളിൽ ചേരും; ഗുണവാൻ അകൻ അല്ല → ഒഴിവാക്കാം.
  4. (C) 'വൾ' തനി മലയാളം പ്രത്യയമാണ്; സംസ്കൃത 'ഗുണവാൻ' + വൾ എന്ന് ഉപയോഗിക്കില്ല → ഒഴിവാക്കാം.

ഉത്തരം: (B) ഗുണവതി.
⚠️ ഈ ഒഴിവാക്കൽ -വാൻ → -വതി നിയമം അറിയുന്നതിനെ ആശ്രയിച്ചിരിക്കുന്നു. നിയമം അറിയില്ലെങ്കിൽ ഇത് ഊഹം മാത്രം.

Trick 2: Keyword Trick (ചോദ്യത്തിലെ 'ഇല്ലാത്തത്' / 'അല്ലാത്തത്')

ചോദ്യം: 'ഭാര്യ' എന്ന അർത്ഥം ഇല്ലാത്ത പദം ഏത്?
(A) കളത്രം   (B) ജായ   (C) തനയ   (D) പത്നി

  1. കീവേഡ്: "ഇല്ലാത്തത്". മൂന്ന് ഓപ്ഷൻ ശരിയും ഒന്ന് മാത്രം പുറത്തുള്ളതും ആകും.
  2. അറിയുന്ന പദങ്ങൾ ആദ്യം ഒഴിവാക്കുക: കളത്രം, ജായ, പത്നി = ഭാര്യ.
  3. ബാക്കി ഒന്ന്: തനയ.

ഉത്തരം: (C) തനയ (തനയ = മകൾ).
കീവേഡ് ഒരു സൂചന മാത്രമാണ്. "ഇല്ലാത്തത്" എന്ന വാക്ക് ഉത്തരം തരില്ല; എന്താണ് പുറത്തുള്ളത് എന്ന് അറിവുകൊണ്ടേ കണ്ടെത്താനാവൂ.

Trick 3: Common-Sense Logic (കാരണ-ഫല ബന്ധം)

ചോദ്യം: ഇന്ദ്രന്റെ ഭാര്യയെ കുറിക്കുന്ന പദം?
(A) ഇന്ദ്രാണി   (B) ഇന്ദ്ര   (C) ഇന്ദിര   (D) ഇന്ദ്രിണി

  1. ഭർത്താവിന്റെ പദവി കൊണ്ട് ഭാര്യക്ക് കിട്ടുന്ന പേര് → ആനി/ആണി പ്രത്യയം.
  2. (B) ഇന്ദ്ര = ഇന്ദ്രന്റെ തന്നെ പേരിലെ രൂപം; സ്ത്രീലിംഗ പ്രത്യയം ഇല്ല → ഒഴിവാക്കാം.
  3. (C) ഇന്ദിര എന്നത് മറ്റൊരു പേരാണ് → ഒഴിവാക്കാം.
  4. (D) 'ഇന്ദ്രിണി' ഏതെങ്കിലും നിയമത്തിൽ ഇല്ല.

ഉത്തരം: (A) ഇന്ദ്രാണി.
ഇവിടെ യുക്തി "ആനി = ഭാര്യ" എന്ന അറിവിൽ നിന്നാണ്. ഈ അറിവ് ഇല്ലെങ്കിൽ ഇതും ഊഹം തന്നെ.

Trick 4: Statement-Based + Extreme Statement Check

ചോദ്യം: ശരിയായ പ്രസ്താവനകൾ ഏതെല്ലാം?
1. ത്തി, ച്ചി, ട്ടി എന്നിവ ഒരേ പ്രത്യയത്തിന്റെ രൂപഭേദങ്ങളാണ്.
2. എല്ലാ സ്ത്രീലിംഗ പദങ്ങളും 'ഇ'-കാരത്തിൽ അവസാനിക്കുന്നു.
3. ആചാര്യാനി = ആചാര്യന്റെ ഭാര്യ.

(A) 1 മാത്രം   (B) 1, 2   (C) 2, 3   (D) 1, 3

  1. ഓരോ പ്രസ്താവനയും വേറിട്ട് പരിശോധിക്കുക.
  2. പ്രസ്താവന 2 ൽ "എല്ലാ" എന്ന അതിവ്യാപ്തി → എതിർ ഉദാഹരണം: അവൾ (ൾ), സുത (അ), അമ്മ (അ), ബാല (അ), പെണ്ണ് (ണ്) എന്നിവ ഇകാരത്തിൽ അവസാനിക്കുന്നില്ല → പ്രസ്താവന 2 തെറ്റ്.
  3. (B), (C) ഒഴിവാക്കാം (രണ്ടിലും 2 ഉണ്ട്).
  4. പ്രസ്താവന 1 ഉം 3 ഉം ശരി.

ഉത്തരം: (D) 1, 3.

Trick 6: Assertion–Reason

Assertion (A): 'ഗൃഹിണി' എന്ന പദത്തിൽ 'നി' അല്ല, 'ണി' ആണ് വരുന്നത്.
Reason (R): 'ഋ' വന്നതിന് ശേഷമുള്ള 'ന' മൂർദ്ധന്യമായി 'ണ' ആകുന്നു.

(A) A, R രണ്ടും ശരി; R, A യെ വിശദീകരിക്കുന്നു
(B) A, R രണ്ടും ശരി; R, A യെ വിശദീകരിക്കുന്നില്ല
(C) A ശരി, R തെറ്റ്
(D) A തെറ്റ്, R ശരി

  1. A ശരിയാണോ? ഗൃഹിണി = ശരി ✔.
  2. R ശരിയാണോ? ണത്വ നിയമം = ശരി ✔.
  3. R തന്നെയാണോ A യുടെ കാരണം? ഗൃ-ൽ ഋ ഉള്ളതുകൊണ്ടാണ് ണി ആയത് → ഉവ്വ്.

ഉത്തരം: (A).
മുന്നറിയിപ്പ്: രണ്ട് പ്രസ്താവനയും ശരിയായാൽ പോലും R, A യെ വിശദീകരിക്കണമെന്നില്ല. ഓരോ തവണയും ഈ മൂന്നാം പരിശോധന ഒഴിവാക്കരുത്.

Trick 7: Similar-Option Comparison (സ്പെല്ലിംഗ് ചോദ്യങ്ങൾ)

ചോദ്യം: ശരിയായ പദം തിരഞ്ഞെടുക്കുക.
(A) കവിയിത്രി   (B) കവയത്രി   (C) കവയിത്രി   (D) കവിത്രി

  1. നാല് ഓപ്ഷനും തമ്മിലുള്ള വ്യത്യാസം മാത്രം നോക്കുക: 'കവി/കവയ', 'യി/യ' എന്നിവ.
  2. അറിയാവുന്ന സമാന പദവുമായി താരതമ്യം: രചയിതാവ് → രചയിത്രി (യിത്രി).
  3. 'യിത്രി' ഘടന ഇല്ലാത്ത (B) 'കവയത്രി', (D) 'കവിത്രി' ഒഴിവാക്കാം.
  4. ശേഷിച്ച (A), (C) ൽ 'കവയ' / 'കവി' എന്ന ആദ്യഭാഗം തീരുമാനിക്കണം. ഓർമ്മ വേണം: കവയിത്രി.

ഉത്തരം: (C). ഈ വിദ്യ നാലിൽ നിന്ന് രണ്ടിലേക്ക് ചുരുക്കാൻ സഹായിക്കും. അവസാന തീരുമാനത്തിന് സ്പെല്ലിംഗ് ഓർമ്മ വേണം.

Trick 8: Question Wording + Informed Guessing

ചോദ്യം: 'സ്ത്രീ' എന്ന പദത്തിന്റെ പര്യായം അല്ലാത്ത പദം?
(A) വനിത   (B) അംഗന   (C) മഹിള   (D) തരണി

  1. "അല്ലാത്തത്" എന്ന വാക്ക് വായിക്കുക. മൂന്ന് ശരിയും ഒന്ന് പുറത്തും.
  2. വനിത, അംഗന, മഹിള = സ്ത്രീ (ഉറപ്പ്).
  3. തരണി vs തരുണി: തരണി = സൂര്യൻ / വഞ്ചി; യുവതി = തരുണി.

ഉത്തരം: (D) തരണി.

8. 'സ്ത്രീ' എന്ന പദത്തിന്റെ പര്യായം അല്ലാത്ത പദം?
ശരിയുത്തരം: (D) തരണി
തരണി = സൂര്യൻ / വഞ്ചി; തരുണി = യുവതി.
9. 'വിധവ' എന്ന പദത്തിന്റെ വിപരീതപദം?
ശരിയുത്തരം: (B) സധവ
വിധവയുടെ പുല്ലിംഗം = വിധുരൻ; വിപരീതപദം = സധവ / സുമംഗലി.
10. ആനയുടെ സ്ത്രീലിംഗ രൂപം?
ശരിയുത്തരം: (B) പിടി
ആന → പിടി (പിടിയാന); കോഴി → പിട (പിടക്കോഴി); മാൻ → പേട (പേടമാൻ).
