പിരിച്ചെഴുതൽ / സന്ധി

Malayalam Grammar: Splitting of Words & Sandhi | LDC • LGS • Degree • SI

🔍 ഒന്നും കണ്ടെത്തിയില്ല. മറ്റൊരു വാക്ക് ശ്രമിക്കുക.

⭐ Star Guide

⭐ പ്രാധാന്യ സൂചകങ്ങൾ
  • ⭐⭐⭐⭐⭐ അതിപ്രധാനം — സ്വാഗതം = സു + ആഗതം; ആദേശസന്ധി (കണ്ണീർ = കൺ + നീർ); ദ്വിത്വത്തിൽ 'ം' തിരികെ ചേർക്കൽ (മരച്ചില്ല = മരം + ചില്ല); ഇന്ദ്രൻ (ഹ്രസ്വ) vs ഈശൻ (ദീർഘ)
  • ⭐⭐⭐⭐ പ്രധാനം — യൺസന്ധി (അത്യാവശ്യം = അതി + ആവശ്യം); ഗുണസന്ധി (ദേവേന്ദ്രൻ, സൂര്യോദയം); വൃദ്ധി (ഏകൈകം, സദൈവ); വിസർഗ്ഗം (മനോരഥം = മനസ് + രഥം)
  • ⭐⭐⭐ ശ്രദ്ധിക്കേണ്ടത് — ലോപസന്ധി (കണ്ടില്ല = കണ്ടു + ഇല്ല); ആഗമസന്ധി (തിരുവോണം = തിരു + ഓണം); വ്യഞ്ജനസന്ധി (ഷണ്മുഖൻ, ജഗന്നാഥൻ)
  • ⭐⭐ അറിഞ്ഞാൽ മതി — [രൂപഭേദം] ഹിമ/ഹിമം + ആലയം; അഞ്ഞൂറ് = ഐ + നൂറ്; ഷട്പദം/ഷഡ്‌പദം
  • ⭐ ചരിത്ര വിവരം — കേരള പാണിനീയം (എ.ആർ. രാജരാജവർമ്മ); ചില്ലക്ഷരങ്ങൾ ൺ, ൻ, ർ, ൽ, ൾ
➕ ചുരുക്കം
  • സന്ധി: രണ്ട് വർണ്ണങ്ങൾ ചേരുമ്പോഴുണ്ടാകുന്ന മാറ്റം
  • മലയാള സന്ധികൾ (4): ലോപം, ആഗമം, ദ്വിത്വം, ആദേശം
  • സംസ്കൃത സന്ധികൾ: സവർണ്ണദീർഘം, ഗുണം, വൃദ്ധി, യൺ, വ്യഞ്ജനം, വിസർഗ്ഗം
  • അടയാള കോഡ്: േ/ോ/ർ = ഗുണം; ൈ/ൗ = വൃദ്ധി; ്യ/്വ = യൺ
  • കണ്ണീർ = കൺ + നീർ, എണ്ണൂറ് = എൺ + നൂറ്, നന്മ = നൽ + മ
  • ചില്ലക്ഷരങ്ങൾ: ൺ, ൻ, ർ, ൽ, ൾ — ആദേശസന്ധിയിൽ ഇവ തിരികെ വേണം

1. വസ്തുതാ പരിശോധനാ നില

ഈ പതിപ്പിലെ ലേബലുകൾ

  • [ഉറപ്പ്]: എ.ആർ. രാജരാജവർമ്മയുടെ കേരള പാണിനീയം, പാഠപുസ്തക വ്യാകരണം എന്നിവയിലെ സ്ഥിരീകൃത നിയമം.
  • [രൂപഭേദം]: ഒന്നിലധികം പിരിവ് ശരിയായി സ്വീകരിക്കപ്പെടാം (ഉദാ: ഹിമ/ഹിമം + ആലയം). ചോദ്യത്തിലെ ഓപ്ഷനുകൾ നോക്കി തീരുമാനിക്കുക.
  • [പരിശോധിക്കുക]: ഉറപ്പില്ലാത്തത്. പാഠപുസ്തകത്തിലോ ഔദ്യോഗിക ഉത്തരസൂചികയിലോ ഒത്തുനോക്കിയ ശേഷം മാത്രം പഠിക്കുക.
⚠️ മുൻ പതിപ്പിലെ അവകാശവാദം ഒഴിവാക്കി

"2015–2026 വരെയുള്ള എല്ലാ KPSC ഔദ്യോഗിക ഉത്തരസൂചികകളുമായി ഒത്തുനോക്കി" എന്ന് മുൻപ് പറഞ്ഞിരുന്നു. ഓരോ ചോദ്യവും ഉത്തരസൂചികയുമായി ഒത്തുനോക്കി എന്നത് ഇവിടെ തെളിയിക്കാൻ കഴിയില്ല. അതിനാൽ ഈ കുറിപ്പിൽ യഥാർത്ഥ PYQ-കൾ ഉൾപ്പെടുത്തിയിട്ടില്ല. എല്ലാ ചോദ്യങ്ങളും പുതുതായി നിർമ്മിച്ച practice MCQ-കൾ ആണ്. PYQ പഠിക്കാൻ KPSC വെബ്‌സൈറ്റിലെ (keralapsc.gov.in) ചോദ്യപേപ്പറുകളും ഉത്തരസൂചികകളും ഉപയോഗിക്കുക.

✍️ ചന്ദ്രക്കലയും ചില്ലും

പിരിച്ചെഴുതൽ ചോദ്യങ്ങളിൽ ശരിയും തെറ്റും തമ്മിലുള്ള വ്യത്യാസം പലപ്പോഴും ഒരു ചില്ലക്ഷരമോ ചന്ദ്രക്കലയോ ആണ്. ചില്ലക്ഷരങ്ങൾ: ൺ ൻ ർ ൽ ൾ. ഉദാ: കൺ + നീർ = കണ്ണീർ ✔, കണ്ണ് + നീർ ✘.

2. അടിസ്ഥാന ആശയങ്ങൾ (Orientation Block)

2.1 അടിസ്ഥാന നിർവചനങ്ങൾ

പദംഅർത്ഥംഉദാഹരണം
സന്ധിരണ്ട് വർണ്ണങ്ങൾ (അക്ഷരങ്ങൾ) ചേരുമ്പോഴുണ്ടാകുന്ന മാറ്റംകല + ആലയം = കലാലയം
പൂർവ്വപദംആദ്യത്തെ പദംകല
ഉത്തരപദംരണ്ടാമത്തെ പദംആലയം
പിരിച്ചെഴുതൽസന്ധി ചെയ്ത പദത്തെ പൂർവ്വപദം + ഉത്തരപദം എന്ന് വേർതിരിക്കൽകലാലയം → കല + ആലയം
സമാസംരണ്ട് പദങ്ങൾ ചേർന്ന് ഒരു പദമാകൽപനിനീർ = പനി + നീർ

2.2 മലയാള സന്ധി: 4 വഴികൾ

സന്ധിചേരുമ്പോൾപിരിക്കുമ്പോൾഉദാഹരണം
ലോപസന്ധിഒരു വർണ്ണം പോകുന്നുപോയ വർണ്ണം തിരികെ ചേർക്കുകതണുപ്പുണ്ട് = തണുപ്പ് + ഉണ്ട്
ആഗമസന്ധിഇടയിൽ പുതിയ വർണ്ണം വരുന്നു (യ, വ…)ഇടയിലെ വർണ്ണം ഒഴിവാക്കുകതിരുവോണം = തിരു + ഓണം
ദ്വിത്വസന്ധിഉത്തരപദത്തിലെ ആദ്യ വ്യഞ്ജനം ഇരട്ടിക്കുന്നുഇരട്ടിപ്പ് ഒഴിവാക്കുകമഴക്കാലം = മഴ + കാലം
ആദേശസന്ധിഒരു വർണ്ണത്തിന് പകരം മറ്റൊന്ന്മൂലരൂപം (പലപ്പോഴും ചില്ലക്ഷരം)കണ്ണീർ = കൺ + നീർ

2.3 സംസ്കൃത സന്ധി: ഒറ്റനോട്ടത്തിൽ

വിഭാഗംതിരിച്ചറിയാനുള്ള അടയാളം
സവർണ്ണദീർഘംആ / ഈ / ഊ ഇടയിൽ; രണ്ട് സമാന സ്വരം ചേർന്നത്
ഗുണംേ / ോ / ർ ഇടയിൽ വരുന്നു
വൃദ്ധിൈ / ൗ ഇടയിൽ വരുന്നു
യൺ്യ / ്വ / ്ര ഇടയിൽ വരുന്നു
വ്യഞ്ജനസന്ധിക്, ത്, ട് → ഗ്/ങ്, ദ്/ന്, ഡ്/ണ് ആയി മാറുന്നു
വിസർഗ്ഗസന്ധിോ / ർ / ീർ; സ്, ർ, ഃ എന്നിവയിൽ നിന്ന് വരുന്നു

3. മലയാള സന്ധികൾ (Detail Block A)

3.1 ലോപസന്ധി (Elision)

രണ്ട് പദങ്ങൾ ചേരുമ്പോൾ പൂർവ്വപദത്തിന്റെ അവസാനത്തെ സ്വരമോ ചന്ദ്രക്കലയോ ലോപിക്കുന്നു. പിരിക്കുമ്പോൾ അത് തിരികെ ചേർക്കണം.

(a) ചന്ദ്രക്കല (്) ലോപിക്കുന്നവ [ഉറപ്പ്]

  • തണുപ്പുണ്ട് = തണുപ്പ് + ഉണ്ട്
  • കാറ്റടി = കാറ്റ് + അടി
  • നാവടക്കുക = നാവ് + അടക്കുക
  • വേപ്പില = വേപ്പ് + ഇല

(b) 'ു' (ഉകാരം) ലോപിക്കുന്നവ: ക്രിയാരൂപങ്ങൾ [ഉറപ്പ്]

  • കണ്ടില്ല = കണ്ടു + ഇല്ല (കണ്ട് + ഇല്ല എന്ന് പിരിക്കരുത്)
  • വന്നില്ല = വന്നു + ഇല്ല
  • കൊണ്ടില്ല = കൊണ്ടു + ഇല്ല

(c) 'ഇ' / 'അ' ലോപിക്കുന്നവ [ഉറപ്പ്]

  • പോയല്ലോ = പോയി + അല്ലോ
  • അല്ലെങ്കിൽ = അല്ല + എങ്കിൽ
  • ഇല്ലെങ്കിൽ = ഇല്ല + എങ്കിൽ

3.2 ആഗമസന്ധി (Augmentation)

രണ്ട് സ്വരങ്ങൾ ചേരുമ്പോൾ ഉച്ചാരണ സൗകര്യത്തിനായി ഇടയിൽ യ / വ വരുന്നു. പിരിക്കുമ്പോൾ ആ യ/വ ഒഴിവാക്കണം.

(a) 'യ' കാരാഗമം: ഇ, ഈ, എ, ഏ, ഐ എന്നിവയ്ക്ക് ശേഷം [ഉറപ്പ്]

  • വഴിയമ്പലം = വഴി + അമ്പലം
  • പണിയായുധം = പണി + ആയുധം
  • ഓടിയെത്തി = ഓടി + എത്തി
  • കൈയൊപ്പ് = കൈ + ഒപ്പ്

(b) 'വ' കാരാഗമം: ഉ, ഊ, ഓ, ഒ, അ, ആ തുടങ്ങിയവയ്ക്ക് ശേഷം [ഉറപ്പ്]

  • തിരുവോണം = തിരു + ഓണം
  • തിരുവാതിര = തിരു + ആതിര
  • പോവുക = പോ + ഉക
  • മൂവായിരം = മൂ + ആയിരം

(c) അനുനാസികാഗമം [ഉറപ്പ്, രൂപഭേദം]

  • പൂന്തോട്ടം = പൂ + തോട്ടം
  • പൂന്തൊട്ടിൽ = പൂ + തൊട്ടിൽ
  • കരിങ്കല്ല് = കരി + കല്ല്
  • മാമ്പഴം = മാ + പഴം (മാവ് + പഴം എന്നും പിരിക്കാം)

3.3 ദ്വിത്വസന്ധി (Gemination)

ഉത്തരപദത്തിലെ ആദ്യ ഖരം (ക, ച, ട, ത, പ) ഇരട്ടിക്കുന്നു: ക്ക, ച്ച, ട്ട, ത്ത, പ്പ. പിരിക്കുമ്പോൾ ഇരട്ടിപ്പ് ഒഴിവാക്കുക. [ഉറപ്പ്]

  • താമരക്കുളം = താമര + കുളം
  • പച്ചക്കല്ല് = പച്ച + കല്ല്
  • മഴക്കാലം = മഴ + കാലം
  • എണ്ണക്കട = എണ്ണ + കട
  • വഴിച്ചെലവ് = വഴി + ചെലവ്
  • കൈത്തറി = കൈ + തറി
  • ചന്തപ്പുര = ചന്ത + പുര
ℹ️ ഇരട്ടിക്കാത്തവ

തീവണ്ടി = തീ + വണ്ടി. 'വ' ഖരമല്ലാത്തതിനാൽ ഇരട്ടിച്ചില്ല. ഇത് ദ്വിത്വസന്ധിക്ക് ഉദാഹരണമല്ല.

⚠️ PSC Trap: 'ം' ഉള്ള പൂർവ്വപദം

പൂർവ്വപദത്തിന്റെ അവസാനത്തെ 'ം' ചേരുമ്പോൾ പോയി, ഉത്തരപദത്തിലെ ഖരം ഇരട്ടിച്ചിരിക്കും. പിരിക്കുമ്പോൾ 'ം' തിരികെ ചേർക്കണം. [ഉറപ്പ്]

സന്ധി ചെയ്ത പദംശരിയായ പിരിവ്തെറ്റായ പിരിവ്
മരച്ചില്ലമരം + ചില്ലമര + ചില്ല
കുളക്കരകുളം + കരകുള + കര
വട്ടപ്പലകവട്ടം + പലകവട്ട + പലക
സ്വർണ്ണക്കടസ്വർണ്ണം + കടസ്വർണ്ണ + കട

3.4 ആദേശസന്ധി (Substitution) ★★★

ഒരു വർണ്ണത്തിന് പകരം മറ്റൊന്ന് വരുന്നതാണ് ആദേശസന്ധി. സമാസത്തിൽ പദങ്ങൾ ചില്ലക്ഷര രൂപത്തിൽ (കൺ, തൺ, നൽ, നെൽ, എൺ) ചേരുന്നു എന്നതാണ് അടിസ്ഥാന നിയമം.

പ്രധാന നിയമങ്ങൾ

നിയമംഫലംഉദാഹരണം
ൺ + നണ്ണകൺ + നീർ = കണ്ണീർ
ൺ + തണ്ടവിൺ + തലം = വിണ്ടലം
ൽ + മന്മനൽ + മ = നന്മ
ൽ + സ്വരംല്ലവിൽ + ഒടിഞ്ഞു = വില്ലൊടിഞ്ഞു
ൻ + സ്വരംന്നപൊൻ + ഓണം = പൊന്നോണം
ൺ + സ്വരംണ്ണമൺ + എണ്ണ = മണ്ണെണ്ണ

പ്രധാന പദങ്ങൾ

സന്ധി ചെയ്ത പദംശരിയായ പിരിവ്വിശദീകരണം
കണ്ണീർകൺ + നീർൺ + ന = ണ്ണ (കണ്ണ് + നീർ അല്ല)
തണ്ണീർതൺ + നീർതണുത്ത നീർ
വെണ്ണീർവെൺ + നീർവെളുത്ത നീർ, അതായത് ചാരം
എണ്ണൂറ്എൺ + നൂറ്എട്ട് → എൺ
എൺപത്എൺ + പത്ത്ഇതേ രൂപം
വിണ്ടലംവിൺ + തലംൺ + ത = ണ്ട
മണ്ണെണ്ണമൺ + എണ്ണമണ്ണിന്റെ എണ്ണ
നെന്മണിനെൽ + മണിൽ + മ = ന്മ
കന്മദംകൽ + മദംൽ + മ = ന്മ
നന്മനൽ + മൽ + മ = ന്മ
വില്ലൊടിഞ്ഞുവിൽ + ഒടിഞ്ഞുൽ ഇരട്ടിച്ചു
പൊന്നോണംപൊൻ + ഓണംൻ ഇരട്ടിച്ചു
പൊന്നിൻപൊൻ + ഇൻൻ ഇരട്ടിച്ചു
ഇരുനൂറ്ഇരു + നൂറ്ഇരു = രണ്ട്
ഇരുപത്ഇരു + പത്ത്ഇരു = രണ്ട്
അഞ്ഞൂറ്ഐ + നൂറ്ഐ = അഞ്ച് (കേരള പാണിനീയം) [പരിശോധിക്കുക]

4. സംസ്കൃത സ്വരസന്ധി (Detail Block B) ★★★

4.1 സവർണ്ണദീർഘസന്ധി

അ/ആ + അ/ആ = ആ; ഇ/ഈ + ഇ/ഈ = ഈ; ഉ/ഊ + ഉ/ഊ = ഊ [ഉറപ്പ്]

'ആ' (ദീർഘം)

  • കലാലയം = കല + ആലയം
  • വിദ്യാലയം = വിദ്യ + ആലയം
  • ഹിമാലയം = ഹിമ + ആലയം [രൂപഭേദം: ഹിമം + ആലയം]
  • ദേവാലയം = ദേവ + ആലയം
  • സത്യാഗ്രഹം = സത്യ + ആഗ്രഹം
  • ശതാബ്ദം = ശത + അബ്ദം
  • സൂര്യാസ്തമയം = സൂര്യ + അസ്തമയം
  • പരമാണു = പരമ + അണു
  • സിംഹാസനം = സിംഹ + ആസനം

'ഈ'

  • ഗിരീശൻ = ഗിരി + ഈശൻ
  • കവീന്ദ്രൻ = കവി + ഇന്ദ്രൻ
  • രവീന്ദ്രൻ = രവി + ഇന്ദ്രൻ
  • മഹീന്ദ്രൻ = മഹി + ഇന്ദ്രൻ
  • മുനീശ്വരൻ = മുനി + ഈശ്വരൻ
  • പരീക്ഷ = പരി + ഈക്ഷ
  • പ്രതീക്ഷ = പ്രതി + ഈക്ഷ
  • അതീന്ദ്രിയം = അതി + ഇന്ദ്രിയം

'ഊ'

  • ഗുരൂപദേശം = ഗുരു + ഉപദേശം
  • ഭാനൂദയം = ഭാനു + ഉദയം
  • സാധൂക്തി = സാധു + ഉക്തി
⚠️ ഹ്രസ്വ–ദീർഘ ശ്രദ്ധ

ഇന്ദ്രൻ, ഇന്ദ്രിയം, ഇഷ്ടം എന്നിവ എപ്പോഴും ഹ്രസ്വ 'ഇ' കൊണ്ട് തുടങ്ങുന്നു. ഈശൻ, ഈശ്വരൻ, ഈക്ഷ എന്നിവ ദീർഘ 'ഈ' കൊണ്ട്.

4.2 ഗുണസന്ധി

അ/ആ + ഇ/ഈ = ഏ; അ/ആ + ഉ/ഊ = ഓ; അ/ആ + ഋ = അർ. പദമധ്യത്തിൽ േ, ോ, ർ കണ്ടാൽ ഗുണസന്ധി. [ഉറപ്പ്]

ഏ

  • ദേവേന്ദ്രൻ = ദേവ + ഇന്ദ്രൻ
  • ഗജേന്ദ്രൻ = ഗജ + ഇന്ദ്രൻ
  • നരേന്ദ്രൻ = നര + ഇന്ദ്രൻ
  • മഹേന്ദ്രൻ = മഹാ + ഇന്ദ്രൻ
  • രമേശൻ = രമ + ഈശൻ
  • ഗണേശൻ = ഗണ + ഈശൻ
  • മഹേശ്വരൻ = മഹാ + ഈശ്വരൻ
  • യഥേഷ്ടം = യഥാ + ഇഷ്ടം (യഥ അല്ല, യഥാ)

ഓ

  • സൂര്യോദയം = സൂര്യ + ഉദയം
  • ചന്ദ്രോദയം = ചന്ദ്ര + ഉദയം
  • പരോപകാരം = പര + ഉപകാരം
  • മഹോത്സവം = മഹാ + ഉത്സവം
  • ലോകോക്തി = ലോക + ഉക്തി
  • നവോത്ഥാനം = നവ + ഉത്ഥാനം
  • മഹോദധി = മഹാ + ഉദധി
  • ഗംഗോദകം = ഗംഗാ + ഉദകം

അർ

  • ദേവർഷി = ദേവ + ഋഷി
  • മഹർഷി = മഹാ + ഋഷി
  • രാജർഷി = രാജ + ഋഷി
  • സപ്തർഷികൾ = സപ്ത + ഋഷികൾ

4.3 വൃദ്ധിസന്ധി

അ/ആ + എ/ഏ/ഐ = ഐ; അ/ആ + ഒ/ഓ/ഔ = ഔ. പദമധ്യത്തിൽ ൈ, ൗ കണ്ടാൽ വൃദ്ധിസന്ധി. [ഉറപ്പ്]

  • ഏകൈകം = ഏക + ഏകം
  • ലോകൈക = ലോക + ഏക
  • സദൈവ = സദാ + ഏവ
  • തഥൈവ = തഥാ + ഏവ
  • വസുധൈവ = വസുധാ + ഏവ
  • മതൈക്യം = മത + ഐക്യം
  • മഹൗഷധം = മഹാ + ഔഷധം
  • വനൗഷധി = വന + ഔഷധി
  • പരമൗഷധം = പരമ + ഔഷധം

4.4 യൺസന്ധി

ഇ/ഈ + സ്വരം = യ്; ഉ/ഊ + സ്വരം = വ്; ഋ + സ്വരം = ര്. [ഉറപ്പ്]

്യ → 'ഇ'

  • അത്യാഗ്രഹം = അതി + ആഗ്രഹം
  • അത്യാവശ്യം = അതി + ആവശ്യം
  • അത്യന്തം = അതി + അന്തം
  • അത്യുത്തമം = അതി + ഉത്തമം
  • പ്രത്യുപകാരം = പ്രതി + ഉപകാരം
  • പ്രത്യേകം = പ്രതി + ഏകം
  • ഇത്യാദി = ഇതി + ആദി
  • പര്യന്തം = പരി + അന്തം
  • പര്യടനം = പരി + അടനം

്വ → 'ഉ'

  • സ്വാഗതം = സു + ആഗതം
  • സ്വല്പം = സു + അല്പം
  • മന്വന്തരം = മനു + അന്തരം
  • അന്വയം = അനു + അയം
  • ഗുർവാജ്ഞ = ഗുരു + ആജ്ഞ

്ര → 'ഋ'

  • പിത്രാർജ്ജിതം = പിതൃ + ആർജ്ജിതം
  • മാത്രാജ്ഞ = മാതൃ + ആജ്ഞ
⚠️ യൺസന്ധി തിരിച്ചറിയുമ്പോൾ സൂക്ഷിക്കുക

്യ കണ്ടാലെല്ലാം യൺസന്ധിയല്ല. സത്യം, രാജ്യം, ധൈര്യം, ആരോഗ്യം എന്നിവയിൽ ്യ പദത്തിന്റെ ഭാഗം തന്നെയാണ്, പിരിക്കാനില്ല. അതുപോലെ ദ്വാരം, ശ്വാസം, ത്വരിതം എന്നിവയിലെ ്വ യൺസന്ധിയല്ല. പിരിച്ചാൽ രണ്ട് പദത്തിനും അർത്ഥമുണ്ടോ എന്ന് നോക്കുക.

5. സംസ്കൃത വ്യഞ്ജന–വിസർഗ്ഗ സന്ധി (Detail Block C) ★★★

5.1 വ്യഞ്ജനസന്ധി

അടിസ്ഥാന നിയമങ്ങൾ

പൂർവ്വപദാന്ത്യംസ്വരം / മൃദു അടുത്ത്അനുനാസികം (മ, ന) അടുത്ത്
ക്ഗ്ങ്
ട്ഡ്ണ്
ത്ദ്ന്

'ക്'

  • വാഗീശൻ = വാക് + ഈശൻ
  • വാഗ്വാദം = വാക് + വാദം
  • വാഗ്ദാനം = വാക് + ദാനം
  • ദിഗന്തം = ദിക് + അന്തം
  • ദിഗ്വിജയം = ദിക് + വിജയം
  • വാങ്മയം = വാക് + മയം

'ട്'

  • ഷഡംഗം = ഷട് + അംഗം
  • ഷണ്മുഖൻ = ഷട് + മുഖൻ
  • ഷഡാനനൻ = ഷട് + ആനനൻ

'ത്'

  • സദാചാരം = സത് + ആചാരം
  • സദ്ഗുണം = സത് + ഗുണം
  • സന്മാർഗ്ഗം = സത് + മാർഗ്ഗം
  • സജ്ജനം = സത് + ജനം
  • സച്ചിദാനന്ദം = സത് + ചിത് + ആനന്ദം
  • ജഗന്നാഥൻ = ജഗത് + നാഥൻ
  • ജഗദീശൻ = ജഗത് + ഈശൻ
  • തന്മയത്വം = തത് + മയത്വം
  • തന്മാത്ര = തത് + മാത്ര
  • ചിന്മയം = ചിത് + മയം

  • ഉന്നതി = ഉത് + നതി

  • ഉദ്യോഗം = ഉത് + യോഗം
  • ശരച്ചന്ദ്രൻ = ശരത് + ചന്ദ്രൻ

  • ഷഡ്‌പദം: ശുദ്ധ സംസ്കൃത രൂപം ഷട്പദം (ഷട് + പദം). 'ഷഡ്പദം' പ്രചാരത്തിലുള്ള രൂപം. [പരിശോധിക്കുക]

5.2 വിസർഗ്ഗസന്ധി

സംസ്കൃതത്തിൽ 'ഃ' (വിസർഗ്ഗം) അല്ലെങ്കിൽ 'സ്' / 'ർ' അവസാനമുള്ള പദം ചേരുമ്പോൾ ോ അല്ലെങ്കിൽ ര ആയി മാറുന്നു.

  • മനോരഥം = മനസ് + രഥം (മനഃ + രഥം)

  • നിരായുധൻ = നിർ + ആയുധൻ

കണ്ണീർകൺ + നീർതണ്ണീർതൺ + നീർകണ്ണിന്റെ നീർ / തണുത്ത നീർ
തണ്ണീർതൺ + നീർവെണ്ണീർവെൺ + നീർതണുത്തത് / വെളുത്തത് (ചാരം)
ദേവേന്ദ്രൻദേവ + ഇന്ദ്രൻകവീന്ദ്രൻകവി + ഇന്ദ്രൻഗുണസന്ധി / സവർണ്ണദീർഘം; രണ്ടിലും 'ഇന്ദ്രൻ' ഹ്രസ്വം
ഗിരീശൻഗിരി + ഈശൻഗണേശൻഗണ + ഈശൻസവർണ്ണദീർഘം / ഗുണം; രണ്ടിലും 'ഈശൻ' ദീർഘം
മരച്ചില്ലമരം + ചില്ലപച്ചക്കല്ല്പച്ച + കല്ല്മരത്തിന് 'ം' ഉണ്ട്; പച്ചയ്ക്ക് ഇല്ല
കണ്ടില്ലകണ്ടു + ഇല്ലകണ്ണില്ലകണ്ണ് + ഇല്ലക്രിയ 'ു' ചേർത്ത് / നാമം 'ണ്ണ്'
ഷണ്മുഖൻഷട് + മുഖൻഷഡംഗംഷട് + അംഗംമ ചേർന്നാൽ ണ്; സ്വരം ചേർന്നാൽ ഡ്

7. പരീക്ഷയിലെ ചതിക്കുഴികൾ

8. മെമ്മറി ട്രിക്കുകൾ

🧠 1. "ഇന്ദ്രന് ചെറിയ ഇ, ഈശന് വലിയ ഈ"
  • രവീന്ദ്രൻ, കവീന്ദ്രൻ, ദേവേന്ദ്രൻ, മഹേന്ദ്രൻ → രണ്ടാം പദം ഇന്ദ്രൻ (ഹ്രസ്വം).
  • ഗിരീശൻ, രമേശൻ, ഗണേശൻ, മഹേശ്വരൻ, പരീക്ഷ, പ്രതീക്ഷ → ഈശൻ / ഈശ്വരൻ / ഈക്ഷ (ദീർഘം).
🧠 2. യൺസന്ധി കോഡ്
  • ത്യ → തി ആക്കുക: അത്യാവശ്യം = അതി + ആവശ്യം.
  • ്വ → ു ആക്കുക: സ്വാഗതം = സു + ആഗതം, മന്വന്തരം = മനു + അന്തരം.
  • ത്യു, ന്വ എന്നിങ്ങനെ കൂടിച്ചേർന്ന രൂപങ്ങൾ ആണെന്ന് ഓർക്കുക: പ്രത്യുപകാരം = പ്രതി + ഉപകാരം.
🧠 3. ന്മ കോഡ്
  • തനി മലയാളം: ന്മ → ൽ + മ (നൽ + മ = നന്മ; നെൽ + മണി = നെന്മണി; കൽ + മദം = കന്മദം).
  • സംസ്കൃതം: ന്മ → ത് + മ (തത് + മയത്വം = തന്മയത്വം; സത് + മാർഗ്ഗം = സന്മാർഗ്ഗം; ചിത് + മയം = ചിന്മയം).
🧠 4. ഗുണ-വൃദ്ധി അടയാള കോഡ്
  • നടുവിൽ േ / ോ / ർ → ഗുണം (അ + ഇ/ഉ/ഋ).
  • നടുവിൽ ൈ / ൗ → വൃദ്ധി (അ + ഏ/ഐ/ഓ/ഔ).
🧠 5. "ഖരം ഇരട്ടിച്ചാൽ ദ്വിത്വം, 'ം' പോയാൽ തിരികെ വെക്കുക"

മരച്ചില്ല = മരം + ചില്ല (ഇരട്ടിച്ച 'ച്ച', പോയ 'ം').

9. Theory അറിയില്ലെങ്കിലും ഉത്തരം കണ്ടെത്താനുള്ള PSC Smart Tricks

⚠️ ആദ്യം മനസ്സിലാക്കുക

ഈ തന്ത്രങ്ങൾ ശരിയുത്തരം കിട്ടാനുള്ള സാധ്യത കൂട്ടുന്നു, ഉറപ്പ് തരില്ല. "ദൈർഘ്യമേറിയ ഉത്തരം ശരി", "C ഓപ്ഷൻ ശരി" തുടങ്ങിയ മിഥ്യാധാരണകൾ ഇവിടെ ഉപയോഗിക്കുന്നില്ല. ഉറപ്പുള്ള ഉത്തരത്തിന് പകരം വെക്കാവുന്ന ഒന്നല്ല ഇവ.

തന്ത്രം 1: ഓപ്ഷൻ ഒഴിവാക്കൽ (Option Elimination), അർത്ഥം ഉപയോഗിച്ച്

ചോദ്യം: 'ഗിരീശൻ' പിരിച്ചെഴുതിയത്?
(A) ഗിരി + ഇശൻ (B) ഗിരീ + ഈശൻ (C) ഗിരി + ഈശൻ (D) ഗിര + ഈശൻ

  1. (A): 'ഇശൻ' എന്ന പദം പരിചിതമല്ല. 'ഈശൻ' (ദൈവം/പ്രഭു) ആണ് പരിചിതം. ഒഴിവാക്കാം.
  2. (B): 'ഗിരീ' ഒരു പദരൂപമല്ല; 'ഗിരി' (മല) ആണ് പദം. ഒഴിവാക്കാം.
  3. (D): അ + ഈ = ഏ (ഗുണസന്ധി), ഫലം 'ഗിരേശൻ' ആകും. ഒഴിവാക്കാം.
  4. ബാക്കി (C).

ഉത്തരം: (C). മുന്നറിയിപ്പ്: ഇത് ഫലപ്രദം രണ്ട് ഓപ്ഷനെങ്കിലും ഒഴിവാക്കാൻ കഴിയുമ്പോൾ മാത്രം.

തന്ത്രം 2: Keyword & ചോദ്യ ശൈലി ശ്രദ്ധ

ചോദ്യം: താഴെ കൊടുത്തവയിൽ തെറ്റായ പിരിവ് ഏത്?
(A) മഹർഷി = മഹാ + ഋഷി (B) നന്മ = നൽ + മ (C) പ്രത്യേകം = പ്രത + ഏകം (D) സൂര്യോദയം = സൂര്യ + ഉദയം

  1. "തെറ്റായ" എന്ന വാക്ക് വട്ടമിടുക.
  2. (A): ഋ ചേർന്ന 'അർ' → ഗുണസന്ധി, ശരി.
  3. (B): ൽ + മ = ന്മ, ശരി.
  4. (D): അ + ഉ = ഓ, ശരി.
  5. (C): ്യേ കണ്ടാൽ 'തി' ആക്കുക → പ്രതി + ഏകം. 'പ്രത' തെറ്റ്.

ഉത്തരം: (C).

തന്ത്രം 3: ചേരുംപടി (Match the Following): അറിയുന്ന ജോഡി ആദ്യം

പട്ടിക Iപട്ടിക II
a. തണ്ണീർ1. ഷട് + മുഖൻ
b. സൂര്യോദയം2. തൺ + നീർ
c. ഷണ്മുഖൻ3. സൂര്യ + ഉദയം

(A) a-2, b-3, c-1 (B) a-1, b-2, c-3 (C) a-3, b-1, c-2 (D) a-2, b-1, c-3

  1. 'തണ്ണീർ = തൺ + നീർ' ഉറപ്പാണെങ്കിൽ a-2. a-2 അല്ലാത്ത (B), (C) ഒഴിവാക്കാം.
  2. (A), (D) ഇവയിൽ നിന്ന് 'സൂര്യോദയം = സൂര്യ + ഉദയം' (b-3) ഉറപ്പാണെങ്കിൽ (A) മാത്രം.

ഉത്തരം: (A).

തന്ത്രം 4: സന്ധി തിരിച്ചറിയാൻ അടയാളം (Pattern Recognition)

ചോദ്യം: 'അത്യാവശ്യം' ഏത് സന്ധി?
(A) ഗുണസന്ധി (B) വൃദ്ധിസന്ധി (C) യൺസന്ധി (D) ലോപസന്ധി

  1. പദമധ്യത്തിൽ 'ത്യ' കാണുന്നു. ്യ യൺസന്ധിയുടെ അടയാളമാണ്.
  2. ഗുണം (േ/ോ/ർ), വൃദ്ധി (ൈ/ൗ) എന്നിവ പദത്തിൽ ഇല്ല.

ഉത്തരം: (C) യൺസന്ധി (അതി + ആവശ്യം).

തന്ത്രം 5: Statement-Based ചോദ്യം: ഓരോ പ്രസ്താവനയും വെവ്വേറെ

ചോദ്യം: ശരിയായ പ്രസ്താവനകൾ ഏതെല്ലാം?
1. മഹർഷി = മഹാ + ഋഷി (ഗുണസന്ധി)
2. അത്യാവശ്യം = അതി + ആവശ്യം (യൺസന്ധി)
3. നന്മ = നൽ + മ (ആദേശസന്ധി)
4. കണ്ടില്ല = കണ്ടു + ഇല്ല (ആഗമസന്ധി)
(A) 1, 2 (B) 1, 2, 3 (C) 2, 3, 4 (D) 1, 3, 4

  1. 1, 2, 3 ശരി.
  2. 4 തെറ്റ്: 'കണ്ടു' + 'ഇല്ല' → 'ു' പോയതിനാൽ ലോപസന്ധി ആണ്.
  3. 4 ഉള്ള (C), (D) ഒഴിവാക്കാം. 3 ശരിയാണെന്ന് ഉറപ്പിച്ചാൽ (A) ഒഴിവാകും.

ഉത്തരം: (B).

തന്ത്രം 6: Assertion–Reason

A: 'സൂര്യോദയം' ഗുണസന്ധിക്ക് ഉദാഹരണമാണ്.
R: അ + ഉ ചേരുമ്പോൾ 'ഓ' ആയി മാറുന്നു.

  1. സൂര്യ + ഉദയം = സൂര്യോദയം (A ശരി).
  2. അ + ഉ = ഓ ഗുണസന്ധി നിയമം (R ശരി).
  3. സൂര്യോദയത്തിൽ 'ോ' വരാൻ കാരണം തന്നെ ഈ നിയമമാണ്, അതിനാൽ R ആണ് A-യുടെ വിശദീകരണം.

ഉത്തരം: A, R ശരി; R, A-യുടെ ശരിയായ വിശദീകരണം.

തന്ത്രം 7: ഹ്രസ്വ–ദീർഘ വ്യത്യാസ താരതമ്യം

ചോദ്യം: 'പരീക്ഷ' ശരിയായ പിരിവ്?
(A) പരി + ഇക്ഷ (B) പരീ + ഇക്ഷ (C) പരി + ഈക്ഷ (D) പര + ഈക്ഷ

  1. ഫലത്തിൽ 'ീ' ആണ്. (D) പര + ഈക്ഷ = അ + ഈ = ഏ → 'പരേക്ഷ' ആകും, ഒഴിവാക്കാം.
  2. (A), (B) 'ഇക്ഷ' എന്ന പദമില്ല. 'ഈക്ഷ' (നോട്ടം) ആണ് പദം.

ഉത്തരം: (C).

തന്ത്രം 8: സംഖ്യാ/ചില്ല് യുക്തി

ചോദ്യം: 'എണ്ണൂറ്' പിരിച്ചാൽ?
(A) എണ്ണ + നൂറ് (B) എട്ട് + നൂറ് (C) എൺ + നൂറ് (D) എണ്ണം + നൂറ്

  1. 'എണ്ണ' = oil, എട്ടിന്റെ അർത്ഥമില്ല, ഒഴിവാക്കാം.
  2. 'എണ്ണം' = count, ഒഴിവാക്കാം.
  3. 'എട്ട് + നൂറ്' ചേർന്നാൽ 'എട്ടുനൂറ്' ആകും.
  4. 'ണ്ണ' വരാൻ ചില്ല് 'ൺ' ആവശ്യം → (C).

ഉത്തരം: (C).

ശരിയുത്തരം: (B) യൺസന്ധി
സു + ആഗതം → ു + ആ = വാ (യൺസന്ധി).
2. 'മരച്ചില്ല' ശരിയായ പിരിവ്?
ശരിയുത്തരം: (B) മരം + ചില്ല
പൂർവ്വപദത്തിലെ 'ം' പോയി, ഉത്തരപദത്തിലെ 'ച' ഇരട്ടിച്ചു. പിരിക്കുമ്പോൾ 'ം' തിരികെ വേണം.
3. 'മനോരഥം' ഏത് സന്ധി?
ശരിയുത്തരം: (B) വിസർഗ്ഗസന്ധി
മനസ് + രഥം → 'ഓ' വിസർഗ്ഗത്തിൽ നിന്ന്. 'ോ' കണ്ട് ഗുണസന്ധിയെന്ന് തെറ്റിദ്ധരിക്കരുത്!
4. 'ജഗന്നാഥൻ' ശരിയായ പിരിവ്?
ശരിയുത്തരം: (B) ജഗത് + നാഥൻ
വ്യഞ്ജനസന്ധി: ത് + ന = ന്ന.
5. 'സദൈവ' ശരിയായ പിരിവ്?
ശരിയുത്തരം: (B) സദാ + ഏവ
വൃദ്ധിസന്ധി: ആ + ഏ = ഐ. 'സദ' തെറ്റ്.
6. 'സൂര്യോദയം' ഏത് സന്ധി?
ശരിയുത്തരം: (A) ഗുണസന്ധി
സൂര്യ + ഉദയം → അ + ഉ = ഓ (ഗുണം).
7. 'വാഗീശൻ' ശരിയായ പിരിവ്?
ശരിയുത്തരം: (B) വാക് + ഈശൻ
വ്യഞ്ജനസന്ധി: ക് + ഈ = ഗീ.
8. 'അത്യാവശ്യം' ശരിയായ പിരിവ്?
ശരിയുത്തരം: (B) അതി + ആവശ്യം
യൺസന്ധി: ഇ + ആ = യാ.
9. 'യഥേഷ്ടം' ശരിയായ പിരിവ്?
ശരിയുത്തരം: (B) യഥാ + ഇഷ്ടം
ഗുണസന്ധി: ആ + ഇ = ഏ. 'യഥ' (ഹ്രസ്വ) തെറ്റ്.
10. 'കണ്ടില്ല' ശരിയായ പിരിവ്?
ശരിയുത്തരം: (B) കണ്ടു + ഇല്ല
ലോപസന്ധി: 'ു' ലോപിച്ചു. 'കണ്ട് + ഇല്ല' തെറ്റ്.
