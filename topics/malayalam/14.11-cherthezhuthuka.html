ചേർത്തെഴുതുക – സന്ധി സംശ്ലേഷണം

Kerala PSC Verified Notes | ലോപം · ആഗമം · ദ്വിത്വം · ആദേശം · സ്വരസന്ധി · വിസർഗ്ഗം · ചില്ല്

🔍 ഒന്നും കണ്ടെത്തിയില്ല. മറ്റൊരു വാക്ക് ശ്രമിക്കുക.

0. വസ്തുതാ പരിശോധനാ നില

⭐ ഈ കുറിപ്പിന്റെ സ്വഭാവം
  • അടിസ്ഥാന സന്ധി നിയമങ്ങൾ (സവർണ്ണദീർഘം, ഗുണം, വൃദ്ധി, യണ്‍, വിസർഗ്ഗം) ✅ സ്വീകാര്യം.
  • 🔧 = തിരുത്തിയത്; ⚠️ = ശബ്ദതാരാവലി/നിഘണ്ടു നോക്കി ഉറപ്പിക്കേണ്ടത്.
  • 50 സംസ്കൃത ചേർത്തെഴുത്തുകളിൽ ഒന്നൊഴികെ എല്ലാം ശരിയാണ്; സംശയമുള്ളവ §11-ൽ.
  • എല്ലാ ചോദ്യങ്ങളും PSC-style practice ആണ്; ഒന്നും ഒറിജിനൽ PYQ അല്ല.

1. ആദ്യം മനസ്സിലാക്കേണ്ട 4 വാക്കുകൾ

പദംഅർത്ഥംഉദാഹരണം
പൂർവ്വപദംആദ്യത്തെ വാക്ക്കൈ + തറി
ഉത്തരപദംരണ്ടാമത്തെ വാക്ക്കൈ + തറി
സന്ധിരണ്ടു വർണ്ണങ്ങൾ ചേരുമ്പോഴുള്ള മാറ്റംകൈ+തറി = കൈത്തറി
ചേർത്തെഴുതൽരണ്ടു പദങ്ങൾ ചേർത്ത് ഒറ്റപദമാക്കൽപിരിച്ചെഴുതലിന്റെ വിപരീതം
🧠 നാല് തരം മാറ്റങ്ങൾ
  1. ലോപം = ഒരു വർണ്ണം പോകുന്നു: കാറ്റ്+അടി = കാറ്റടി.
  2. ആഗമം = പുതിയ വർണ്ണം വരുന്നു: വഴി+അമ്പലം = വഴിയമ്പലം.
  3. ദ്വിത്വം = വർണ്ണം ഇരട്ടിക്കുന്നു: തീ+പെട്ടി = തീപ്പെട്ടി.
  4. ആദേശം = ഒരു വർണ്ണത്തിന് പകരം മറ്റൊന്ന്: നെൽ+മണി = നെന്മണി.
ചിത്രം 1.1 – സന്ധിയിലെ നാല് അടിസ്ഥാന പ്രവർത്തനങ്ങൾ.

2. ഒറ്റനോട്ടത്തിൽ (Orientation)

ചിത്രം 2.1 – ചേർത്തെഴുത്തിന്റെ പ്രധാന വിഭാഗങ്ങൾ.
⭐ ആദ്യം ചോദിക്കേണ്ട 3 ചോദ്യങ്ങൾ
  1. വാക്ക് മലയാളമോ സംസ്കൃതമോ? (സംസ്കൃതമെങ്കിൽ ദീർഘ/ഗുണ/വൃദ്ധി).
  2. ആദ്യപദം ചില്ലിലോ അനുസ്വാരത്തിലോ സ്വരത്തിലോ അവസാനിക്കുന്നുവോ?
  3. രണ്ടാം പദം സ്വരത്തിലോ ഖരത്തിലോ മറ്റു വ്യഞ്ജനത്തിലോ തുടങ്ങുന്നുവോ?

3. വിശദ പഠനം A–H

A. സ്വരത്തിൽ തുടങ്ങുന്ന പദം (മലയാള നിയമം)

നിയമംഉദാഹരണം
ചന്ദ്രക്കല + സ്വരം → ലോപംകാറ്റ്+അടി = കാറ്റടി
ഇ/ഈ/എ/ഐ + സ്വരം → ‘യ’ ആഗമംവഴി+അമ്പലം = വഴിയമ്പലം
ഉ/ഊ/ഓ + സ്വരം → ‘വ’ ആഗമംതിരു+ഓണം = തിരുവോണം
ചുട്ടെഴുത്തിനു ശേഷം സ്വരം → ‘വ’ ആഗമംഅ+ഇടം = അവിടം, ഇ+ഇടം = ഇവിടം
⚠️ സംസ്കൃത യണ്‍സന്ധിയുമായി കൂട്ടിക്കുഴയ്ക്കരുത്

അതി+ഉത്തമം = അത്യുത്തമം (സംസ്കൃതം) vs വഴി+അമ്പലം = വഴിയമ്പലം (മലയാളം).

B. ഖരാക്ഷരം (ക, ച, ത, പ) ഇരട്ടിക്കുമോ?

ഇരട്ടിക്കുന്നു:

  • വിശേഷണ-വിശേഷ്യ ബന്ധം: പച്ച+കല്ല് = പച്ചക്കല്ല്; മഴ+കാലം = മഴക്കാലം; കൈ+തറി = കൈത്തറി; തീ+പെട്ടി = തീപ്പെട്ടി; പൂ+കച്ചവടം = പൂക്കച്ചവടം.
  • ‘ം’ ലോപിച്ച് ഖരം ഇരട്ടിക്കും: മരം+ചില്ല = മരച്ചില്ല; കുളം+കര = കുളക്കര; വട്ടം+പലക = വട്ടപ്പലക; പണം+കിഴി = പണക്കിഴി.
  • ചുട്ടെഴുത്തുകൾക്ക് ശേഷം: അ+കാലം = അക്കാലം; ഇ+തവണ = ഇത്തവണ; എ+പോൾ = എപ്പോൾ.

ഇരട്ടിക്കാത്തത് / അപവാദങ്ങൾ:

  • രണ്ടാം പദം ഖരമല്ലാത്തപ്പോൾ: തീ+വണ്ടി = തീവണ്ടി; കൈ+വിരൽ = കൈവിരൽ; പൂ+മാല = പൂമാല.
  • ദ്വന്ദ്വസമാസം: കൈ+കാൽ = കൈകാൽ (സാധാരണ). എന്നാൽ രാപ്പകൽ ഇരട്ടിപ്പോടെയാണ് നിഘണ്ടു രൂപം.
  • കർമ്മ-ക്രിയ ബന്ധം: വഴി+കാട്ടി = വഴികാട്ടി (വഴിക്കാട്ടി അല്ല).
⚠️ PSC Trap

“ചില്ലിനു ശേഷം വ്യഞ്ജനം വന്നാൽ ഒരിക്കലും ഇരട്ടിക്കില്ല” എന്ന് ഉറപ്പിക്കരുത്. കൽക്കണ്ടം, കൽത്തൊട്ടി, നെൽപ്പാടം ഇരട്ടിക്കുന്നു; മൺകുടം, പൊൻകുടം, കൽവിളക്ക് ഇരട്ടിക്കുന്നില്ല. ഓപ്ഷനിലെ പദം നോക്കുക.

C. ചില്ലക്ഷരങ്ങൾ (ൺ ൻ ർ ൽ ൾ)

#നിയമംഉദാഹരണം
1ൽ + മ = ന്മനൽ+മ = നന്മ; നെൽ+മണി = നെന്മണി; കൽ+മദം = കന്മദം
2ചില്ല് + സ്വരം → ചില്ല് ഇരട്ടിക്കുംകൽ+അറ = കല്ലറ; പൊൻ+ഓണം = പൊന്നോണം; കൺ+ഇമ = കണ്ണിമ; മൺ+അടുപ്പ് = മണ്ണടുപ്പ്
3ൺ + ത = ണ്ടവിൺ+തലം = വിണ്ടലം
4ൺ + ന = ണ്ണകൺ+നീർ = കണ്ണീർ; എൺ+നൂറ് = എണ്ണൂറ്; വെൺ+നീർ = വെണ്ണീർ
5ൻ + വ്യഞ്ജനം → ചില്ല് നിലനിൽക്കുംമുൻ+കാലം = മുൻകാലം; പിൻ+തുടർച്ച = പിൻതുടർച്ച
✏️ തിരുത്തലുകൾ
  • “വെൾ+നീർ” അല്ല; “വെൺ+നീർ” ആണ് → വെണ്ണീർ (ചാരം).
  • “കൺ+തുറന്നു = കണ്ടുറന്നു” തെറ്റ്; ശരി കൺതുറന്നു (ഒരു പദമല്ല).
  • “പൊൻ+ഇൻ”, “മൺ+ഓലം” ഒഴിവാക്കി; മൺ+അടുപ്പ് = മണ്ണടുപ്പ് നൽകി.
  • “മുങ്കാലം”, “പൊന്താമര” എന്നിവയ്ക്ക് പകരം മുൻകാലം, പൊൻതാമര സുരക്ഷിതം.
⚠️ ഉറപ്പില്ലാത്ത രണ്ടു നിയമങ്ങൾ

ൽ+ന = ന്ന (നൽ+നൂൽ = നന്നൂൽ), ൽ+ത = റ്റ (കൽ+തളം = കറ്റളം) — ഇവ പ്രചാരത്തിലുള്ള പദങ്ങളല്ല. നിയമമായി മനഃപാഠമാക്കരുത്; നിഘണ്ടു രൂപം മാത്രം സ്വീകരിക്കുക.

D. സംസ്കൃത സ്വരസന്ധികൾ

സന്ധിനിയമംഉദാഹരണം
സവർണ്ണദീർഘംഅ/ആ+അ/ആ=ആ; ഇ/ഈ+ഇ/ഈ=ഈ; ഉ/ഊ+ഉ/ഊ=ഊവിദ്യ+ആലയം = വിദ്യാലയം; ഗിരി+ഈശൻ = ഗിരീശൻ; ഗുരു+ഉപദേശം = ഗുരൂപദേശം
ഗുണംഅ/ആ+ഇ/ഈ=ഏ; അ/ആ+ഉ/ഊ=ഓ; അ/ആ+ഋ=അർദേവ+ഇന്ദ്രൻ = ദേവേന്ദ്രൻ; സൂര്യ+ഉദയം = സൂര്യോദയം; മഹാ+ഋഷി = മഹർഷി
വൃദ്ധിഅ/ആ+ഏ/ഐ=ഐ; അ/ആ+ഓ/ഔ=ഔഏക+ഏകം = ഏകൈകം; സദാ+ഏവ = സദൈവ; മഹാ+ഔഷധം = മഹൗഷധം
യണ്‍ഇ/ഉ/ഋ + വേറെ സ്വരം → യ്/വ്/ര് + സ്വരംഅതി+ആഗ്രഹം = അത്യാഗ്രഹം; സു+ആഗതം = സ്വാഗതം; പിതൃ+ആർജ്ജിതം = പിത്രാർജ്ജിതം
ചിത്രം 3.1 – സംസ്കൃത സ്വരസന്ധി തിരഞ്ഞെടുക്കൽ.

E. വിസർഗ്ഗസന്ധി (ഃ)

നിയമംഉദാഹരണം
ഃ + മൃദു/സ്വരം → ർപുനഃ+ജന്മം = പുനർജന്മം; ദുഃ+ഗന്ധം = ദുർഗന്ധം
അഃ + മൃദു → ഓമനഃ+ഹരം = മനോഹരം; തപഃ+വനം = തപോവനം
ഃ + ച → ശ്ചനിഃ+ചയം = നിശ്ചയം
ഃ + ശ → ശ്ശനിഃ+ശബ്ദം = നിശ്ശബ്ദം
ഃ + ഫ → ഷ്ഫനിഃ+ഫലം = നിഷ്ഫലം
ഇഃ + ര → ഈനിഃ+രസം = നീരസം; നിഃ+രോഗം = നീരോഗം

F. വ്യഞ്ജനസന്ധി (ത്, ക്, ട്)

സത്+ഗതി = സദ്ഗതി | സത്+വിചാരം = സദ്വിചാരം | ഉത്+യോഗം = ഉദ്യോഗം | ഉത്+ഭവം = ഉദ്ഭവം | ഉത്+ഘാടനം = ഉദ്ഘാടനം | ഉത്+ചാരണം = ഉച്ചാരണം | ഉത്+നതി = ഉന്നതി | സത്+ചരിത്രം = സച്ചരിത്രം | ജഗത്+ഈശൻ = ജഗദീശൻ | വാക്+ദാനം = വാഗ്ദാനം | ദിക്+ഗജം = ദിഗ്ഗജം.

G. ‘സം’ (മകാര) സന്ധി

സം+കല്പം = സങ്കല്പം | സം+ചയം = സഞ്ചയം | സം+തോഷം = സന്തോഷം | സം+പത്ത് = സമ്പത്ത് | സം+പൂർണ്ണം = സമ്പൂർണ്ണം | സം+യോഗം = സംയോഗം | സം+ഹാരം = സംഹാരം | സം+സാരം = സംസാരം | സം+ഗീതം = സംഗീതം | സം+ഘം = സംഘം.

H. സംഖ്യാനാമങ്ങൾ

ചേർക്കേണ്ടവശരിയായ രൂപം
ഒന്ന്+ഒന്ന്ഓരോന്ന്
രണ്ട്+രണ്ട്ഈരണ്ട്
ഇരു+നൂറ്ഇരുനൂറ്
മൂന്ന്+മൂന്ന്മുമ്മൂന്ന്
മൂ+ആയിരംമൂവായിരം
നാല്+നാല്നന്നാല്
നാല്+നൂറ്നാനൂറ്
അഞ്ച്+അഞ്ച്അയ്യഞ്ച്
അഞ്ച്+നൂറ്അഞ്ഞൂറ്
ആറ്+ആറ്ആറാറ്
അറു+നൂറ്അറുനൂറ്
ഏഴ്+ഏഴ്ഏഴേഴ്
എഴു+നൂറ്എഴുനൂറ്

4. താരതമ്യ പട്ടികകൾ

പട്ടിക 1: ഇരട്ടിക്കുന്നത് vs ഇരട്ടിക്കാത്തത്

ഇരട്ടിക്കുന്നുഇരട്ടിക്കുന്നില്ലകാരണം
കൈ+തറി = കൈത്തറികൈ+വിരൽ = കൈവിരൽ‘ത’ ഖരം; ‘വ’ ഖരമല്ല
തീ+പെട്ടി = തീപ്പെട്ടിവഴി+കാട്ടി = വഴികാട്ടിവിശേഷണ ബന്ധം vs കർമ്മ-ക്രിയ
മരം+ചില്ല = മരച്ചില്ലമരം+വടി = മരവടി‘ം’ ലോപിച്ച ശേഷം ഖരം ഉണ്ടോ?
പൊൻ+ഓണം = പൊന്നോണംപൊൻ+താമര = പൊൻതാമരചില്ലിനു ശേഷം സ്വരം vs വ്യഞ്ജനം
കൽ+അറ = കല്ലറകൽ+വിളക്ക് = കൽവിളക്ക്സ്വരം vs വ്യഞ്ജനം

പട്ടിക 2: ദീർഘം vs ഹ്രസ്വം

ദീർഘംഹ്രസ്വം
ഗുരു+ഉപദേശം = ഗുരൂപദേശം (ഉ+ഉ)അതി+ഉത്തമം = അത്യുത്തമം (ഇ+ഉ, ഉ ഹ്രസ്വം)
പരി+ഈക്ഷ = പരീക്ഷ (ഇ+ഈ)പ്രതി+ഉപകാരം = പ്രത്യുപകാരം
നിഃ+രസം = നീരസംമഹാ+ഋഷി = മഹർഷി (ആ ദീർഘം പോയി)

പട്ടിക 3: സ്വര സംയോജനം

ഇ+ഇ → ഈ (സവർണ്ണം) | ഇ+ഉ → യു (യണ്‍) | ഉ+ഉ → ഊ (സവർണ്ണം) | ഉ+അ → വ (യണ്‍) | അ+ഇ → ഏ (ഗുണം) | അ+ഏ → ഐ (വൃദ്ധി)

5. പരീക്ഷയിലെ ചതിക്കുഴികൾ

⚠️ 10 പ്രധാന കെണികൾ
  1. ഗുരുപദേശം ✗ → ഗുരൂപദേശം ✓ (ഉ+ഉ = ഊ).
  2. മഹൃഷി / മഹാർഷി ✗ → മഹർഷി ✓ (ആ+ഋ = അർ).
  3. നിരസം / നിര്യസം ✗ → നീരസം ✓; നീരോഗം ✓.
  4. ആശിർവാദം ✗ → ആശീർവാദം ✓.
  5. അത്യൂത്തമം ✗ → അത്യുത്തമം ✓ (യണ്‍ സന്ധിയിൽ സ്വരം ഹ്രസ്വം).
  6. ഏകേകം ✗ → ഏകൈകം ✓ (വൃദ്ധി).
  7. ഉജ്വലം ✗ → ഉജ്ജ്വലം ✓ (ഉത്+ജ്വലം).
  8. വെൾനീർ / വെൺനീർ ✗ → വെണ്ണീർ ✓.
  9. വഴിക്കാട്ടി ✗ → വഴികാട്ടി ✓.
  10. സംതോഷം ✗ → സന്തോഷം ✓.

6. മെമ്മറി ട്രിക്കുകൾ

🧠 10 ഓർമ്മവിദ്യകൾ
  1. “ചില്ലിനു ശേഷം സ്വരം = ഇരട്ടി”: മൺ+അടുപ്പ് = മണ്ണടുപ്പ്; പൊൻ+ഓണം = പൊന്നോണം.
  2. “നിർ + ര = നീ”: നീരസം, നീരോഗം, നീരവം.
  3. “ആ+ഋ = അർ”: മഹാ ദീർഘം വിടും → മഹർഷി.
  4. “ഒരേ സ്വരം = ദീർഘം; വേറെ സ്വരം = യ/വ”: ഉ+ഉ = ഊ; ഇ+ഉ = യു.
  5. “ഗുണം ഏ/ഓ/അർ”: ദേവേന്ദ്രൻ, സൂര്യോദയം, മഹർഷി.
  6. “വൃദ്ധി = ഐ/ഔ”: ഏകൈകം, സദൈവ.
  7. “ഷണ്മുഖൻ”: ഷട്+മുഖൻ; ട്+മ = ണ്മ.
  8. “ത് + ജ/ച/ല → അതേ അക്ഷരം ഇരട്ടി”: സജ്ജനം, സച്ചിദാനന്ദം, ഉല്ലാസം.
  9. “ത്+മ = ന്മ”: സന്മാർഗ്ഗം, തന്മയത്വം; ത്+ന = ന്ന (ജഗന്നാഥൻ).
  10. “സ്→ഓ”: മനസ്/തപസ്/തേജസ് → മനോ/തപോ/തേജോ.

8. PSC Smart Tricks

⭐ Trick 1: Option Elimination

ചോദ്യം: ‘ഗുരു+ഉപദേശം’?

(A) ഗുരുപദേശം (B) ഗുരൂപദേശം (C) ഗുര്യുപദേശം (D) ഗുരുവുപദേശം

യുക്തി: ഉ+ഉ = ഊ → ദീർഘം വേണം. (A) തെറ്റ്. (C), (D) യണ്‍/വ ആഗമം — ഇവിടെ ബാധകമല്ല. ഉത്തരം: (B).

⭐ Trick 2: Keyword Trick

ചോദ്യം: തെറ്റായത് ഏത്?

(A) കൺ+നീർ = കണ്ണീർ (B) നിർ+രസം = നീരസം (C) മഹാ+ഋഷി = മഹാർഷി (D) സു+ആഗതം = സ്വാഗതം

യുക്തി: “തെറ്റായത്” എന്ന കീവേഡ് ശ്രദ്ധിക്കുക. (C) ആ+ഋ = അർ → മഹർഷി, “മഹാർഷി” തെറ്റ്. ഉത്തരം: (C).

⭐ Trick 3: Extreme Statement Check

ചോദ്യം: ഖര ഇരട്ടിപ്പിനെക്കുറിച്ച് ശരിയായ പ്രസ്താവന?

(A) രണ്ടാം പദം ഖരമല്ലാത്തപ്പോൾ ഈ നിയമപ്രകാരം ഇരട്ടിപ്പ് വരില്ല

(B) ദ്വന്ദ്വസമാസത്തിൽ ഖരം എപ്പോഴും ഇരട്ടിക്കും

(C) ചില്ലിനു ശേഷം വ്യഞ്ജനം വന്നാൽ എപ്പോഴും ഇരട്ടിക്കും

(D) ഇരട്ടിപ്പ് ഒരിക്കലും ഉണ്ടാകില്ല

യുക്തി: “എപ്പോഴും/ഒരിക്കലും” ഉള്ള (B), (C), (D) എതിരുദാഹരണം കൊണ്ട് തെറ്റ്. ഉത്തരം: (A).

⚠️ Trick 4: Negative Marking

KPSC-യിൽ സാധാരണ തെറ്റായ ഉത്തരത്തിന് മാർക്ക് കുറയ്ക്കൽ ഉണ്ട്. രണ്ട് ഓപ്ഷൻ ഒഴിവാക്കാൻ കഴിഞ്ഞില്ലെങ്കിൽ ആ ചോദ്യം ഒഴിവാക്കുക.

9. മാതൃകാ ചോദ്യങ്ങൾ

Q1. ‘നിർ+രോഗം’ ചേർത്തെഴുതിയാൽ?
‘ര’ പിന്നാലെ വരുമ്പോൾ ‘ർ’ ലോപിച്ച് ‘നി’ ദീർഘിക്കും → നീരോഗം.
Q2. ‘ആശിസ്+വാദം’ ശരിയായ രൂപം?
ഇ ദീർഘിക്കുന്നു (ശീ), സ്→ർ → ആശീർവാദം.
Q3. ‘ഉത്+ജ്വലം’ ശരിയായ രൂപം?
ത്+ജ = ജ്ജ → ഉജ്ജ്വലം.
Q4. ‘മനസ്+രഥം’?
സ്→ഓ → മനോരഥം.
Q5. ശരിയായ ജോഡി ഏത്?
(B) കണ്ണീർ, (C) എണ്ണൂറ്, (D) വിണ്ടലം ആണ് ശരി.
Q6. ‘പുനഃ+ജന്മം’?
ഃ + മൃദു = ർ → പുനർജന്മം.
Q7. ‘മരം+ചില്ല’ ശരിയായ ചേർത്തെഴുത്ത്?
‘ം’ ലോപിച്ച് ‘ച’ ഇരട്ടിക്കും → മരച്ചില്ല.
Q8. ‘സം+തോഷം’?
സം+ത = സന്ത → സന്തോഷം.

#സന്ധിസൂത്രംഉദാഹരണം
1സവർണ്ണദീർഘംഒരേ സ്വരം → ദീർഘംഗുരു+ഉപദേശം = ഗുരൂപദേശം
2ഗുണംഅ/ആ+ഇ=ഏ, അ/ആ+ഉ=ഓ, അ/ആ+ഋ=അർദേവ+ഇന്ദ്രൻ = ദേവേന്ദ്രൻ; മഹാ+ഋഷി = മഹർഷി
3വൃദ്ധിഅ/ആ+ഏ=ഐ, അ/ആ+ഓ=ഔസദാ+ഏവ = സദൈവ
4യണ്‍ഇ+സ്വരം → യ്; ഉ+സ്വരം → വ്; ഋ+സ്വരം → ര്അതി+ഉത്തമം = അത്യുത്തമം; സു+അല്പം = സ്വല്പം
5വിസർഗ്ഗംഃ+മൃദു → ർ/ഓ; നിഃ+ര = നീനിഃ+രസം = നീരസം
6വ്യഞ്ജനംത്+ജ=ജ്ജ, ത്+മ=ന്മ, ട്+മ=ണ്മ, ക്+മ=ങ്മസജ്ജനം, സന്മാർഗ്ഗം, ഷണ്മുഖൻ, വാങ്മയം
7മലയാളം ആഗമംഇ/ഈ/എ/ഐ+സ്വരം → യ; ഉ/ഊ/ഓ+സ്വരം → വവഴിയമ്പലം, തിരുവോണം
8ചില്ല്+സ്വരംചില്ല് ഇരട്ടിക്കുംകല്ലറ, പൊന്നോണം
9ൺ+നണ്ണകണ്ണീർ, എണ്ണൂറ്
10ൽ+മന്മനെന്മണി
11‘ം’ ലോപം+ഖരംഖരം ഇരട്ടിക്കുംമരച്ചില്ല

11. തിരുത്തൽ രജിസ്റ്റർ

✏️ പ്രധാന തിരുത്തലുകൾ
  • “ഒരു” ഇരട്ടിപ്പിക്കുന്ന കൂട്ടത്തിൽ നിന്ന് ഒഴിവാക്കി (ഒരുകാലം, ഒരുതവണ).
  • “താമര+ഇതൾ = താമരയിതൾ” യകാരാഗമ വിഭാഗത്തിലേക്ക് മാറ്റി.
  • “രാപകൽ” vs “രാപ്പകൽ” വൈരുദ്ധ്യം ഒഴിവാക്കി; രാപ്പകൽ നിഘണ്ടു രൂപം.
  • “വെൾ+നീർ” → വെൺ+നീർ = വെണ്ണീർ.
  • “കൺ+തുറന്നു = കണ്ടുറന്നു” ഒഴിവാക്കി; ശരി കൺതുറന്നു.
  • “പൊൻ+ഇൻ”, “മൺ+ഓലം” ഒഴിവാക്കി; മൺ+അടുപ്പ് = മണ്ണടുപ്പ്.
  • “ൽ+ന = ന്ന”, “ൽ+ത = റ്റ” ⚠️ ഉറപ്പില്ലാത്തതിനാൽ നിയമമായി ഒഴിവാക്കി.
  • “വഴികാട്ടി” (കർമ്മ-ക്രിയ ബന്ധം) ശരി; “വഴിക്കാട്ടി” അല്ല.

12. അവസാനവട്ട ചെക്ക്‌ലിസ്റ്റ്

  • ഗുരൂപദേശം, ഭാനൂദയം, പരീക്ഷ, പ്രതീക്ഷ ദീർഘം ഓർമ്മയുണ്ടോ?
  • മഹർഷി, സപ്തർഷികൾ, രാജർഷി (ആ/അ+ഋ = അർ) ഉറപ്പാണോ?
  • നീരസം, നീരോഗം, ആശീർവാദം, നിശ്ശബ്ദം, നിഷ്ഫലം എഴുതാമോ?
  • വിണ്ടലം, കണ്ണീർ, വെണ്ണീർ, എണ്ണൂറ്, നെന്മണി, കല്ലറ, പൊന്നോണം, മൺകുടം തെറ്റാതെ എഴുതാമോ?
  • അത്യുത്തമം, സ്വല്പം, ഉജ്ജ്വലം, സച്ചിദാനന്ദം, ഷണ്മുഖൻ, ജഗന്നാഥൻ ശരിയായി എഴുതാമോ?
  • ഗുണം (ഏ/ഓ/അർ), വൃദ്ധി (ഐ/ഔ), സവർണ്ണദീർഘം, യണ്‍ വേർതിരിക്കാമോ?
  • ⚠️ അടയാളമുള്ള പദങ്ങൾ (ഒരു, രാപ്പകൽ, വഴികാട്ടി, ഷട്പദം/ഷഡ്പദം, തൊണ്ണൂറ്) നിഘണ്ടുവിൽ നോക്കിയോ?
  • “ശരിയല്ലാത്തത്” / “ഒഴികെ” ചോദ്യവാചകം ആദ്യം വായിക്കുന്ന ശീലമുണ്ടോ?
  • ഒരു ഓപ്ഷൻ പോലും ഒഴിവാക്കാൻ കഴിയുന്നില്ലെങ്കിൽ (negative marking ഉണ്ടെങ്കിൽ) ചോദ്യം വിടാൻ തയ്യാറാണോ?
