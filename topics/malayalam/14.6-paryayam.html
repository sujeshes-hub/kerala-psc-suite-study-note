പര്യായപദങ്ങൾ – Paryayapadangal / Synonyms

KPSC Complete Verified Notes | പദനിർമ്മാണ സൂത്രവാക്യം · പ്രകൃതി · ജീവജാലങ്ങൾ · ശരീരം · ബന്ധങ്ങൾ · ദേവതകൾ · Smart Tricks · Interactive MCQs

🔍 ഒന്നും കണ്ടെത്തിയില്ല. മറ്റൊരു വാക്ക് ശ്രമിക്കുക.

⭐ Star Guide

⭐ പ്രാധാന്യ സൂചകങ്ങൾ (KPSC അടിസ്ഥാനത്തിൽ)
  • ⭐⭐⭐⭐⭐ അതിപ്രധാനം — ജല-പദ സൂത്രവാക്യം (`-ജം` = താമര, `-ദം` = മേഘം, `-ധി` = സമുദ്രം), സൂര്യൻ/ചന്ദ്രൻ/ഭൂമി പര്യായങ്ങൾ, ആന/സിംഹം/കുതിര/പാമ്പ്, ആശയക്കുഴപ്പ ജോഡികൾ (തരണി/തരുണി/ധരണി, അനിലൻ/അനലൻ)
  • ⭐⭐⭐⭐ പ്രധാനം — പദഘടക ഡീകോഡർ (`-ഗം`, `-രുഹം`, `-കരൻ`, `-പതി`, `-അങ്കൻ`, ദ്വി-), നദി/അഗ്നി/കാറ്റ്/വണ്ട്/തലമുടി/രക്തം/സ്വർണ്ണം
  • ⭐⭐⭐ ശ്രദ്ധിക്കേണ്ടത് — നാനാർത്ഥ പദങ്ങൾ (നാഗം, ശിഖി, ദ്വിജം, ഹരി), ദേവതകൾ, ഭാവങ്ങൾ
  • ⭐⭐ അറിഞ്ഞാൽ മതി — അധിക വസ്തുതകൾ (കുളം, വഴി, യുദ്ധം, വില്ല്)
  • ⭐ ചരിത്ര വിവരം — തിരുത്തൽ രേഖ, ഉറവിട കുറിപ്പുകൾ
➕ ചുരുക്കം (5 മാസ്റ്റർ കോഡുകൾ)
  • `-ജം` = താമര: അംബുജം, വാരിജം, പങ്കജം, സരോജം
  • `-ദം` = മേഘം: അംബുദം, വാരിദം, നീരദം, പയോദം
  • `-ധി` = സമുദ്രം: അംബുധി, വാരിധി, ജലധി, പയോധി
  • തരണി = സൂര്യൻ, തരുണി = യുവതി, ധരണി = ഭൂമി
  • അനിലൻ = കാറ്റ്, അനലൻ = അഗ്നി
  • ദ്വിജം = പക്ഷി/പല്ല്/ബ്രാഹ്മണൻ · ദ്വിപം = ആന · ദ്വിരേഫം = വണ്ട്

1. അധ്യായ ആമുഖം

ഒരേ അർത്ഥം തന്നെ സൂചിപ്പിക്കുന്ന വ്യത്യസ്ത പദങ്ങളെയാണ് മലയാള വ്യാകരണത്തിൽ പര്യായപദങ്ങൾ (Synonyms) എന്ന് വിളിക്കുന്നത്. ഉദാഹരണത്തിന് 'കണ്ണ്' എന്ന ഒരൊറ്റ വസ്തുവിനെ നയനം, ലോചനം, അക്ഷി, ദൃക്ക്, ചക്ഷുസ്സ്, മിഴി, നേത്രം എന്നിങ്ങനെ പല പദങ്ങൾ കൊണ്ട് പറയാം.

⭐ ഇതൊരു ഓർമ്മയുടെ കളി മാത്രമല്ല

പര്യായപദങ്ങളിൽ ഭൂരിഭാഗവും സംസ്കൃതത്തിൽ നിന്ന് വന്നതാണ്. ഓരോ പദവും ആ വസ്തുവിന്റെ ഒരു സ്വഭാവത്തെ സൂചിപ്പിക്കുന്നു.

  • കരി = കരം (തുമ്പിക്കൈ) ഉള്ളത്, അതായത് ആന.
  • ദ്വിജം = രണ്ടുവട്ടം ജനിക്കുന്നത്, അതായത് പക്ഷി.
  • ഉരഗം = ഉരസ്സ് (നെഞ്ച്) കൊണ്ട് ഇഴയുന്നത്, അതായത് പാമ്പ്.

ഈ "പേരിന്റെ പിന്നിലെ കാരണം" അറിഞ്ഞാൽ പദം മറന്നുപോയാലും ഓർത്തെടുക്കാം.

പരീക്ഷയിലെ ചോദ്യരൂപങ്ങൾ

  1. "'സൂര്യൻ' / 'ആന' / 'നദി' എന്നതിന്റെ പര്യായമല്ലാത്ത പദം ഏത്?" (നെഗറ്റീവ് രൂപം)
  2. "ശരിയായ പര്യായജോഡി തിരഞ്ഞെടുക്കുക"
  3. "'അംബുജം' എന്ന വാക്കിന്റെ അർത്ഥം?" (പദം കൊടുത്ത് അർത്ഥം ചോദിക്കുന്ന രൂപം)
  4. ചേരുംപടി ചേർക്കുക, പ്രസ്താവനാ രൂപം.
🧠 3 ഘട്ട പഠന രീതി
  1. ഫോർമുല ആദ്യം (Sec 4, 5): സൂത്രവാക്യം പഠിച്ചാൽ നൂറിലധികം പദങ്ങൾ ഒറ്റയടിക്ക് കിട്ടും.
  2. പിന്നെ പട്ടികകൾ (Sec 7 മുതൽ 12): ഓരോ വിഷയത്തിനും 4–5 പ്രധാന പദങ്ങൾ ആദ്യം ഉറപ്പിക്കുക.
  3. അവസാനം ചതിക്കുഴികൾ (Sec 10, 19): സമാനപദങ്ങളും നാനാർത്ഥങ്ങളും.
📌 ഉറവിടം സംബന്ധിച്ച കുറിപ്പ്

പര്യായപദങ്ങൾക്ക് സാധാരണ ആധാരമാക്കുന്നത് അമരകോശം (നാമലിംഗാനുശാസനം), ശബ്ദതാരാവലി (ശ്രീകണ്ഠേശ്വരം ജി. പത്നാഭപിള്ള) തുടങ്ങിയ ഗ്രന്ഥങ്ങളാണ്. ഏതെങ്കിലും പദത്തിൽ സംശയം തോന്നിയാൽ ശബ്ദതാരാവലിയിൽ നോക്കി ഉറപ്പിക്കുക. ഉറപ്പുകുറഞ്ഞ/അപൂർവ്വ പദങ്ങൾ ⚠️ ചിഹ്നത്തോടെ അടയാളപ്പെടുത്തിയിട്ടുണ്ട്. ആദ്യം ഉറപ്പുള്ള പദങ്ങൾ പഠിക്കുക.

2. പിന്നാമ്പുറ കഥ – ജല-പദ മാന്ത്രികത

പത്ത് വയസ്സുള്ള കുട്ടിക്കും മനസ്സിലാകുന്ന ഒരു മാന്ത്രിക സൂത്രവാക്യത്തിലൂടെ തുടങ്ങാം.

പരീക്ഷയിൽ ജലം, താമര, മേഘം, സമുദ്രം എന്നിവയുടെ പര്യായങ്ങൾ എല്ലാവർക്കും മാറിപ്പോകാറുണ്ട്. (അംബുജം താമരയാണോ മേഘമാണോ? അംബുദം മേഘമാണോ സമുദ്രമാണോ?) ഒരു രഹസ്യ കോഡ് അറിഞ്ഞാൽ ഇവ നാലും ഒറ്റയടിക്ക് പഠിക്കാം.

ആദ്യം: ജലത്തിന്റെ പേരുകൾ

അംബു, ജലം, വാരി, നീരം, തോയം, പയസ്സ്, അപ്പ്

ഇനി ഓരോ അറ്റഭാഗവും ചേർക്കാം

⭐ 1. `-ജം` (ജനിച്ചത്) → താമര

വെള്ളത്തിൽ ജനിക്കുന്നത് എന്താണ്? താമര!

  • അംബു + ജം = അംബുജം
  • ജലം + ജം = ജലജം
  • വാരി + ജം = വാരിജം
  • നീരം + ജം = നീരജം
  • തോയം + ജം = തോയജം
  • പയസ്സ് + ജം = പയോജം ⚠️ (അപൂർവ്വം), അപ്പ് + ജം = അബ്ജം
  • പങ്കജം = പങ്കം (ചെളി) + ജം (ചെളിയിൽ ജനിച്ചത്)
⭐ 2. `-ദം` (നൽകുന്നത്) / `-ധരം` (ധരിക്കുന്നത്) → മേഘം

വെള്ളം മഴയായി നൽകുന്നത് ആരാണ്? മേഘം!

  • അംബുദം, ജലദം, വാരിദം, നീരദം, തോയദം, പയോദം
  • അതുപോലെ: ജലധരം, പയോധരം, അംബുധരം
⭐ 3. `-ധി` (സംഭരിക്കുന്ന ഇടം) → സമുദ്രം

വെള്ളമെല്ലാം സംഭരിച്ചു വെച്ചിരിക്കുന്നത് എവിടെ? സമുദ്രത്തിൽ!

  • അംബുധി, ജലധി, വാരിധി, പയോധി, ഉദധി, അബ്ധി
  • നിധി ചേർത്താലും: അംബുനിധി, വാരിനിധി, വാരാന്നിധി
🧠 കണ്ടോ!

ഒരു ജലപര്യായം പഠിച്ചാൽ അതിൽ നിന്ന് താമര, മേഘം, സമുദ്രം എന്നിങ്ങനെ 3 പദങ്ങൾ കൂടി കിട്ടും. ഇതുപോലെ വെറും 6 ജലപദങ്ങൾ കൊണ്ട് ഇരുപതിലധികം പര്യായങ്ങൾ ഓർത്തെടുക്കാം.

⚠️ മുന്നറിയിപ്പ്
  • ഈ ഫോർമുല പദനിർമ്മാണം മനസ്സിലാക്കാനുള്ള സഹായം മാത്രമാണ്. ഭാഷയിൽ പ്രചാരത്തിലുള്ള പദങ്ങളേ പരീക്ഷയിൽ വരൂ.
  • അംബുജം, വാരിജം, നീരജം, പങ്കജം, സരോജം (താമര), വാരിദം, അംബുദം, നീരദം, ജലദം, പയോദം (മേഘം), വാരിധി, അംബുധി, ജലധി, പയോധി, ഉദധി (സമുദ്രം) — ഇവ ഉറപ്പുള്ളവ.
  • തോയധി, നീരധി, പയോജം പോലുള്ളവ അപൂർവ്വം. ഓപ്ഷനായി വന്നാൽ തിരിച്ചറിയാനുള്ള സൂചന മാത്രമായി ഉപയോഗിക്കുക.
  • `-ജം` എന്ന ഘടകത്തിന് "ജലത്തിൽ ജനിച്ചത്" എന്ന പൊതുഅർത്ഥമേ ഉള്ളൂ. അതിനാൽ ജലജം, വാരിജം എന്നിവ സന്ദർഭമനുസരിച്ച് ശംഖ്, മത്സ്യം എന്നിവയെയും കുറിക്കാം. പി.എസ്.സി ഓപ്ഷനിൽ സാധാരണ ഉത്തരം താമര തന്നെയാണ്.

3. പര്യായം, നാനാർത്ഥം, ഏകാർത്ഥം

  1. ⭐⭐⭐⭐⭐ പര്യായപദം (Synonyms): ഒരേ വസ്തുവിനെയോ ആശയത്തെയോ കുറിക്കുന്ന വ്യത്യസ്ത പദങ്ങൾ.
    • ഉദാ: ഭൂമി = ധര, വസുധ, വസുന്ധര, മഹി, മേദിനി, ഉർവി, ക്ഷോണി, അവനി, ധരണി.
  2. ⭐⭐⭐⭐ നാനാർത്ഥം (Polysemy / Homonym): ഒരേ പദത്തിന് സന്ദർഭമനുസരിച്ച് പല അർത്ഥങ്ങൾ.
    • ഉദാ: പതംഗം = പക്ഷി, സൂര്യൻ, ശലഭം, വെട്ടുകിളി.
    • ഗോ = പശു, ഭൂമി, കണ്ണ്, സ്വർഗ്ഗം, രശ്മി, ജലം.
  3. ⭐⭐ ഏകാർത്ഥം: ഒരു അർത്ഥം മാത്രമുള്ള പദം.

4. Water-Root Multiplier Formula (ജല-പദ സൂത്രവാക്യം)

ചിത്രം 4.1 – ജലപര്യായങ്ങളിൽ നിന്ന് 3 വഴികളിലൂടെ താമര, മേഘം, സമുദ്രം.

ജലപര്യായ സംഭാരം

ജലം: അംബു, വാരി, നീരം, തോയം, ജലം, പയസ്സ്, അപ്പ്, സലിലം, ഉദകം, ജീവനം.

ഒപ്പം ഓർക്കേണ്ട 4 പദങ്ങൾ

  • സരോജം = സരസ്സ് (പൊയ്ക) + ജം → താമര
  • പങ്കജം = പങ്കം (ചെളി) + ജം → താമര
  • രത്നാകരൻ = രത്നങ്ങൾക്ക് ആകരം (ഉറവിടം) → സമുദ്രം
  • വാരാന്നിധി = വാരം (ജലം) + നിധി → സമുദ്രം
📌 ബാക്കി പദങ്ങൾ

സമുദ്രം: സാഗരം, സിന്ധു, അർണ്ണവം, ആഴി, പാരാവാരം, അകൂപാരം. മേഘം: ഘനം, ജീമൂതം, മുകിൽ, കാർമുകിൽ, വലാഹകം, മുദിരം. ഇവ ഫോർമുലയിൽ നിന്നല്ല, നേരിട്ട് പഠിക്കേണ്ടവ.

  • ചന്ദ്രൻ (നിശ / രജനി / ഹിമം / സുധ / ശശം + കരൻ / പതി / ധരൻ / അങ്കൻ): നിശാകരൻ, നിശാപതി, രജനീകരൻ, രാകേന്ദു, ഹിമകരൻ, ശീതകരൻ, സുധാകരൻ, ശശധരൻ, ശശി, ശശാങ്കൻ, മൃഗാങ്കൻ, തിങ്കൾ, ഇന്ദു, സോമൻ, കലാനിധി, താരാപതി, അമ്പിളി, വിധു.

ചിത്രം 10.1 – 12 ട്രാപ്പ് പദങ്ങൾ: ഇവയിൽ ഒരൊറ്റ അക്ഷര വ്യത്യാസം അർത്ഥം മാറ്റുന്നു.

  2. ⭐⭐⭐⭐⭐ `അനിലൻ` vs `അനലൻ`: അനിലൻ = കാറ്റ്, അനലൻ = അഗ്നി.

  7. ⭐⭐⭐ `അർക്കൻ` vs `അർക്കം`: അർക്കൻ = സൂര്യൻ; അർക്കം = സൂര്യൻ, ഒപ്പം എരിക്ക് (ചെടി).
  8. ⭐⭐⭐ `നീലകണ്ഠൻ`: ശിവൻ, മയിൽ (രണ്ടും).
  9. ⭐⭐⭐ `അബ്ദം` vs `അബ്ജം` vs `അബ്ധി`: അബ്ദം = മേഘം (ഒപ്പം വർഷം), അബ്ജം = താമര, അബ്ധി = സമുദ്രം.
  10. ⭐⭐⭐ `പയോധരം`: മേഘം; കൂടാതെ സ്തനം എന്നും അർത്ഥം (നാനാർത്ഥം).

14. പ്രധാന വസ്തുതകൾ

  • ഒരേ അർത്ഥമുള്ള വ്യത്യസ്ത പദങ്ങളാണ് പര്യായപദങ്ങൾ. ഒരു പദത്തിന് പല അർത്ഥങ്ങൾ വരുന്നത് നാനാർത്ഥം.
  • ജലപര്യായ + `-ജം` = താമര; + `-ദം` = മേഘം; + `-ധി` = സമുദ്രം.
  • തരണി = സൂര്യൻ (തോണി); തരുണി = യുവതി; ധരണി = ഭൂമി.

  • ആന: കരി, കുംഭി, ദന്തി, മാതംഗം, ഇഭം, വാരണം, സിന്ധുരം, ദ്വിപം.

  • വണ്ട്: അളി, ഭൃംഗം, മധുപൻ, ഭ്രമരം, ഷട്പദം, ദ്വിരേഫം.
  • തലമുടി: ചികുരം, കുന്തളം, അളകം, കചം, കേശം, ശിരോരുഹം.

മുൻ കുറിപ്പിൽ ചില ചോദ്യങ്ങൾ "LDC / VFA / Degree Prelims PYQ" എന്ന് ലേബൽ ചെയ്തിരുന്നു. ഇവ പരീക്ഷയിൽ വന്നതാണെന്ന് ഉറപ്പിക്കാൻ കഴിയാത്തതുകൊണ്ട് ഇവിടെ "PSC ശൈലിയിലുള്ള മാതൃകാ ചോദ്യങ്ങൾ" (പ്രാക്ടീസ്) എന്നാണ് ലേബൽ ചെയ്യുന്നത്. യഥാർത്ഥ ചോദ്യങ്ങൾ keralapsc.gov.in ലെ Question Papers വിഭാഗത്തിൽ നിന്ന് എടുത്ത് ഈ ഭാഗത്ത് "യഥാർത്ഥ PYQ (പരീക്ഷ + വർഷം)" എന്ന് ചേർക്കുക.

4 സ്ഥിരം രൂപങ്ങൾ

  1. നെഗറ്റീവ്: "'സൂര്യൻ' എന്നതിന്റെ പര്യായമല്ലാത്ത പദം ഏത്? (A) മാർത്താണ്ഡൻ (B) തരണി (C) മിഹിരൻ (D) ശശാങ്കൻ" → (D): ശശാങ്കൻ ചന്ദ്രന്റെ പര്യായം.
  2. നെഗറ്റീവ്: "'ആന'യുടെ പര്യായമല്ലാത്തത്? (A) കരി (B) ദന്തി (C) തുരഗം (D) മാതംഗം" → (C): തുരഗം = കുതിര.
  3. പോസിറ്റീവ്: "'നദി'യുടെ പര്യായം? (A) തടിനി (B) അചലം (C) അടവി (D) അംബുധി" → (A): അചലം = പർവ്വതം, അടവി = കാട്, അംബുധി = സമുദ്രം.
  4. അർത്ഥം ചോദിക്കുന്ന രൂപം: 'വണ്ടി'ന്റെ പര്യായം, 'തലമുടി'യുടെ പര്യായം, 'അഗ്നി'യുടെ പര്യായമല്ലാത്തത് (A) അനലൻ (B) പാവകൻ (C) കൃശാനു (D) അനിലൻ → (D) അനിലൻ = കാറ്റ്.
🧠 പാറ്റേൺ നിരീക്ഷണം (ഉറപ്പല്ല)

18. മെമ്മറി ട്രിക്കുകൾ (Mnemonics)

🧠 10 മെമ്മറി ട്രിക്കുകൾ
  1. `ജം` = താമര, `ദം` = മേഘം, `ധി` = കടൽ: അറ്റത്ത് -ജം (*അംബുജം, വാരിജം, പങ്കജം*) → താമര. -ദം (*അംബുദം, വാരിദം, പയോദം*) → മേഘം. -ധി (*അംബുധി, വാരിധി, പയോധി*) → സമുദ്രം.
    ഓർമ്മവാക്യം: "ജനിക്കുന്നത് താമര, ദാനം ചെയ്യുന്നത് മേഘം, ധരിക്കുന്നത് കടൽ."
  2. അനിലൻ vs അനലൻ: `അനിലൻ` എന്നതിലെ 'നി' → കാറ്റ് വീശുമ്പോൾ ഇല ആടുന്നു → കാറ്റ്. `അനലൻ` → അഗ്നി.
  3. തരണി – തരുണി – ധരണി: ധരണി (ധര = ഭൂമി) → ഭൂമി. തരുണി (തരുണി = യുവതി) → സ്ത്രീ. തരണി (ര = രവി) → സൂര്യൻ.
  4. സഞ്ചാരത്തിന്റെ കോഡ് (`-ഗം`): ഉരഗം (ഉരസ്സ് = നെഞ്ച്) → പാമ്പ്; ഖഗം / വിഹഗം (ഖം = ആകാശം) → പക്ഷി; തുരഗം (വേഗം) → കുതിര.
  5. ആന 5-കോഡ്: "കരി, ദന്തി, കുംഭി, ഇഭം, മാതംഗം" → ക ദ കു ഇ മാ.
  6. തലമുടി 4-കോഡ്: ചി-കു-അ-ക → ചികുരം, കുന്തളം, അളകം, കചം. കൂടെ ശിരോരുഹം.
  7. ഇല്ലാത്ത കാൽ കോഡ്: ഉരഗം, പന്നഗം, ഭുജംഗം = കാലില്ലാതെ നീങ്ങുന്നത് → പാമ്പ്.
  8. രണ്ടിന്റെ കോഡ് (`ദ്വി`): ദ്വിജം (2 ജനനം), ദ്വിപം (2 തവണ കുടിക്കൽ), ദ്വിരദം (2 ദന്തം), ദ്വിരേഫം (2 'ര').
  9. ശശാങ്കൻ vs മൃഗാങ്കൻ: ശശം = മുയൽ, മൃഗം = മാൻ. രണ്ടും ചന്ദ്രന്റെ പര്യായങ്ങൾ.
  10. സൂര്യൻ-ചന്ദ്രൻ കോഡ്: പകലിനോട് (ദിന, ദിവാ, പ്രഭാ) കരൻ → സൂര്യൻ. രാത്രിയോട് (നിശാ, രജനീ) / തണുപ്പിനോട് (ഹിമ, ശീത) / അമൃതിനോട് (സുധാ) കരൻ → ചന്ദ്രൻ.

19. Common PSC Traps (ചതിക്കുഴികൾ)

  1. `പയോദം` vs `പയോധി`: `പയസ്സ്` = വെള്ളം. `-ദം` ചേർന്ന പയോദം = മേഘം; `-ധി` ചേർന്ന പയോധി = സമുദ്രം.
  2. `കരി`: പര്യായചോദ്യത്തിൽ `കരി` കണ്ടാൽ അത് ആന (കറുപ്പ് / കരിക്കട്ട അല്ല).
  3. `മൃഗം`, `മൃഗേന്ദ്രൻ`, `മൃഗാങ്കൻ`: മൃഗം = മാൻ (സംസ്കൃതത്തിൽ). മൃഗേന്ദ്രൻ = സിംഹം. മൃഗാങ്കൻ = ചന്ദ്രൻ.
  4. `ജലജം`: ജലത്തിൽ ജനിച്ചതെന്തും (താമര, മത്സ്യം, ശംഖ്). പി.എസ്.സി ഉത്തരം സാധാരണ താമര.
  5. `അർക്കം`: സൂര്യൻ, എരിക്ക് (ചെടി).
  6. `പയോധരം`, `അബ്ദം`: പയോധരം = മേഘം (സ്തനവും); അബ്ദം = മേഘം (വർഷവും).
  7. `പരഭൃത്ത്`: കാക്കയല്ല, കുയിലാണ്. (കാക്കയുടെ പര്യായങ്ങൾ: വായസം, ബലിഭുക്ക്, കരടം.)
  8. `നീലകണ്ഠൻ`, `ശിഖി`, `നാഗം`: ഓരോന്നിനും രണ്ടർത്ഥം; ചോദ്യത്തിന്റെ വിഷയം നോക്കുക.
  9. `അംബരം`, `അംബു`, `അംബ`, `അംബകം`: ആകാശം / ജലം / അമ്മ / കണ്ണ് — നാലും വേറെ.
  10. `തുരഗം` vs `ഉരഗം`: ഒരൊറ്റ അക്ഷരം — അർത്ഥം മാറുന്നു.

20. PSC Smart Tricks (Theory അറിയില്ലെങ്കിലും)

⭐ ആദ്യം ഓർക്കുക

ഈ തന്ത്രങ്ങൾ ശരിയുത്തരത്തിന്റെ സാധ്യത കൂട്ടാൻ സഹായിക്കുന്നു. ഒരു ട്രിക്കും ഉത്തരം ഉറപ്പിക്കില്ല. "ഏറ്റവും നീണ്ട ഉത്തരം ശരി", "എപ്പോഴും C" പോലുള്ള വിശ്വാസങ്ങൾ വെറും മിഥ്യയാണ്. അവ ഒരിക്കലും ഉപയോഗിക്കരുത്. വിഷയജ്ഞാനത്തിന് പകരമാവില്ല ഇത്.

ട്രിക്ക് 1: ഘടക കോഡ് വെച്ച് ഒഴിവാക്കൽ

ചോദ്യം: 'മേഘം' എന്നതിന്റെ പര്യായമല്ലാത്തത് ഏത്?
(A) ജീമൂതം (B) വാരിദം (C) പയോദം (D) വാരിജം

  1. നെഗറ്റീവ് ചോദ്യം. "മേഘപര്യായം അല്ലാത്തത്" ആണ് വേണ്ടത്.
  2. (B) വാരിദം, (C) പയോദം എന്നിവയുടെ അറ്റത്ത് -ദം → മേഘം. അതിനാൽ ഇവ പുറത്ത്.
  3. (D) വാരിജം → `-ജം` = താമര. ഇത് മേഘമല്ല.
  4. ഉത്തരം: (D) വാരിജം
⚠️ (A) ജീമൂതം ഘടക കോഡിൽ പെടുന്നില്ല (നേരിട്ട് പഠിക്കേണ്ടത്). ഒരൊറ്റ ഓപ്ഷനിൽ പോലും `-ജം/-ദം/-ധി` ഇല്ലെങ്കിൽ ഈ ട്രിക്ക് ഉപയോഗപ്പെടില്ല.

ട്രിക്ക് 2: ഘടക കോഡ് (നേരിട്ടുള്ള ചോദ്യം)

ചോദ്യം: 'സമുദ്രം' എന്നതിന്റെ പര്യായം?
(A) അംബുജം (B) അംബുദം (C) അംബുധി (D) അംബരം

  • `അംബു` എല്ലാ ഓപ്ഷനിലും ഉണ്ട്, അതുകൊണ്ട് അവസാന ഭാഗം നോക്കുക.
  • (A) ജം = താമര ✗. (B) ദം = മേഘം ✗. (C) ധി = സമുദ്രം ✓. (D) അംബരം = ആകാശം ✗.
  • ഉത്തരം: (C) അംബുധി

ട്രിക്ക് 3: നെഗറ്റീവ് ചോദ്യം + Odd-One-Out

ചോദ്യം: 'ആന' എന്നതിന്റെ പര്യായമല്ലാത്തത്?
(A) ദന്തി (B) ദ്വിപം (C) ഉരഗം (D) വാരണം

  • ആനയുടെ ഏറ്റവും സാധാരണ പര്യായങ്ങളായ കരി, ദന്തി അറിയാമെങ്കിൽ (A) പുറത്ത്.
  • ദ്വിപം എന്നതിലെ `ദ്വി` ഓർത്താൽ (രണ്ടുതവണ കുടിക്കുന്നത്) അത് ആനയായി ഓർമ്മ വരും. (B) പുറത്ത്.
  • ഉരഗം എന്നതിൽ `ഉര` = ഉരസ്സ് (നെഞ്ച്), നെഞ്ചു കൊണ്ട് ഇഴയുന്നത് → പാമ്പ്.
  • ഉത്തരം: (C) ഉരഗം

ട്രിക്ക് 4: ചേരുംപടി – അറിയുന്ന ജോഡി ആദ്യം

ചോദ്യം: പട്ടിക I: a. ശിഖി b. പികം c. ഷട്പദം d. മരാളം | പട്ടിക II: 1. വണ്ട് 2. അരയന്നം 3. കുയിൽ 4. മയിൽ

(A) a-4, b-3, c-1, d-2
(B) a-3, b-4, c-1, d-2
(C) a-4, b-1, c-3, d-2
(D) a-1, b-3, c-4, d-2

  1. ഏറ്റവും ഉറപ്പുള്ള ജോഡി: ഷട്പദം (ഷട് = 6 കാൽ) = വണ്ട് → c-1.
  2. c-1 ഇല്ലാത്ത ഓപ്ഷനുകൾ ഒഴിവാക്കുക: (C) c-3 ✗, (D) c-4 ✗.
  3. (A), (B) ബാക്കി. ഇവയിൽ b വ്യത്യാസമുണ്ട്. പികം = കുയിൽ → b-3 → (A).
  4. ഉത്തരം: (A)
⚠️ ഒരു ജോഡി തെറ്റായി ഓർത്താൽ എല്ലാം തെറ്റും. ഉറപ്പുള്ള ജോഡിയിൽ മാത്രം ആശ്രയിക്കുക.

ട്രിക്ക് 5: പ്രസ്താവനാ ചോദ്യം – ഓരോന്നും വേറെ പരിശോധിക്കുക

ചോദ്യം:
1. അനിലൻ = കാറ്റ്
2. ധരണി = ഭൂമി
3. തരുണി = സൂര്യൻ
4. ദ്വിരേഫം = വണ്ട്

(A) 1, 2, 3 മാത്രം (B) 1, 2, 4 മാത്രം (C) 2, 3, 4 മാത്രം (D) 1, 3, 4 മാത്രം

  • ഒരു പ്രസ്താവന മാത്രം തെറ്റാണെന്ന് ഉറപ്പിച്ചാൽ മതി. 3 തെറ്റ് (തരുണി = യുവതി; സൂര്യൻ = തരണി).
  • 3 ഉള്ള ഓപ്ഷനുകൾ (A), (C), (D) ഒഴിവാക്കുക.
  • ഉത്തരം: (B)
⚠️ "ശരിയായവ" / "തെറ്റായവ" ഏതാണ് ചോദിച്ചതെന്ന് ആദ്യം ഉറപ്പിക്കുക.

ട്രിക്ക് 6: Assertion–Reason

ചോദ്യം:
A: 'വാരിജം' സമുദ്രത്തിന്റെ പര്യായമാണ്.
R: `-ജം` എന്നതിന് 'ജനിച്ചത്' എന്നാണ് അർത്ഥം.

(A) A, R ശരി; R, A യുടെ വിശദീകരണം
(B) A, R ശരി; R വിശദീകരണമല്ല
(C) A ശരി, R തെറ്റ്
(D) A തെറ്റ്, R ശരി

  • R: `-ജം` = ജനിച്ചത്. ശരി.
  • A: വാരിജം = വെള്ളത്തിൽ ജനിച്ചത് = താമര. സമുദ്രം (`-ധി`) അല്ല. തെറ്റ്.
  • ഉത്തരം: (D)

ട്രിക്ക് 7: സംഖ്യാ സൂചന (Number Logic)

ചോദ്യം: 'ഷട്പദം' ഏതിന്റെ പര്യായം?
(A) പാമ്പ് (B) വണ്ട് (C) മത്സ്യം (D) പക്ഷി

  • ഷട് = ആറ്. പദം = കാൽ. ആറ് കാലുള്ള ജീവി: പ്രാണി → വണ്ട്.
  • പാമ്പിന് കാലില്ല, മത്സ്യത്തിന് കാലില്ല, പക്ഷിക്ക് രണ്ട് കാൽ.
  • ഉത്തരം: (B) വണ്ട്

ട്രിക്ക് 8: സമാന ഓപ്ഷനുകൾ താരതമ്യം

ചോദ്യം: 'ധരണി' എന്നതിന്റെ അർത്ഥം?
(A) സൂര്യൻ (B) യുവതി (C) ഭൂമി (D) തോണി

  • `തരണി / തരുണി / ധരണി` എന്ന ത്രയം ഓർക്കുക. ഉറപ്പുള്ള ഒരു പദം: ധര = ഭൂമി.
  • `ധര` + `ണി` → ധരണി = ഭൂമി.
  • ഉത്തരം: (C) ഭൂമി

ട്രിക്ക് 9: ചോദ്യത്തിലെ വാക്കുകൾ

ചോദ്യം: ശരിയല്ലാത്ത ജോഡി ഏത്?
(A) അനലൻ – അഗ്നി (B) അനിലൻ – കാറ്റ് (C) തടിനി – മിന്നൽ (D) തുരഗം – കുതിര

  • "ശരിയല്ലാത്ത" എന്ന വാക്ക് അടിവരയിടുക.
  • (A), (B), (D) ശരി. (C): തടിനി = നദി; മിന്നൽ = തടിത്ത്.
  • ഉത്തരം: (C)
⚠️ അല്ലാത്തത്, ശരിയല്ലാത്ത, ഒഴികെ, തെറ്റായ → നെഗറ്റീവ്. മാത്രം, എപ്പോഴും, ഒരിക്കലും → ശ്രദ്ധിച്ച് പരിശോധിക്കുക. ഇത്തരം വാക്കുകൾ സൂചന മാത്രമാണ്.

ട്രിക്ക് 10: ഘടന വെച്ചുള്ള യുക്തി

ചോദ്യം: 'ശിരോരുഹം' എന്ന പദം എന്തിനെ കുറിക്കുന്നു?
(A) തലമുടി (B) തൊപ്പി (C) തലച്ചോർ (D) കിരീടം

  • `ശിരസ്സ്` = തല. `-രുഹം` = മുളയ്ക്കുന്നത് (മഹീരുഹം = ഭൂമിയിൽ മുളയ്ക്കുന്നത് = വൃക്ഷം).
  • തലയിൽ മുളയ്ക്കുന്നത് → തലമുടി.
  • ഉത്തരം: (A) തലമുടി

ട്രിക്ക് 11: അതിരുകടന്ന പ്രസ്താവന (Extreme Statement)

ചോദ്യം: താഴെ ശരിയായത് ഏത്?
(A) ഒരു വാക്കിന് ഒരു അർത്ഥം മാത്രമേ ഉണ്ടാകൂ
(B) ഒരു വാക്കിന് പല അർത്ഥങ്ങൾ വരാം; ഇതിനെ നാനാർത്ഥം എന്ന് പറയുന്നു
(C) പര്യായപദങ്ങൾ എപ്പോഴും ഒരേ അക്ഷരത്തിൽ അവസാനിക്കും
(D) നാനാർത്ഥവും പര്യായവും ഒന്നാണ്

  • (A) "മാത്രമേ", (C) "എപ്പോഴും" എന്നിവ അതിരുകടന്ന വാക്കുകൾ. ശിഖി = മയിൽ/അഗ്നി എന്ന് കണ്ടിട്ടുണ്ടല്ലോ, അതുകൊണ്ട് (A) തെറ്റ്. കരി, ദന്തി, ഗജം ഒരേ അക്ഷരത്തിൽ അവസാനിക്കുന്നില്ല, അതുകൊണ്ട് (C) തെറ്റ്.
  • (D) രണ്ടും വേറെ ആശയങ്ങൾ (Sec 3 പട്ടിക).
  • ഉത്തരം: (B)
⚠️ അതിരുകടന്ന വാക്കുള്ള പ്രസ്താവന എപ്പോഴും തെറ്റല്ല. ("ഭൂമിക്ക് ഒരു ഉപഗ്രഹമേ ഉള്ളൂ" ശരി.) വിഷയജ്ഞാനത്തിൽ പരിശോധിക്കുക.

ട്രിക്ക് 12: നാനാർത്ഥ ചോദ്യത്തിൽ ഉറപ്പുള്ള പദം ആദ്യം

ചോദ്യം: 'ശിഖി' എന്ന പദത്തിന്റെ അർത്ഥങ്ങൾ?
(A) മയിൽ, അഗ്നി (B) മയിൽ, കാറ്റ് (C) കുയിൽ, അഗ്നി (D) വണ്ട്, അഗ്നി

  • ഉറപ്പുള്ള ഒരു അർത്ഥം: അഗ്നി (ശിഖ = ജ്വാല). (B) പുറത്ത്.
  • ശേഷിക്കുന്നത് (A), (C), (D). രണ്ടാമത്തെ അർത്ഥത്തിൽ: `ശിഖ` = പൂട / ശിഖണ്ഡം. പൂടയുള്ള പക്ഷി → മയിൽ (ശിഖണ്ഡി, ശിഖി).
  • ഉത്തരം: (A) മയിൽ, അഗ്നി

ട്രിക്ക് 13: ഘടന വെച്ചുള്ള യുക്തി (Informed Guessing)

ചോദ്യം: 'നിമ്നഗ' എന്നതിന്റെ പര്യായം?
(A) നദി (B) നിധി (C) പർവ്വതം (D) വൃക്ഷം

  • `നിമ്ന` = താഴ്ന്ന സ്ഥലം, `ഗ` = പോകുന്നത്. താഴേക്ക് ഒഴുകുന്നത് → നദി.

  • ഉത്തരം: (A) നദി

ശരിയുത്തരം: (D) അടവി

5. 'കാഞ്ചനം', 'ഹേമം', 'ചാമീകരം' എന്നിവ ഏതിന്റെ പര്യായങ്ങൾ?
ശരിയുത്തരം: (B) സ്വർണ്ണം
കനകം, കാഞ്ചനം, ഹേമം, ഹിരണ്യം, ചാമീകരം, തങ്കം, പൊന്ന് — എല്ലാം സ്വർണ്ണത്തിന്റെ പര്യായങ്ങൾ.
6. 'പത്മജൻ' എന്ന പദം ആരെ സൂചിപ്പിക്കുന്നു?

പത്മ (താമര) + ജൻ (ജനിച്ചവൻ) = താമരയിൽ ജനിച്ചവൻ = ബ്രഹ്മാവ്. 🧠 `-ജൻ` = ജനിച്ചവൻ.
7. 'മകൾ' എന്നതിന്റെ പര്യായമല്ലാത്തത്?
ശരിയുത്തരം: (D) തനയൻ
തനയൻ = മകൻ (പുല്ലിംഗം). തനയ, ആത്മജ, ദുഹിതാവ്, പുത്രി, സുത, നന്ദന — എല്ലാം മകൾ. 🧠 തനയൻ = മകൻ; തനയ = മകൾ.
8. 'സമുദ്രം' എന്നതിന്റെ പര്യായമല്ലാത്തത്?
ശരിയുത്തരം: (D) അചലം
അചലം = പർവ്വതം (ചലിക്കാത്തത്). സാഗരം, അർണ്ണവം, ആഴി, വാരിധി — എല്ലാം സമുദ്രം.
9. 'താമര' എന്നതിന്റെ പര്യായമല്ലാത്തത്?
ശരിയുത്തരം: (D) കുമുദം
കുമുദം = ആമ്പൽ (രാത്രി വിരിയുന്നത്). പത്മം, കമലം, നളിനം, അരവിന്ദം, രാജീവം — എല്ലാം താമര.
10. 'ഇരുട്ട്' എന്നതിന്റെ പര്യായം?
ശരിയുത്തരം: (A) തമസ്സ്
തമസ്സ്, തിമിരം, അന്ധകാരം, ധ്വാന്തം, തമിസ്രം — ഇരുട്ട്. ദ്യുതി, പ്രഭ, കാന്തി — വെളിച്ചം.
11. 'കളത്രം' എന്ന പദത്തിന്റെ അർത്ഥം?
ശരിയുത്തരം: (B) ഭാര്യ
കളത്രം = ഭാര്യ. കളഭം = ആനക്കുട്ടി; കളകണ്ഠം = കുയിൽ. 🧠 കളത്രം = ഭാര്യ; കളഭം = ആനക്കുട്ടി; കളകണ്ഠം = കുയിൽ.
12. 'തടിത്ത്' എന്നതിന്റെ അർത്ഥം?
ശരിയുത്തരം: (B) മിന്നൽ
തടിത്ത് / സൗദാമിനി / ചഞ്ചല = മിന്നൽ. തടിനി = നദി; തടാകം = കുളം. 🧠 ഒരൊറ്റ ശബ്ദ വ്യത്യാസം!
13. 'വാരിജം' എന്നതിന്റെ അർത്ഥം?
ശരിയുത്തരം: (C) താമര
വാരിജം (`-ജം`) = താമര. വാരിദം (`-ദം`) = മേഘം. വാരിധി (`-ധി`) = സമുദ്രം. 🧠 ജം-ദം-ധി!
14. 'തരുണി' എന്ന പദത്തിന്റെ അർത്ഥം?
ശരിയുത്തരം: (C) യുവതി
തരുണി = യുവതി / സ്ത്രീ. തരണി = സൂര്യൻ. ധരണി = ഭൂമി. 🧠 തരുണി = യുവതി!

22.5 5-Minute Revision

`-ജം / -ദം / -ധി` Master Key:

  • `-ജം` (അംബുജം, വാരിജം, പങ്കജം) = താമര
  • `-ദം` (അംബുദം, വാരിദം, നീരദം, ജീമൂതം) = മേഘം
  • `-ധി` (അംബുധി, വാരിധി, ജലധി, അർണ്ണവം) = സമുദ്രം

Confusing Pairs Flash Check:

  • `തരണി` = സൂര്യൻ | `തരുണി` = യുവതി | `ധരണി` = ഭൂമി
  • `അനിലൻ` = കാറ്റ് | `അനലൻ` = അഗ്നി
  • `തുരഗം / വാജി / ഹയം` = കുതിര | `ഉരഗം / പന്നഗം / ഭുജംഗം` = പാമ്പ്
  • `തടിനി / തരംഗിണി / ആപഗ` = നദി | `തടിത്ത് / സൗദാമിനി` = മിന്നൽ
  • `കരി / ദന്തി / മാതംഗം / ഇഭം` = ആന | `കേസരി / കണ്ഠീരവം / പഞ്ചാനനൻ` = സിംഹം
  • `വായസം / ബലിഭുക്ക്` = കാക്ക | `പരഭൃതം / പരഭൃത്ത് / പികം / കളകണ്ഠം` = കുയിൽ
  • `അളി / ഭൃംഗം / ഷട്പദം / ദ്വിരേഫം` = വണ്ട്
  • `ചികുരം / കുന്തളം / അളകം` = തലമുടി | `ശോണിതം / അസൃക്ക് / രുധിരം` = രക്തം | `കാഞ്ചനം / ഹേമം` = സ്വർണ്ണം

നാനാർത്ഥ ഫ്ലാഷ്: നാഗം (പാമ്പ്/ആന) · ശിഖി (മയിൽ/അഗ്നി) · ദ്വിജം (പക്ഷി/പല്ല്/ബ്രാഹ്മണൻ) · നീലകണ്ഠൻ (ശിവൻ/മയിൽ) · അർക്കം (സൂര്യൻ/എരിക്ക്) · പതംഗം (പക്ഷി/സൂര്യൻ/ശലഭം) · അബ്ദം (മേഘം/വർഷം).

ഘടക ഫ്ലാഷ്: `-ജം` ജനിച്ചത് · `-ദം` നൽകുന്നത് · `-ധി` സംഭരിക്കുന്നത് · `-ഗം` സഞ്ചരിക്കുന്നത് · `-രുഹം` മുളയ്ക്കുന്നത് · `-ധരം` ധരിക്കുന്നത്.

  24. അക്ഷര ശുദ്ധി: ഭാസ്സു്, കുന്നു് → ഭാസ്സ്, കുന്ന്; ദിജരാജൻ → ദ്വിജരാജൻ; സവിതാ → സവിതാവ്.
  25. ലേബലിംഗ്: "LDC / VFA / Degree Prelims PYQ" ലേബലുകൾ യഥാർത്ഥ PYQ ആണെന്ന് ഉറപ്പില്ലാത്തതിനാൽ "PSC ശൈലിയിലുള്ള മാതൃകാ ചോദ്യം" എന്നാക്കി. "1–2 ചോദ്യങ്ങൾ ഉറപ്പായും" → "പതിവായി വരാറുണ്ട്" എന്നാക്കി മൃദുവാക്കി.

22.7 ഉറപ്പിക്കാൻ ബാക്കി

ഈ തിരുത്തലുകൾ ഭാഷാ അറിവിനെ ആശ്രയിച്ചുള്ളതാണ്. ശബ്ദതാരാവലി / അമരകോശം തുടങ്ങിയ ഉറവിടങ്ങൾ ഉപയോഗിച്ച് ഓരോ വാക്കും പ്രത്യേകം ഒത്തുനോക്കിയിട്ടില്ല. ⚠️ അടയാളമുള്ള അപൂർവ്വ പദങ്ങൾ (നീരധി, തോയധി, പയോജം) പരീക്ഷയ്ക്ക് മുൻപ് ശബ്ദതാരാവലിയിൽ നോക്കി ഉറപ്പിക്കുക. കൂടാതെ keralapsc.gov.in ലെ യഥാർത്ഥ ചോദ്യപേപ്പറുകളിൽ നിന്ന് PYQ ചേർത്ത് Sec 16 പൂർത്തിയാക്കുക.
