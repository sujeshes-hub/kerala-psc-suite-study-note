പദ സമാനതകൾ (Word Analogy) – സമ്പൂർണ്ണ പഠനക്കുറിപ്പ്

Word Analogy · 12 Relationship Types · Science & GK Pairs · Kerala PSC Rank File

🔍 ഒന്നും കണ്ടെത്തിയില്ല. മറ്റൊരു വാക്ക് ശ്രമിക്കുക.

⭐ Star Guide

⭐ പ്രാധാന്യ സൂചകങ്ങൾ (Kerala PSC അടിസ്ഥാനത്തിൽ)
  • ⭐⭐⭐⭐⭐ അതിപ്രധാനം — അസംസ്കൃത വസ്തു (Candle:Wax :: Paper:Pulp), ഉപകരണം-ധർമ്മം (Sword:Slaughter :: Scalpel:Surgery), നിർമ്മാണ സ്ഥലം (Bread:Bakery :: Brick:Kiln), ജീവി-വാസസ്ഥലം (Dog:Kennel :: Horse:Stable)
  • ⭐⭐⭐⭐ പ്രധാനം — ശാസ്ത്ര ഉപകരണങ്ങൾ (Barometer:Pressure :: Hygrometer:Humidity), Ologies (Ornithology:Birds :: Entomology:Insects), ജീവകങ്ങൾ (Vitamin C:Scurvy :: Vitamin D:Rickets), അളവ്-യൂണിറ്റ്
  • ⭐⭐⭐ ശ്രദ്ധിക്കേണ്ടത് — ഭാഷാപരം (പര്യായം, വിപരീതം, ലിംഗം), GK (രാജ്യം-നാണയം, രാജ്യം-പാർലമെന്റ്, കായികം-ട്രോഫി), മലയാള സാഹിത്യ ജോഡികൾ
  • ⭐⭐ അറിഞ്ഞാൽ മതി — Phobias (Hydrophobia, Acrophobia), Collective Nouns (Pride, Flock), ജ്ഞാനപീഠം പട്ടിക
  • ⭐ ട്രിക്കുകൾ — പാലം വാക്യ രീതി (Bridge Sentence), ദിശാ പരിശോധന, പദവിഭാഗം തുല്യമാക്കൽ
➕ ചുരുക്കം
  • രൂപം: A : B :: C : ?
  • പാലം വാക്യം: A യും B യും തമ്മിലുള്ള ബന്ധം വാചകമാക്കുക → C യിൽ ചേർക്കുക
  • ദിശ ഒരുപോലെ: ആൾ:ഉപകരണം ആണെങ്കിൽ ഉത്തരവും ആൾ:ഉപകരണം
  • പദവിഭാഗം: നാമം:ക്രിയ ആണെങ്കിൽ ഉത്തരവും നാമം:ക്രിയ

1. അധ്യായ ആമുഖം (Chapter Introduction)

  • ⭐⭐⭐⭐⭐ Analogy = സാദൃശ്യം / സമാന ബന്ധം. ആദ്യ രണ്ടു വാക്കുകൾ തമ്മിലുള്ള ബന്ധം കണ്ടെത്തി, അതേ ബന്ധം മൂന്നാം വാക്കിനും നാലാം വാക്കിനും ഇടയിൽ ഉണ്ടാക്കുക. ഇതാണ് പദ സമാനത.
  • ⭐⭐⭐⭐⭐ രൂപം: A : B :: C : ? (വായന: "A യും B യും തമ്മിലുള്ള ബന്ധം തന്നെയാണ് C യും ? ഉം തമ്മിൽ")
  • ⭐⭐⭐⭐ ഒരു ചോദ്യത്തിൽ മാനസിക ശേഷി, പൊതുവിജ്ഞാനം, ശാസ്ത്രം, ഭാഷാജ്ഞാനം എന്നിവ ഒരുമിച്ച് പരിശോധിക്കപ്പെടുന്നു.
  • ⭐⭐⭐⭐ പരീക്ഷകൾ: LDC, LGS, VFA, Police Constable, ഡിഗ്രി ലെവൽ പ്രിലിംസ്/മെയിൻസ് തുടങ്ങിയ പരീക്ഷകളുടെ മാനസിക ശേഷി ഭാഗത്ത് ഈ വിഷയം ഉൾപ്പെടുന്നു. ഓരോ പരീക്ഷയുടെയും സിലബസ് വിജ്ഞാപനത്തിൽ ഇത് ഉറപ്പാക്കുക.
  • ⭐⭐⭐ ഓരോ പരീക്ഷയിലും ചോദ്യങ്ങളുടെ എണ്ണം വ്യത്യാസപ്പെടും. ഇവിടത്തെ പ്രാധാന്യ റേറ്റിംഗ് (★) ഈ നോട്ടിന്റെ വിലയിരുത്തലാണ്. ഔദ്യോഗിക കണക്കല്ല.

ഈ അധ്യായത്തിലെ ഉപവിഭാഗങ്ങൾ

  • A: ഉൽപ്പന്നം – അസംസ്കൃത വസ്തു – നിർമ്മാണ സ്ഥലം, ബന്ധങ്ങളുടെ 12 തരം
  • B: തൊഴിലാളി – ഉപകരണം – പ്രവൃത്തി – തൊഴിലിടം, വാഹനം – സൂക്ഷിക്കുന്ന സ്ഥലം
  • C: പഠനശാഖകൾ, അളവുപകരണങ്ങൾ, യൂണിറ്റുകൾ, ജീവകങ്ങൾ – രോഗങ്ങൾ
  • D: ജീവികൾ – കുഞ്ഞ്, വാസസ്ഥലം, ശബ്ദം, കൂട്ടം
  • E: GK സമാനതകൾ – തലസ്ഥാനം, നാണയം, പാർലമെന്റ്, കായികം, കല, സാഹിത്യം
  • F: ഭാഷാപരമായ സമാനതകൾ – പര്യായം, വിപരീതം, ലിംഗം, തീവ്രത

2. പിന്നാമ്പുറ കഥ – പാലം വാക്യ രീതി

മുത്തശ്ശി ചോദിച്ചു: "മീനിന് വെള്ളം എങ്ങനെയാണോ, അതുപോലെയാണ് പക്ഷിക്ക് ......?"

മീൻ ജീവിക്കുന്നത് വെള്ളത്തിൽ. പക്ഷി പറക്കുന്നത് ആകാശത്ത്. ഉത്തരം ആകാശം.

മൂന്ന് ഘട്ടങ്ങൾ

  1. ആദ്യ ജോഡിയിലെ ബന്ധം തിരിച്ചറിഞ്ഞു (മീൻ → ജീവിക്കുന്ന ഇടം).
  2. ആ ബന്ധത്തെ ഒരു ചെറിയ വാചകമാക്കി (മീൻ ജീവിക്കുന്നത് വെള്ളത്തിലാണ്).
  3. അതേ വാചകത്തിൽ മൂന്നാം വാക്ക് വെച്ചു (പക്ഷി ജീവിക്കുന്നത് ......ലാണ്).

🌉 പാലം വാക്യ രീതി (Bridge Sentence Technique)

📌 ഉദാഹരണം

മെഴുകുതിരി : മെഴുക് :: കടലാസ് : ?

  • പാലം വാക്യം: "മെഴുകുതിരി ഉണ്ടാക്കാനുള്ള അസംസ്കൃത വസ്തു മെഴുക്."
  • മൂന്നാം വാക്കിൽ: "കടലാസ് ഉണ്ടാക്കാനുള്ള അസംസ്കൃത വസ്തു ......" → പൾപ്പ് (Pulp)

പാലം വാക്യം കൃത്യമാക്കാൻ

  • വാചകം എത്ര ചെറുതും വ്യക്തവുമാണോ അത്രയും തെറ്റ് കുറയും.
  • "വാൾ → വധം" എന്നതിന് "വാൾ കൊണ്ട് വധിക്കുന്നു" എന്ന് പറയാം. പക്ഷേ "വാൾ ഒരു ആയുധമാണ്" എന്ന് പറഞ്ഞാൽ ബന്ധം തെറ്റും.
  • ഉത്തരം തിരയുമ്പോൾ ആ വാചകത്തിൽ നാലാം വാക്ക് ചേരുന്ന ഓപ്ഷൻ മാത്രം തിരഞ്ഞെടുക്കുക.

🧠 Trick: ആദ്യം ബന്ധം കണ്ടെത്തുക → വാചകം ഉണ്ടാക്കുക → മൂന്നാം വാക്കിൽ പ്രയോഗിക്കുക.

16. മെമ്മറി ട്രിക്കുകൾ (Mnemonics)

🧠 Trick 1 – പാലം വാക്യം

രണ്ടു വാക്കിനെ ഒരു വാചകമാക്കുക; മൂന്നാം വാക്ക് ആ വാചകത്തിൽ വെയ്ക്കുക.

  • Candle : Wax → "Candle made from Wax"
  • Paper : ? → "Paper made from Pulp"
🧠 Trick 2 – പദവിഭാഗം തുല്യമാക്കൽ

ആദ്യ ജോഡി (നാമം : ക്രിയ) ആണെങ്കിൽ ഉത്തരവും (നാമം : ക്രിയ).

  • Soap : Wash → Broom : Sweep ("Floor" നാമമാണ്, ക്രിയ അല്ല)
🧠 Trick 3 – ക്രമം പരിശോധന (രോഗകാരി : രോഗം)
  • Virus : Influenza
  • Bacteria : Typhoid
  • Protozoa : Malaria
  • Fungus : Ringworm
🧠 Trick 4 – ജീവകം ട്രിക്ക്

"A നിശ, B1 ബെറി, C സ്കർ, D കണ"

  • A = നിശാന്ധത
  • B1 = ബെറിബെറി
  • C = സ്കർവി
  • D = കണ/റിക്കറ്റ്സ്
🧠 Trick 5 – Ology ട്രിക്ക്
  • Orni = പക്ഷി (ഓർണി → "ഓടി" പറക്കുന്ന പക്ഷി)
  • Ento = പ്രാണി
  • Phyco = പായൽ
  • Myco = കൂൺ
  • Ichthyo = മത്സ്യം ("ഇച്ച്തി" = മീൻ)
  • Herpeto = ഇഴജന്തു
🧠 Trick 6 – ഹൈഗ്രോ/ഹൈഡ്രോ

"ഹൈ-ഗ്രോ" = ഈർപ്പം ഗ്രോചെയ്യുന്നു (വളരുന്നു) = Humidity.

"ഹൈ-ഡ്രോ" = ജലത്തിന്റെ (Hydro) സാന്ദ്രത = Relative density.

🧠 Trick 7 – സ്ഥലങ്ങൾ ഓർക്കാൻ
  • Kennel = പട്ടി
  • Stable = കുതിര
  • Sty = പന്നി
  • Den = സിംഹം
  • Hive / Apiary = തേനീച്ച
  • Aviary = പക്ഷി
  • Aquarium = മത്സ്യം
🧠 Trick 8 – മലയാളം അർത്ഥം മനസ്സിൽ പറയുക

ഇംഗ്ലീഷ് വാക്കിന്റെ മലയാളം അർത്ഥം മനസ്സിൽ പറഞ്ഞാൽ ബന്ധം 2 സെക്കൻഡിൽ വ്യക്തമാകും.

ഉദാ: "Scalpel = ശസ്ത്രക്രിയാ കത്തി → Surgery".

17. Common PSC Traps (ചതിക്കുഴികൾ)

⚠️ Trap 1 – ധർമ്മം vs വിഷയം

കണ്ണ് : കാഴ്ച :: ചെവി : ? → "ശബ്ദം" (ഉത്തേജനം) അല്ല; കേൾവി (Hearing) (ധർമ്മം).

⚠️ Trap 2 – അടിസ്ഥാന ഘടകം

വൃക്ക (നെഫ്രോൺ) : Nephrology; നാഡീകോശം (ന്യൂറോൺ) : Neurology.

⚠️ Trap 3 – ദിശ തിരിച്ചിടൽ

ഓപ്ഷനിൽ "ഉപകരണം : ആൾ" എന്ന് തലതിരിച്ച് കൊടുക്കും. ചോദ്യത്തിലെ ദിശ എപ്പോഴും പരിശോധിക്കുക.

ഉദാ: Doctor : Stethoscope :: ? — ഉത്തരം Carpenter : Saw (ആൾ : ഉപകരണം). "Saw : Carpenter" (ഉപകരണം : ആൾ) എന്ന ഓപ്ഷൻ തെറ്റ്.

⚠️ Trap 4 – ഒരേ വിഭാഗം, വ്യത്യസ്ത ബന്ധം

Lion : Den-ന് Bear : Cave എന്ന് തോന്നാം. പക്ഷേ ഉത്തര ജോഡിയിൽ ഉള്ളത് ഒരേ ബന്ധമാണോ (വാസസ്ഥലം) എന്ന് നോക്കുക.

⚠️ Trap 5 – വിഭാഗ ബന്ധം vs ധർമ്മ ബന്ധം

Dog : Animal (ഇനം : വിഭാഗം) ഉം Dog : Bark (ജീവി : ശബ്ദം) ഉം തമ്മിൽ മാറിപ്പോകരുത്.

⚠️ Trap 6 – പൊതു vs പ്രത്യേക

Broom : Sweep (പ്രത്യേക ഉപകരണം) — Broom : Clean (പൊതു ഫലം) അല്ല. ചോദ്യത്തിലെ ജോഡിയുടെ പ്രത്യേകത നോക്കുക.

⚠️ Trap 7 – ഉത്തേജനം vs അവയവം

Eye : Light (ഉത്തേജനം) vs Eye : Vision (ധർമ്മം) — രണ്ടും ശരിയാണ്, ചോദ്യത്തിൽ ഏതാണ് ചോദിച്ചതെന്ന് നോക്കുക.

⚠️ Trap 8 – രണ്ട് ഓപ്ഷനും ശരി തോന്നുന്നു

"അസംസ്കൃത വസ്തു" എന്നത് "നേരിട്ടുള്ള അസംസ്കൃത വസ്തു" ആണോ "വ്യുൽപ്പന്നം" ആണോ എന്ന് വേർതിരിക്കുക. Wax → Candle എന്നതിൽ Wax നേരിട്ടുള്ളത്; Wood → Paper എന്നതിൽ Wood ഇടനിലയാണ് (Pulp ആണ് നേരിട്ടുള്ളത്).

19. 🎯 Theory അറിയില്ലെങ്കിലും ഉത്തരം കണ്ടെത്താനുള്ള PSC Smart Tricks

⚠️ മുന്നറിയിപ്പ്

ഈ തന്ത്രങ്ങൾ സാധ്യത (Probability) കൂട്ടുകയേ ഉള്ളൂ; ഉത്തരം ഉറപ്പാക്കില്ല. അറിവിന് പകരമാവില്ല. "ഏറ്റവും നീളമുള്ള ഓപ്ഷൻ ശരി", "എപ്പോഴും C" തുടങ്ങിയ വിശ്വാസങ്ങൾ അടിസ്ഥാനമില്ലാത്തവയാണ്. ഒരിക്കലും അവ ഉപയോഗിക്കരുത്.

Trick 1: Option Elimination (ഓപ്ഷൻ ഒഴിവാക്കൽ)

MCQ: Frog : Tadpole :: Butterfly : ?

(A) Cub   (B) Caterpillar   (C) Calf   (D) Puppy

ഘട്ടങ്ങൾ:

  1. Tadpole = തവളയുടെ ലാർവ ഘട്ടം. അതായത് "കുഞ്ഞിന്റെ ആദ്യ രൂപം".
  2. Cub (സിംഹം/കടുവ), Calf (പശു/ആന), Puppy (പട്ടി) ഇവയെല്ലാം സസ്തനികളുടെ കുഞ്ഞുങ്ങൾ. ശലഭം സസ്തനിയല്ല → (A), (C), (D) ഒഴിവാക്കി.
  3. ബാക്കി (B).

ഉത്തരം: (B) Caterpillar.

മുന്നറിയിപ്പ്: നാല് ഓപ്ഷനും ഒരേ വിഭാഗത്തിൽപ്പെട്ടതാണെങ്കിൽ elimination പ്രവർത്തിക്കില്ല. അപ്പോൾ അറിവ് വേണം.

Trick 2: Keyword Tricks (കീവേഡ് ശ്രദ്ധ)

Only, always, never, all, none, first, largest, NOT, incorrect, except എന്നിവ ഒരു സൂചന മാത്രമാണ്, ഉത്തരം തെറ്റാണെന്ന് സ്വയം ഉറപ്പിക്കരുത്.

MCQ: ശരിയല്ലാത്ത (NOT correct) ജോഡി ഏത്?

(A) Ornithology : Birds   (B) Entomology : Insects   (C) Mycology : Algae   (D) Cytology : Cell

ഘട്ടങ്ങൾ:

  1. ചോദ്യം നെഗറ്റീവ് ആണ് ("ശരിയല്ലാത്തത്"). ശരിയായവയെ ഒഴിവാക്കണം.
  2. (A), (B), (D) ശരിയാണ് → ഒഴിവാക്കി.
  3. Mycology = ഫംഗസ്; Algae = Phycology. → (C) തെറ്റ്.

ഉത്തരം: (C).

പാഠം: നെഗറ്റീവ് ചോദ്യങ്ങളിൽ "ശരിയുത്തരം" തിരഞ്ഞെടുത്ത് മാർക്ക് കളയുന്നവർ ഏറെയാണ്. ചോദ്യം രണ്ടുതവണ വായിക്കുക.

Trick 3: Common-Sense Logic (കാരണം–ഫലം)

MCQ: Vitamin C deficiency : Scurvy :: Iodine deficiency : ?

(A) Goitre   (B) Rickets   (C) Night blindness   (D) Beriberi

ഘട്ടങ്ങൾ:

  1. ആദ്യ ജോഡി "അപര്യാപ്തത : രോഗം".
  2. Rickets (D), Night blindness (A), Beriberi (B1) = ജീവകങ്ങളുടെ കുറവിൽ ഉണ്ടാകുന്നവ. അയഡിൻ ധാതുവാണ് (ജീവകമല്ല).
  3. ധാതുവിന്റെ കുറവ് → Goitre.

ഉത്തരം: (A).

പാഠം: ഇവിടെ ഏതെങ്കിലും ഒരു രോഗം മാത്രം അറിയാമെങ്കിൽ (ഗോയിറ്റർ → തൈറോയ്ഡ് → അയഡിൻ) മതി.

Trick 4: Extreme Statement Check (അതിരുകടന്ന പ്രസ്താവന)

MCQ:

  1. എല്ലാ ജീവികളുടെയും കുഞ്ഞിനെ "Cub" എന്ന് വിളിക്കുന്നു.
  2. സിംഹത്തിന്റെ കുഞ്ഞ് "Cub" ആണ്.

(A) 1 മാത്രം ശരി   (B) 2 മാത്രം ശരി   (C) രണ്ടും ശരി   (D) രണ്ടും തെറ്റ്

ഘട്ടങ്ങൾ:

  1. "എല്ലാ" (All) എന്ന വാക്ക് → അപവാദങ്ങൾ തിരയുക: Calf, Puppy, Kitten, Tadpole ഇവയും കുഞ്ഞുങ്ങളാണ് → പ്രസ്താവന 1 തെറ്റ്.
  2. പ്രസ്താവന 2 ശരി.

ഉത്തരം: (B).

പാഠം: എല്ലാ "എല്ലാ/എപ്പോഴും/ഒരിക്കലും" ഉള്ള പ്രസ്താവനയും തെറ്റല്ല. "എല്ലാ സസ്തനികളും ശ്വസിക്കുന്നത് ശ്വാസകോശം കൊണ്ടാണ്" ശരിയാണ്. ഓരോന്നും വസ്തുതയുമായി ഒത്തുനോക്കുക.

Trick 5: Match the Following (അറിയാവുന്നത് ആദ്യം)

പട്ടിക Iപട്ടിക II
a. Hygrometer1. Pressure
b. Seismograph2. Humidity
c. Barometer3. Earthquake
d. Ammeter4. Current

(A) a-2, b-3, c-1, d-4   (B) a-1, b-3, c-2, d-4   (C) a-2, b-1, c-3, d-4   (D) a-3, b-2, c-1, d-4

ഘട്ടങ്ങൾ:

  1. ഏറ്റവും ഉറപ്പുള്ളത് ആദ്യം: b-3 (Seismograph–Earthquake) → (C), (D) പുറത്ത്.
  2. ഇനി (A), (B). a-2 (Hygrometer–Humidity) → (B)-യിൽ a-1 ആണ് → (B) പുറത്ത്.

ഉത്തരം: (A).

മുന്നറിയിപ്പ്: ഒരു ജോഡിയെങ്കിലും ഉറപ്പില്ലെങ്കിൽ ഒന്നിലധികം ഓപ്ഷൻ ബാക്കിയാകാം.

Trick 6: Statement-Based Questions (ഓരോന്നും വേർതിരിച്ച്)

MCQ:

  1. Arsenal – ആയുധം സൂക്ഷിക്കുന്ന സ്ഥലം
  2. Aviary – മത്സ്യങ്ങളെ വളർത്തുന്ന സ്ഥലം
  3. Granary – ധാന്യം സൂക്ഷിക്കുന്ന സ്ഥലം

(A) 1, 2 മാത്രം   (B) 1, 3 മാത്രം   (C) 2, 3 മാത്രം   (D) 1, 2, 3

ഘട്ടങ്ങൾ:

  1. 1 → ശരി. 2 → Aviary പക്ഷികൾക്ക്; മത്സ്യത്തിന് Aquarium → തെറ്റ്. 3 → ശരി.
  2. 2 തെറ്റായതിനാൽ (A), (C), (D) ഒഴിവാക്കി.

ഉത്തരം: (B).

പാഠം: ഒരു പ്രസ്താവനയെങ്കിലും ഉറപ്പായി തെറ്റാണെന്ന് കണ്ടാൽ, അത് ഉൾപ്പെടുന്ന ഓപ്ഷനുകൾ ഉടൻ വെട്ടാം.

Trick 7: Assertion–Reason

MCQ:

  • A: Seismograph : Earthquake :: Barometer : Pressure എന്നത് ശരിയായ സമാനതയാണ്.
  • R: Seismograph അളക്കുന്നത് അന്തരീക്ഷ മർദ്ദമാണ്.

(A) A, R ശരി; R, A യെ വിശദീകരിക്കുന്നു   (B) A, R ശരി; R വിശദീകരിക്കുന്നില്ല   (C) A ശരി, R തെറ്റ്   (D) A തെറ്റ്, R ശരി

ഘട്ടങ്ങൾ:

  1. A ശരിയാണ് (ഉപകരണം : അളക്കുന്ന കാര്യം).
  2. R: Seismograph ഭൂകമ്പ തരംഗങ്ങൾ രേഖപ്പെടുത്തുന്നു, മർദ്ദം അളക്കുന്നത് ബാരോമീറ്റർ. → R തെറ്റ്.

ഉത്തരം: (C).

പാഠം: ആദ്യം A ഉം R ഉം വേറെ വേറെ ശരിയോ തെറ്റോ എന്ന് നോക്കുക; അതിനുശേഷം മാത്രം "വിശദീകരിക്കുന്നുണ്ടോ" എന്ന് നോക്കുക.

Trick 8: Chronology & Sequence Logic (ക്രമം)

MCQ: Egg : Larva :: Pupa : ?

(A) Adult   (B) Egg   (C) Caterpillar   (D) Nymph

ഘട്ടങ്ങൾ:

  1. ശലഭ ജീവിതചക്രം: Egg → Larva → Pupa → Adult. ആദ്യ ജോഡി "ഒരു ഘട്ടം → അടുത്ത ഘട്ടം".
  2. Pupa-യുടെ അടുത്ത ഘട്ടം Adult.
  3. Caterpillar = Larva (മുൻ ഘട്ടം); Egg ആദ്യ ഘട്ടം; Nymph = അപൂർണ്ണ രൂപാന്തരത്തിലെ ഘട്ടം → ഒഴിവാക്കി.

ഉത്തരം: (A).

Trick 9: Similar-Option Comparison (സമാന ഓപ്ഷനുകൾ)

MCQ: Hygrometer : Humidity :: Hydrometer : ?

(A) Relative density of liquids   (B) Humidity   (C) Pressure   (D) Wind speed

ഘട്ടങ്ങൾ:

  1. പേരുകൾ അടുത്താണെങ്കിലും ഉപയോഗം വ്യത്യസ്തം: Hygro (ഈർപ്പം) vs Hydro (ജലം).
  2. (B) ഹൈഗ്രോമീറ്ററിന്റെ ഉപയോഗമാണ് (ചോദ്യത്തിൽ തന്നെ ഉണ്ട്); ഉത്തരമായി ആവർത്തിക്കില്ല → ഒഴിവാക്കി.
  3. Pressure → Barometer; Wind speed → Anemometer → ഒഴിവാക്കി.

ഉത്തരം: (A).

Trick 10: Question Wording (ചോദ്യം വായിക്കുക)

MCQ: ശരിയല്ലാത്ത (EXCEPT) ജോഡി ഏത്?

(A) Bread : Bakery   (B) Brick : Kiln   (C) Coin : Brewery   (D) Beer : Brewery

ഘട്ടങ്ങൾ:

  1. "ശരിയല്ലാത്തത്" എന്നത് അടിവരയിടുക.
  2. Coin → Mint; Brewery → Beer. → (C) തെറ്റ്.

ഉത്തരം: (C).

പാഠം: Units, "ഏറ്റവും", "ആദ്യം" പോലുള്ള വിശേഷണങ്ങളും ശ്രദ്ധിക്കുക.

Trick 11: ദിശാ പരിശോധന (Direction Check)

MCQ: Doctor : Stethoscope :: ?

(A) Carpenter : Saw   (B) Hammer : Carpenter   (C) Pen : Writer   (D) Needle : Tailor

ഘട്ടങ്ങൾ:

  1. ആദ്യ ജോഡി: ആൾ : ഉപകരണം.
  2. (B), (C), (D) = ഉപകരണം : ആൾ → തലതിരിഞ്ഞു.
  3. (A) = ആൾ : ഉപകരണം.

ഉത്തരം: (A).

Trick 12: PSC Pattern Awareness (ശൈലിയുടെ അറിവ്)

PSC സമാനതാ ചോദ്യങ്ങളിൽ ഈ ബന്ധങ്ങൾ വീണ്ടും വീണ്ടും കാണാം:

  • അസംസ്കൃത വസ്തു
  • ഉപകരണം–ധർമ്മം
  • ജീവി–കുഞ്ഞ്/വാസസ്ഥലം
  • ശാസ്ത്രജ്ഞൻ–ഉപകരണം
  • അളവ്–യൂണിറ്റ്

അതിനാൽ ഈ അധ്യായത്തിലെ പട്ടികകൾ കാണാപ്പാഠം പഠിക്കുക.

മുന്നറിയിപ്പ്: "കഴിഞ്ഞ പരീക്ഷയിൽ ഉത്തരം B ആയിരുന്നു, ഇത്തവണയും B" എന്ന ചിന്ത തെറ്റാണ്. ഉത്തരക്രമത്തിൽ ഒരു രീതിയുമില്ല.

Trick 13: Informed Guessing & Negative Marking

Word Analogy PSC-യിൽ ഏറ്റവും എളുപ്പത്തിൽ സ്കോർ ചെയ്യാവുന്ന ഭാഗങ്ങളിലൊന്നാണ് — കാരണം 12 ബന്ധ തരങ്ങൾ മാത്രം. ട്രാപ്പുകൾ പ്രധാനമാണ്: ദിശ (ആൾ:ഉപകരണം vs ഉപകരണം:ആൾ), പദവിഭാഗം (നാമം:ക്രിയ), ധർമ്മം vs ഉത്തേജനം, പൊതു vs പ്രത്യേക, വിഭാഗം vs ധർമ്മം — ഇവ ഓർമ്മിച്ചാൽ പരീക്ഷയിൽ ആശ്ചര്യപ്പെടുത്തുന്ന ഒന്നും ഉണ്ടാകില്ല.
