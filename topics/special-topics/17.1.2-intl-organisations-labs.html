1. അധ്യായ ആമുഖം

ആഗോളതലത്തിൽ ശാസ്ത്രം, സാങ്കേതികവിദ്യ, വ്യാപാരം, ഉപഭോക്തൃ സംരക്ഷണം, പരിസ്ഥിതി, ആരോഗ്യം എന്നിവയുടെ സ്റ്റാൻഡേർഡുകൾ നിർണ്ണയിക്കുന്ന അനവധി അന്താരാഷ്ട്ര സംഘടനകളുണ്ട്. ഇവയുടെയും ഇന്ത്യയിലെ ദേശീയ ലബോറട്ടറികളുടെയും കേരളത്തിലെ ഗവേഷണ സ്ഥാപനങ്ങളുടെയും വിവരങ്ങളാണ് ഈ അധ്യായത്തിൽ.

⭐ PSC ഫോക്കസ്

ഈ അധ്യായത്തിൽ നിന്ന് LDC, LGS, VFA, CPO, ഡിഗ്രി പ്രിലിംസ്/മെയിൻസ്, KAS പരീക്ഷകളിൽ സ്ഥാപനവും ആസ്ഥാനവും വർഷവും ചോദിക്കാൻ സാധ്യതയുള്ള ഉയർന്ന പ്രാധാന്യമുള്ള ഭാഗമാണ്. എന്നാൽ ഓരോ പരീക്ഷയുടെയും ചോദ്യപേപ്പർ പരിശോധിച്ച് മാത്രം ഉറപ്പിക്കുക.

പ്രധാന വിഭാഗങ്ങൾ

  1. സ്റ്റാൻഡേർഡ് സംഘടനകൾ: ISO, IEC, ITU, BIPM, OIML
  2. അക്രഡിറ്റേഷൻ ബോഡികൾ: NABL, NABH, IAF, ILAC, NBA, NAAC
  3. ഭക്ഷ്യ-മരുന്ന് ലാബുകൾ: FSSAI, CFL, NFL, CFTRI, CDL, CRI
  4. ശാസ്ത്ര ഗവേഷണം: CERN, LIGO, ITER, CSIR, DRDO, ISRO
  5. ഉപഭോക്തൃ-കായിക സംഘടനകൾ: Consumers International, WADA, NADA, NDTL
  6. ധ്രുവ ഗവേഷണം: അന്റാർട്ടിക്, ആർട്ടിക് സ്റ്റേഷനുകൾ
  7. കേരള സ്ഥാപനങ്ങൾ: NIIST, CMFRI, CIFT, CPCRI, IISR

2. പിന്നാമ്പുറ കഥ

നിങ്ങൾ ഒരു മൊബൈൽ ഫോൺ വാങ്ങുന്നു. അത് ഒരു രാജ്യത്ത് നിർമ്മിച്ചത് മറ്റൊരു രാജ്യത്ത് ഉപയോഗിക്കാം. എങ്ങനെ?

  • ചാർജർ പ്ലഗ് ഒരേ രീതിയിൽ ഇരിക്കുന്നു → IEC സ്റ്റാൻഡേർഡ്
  • റേഡിയോ ഫ്രീക്വൻസി മറ്റൊരു സിഗ്നലിനെ ബാധിക്കുന്നില്ല → ITU സ്പെക്ട്രം അനുവദിക്കുന്നു
  • ഗുണനിലവാരം ഉറപ്പാണ് → ISO 9001 സർട്ടിഫിക്കേഷൻ
  • കാലിബ്രേഷൻ ശരിയാണ് → NABL അക്രഡിറ്റേഷൻ
  • ഭക്ഷ്യ സുരക്ഷ ഉറപ്പ് → FSSAI ലൈസൻസ്
🧠 പാഠം

ഓരോ അന്താരാഷ്ട്ര സംഘടനയും ഓരോ പ്രത്യേക മേഖലയുടെ "പോലീസ്" പോലെ പ്രവർത്തിക്കുന്നു — സ്റ്റാൻഡേർഡ് ഉറപ്പാക്കുന്നു.

3. A – അന്താരാഷ്ട്ര സ്റ്റാൻഡേർഡ് സംഘടനകൾ

#സംഘടനസ്ഥാപിതംആസ്ഥാനംമേഖല
1ITU (International Telecommunication Union)1865 മെയ് 17 (International Telegraph Union എന്ന പേരിൽ, പാരീസിൽ)ജനീവ, സ്വിറ്റ്സർലൻഡ്ടെലികോം, റേഡിയോ സ്പെക്ട്രം, ഉപഗ്രഹ ഭ്രമണപഥങ്ങൾ. ഐക്യരാഷ്ട്രസഭയുടെ ഏറ്റവും പഴക്കമുള്ള പ്രത്യേക ഏജൻസി.
2IEC (International Electrotechnical Commission)1906 ജൂൺ 26ജനീവ (ആദ്യ ആസ്ഥാനം ലണ്ടൻ; 1948-ൽ ജനീവയിലേക്ക്)ഇലക്ട്രിക്കൽ, ഇലക്ട്രോണിക്സ്, ഗൃഹോപകരണങ്ങൾ, സെമികണ്ടക്ടറുകൾ, വൈദ്യുതോല്പാദനം എന്നിവയുടെ സ്റ്റാൻഡേർഡുകൾ
3ISO (International Organization for Standardization)1947 ഫെബ്രുവരി 23ജനീവ, സ്വിറ്റ്സർലൻഡ്എല്ലാ മേഖലകളിലെയും സ്റ്റാൻഡേർഡുകൾ. "isos" (ഗ്രീക്ക്: തുല്യം) എന്ന വാക്കിൽ നിന്ന്
4BIPM (Bureau International des Poids et Mesures)1875 മേയ് 20 (മീറ്റർ കൺവെൻഷൻ)സെവ്രെസ്, ഫ്രാൻസ്അന്താരാഷ്ട്ര അളവുതൂക്ക (SI യൂണിറ്റുകൾ) ഏകോപനം
5OIML (International Organization of Legal Metrology)1955പാരീസ്, ഫ്രാൻസ്നിയമപരമായ അളവുതൂക്ക (Legal Metrology)
6ILAC (International Laboratory Accreditation Cooperation)1977—ലബോറട്ടറി അക്രഡിറ്റേഷൻ കൂട്ടായ്മ
7IAF (International Accreditation Forum)1993—ISO 9001 പോലുള്ള മാനേജ്മെന്റ് സിസ്റ്റം സർട്ടിഫിക്കേഷന്റെ ആഗോള അക്രഡിറ്റേഷൻ കൂട്ടായ്മ. 2026-ൽ ILAC-IAF ലയന നീക്കം.

ISO സ്റ്റാൻഡേർഡ് നമ്പറുകൾ ⭐

ISO നമ്പർവിഷയംഓർമ്മിക്കാൻ
ISO 9001ഗുണനിലവാര മാനേജ്മെന്റ്9 = "ഒൻപതിൽ ക്വാളിറ്റി" (ഏറ്റവും പ്രശസ്തം)
ISO 14001പരിസ്ഥിതി മാനേജ്മെന്റ്14 = "പതിന്നാല് പ്രകൃതി"
ISO 22000ഭക്ഷ്യസുരക്ഷ22 = "ഇരുപത്തിരണ്ടിൽ ഊണ്"
ISO 27001വിവര സുരക്ഷ27 = "ഇരുപത്തേഴ് ഡാറ്റ ലോക്ക്"
ISO 45001തൊഴിൽ ആരോഗ്യ-സുരക്ഷ45 = "നാല്പത്തിയഞ്ചിൽ തൊഴിലാളി"
ISO/IEC 17025പരിശോധന-കാലിബ്രേഷൻ ലാബുകൾNABL ഇതിന് അക്രഡിറ്റേഷൻ നൽകുന്നു
ISO 15189മെഡിക്കൽ ലാബുകൾ15-18-9 = മെഡിക്കൽ
⭐ BIPM അധിക വസ്തുത

BIPM-ൽ ആണ് ഒരുകാലത്ത് അന്താരാഷ്ട്ര കിലോഗ്രാം പ്രോട്ടോടൈപ്പ് (IPK) സൂക്ഷിച്ചിരുന്നത്. 2019 മേയ് 20 മുതൽ SI യൂണിറ്റുകൾ ഭൗതിക സ്ഥിരാങ്കങ്ങളെ (ഉദാ: പ്ലാങ്ക് സ്ഥിരാങ്കം) അടിസ്ഥാനമാക്കി പുനർനിർവചിച്ചു.

4. B – അക്രഡിറ്റേഷൻ ബോഡികൾ

⭐ അക്രഡിറ്റേഷൻ എന്നാൽ എന്ത്?

ഒരു ലബോറട്ടറിയോ സ്ഥാപനമോ നിശ്ചിത സ്റ്റാൻഡേർഡ് പാലിക്കുന്നുവെന്ന് ഔദ്യോഗികമായി സാക്ഷ്യപ്പെടുത്തുന്ന പ്രക്രിയ. സർട്ടിഫിക്കേഷൻ = ഉല്പന്നത്തിന്; അക്രഡിറ്റേഷൻ = സ്ഥാപനത്തിന്.

ബോഡിപൂർണ്ണരൂപംഎന്തിന്ഓർമ്മ
NABLNational Accreditation Board for Testing and Calibration Laboratoriesലബോറട്ടറികൾക്ക് അക്രഡിറ്റേഷൻL = Laboratory
NABHNational Accreditation Board for Hospitalsആശുപത്രികൾക്ക് അക്രഡിറ്റേഷൻH = Hospital

  • ILAC (1977): ലബോറട്ടറി അക്രഡിറ്റേഷൻ കൂട്ടായ്മ

17. Common PSC Traps

  • Trap 1: "ITU ഏറ്റവും പഴക്കമുള്ള അന്താരാഷ്ട്ര സംഘടന" എന്ന് പറയരുത്; ഇത് ഐക്യരാഷ്ട്രസഭയുടെ ഏറ്റവും പഴക്കമുള്ള പ്രത്യേക ഏജൻസി മാത്രം.
  • Trap 2: "CSIR-ന്റെ ex-officio പ്രസിഡന്റ് രാഷ്ട്രപതി" → തെറ്റ്; പ്രധാനമന്ത്രി.
  • Trap 3: "CFTRI ഒരു CFL ആണ്" → തെറ്റ്; CSIR ഗവേഷണ സ്ഥാപനം.
  • Trap 4: "IndARC ഭൂഗർഭ ജലനിരീക്ഷണ കേന്ദ്രം" → തെറ്റ്; സമുദ്രത്തിനടിയിലെ observatory.
  • Trap 5: "WADA ആസ്ഥാനം ലൊസാൻ" → 1999-ൽ സ്ഥാപിതം ലൊസാനിൽ; എന്നാൽ 2002 മുതൽ ആസ്ഥാനം മോൺട്രിയൽ.
  • Trap 6: "ISO 9001 = Environmental" → തെറ്റ്; 9001 = Quality; 14001 = Environment.
  • Trap 7: "NIIST ആണ് കേരളത്തിലെ ഏക ദേശീയ ലാബ്" → തെറ്റ്; ഏക CSIR ലാബ് എന്ന് പറയണം.
  • Trap 8: "NIV-ന്റെ യൂണിറ്റ് മഞ്ചേരിയിൽ" → തെറ്റ്; ആലപ്പുഴയിൽ.

⚠️ മുന്നറിയിപ്പ്

ഈ ടെക്നിക്കുകൾ ശരിയുത്തരത്തിന്റെ സാധ്യത കൂട്ടുകയേ ചെയ്യൂ. പഠിച്ച അറിവിന് പകരമാവില്ല. "ഏറ്റവും നീളമുള്ള ഓപ്ഷൻ ശരി", "C ആണ് ഉത്തരം" തുടങ്ങിയ ശീലങ്ങൾ വെറും മിഥ്യകളാണ്, ഒരിക്കലും ആശ്രയിക്കരുത്.

ട്രിക്ക് 1: Option Elimination + പേരിലെ സൂചന

ചോദ്യം: ഇന്ത്യയിൽ പരിശോധനാ ലബോറട്ടറികൾക്ക് അക്രഡിറ്റേഷൻ നൽകുന്ന ബോർഡ് ഏത്?
(A) NABH (B) NABL (C) NBA (D) NAAC

  1. ചോദ്യത്തിൽ "ലബോറട്ടറി" എന്ന വാക്ക് ഉണ്ട്. അക്ഷര സൂചന L = Laboratory.
  2. NABH: അവസാന അക്ഷരം H, Hospital. ഒഴിവാക്കാം.
  3. NBA, NAAC: കോളേജ്/കോഴ്സ് അക്രഡിറ്റേഷൻ പേരുകളായി അറിയാമെങ്കിൽ ഒഴിവാക്കാം.
  4. ഉത്തരം: (B) NABL.

ട്രിക്ക് 2: Odd-One-Out (Negative ചോദ്യം)

ചോദ്യം: ജനീവ ആസ്ഥാനമായി പ്രവർത്തിക്കാത്ത സ്ഥാപനം ഏത്?
(A) ISO (B) IEC (C) ITU (D) BIPM

  1. "പ്രവർത്തിക്കാത്തത്" എന്ന Negative വാക്ക് ആദ്യം വട്ടം ഇടുക. അപ്പോൾ നമുക്ക് തെറ്റായ ഓപ്ഷൻ ആണ് വേണ്ടത്.
  2. ISO, IEC, ITU എന്നിവ ഒരേ ഗണമായ "സ്റ്റാൻഡേർഡ് സംഘടനകൾ" ആണ്, മൂന്നും ജനീവ.
  3. BIPM മാത്രം "അളവുതൂക്ക" ഗണം.
  4. ഉത്തരം: (D) BIPM (സെവ്രെസ്, ഫ്രാൻസ്).

ട്രിക്ക് 3: Match the Following – അറിയാവുന്നത് ആദ്യം

ചോദ്യം: a. CERN b. Codex Alimentarius c. Consumers International d. WADA
1. റോം 2. ലണ്ടൻ 3. ജനീവ 4. മോൺട്രിയൽ

(A) a-3, b-1, c-2, d-4 (B) a-1, b-3, c-2, d-4 (C) a-3, b-2, c-1, d-4 (D) a-4, b-1, c-2, d-3

  1. CERN = ജനീവ (a-3) എന്ന് ഉറപ്പ്. ഇതോടെ B, D ഒഴിവാകും.
  2. ബാക്കി A, C. രണ്ടിലും a-3, d-4 ഒരുപോലെ. വ്യത്യാസം b, c മാത്രം.
  3. Codex = ഭക്ഷ്യം, FAO ആസ്ഥാനം റോം. അതായത് b-1. C-യിൽ b-2 ആയതിനാൽ ഒഴിവാകും.
  4. ഉത്തരം: (A).

ട്രിക്ക് 4: പ്രസ്താവന ചോദ്യങ്ങൾ

ചോദ്യം:
1. CSIR-ന്റെ എക്സ്-ഒഫീഷ്യോ പ്രസിഡന്റ് ഇന്ത്യൻ രാഷ്ട്രപതിയാണ്.

3. NPL ന്യൂഡൽഹിയിലാണ്.

(A) 1, 2 (B) 2, 3 (C) 1, 3 (D) 1, 2, 3

  1. പ്രസ്താവന 1: തെറ്റ് (പ്രധാനമന്ത്രിയാണ്). ഇതോടെ 1 ഉള്ള A, C, D ഒഴിവാകും.
  2. ബാക്കി (B) 2, 3.
  3. ഉത്തരം: (B).

ട്രിക്ക് 5: Chronology / Number Logic

ചോദ്യം: പഴയതിൽ നിന്ന് പുതിയതിലേക്ക് ക്രമീകരിക്കുക: ISO, ITU, IEC, BIPM
(A) ITU, BIPM, IEC, ISO (B) BIPM, ITU, ISO, IEC (C) ITU, IEC, BIPM, ISO (D) IEC, ITU, BIPM, ISO

  1. ISO രണ്ടാം ലോകയുദ്ധാനന്തരം (1947) ആണ്. ഇത് ഏറ്റവും പുതിയതാണെന്ന് അറിയാമെങ്കിൽ അവസാനം വരുന്നത് ISO ആണ് (A, C, D).
  2. ITU "ടെലിഗ്രാഫ്" കാലഘട്ടം (1865) ആയതിനാൽ ഏറ്റവും പഴയത്. ഇതോടെ D ഒഴിവാകും.
  3. BIPM (1875), IEC (1906). 19-ാം നൂറ്റാണ്ട് → 20-ാം നൂറ്റാണ്ട്: BIPM ആദ്യം. C ഒഴിവാകും.
  4. ഉത്തരം: (A).

ട്രിക്ക് 6: Extreme Statement

ചോദ്യം: താഴെ പറയുന്നവയിൽ ശരിയായത് ഏത്?
(A) എല്ലാ CSIR ലബോറട്ടറികളും ഡൽഹിയിലാണ്.
(B) CSIR-ന്റെ ഏക ദേശീയ ലബോറട്ടറി കേരളത്തിൽ NIIST ആണ്.
(C) കേരളത്തിലെ ഏക CSIR ലബോറട്ടറി NIIST ആണ്.
(D) CFTRI ബെംഗളൂരുവിലാണ്.

  1. (A) "എല്ലാം" എന്ന അതിവ്യാപക പ്രസ്താവനയാണ്. CSIR-ന് രാജ്യമെമ്പാടും ലാബുകൾ ഉണ്ട് → തെറ്റ്.
  2. (B) പരിധി "കേരളത്തിൽ" എന്നതിൽ മാത്രമാണ് ശരിയാകുക.
  3. (D) CFTRI മൈസൂരുവിലാണ്.
  4. ഉത്തരം: (C).

ട്രിക്ക് 7: Assertion–Reason

A: ITER ഫ്രാൻസിൽ സ്ഥാപിക്കുന്നു. R: ഇത് അണുസംയോജനത്തിലൂടെ ഊർജ്ജം ഉണ്ടാക്കാനുള്ള പദ്ധതിയാണ്.

  1. A ശരിയാണോ? ശരി, കാഡറാഷ്, ഫ്രാൻസ്.
  2. R ശരിയാണോ? ശരി.
  3. R ആണോ A-യുടെ കാരണം? ഇല്ല. ഫ്രാൻസ് തിരഞ്ഞെടുത്തതിന്റെ കാരണം അണുസംയോജന ലക്ഷ്യമല്ല.
  4. ഉത്തരം: "A, R ശരി; R, A-യുടെ ശരിയായ വിശദീകരണമല്ല".

ട്രിക്ക് 8: സമാന ഓപ്ഷനുകൾ താരതമ്യം

ചോദ്യം: മരുന്നുകളുടെ ഗുണനിലവാരം പരിശോധിക്കുന്ന ദേശീയ സ്റ്റാറ്റ്യൂട്ടറി ലബോറട്ടറി ഏത്, എവിടെ?
(A) CDRI, ലഖ്നൗ (B) CDL, കൊൽക്കത്ത (C) CDRI, കൊൽക്കത്ത (D) CDL, ലഖ്നൗ

  1. "പരിശോധിക്കുന്ന" എന്നാൽ Laboratory, "ഗവേഷണം" അല്ല. അപ്പോൾ CDRI (Research) ഒഴിവാകും: A, C പോകും.
  2. CDL-ന് ബാക്കി രണ്ട് സ്ഥലം: കൊൽക്കത്ത/ലഖ്നൗ. "Research=ലഖ്നൗ" എന്ന് അറിയാമെങ്കിൽ ലഖ്നൗ ഒഴിവാക്കാം.
  3. ഉത്തരം: (B).

2. ഇന്ത്യ CERN-ൽ ഏത് വിഭാഗത്തിലെ അംഗമാണ്?

(A) പൂർണ്ണ അംഗം (B) അസോസിയേറ്റ് അംഗം (C) നിരീക്ഷക രാജ്യം (D) അംഗമല്ല

ഉത്തരം: (B). 2017 ജനുവരി മുതൽ.

3. "ബോസോൺ" എന്ന പേരിന് കാരണമായ ഇന്ത്യൻ ശാസ്ത്രജ്ഞൻ?

ഉത്തരം: (C).

4. ഇന്ത്യയുടെ ആദ്യ അന്റാർട്ടിക് ഗവേഷണ കേന്ദ്രം?

(A) മൈത്രി (B) ഭാരതി (C) ദക്ഷിണ ഗംഗോത്രി (D) ഹിമാദ്രി

(A) Quality (B) Environment (C) Food Safety (D) Information Security

ഉത്തരം: (B). 9001 = Quality; 22000 = Food; 27001 = Info Security.

ISO നമ്പറുകൾ തമ്മിലുള്ള മാറ്റം (9001 vs 14001 vs 22000), CDRI vs CDL, NABL vs NABH, ITU vs ISO vs IEC, അന്റാർട്ടിക് സ്റ്റേഷൻ ക്രമം — ഇവയാണ് PSC-യുടെ പ്രിയപ്പെട്ട കെണികൾ.
